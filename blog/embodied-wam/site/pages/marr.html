Marr 三层 × Kahneman 双过程：对比与可比性

两个「多描述」框架：切分轴不同、可比性有限；正确用法是正交组合

首页 概念：S0-S3 Marr × Kahneman GR00T 系列 WAM 总览 四概念精读

0. 一句话结论

两者都是「多描述」框架，但切分轴不同：Marr 切解释层级（垂直、不可通约），Kahneman 切加工模式（水平、可交互）。不能互译：S1/S2 都在 Marr 的 L2（表征与算法）层内；真正贴切的桥接是 S0（形态计算）≈ Marr 的 L3（物理实现）。

1. 两侧原文

1.1 Marr《Vision》(1982) 三层

"Computational theory — What is the goal of the computation, why is it appropriate, and what is the logic of the strategy by which it can be carried out?"
"Representation and algorithm — How can this computational theory be implemented? In particular, what is the representation for the input and output, and what is the algorithm for the transformation?"
"Hardware implementation — How can the representation and algorithm be realized physically?"
译文：计算理论——计算的目标是什么、为什么恰当、执行策略的逻辑是什么？／表征与算法——该计算理论如何实现？输入输出的表征是什么、变换的算法是什么？／硬件实现——表征与算法如何在物理上实现？
— Marr, Vision, 1982（经摘录页逐字复刻）

1.2 Kahneman (2011) 双系统

"System 1 operates automatically and quickly, with little or no effort and no sense of voluntary control. System 2 allocates attention to the effortful mental activities that demand it, including complex computations."
译文：System 1 自动而快速地运作，几乎不费力、也没有自主控制感；System 2 把注意力分配给需要它的费劲心理活动，包括复杂计算。
— Kahneman 2011，经 arXiv:2410.08328 §1 逐字转引

2. 对比表

维度Marr 三层Kahneman 双过程
切分对象同一任务的解释层级同一系统的加工模式
层间关系垂直、不可通约（实现不能解释算法，算法不能反推计算理论）水平、互补（S1 出直觉，S2 可审核/覆盖）
核心轴问题 → 表征+算法 → 物理实现速度 / 努力 / 控制感 / 意识

目的理解视觉计算并指导 AI理解判断与决策

相似点（为什么觉得接近）

  1. 都反对单一机制解释；
  2. 都有「分工与成本」思想（各层各司其职 / S1 廉价、S2 昂贵按需）；
  3. 都有自上而下的优先序（先定计算理论 / S2 可监督 S1）；
  4. 都可当分析纪律（防层级坍缩 / 防把直觉当推理）。

3. 可比性评估（为什么硬比会失真）

3.1 三条硬差异

  1. 目的不同：Marr 解释「如何解释一个信息处理任务」；Kahneman 描述「同一系统用哪些加工方式」。
  2. 对象不同：任务（可分层的计算）vs 系统（可分模式的决策体）——不是同一类对象。
  3. 结构不同：垂直不可通约 vs 水平互补——垂直结构映射到水平结构不成立。

3.2 可比的有效边界

  1. 共同哲学立场：反对单一机制解释；
  2. 共享「多描述」方法论；
  3. 都在 AI 设计中充当脚手架（先 Marr 定 L1，再双系统设计 L2 分工）；
  4. 「快慢」是资源分配视角，可叠加在 Marr 的 L2 上——是视角叠加，不是层级对应。

3.3 强行对应的四种错误

错误映射为什么错
S2 = L1 计算理论S2 是加工方式，不是任务理论；L1 不因快慢而变
L2 = S1 快系统L2 是表征+算法层，不预设快慢
L3 = S2L3 是物理实现，与快慢无必然关系；L3 真正的对应项是 S0
S1/S2 是 Marr 意义的新层级双系统都在 L2 内部工作，不构成新解释层级

4. 正确的组合用法（两坐标系正交）

坐标系 A（Marr）：L1 任务/约束 → L2 表征+算法 → L3 物理实现。
坐标系 B（双过程）：S1 快自动 ↔ S2 慢审慎（资源与监督关系）。

  • A 用于「定义问题」：先锁 L1（算什么、服务什么下游决策、天然约束）。
  • B 用于「设计分工」：L2 内决定哪些计算交给 S1（低成本、并行、近似），哪些交给 S2（精确、串行、可监督）；L3 决定异步/多卡/频率。
  • S0 补 L3；S3 超出 Marr 框架（社会尺度）。
不要问「S2 是 Marr 的哪一层」，要问「L1 锁定后，L2 内用双过程的哪种分工、L3 上如何落实」。
