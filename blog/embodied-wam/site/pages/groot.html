1. GR00T N1（L3，论文全文）

1.1 架构原文

"GR00T N1 is a Vision-Language-Action (VLA) model with a dual-system architecture. The vision-language module (System 2) interprets the environment through vision and language instructions. The subsequent diffusion transformer module (System 1) generates fluid motor actions in real time. Both modules are tightly coupled and jointly trained end-to-end."
译文：GR00T N1 是采用双系统架构的 VLA 模型。视觉语言模块（System 2）通过视觉与语言指令理解环境；随后的扩散 Transformer 模块（System 1）实时生成流畅动作。两个模块紧密耦合、端到端联合训练。
— 2503.14734 Abstract

1.2 关键实现数字

项数值（原文）
模型规模GR00T-N1-2B：共 2.2B 参数，VLM 1.34B（Eagle-2 = SmolLM2 + SigLIP-2）
图像 token224×224 + pixel shuffle → 64 image tokens/帧
VLM 层用第 12 层中间层 embedding（比最后一层更快且下游成功率更高）
动作块H=16；flow matching K=4 步；τ~Beta((s−τ)/s;1.5,1)，s=0.999
频率/时延S2 ≈10Hz（L40）；S1 ≈120Hz；16 步动作块 63.9ms（L40 bf16）
预训练算力1024×H100；约 5 万 H100 GPU 小时

1.3 数据金字塔（原文）

  • 底层：互联网视频 + 人类 egocentric 视频（OXE 的 RT-1/Bridge-v2/Language Table/DROID 等；AgiBot-Alpha 14 万轨迹）。
  • 中层：潜动作（VQ-VAE 学帧间潜动作，encoder 当 IDM；把无动作视频当作 "LAPA" embodiment）+ 神经轨迹（fine-tune 图生视频模型于 88h 遥操作，生成 827h，≈10× 扩增）。
  • 顶层：真机遥操作（Fourier GR-1，VIVE Tracker + Xsens 手套，20Hz）。
  • 仿真：DexMimicGen 生成 78 万条轨迹 ≈ 6,500 小时，仅 11 小时计算。

2. GR00T N1.5（L1，官方研究页）

2.1 三个改动（原文）

"The main differences from N1 are the following: The VLM model is frozen during both pretraining and finetuning. The adapter MLP connecting the vision encoder to the LLM is simplified and adds layer normalization to both visual and text token embeddings input to the LLM."
译文：与 N1 的主要差异：VLM 在预训练与微调期间均被冻结；连接视觉编码器与 LLM 的 adapter MLP 被简化，并在输入 LLM 的视觉/文本 token 嵌入上加入 LayerNorm。
— GR00T N1.5 官方页（2025-06-11）
  • VLM 换 Eagle 2.5（2.1B），强化 grounding（GR-1 IoU 40.4 / RefCOCOg 89.6，vs Qwen2.5VL-3B 的 35.5 / 85.2）。
  • 新增 FLARE：对齐目标未来嵌入（loss 系数 0.2）——不做生成式未来建模，但让模型能从人类视频学新物体。
  • 训练：250K 步、1K H100、全局 batch 16384。

3. GR00T 2（L1，官方研究页，2026-11）

3.1 范式升级：VLA → WAM

"We introduce GR00T 2, a new generation of foundation world-action models (WAMs). GR00T 2 predicts future video and robot actions together… One diffusion transformer denoises future video and robot actions together."
译文：GR00T 2 是新一代世界-动作模型（WAM）：同时预测未来视频与机器人动作。一个扩散 Transformer 联合去噪未来视频与机器人动作。
— GR00T 2 官方页
  • Turbo 版：2B 参数、更小 transformer + 更高压缩视频编码器；124ms/预测（G1 板载 Jetson Thor），经 SONIC 全身控制器 50Hz 执行；RTX 5090 上 38ms。
  • S2 的外延变了：推理 agent "runs as System 2 (S2)"，通过 WAM API 调用 GR00T 2——S2 从「模型内 VLM 模块」变成「模型外推理 agent」。

3.2 预训练数据（原文数值）

  • 402,730 小时人类 egocentric 工作视频（Human-1M；10 万小时开放为 Human-1M-100K）
  • 10,184 小时手持 UMI 夹爪示教（2,897 任务）
  • 23,500 小时机器人遥操作（YAM/Franka、Sharpa/Wuji 灵巧手、Unitree G1）

5. 精读要点与缺口

  1. N1：双系统 + 数据金字塔；潜动作/IDM 把无动作视频变训练数据；视频生成 10× 扩增真机数据。
  2. N1.5：冻结 VLM + 简化 adapter + FLARE；语言跟随 46.6→93.3%——双系统瓶颈在语言接地而非动作生成。
  3. GR00T 2：S1 从动作头升级为世界-动作模型；S2 外延为外部推理 agent；机上 124ms、5 示教 95%、真机 RL 88–96%。
  4. 可复用数字：63.9ms/16 步（N1，L40）；98.8%（N1.5，G1 1K demos）；124ms（GR00T 2 Turbo，Jetson Thor）。
缺口：N1.5 与 GR00T 2 的 whitepaper 正文未取（官方页为 L1 一手）；GR00T 1.7 仅在 GR00T 2 页被提及（仿真 OOD 40.0%），细节未取；N1 附录 D 超参表与附录 F 数据统计表未取。
