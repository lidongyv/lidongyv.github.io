0. TL;DR

  • WAM = 把「未来状态预测」与「动作生成」耦合在同一个具身基础模型里，建模目标是未来与动作的联合分布 p(o′, a | o, l)，而不是 VLA 的 p(a | o, l)。预测的未来必须进入动作路径（产生/打分/训练动作），否则不算 WAM。
  • 最权威入口 = 两篇 2026 综述（OpenMOSS 2605.12090 的 Cascaded/Joint 分类；NUS 2606.20781 的三大族 + 109 篇官方清单）。
  • 实现路线两条：视频生成骨干（Wan2.2/Cosmos-Predict DiT + 动作专家）与 JEPA/潜空间骨干（冻结 V-JEPA 2/DINOv3 特征 + 未来潜预测器）。
  • 2026 共识趋势：「Dream less, Act more」——训练时联合预测未来，推理时尽量少生成未来（Fast-WAM 4× 加速、Rift 一次前向写未来 K/V、THAW-VLA 蒸馏到 32ms/0.8B）。
  • 动作生成已收敛为 连续 action chunk + flow matching（第二波 10/10 篇全部如此）。
⚠️ 本合集内几乎所有榜单数字为提出方自评；仅 Cosmos Policy 有 ICLR 2026 同行评审版本。引用前请核对各表标注的来源级别与「评测坑」一章。

1. 定义与边界

范式建模对象一句话
VLAp(a | o, l)反应式「观测→动作」映射，不显式建模干预下的世界演化
世界模型 WMp(o′ | o, a)what-if 模拟器：动作进、未来出，但不输出动作
WAMp(o′, a | o, l)预测的未来必须进入动作路径（产生 / 打分 / 训练动作）

边界规则（NUS 综述原文）：预测的未来必须被用来 produce / score / train / check 动作。以下不算 WAM：带辅助 future loss 的 VLA；只在 RL 训练中用的模拟器；推理前就丢弃的未来头。

合法形态三选一：①先预测后动作（predict-then-act）②用预测后果给候选动作打分（score actions）③未来与动作联合生成（joint prediction）。

术语来源：Meta 于 2025-11 发布 WAM 智能体（V-JEPA 2 世界模型 + 潜空间 CoT 搜索，官方博客）；学术奠基视频-WAM 为 UniPi (2023)。

4. ① 输入表征：三条路线

路线一：离散 VQ token（全模态共享词表）

"The compression ratio of the image tokenizer is 16 and the codebook size is 8192. The image tokenizer generates 256 tokens for 256×256 images and 1024 tokens for 512×512 images."— WorldVLA §3.2（L2）

WorldVLA：图像 VQ-GAN token；文本 BPE；动作离散 7 tokens（3 相对位置+3 相对角度+1 夹爪，每维 256 bins）；总词表 65,536；Chameleon 初始化；序列 [BOS]{text}[BOI]{image}…[EOI]×M [BOA]{action}…[EOA]×K。

路线二：连续 VAE latent + 视频 DiT（2025–2026 主流）

  • Fast-WAM：多相机拼单图 → Wan2.2 video VAE latent；T5 文本 cross-attention 注入所有 token；训练三组 token（首帧 clean 锚点 / 未来帧 noisy / 动作），结构化掩码禁止动作分支看未来帧。
  • Motus：Wan 2.2 5B 生成专家 + Qwen3-VL-2B 理解专家（文本经其进入）+ 动作专家，Tri-model Joint Attention；视频帧率为动作 1/6。
  • NavWAM：Cosmos Predict2 因果 VAE 编码进「9 帧 latent canvas」。

路线三：冻结自监督/预测特征 token（2024 早期与 2026 回归阵营）

GR-1（MAE ViT + CLIP + 6D 位姿状态线性层）；V-JEPA Policy（冻结 V-JEPA 2.1 ViT-L tubelet token + T5 + 1 个 proprio token）；LaWAM（DINOv3 冻结特征）；PALM（CLIP+MAE+MLP）。

proprio 三档处理

  • 显式 token 注入：GR-1（线性层）、V-JEPA Policy（1 状态 token）、JEPA-WAM（1 token）、PALM（MLP）；
  • latent frame 化：NavWAM（broadcast 到 latent 网格）；
  • 仅训练辅助或原文未写：LaWAM（辅助头）、WorldVLA、UniPi。
代码对质案例（Fast-WAM proprio）：论文方法节只描述了「三组 token」、通篇未提 proprio——但官方代码实锤：self.proprio_encoder = nn.Linear(self.proprio_dim, self.text_dim)，proprio 投影为 1 个 token 追加到 T5 文本条件序列（torch.cat([context, proprio_token], dim=1)）经 cross-attention 喂两个专家。论文表述不全 ≠ 模型没有。

第二波观察到的迁移链（10 篇全 L3）

语言指令（GR-2/VPP）→ joint latent（UVA）→ 推理期生成未来观测（LingBot-VA，部分去噪 s=0.6）→ 未来 K/V cache 本身就是目标（Rift）→ CoT 压缩为 loop state z（Pelican-Unify）→ 事件级目标（WALL-WM）。

"One fixed final-clean K/V cache nearly preserves execution"— Rift §3.5：目标=未来的一次性表征，延迟从 rollout 法 780–2270ms 降至 248–420ms

已核实的利弊线索

  • JEPA-WAM：文本-动作标注稀疏重复诱发 shortcut（指令接地差）；goal image 可消歧但外观/布局与当前场景不符 → 需 JEPA 编码「去外观、保语义」。
  • Act2Goal：语言粒度不足、视觉 goal 无歧义且长程需中间视觉状态。
  • Fast-WAM：实证「推理时想象未来」非必需——训练期视频共训才是主要收益。
  • WAM-TTT / HOST：人类视频开始作为目标载体（fast-weight 记忆吸收；HOST 唯一做跨具身目标翻译）。
共同缺口（原文均未覆盖）：除 Rift 的 cache 干预外，无一篇做「语言目标 vs 未来视觉目标」的贡献剥离实验。

VAMPO 实操三步（代码级，可直接抄）

  1. 准备：专家视频经 SVD VAE 预编码 latent（step0_prepare_latent.py）+ SFT 视频预测模型（step1_train_svd.py）得 checkpoint。
  2. 采样：sde_start=0, sde_end=1 只首步 SDE；G=8 条 rollout 共享初始噪声（num_videos_per_prompt=8）；奖励在潜空间算（latent_reward_fn：负 MAE + cosine）。
  3. 更新：优势组归一化 (r − mean)/ (std + 1e-8)；loss = mean(minimum(−A·ratio, −A·clip(ratio, 0.8, 1.2)))；lr=1e-6、I=20 步、guidance 7.5、grad norm 0.5、10k 步、8 GPU。

共性模式（仅基于原文）

  1. 奖励全是「免执行」的代理信号：无一篇在训练内环执行真机动作（价值 TD / latent 距离 / LTL 逻辑验证 / IDM 平滑度 / 模拟器 rollout）。
  2. 被优化的是「视频/世界生成器」，不是下游动作策略：VAMPO 训 VPM、CreFlow 训 TI2V、EVA 训视频模型 LoRA、WorldVLN 训自回归 WAM。
  3. 优势/奖励几乎总被归一化或二值化：GigaBrain 二值化、GRPO 系组归一化、CreFlow 组共享掩码（组全成功掩码归零）。
  4. KL/参考锚定是标配：显式 KL（CreFlow/EVA）、理论起点即 KL-RL（GigaBrain）、log π_ref 奖励（WorldVLN）、结构级锚定（VAMPO 仅首步随机）。
  5. 一律以 SFT checkpoint 起步，语义上都是「post-training」。
诚实缺口：五篇 RL 论文中仅 VAMPO 有官方代码（已 L3 取证）；GigaBrain/CreFlow/EVA/WorldVLN 的 G/β/γ/λ 等超参与实验数值在正文或附录未取到（07 文件已逐项标注）。
