Ch 1 · 扩散模型基础

Diffusion / DDPM / DDIM / Flow Matching — 从零讲起

Cosmos 的扩散 WFM 建在这些基础上。本章从"加噪→学去噪→采样"的直觉，讲到 DDPM（奠基）· DDIM（加速）· Flow Matching（速度场/直线路径） 三条路线的原理、端到端训练/推理代码、公式↔代码对应表与三者对照。不熟扩散模型的话，这是全文档的地基。

1 · 一句话直觉

扩散模型干两件事：① 学会"把清晰图一点点加噪声直到变纯雪花"；② 训练网络学会"反过来一步步去噪还原"。生成新图时，从纯噪声出发反复去噪，最后'显影'出全新的图。
比喻：像老照片显影——从一片雪花点里逐渐浮现清晰画面。

2 · 🎮 去噪过程动图（示意）

忠实演示 x_σ = x_0 + σ·ε：σ 从大到小，噪声逐步被磨掉，"场景"从雪花里显影。点 ▶ 看采样过程。（示意用，非真实模型输出）
滑块 = 采样进度（step / 噪声等级 σ）。σ 越大越像纯噪声，σ→0 收敛到干净"场景"。

3 · 原理四步

① 前向（加噪）— 固定规则，无网络

清晰图 x₀ 不断撒高斯噪声，越撒越糊，最后成纯噪声。一步公式：

x_σ = x₀ + σ · ε，　ε ~ N(0, I)

σ（噪声强度）：小=只加一点(还看得清)；大=快看不清；极大=纯噪声。这步没有可学参数。

② 反向（去噪）— 训练一个网络学修复

给网络带噪图 x_σ 和噪声大小 σ，让它猜原本清晰的 x₀（网络记作 D_θ）。

③ 训练目标 — 就是"去噪回归"，超简单

自己造数据：取 x₀、随机 σ、加噪得 x_σ，惩罚网络猜的与真实 x₀ 的差（MSE）：

loss = ‖ D_θ(x_σ, σ) − x₀ ‖²

（也可让网络预测"噪声 ε"，与预测 x₀ 等价：x₀ = x_σ − σε。DDPM 预测 ε，Cosmos 预测 x₀。）

④ 采样（生成）— 从纯噪声一步步显影

从纯噪声(σ 最大)出发 → 网络预测干净版 → 只回退一小步(σ 调小) → 再预测再退…… 几十步后 σ→0，浮现出全新的清晰图。

为什么这么绕反而更好："从纯噪声直接生成清晰图"极难；扩散把它拆成几十个"只去掉一点点噪声"的简单小问题，每步都好学 → 比 GAN 更稳、质量更高。（正是 Cosmos 原文说的 "decompose a difficult problem into easier sub-problems"。）

4 · DDPM（2020）· 地基 标准公式

DDPM 把加噪去噪变成严格的概率框架。定义噪声调度 β_t，令 α_t=1−β_t、ᾱ_t=∏α_s。关键：可一步从 x₀ 跳到任意 t：

x_t = √ᾱ_t · x₀ + √(1−ᾱ_t) · ε　（ᾱ_t 从 1 单调降到 ≈0）

训练＝预测加进去的噪声（MSE）；采样＝逐步 t=T→1，每步带一点随机噪声（所以 DDPM 采样是随机的、需 ~1000 步、慢）。

DDPM 完整实现（端到端可运行：0 公共 → 1 网络 → 2 训练一步 → 3 训练循环 → 4 采样推理）

每行注释里标了对应公式【①②③】；训练与推理都给出了完整「怎么用」。

# ===== 0. 公共：噪声调度 + 前向加噪 =====
import torch, torch.nn as nn, torch.nn.functional as F
device = 'cuda'
T = 1000
betas = torch.linspace(1e-4, 0.02, T, device=device)   # β_t 噪声调度
alphas = 1.0 - betas                                    # α_t = 1-β_t
abar   = torch.cumprod(alphas, 0)                       # ᾱ_t = ∏α_s (累积)

def q_sample(x0, t, eps):                       # 【公式①】x_t = √ᾱ_t·x0 + √(1-ᾱ_t)·ε
    ab = abar[t].view(-1,1,1,1)                         # 取这些 t 的 ᾱ_t，广播到图像形状
    return ab.sqrt()*x0 + (1-ab).sqrt()*eps

# ===== 1. 去噪网络：输入(x_t, t) → 预测噪声 ε_θ（教学用最小 UNet；实际用更深 UNet/DiT）=====
class TimeEmb(nn.Module):                        # 把整数步 t 编码成向量，让网络“知道当前噪声档”
    def __init__(s, d): super().__init__(); s.d = d
    def forward(s, t):
        f = torch.exp(-torch.arange(s.d//2, device=t.device)*(9.21/(s.d//2)))
        a = t[:,None].float()*f[None]; return torch.cat([a.sin(), a.cos()], -1)
class UNet(nn.Module):
    def __init__(s, C=3, ch=64):
        super().__init__()
        s.temb = nn.Sequential(TimeEmb(ch), nn.Linear(ch, ch), nn.SiLU())
        s.d1=nn.Conv2d(C,ch,3,2,1); s.d2=nn.Conv2d(ch,ch,3,2,1); s.mid=nn.Conv2d(ch,ch,3,1,1)
        s.u2=nn.ConvTranspose2d(ch,ch,4,2,1); s.u1=nn.ConvTranspose2d(ch,ch,4,2,1); s.out=nn.Conv2d(ch,C,3,1,1)
    def forward(s, x, t):
        e = s.temb(t)[:,:,None,None]                 # 时间条件注入(加到特征图)
        h = F.silu(s.d1(x)+e); h = F.silu(s.d2(h)+e); h = F.silu(s.mid(h)+e)
        h = F.silu(s.u2(h)+e); h = F.silu(s.u1(h)+e)
        return s.out(h)                               # 输出预测噪声，形状同 x

# ===== 2. 训练一步（DDPM 与 DDIM 共用这套训练）=====
def train_step(model, x0):                     # x0: 一批真实图 [B,C,H,W]，已归一化到 [-1,1]
    t   = torch.randint(0, T, (x0.size(0),), device=device)  # 随机噪声档 t
    eps = torch.randn_like(x0)                          # 真噪声 ε ~ N(0,I)
    x_t = q_sample(x0, t, eps)                          # 【公式①】把 x0 加噪到第 t 步
    eps_pred = model(x_t, t)                            # 网络预测噪声 ε_θ(x_t,t)
    return F.mse_loss(eps_pred, eps)             # 【公式②】loss = ‖ε − ε_θ‖²

# ===== 3. 训练循环（怎么用）=====
model = UNet().to(device)
opt   = torch.optim.Adam(model.parameters(), lr=2e-4)
for epoch in range(100):
    for x0 in dataloader:                        # dataloader 每次给一批真实图 [B,C,H,W](归一化到[-1,1])
        x0 = x0.to(device)
        loss = train_step(model, x0)                    # 加噪→预测→MSE
        opt.zero_grad(); loss.backward(); opt.step()    # 标准反向传播更新参数

# ===== 4. 采样/推理（怎么用）：从纯噪声一步步去噪出新图 =====
@torch.no_grad()
def ddpm_sample(model, shape):               # 逐步 / 随机 / ~1000 步
    x = torch.randn(shape, device=device)              # 从纯噪声 x_T 起
    for t in reversed(range(T)):              # t: 999 → 0
        tt  = torch.full((shape[0],), t, device=device)
        eps = model(x, tt)                             # 预测该步噪声
        a, ab = alphas[t], abar[t]
        mean = (x - (1-a)/(1-ab).sqrt()*eps) / a.sqrt()  # 【公式③】反推均值 μ
        if t > 0:
            x = mean + betas[t].sqrt()*torch.randn_like(x)  # + σ_t·z 随机项(DDPM 随机性)
        else:
            x = mean                                   # 最后一步不加噪 → 输出 x_0
    return x

model.eval()
imgs = ddpm_sample(model, (16, 3, 32, 32))             # 生成 16 张 32×32
imgs = (imgs.clamp(-1,1) + 1) / 2                      # 反归一化 [-1,1]→[0,1]，可存图/使用
# torchvision.utils.save_image(imgs, "ddpm.webp")

5 · DDIM（2021）· 加速采样 标准公式

DDPM 太慢。DDIM 复用 DDPM 训练好的同一网络（不重训），构造一个非马尔可夫但边缘分布相同的过程，做到确定性 + 跳步：只用 20–50 步、可复现、可插值。

DDIM：复用上面训好的 model，只换采样（不重训）

训练完全沿用上面 DDPM 的 train_step/model；DDIM 只是换一种「怎么出图」。

# ===== DDIM 采样/推理：直接用上面 DDPM 训好的 model，不需要重新训练 =====
@torch.no_grad()
def ddim_sample(model, shape, steps=50, eta=0.0):   # eta=0 确定性; eta=1 退化回 DDPM
    seq = list(reversed(torch.linspace(0, T-1, steps).long().tolist()))  # 从1000步挑steps步(跳步加速)
    x = torch.randn(shape, device=device)              # x_T 纯噪声
    for i, t in enumerate(seq):
        tt   = torch.full((shape[0],), t, device=device)
        eps  = model(x, tt)                            # 同一个 ε_θ(x_t,t)
        ab_t = abar[t]
        x0   = (x - (1-ab_t).sqrt()*eps) / ab_t.sqrt() # 【公式④】反推干净图 x0
        tp   = seq[i+1] if i+1 < len(seq) else -1  # 下一个更干净的档(-1=到x0)
        ab_p = abar[tp] if tp>=0 else torch.tensor(1.0, device=device)
        sig  = eta*((1-ab_p)/(1-ab_t)).sqrt()*(1-ab_t/ab_p).sqrt()  # 【公式⑤】η 控随机性
        x    = ab_p.sqrt()*x0 + (1-ab_p-sig**2).clamp(min=0).sqrt()*eps  # 指向 x_{t-1}(η=0 无随机)
        if eta>0 and tp>=0: x = x + sig*torch.randn_like(x)  # η>0 才加随机项
    return x

# 用法：同一个训好的 model，20–50 步出图（比 DDPM 快几十倍）
model.eval()
imgs = ddim_sample(model, (16, 3, 32, 32), steps=50, eta=0.0)  # 确定性、快
imgs = (imgs.clamp(-1,1) + 1) / 2                     # 反归一化，可存图/使用

η=0 时无随机项 → 完全确定（等价解一条概率流 ODE）；能跳步所以快 20–50 倍。

5.5 · Flow Matching / Rectified Flow（2022+）标准公式

第三条主流路线（Stable Diffusion 3、Flux 用的就是它）。它不学"去噪"，而是学一个连续向量场（速度） v_θ(x,t)，把噪声沿 ODE 从 t=0 直线"流"到数据 t=1。路径更直 → 采样步数更少。

直觉：DDPM/DDIM 是"从噪声一点点擦干净"；Flow Matching 是"给空间每个点一个箭头(速度)，从噪声顺着箭头径直漂到真实图"。训练就是教网络在每个位置和时刻该指哪个方向。

核心公式（4 条）

直线插值　x_t = (1−t)·x₀ + t·x₁　（x₀~噪声, x₁~真实图, t∈[0,1]）
目标速度　u_t = dx_t/dt = x₁ − x₀　（这条直线上是常向量）
训练目标　L = ‖ v_θ(x_t, t) − (x₁ − x₀) ‖²　（网络回归速度）
采样(解ODE)　x ← x + v_θ(x, t)·dt，　t: 0 → 1

Flow Matching 完整实现（复用同款 UNet 骨架，但网络学"速度"，需单独训一个）

# Flow Matching (Rectified Flow / 条件OT)：网络学"速度场"而非噪声
model_fm = UNet().to(device)                        # 同款 UNet 骨架，但输出解释为速度 v(x,t)
opt = torch.optim.Adam(model_fm.parameters(), lr=2e-4)

def fm_train_step(model, x1):            # x1: 真实图 [B,C,H,W](归一化[-1,1])
    x0 = torch.randn_like(x1)                       # 噪声端 x0 ~ N(0,I)
    t  = torch.rand(x1.size(0), device=device)      # 连续时间 t ~ U(0,1)
    tb = t.view(-1,1,1,1)
    xt = (1-tb)*x0 + tb*x1                          # 【公式⑥】直线插值 x_t=(1-t)x0+t·x1
    target = x1 - x0                                # 【公式⑦】目标速度 u = x1-x0 (常向量)
    v = model(xt, t)                                # 预测速度 v_θ(x_t,t)  (t 为连续[0,1])
    return F.mse_loss(v, target)             # 【公式⑧】loss = ‖v_θ − (x1-x0)‖²

# 训练循环（用法同 DDPM）
for epoch in range(100):
    for x1 in dataloader:                    # 只需真实图 x1（x0 在内部现采）
        loss = fm_train_step(model_fm, x1.to(device))
        opt.zero_grad(); loss.backward(); opt.step()

# 采样/推理：从噪声解 ODE 到 t=1（Euler，几十步甚至更少）
@torch.no_grad()
def fm_sample(model, shape, steps=50):
    x  = torch.randn(shape, device=device)          # 从噪声端 x0 起
    dt = 1.0/steps
    for i in range(steps):
        t = torch.full((shape[0],), i*dt, device=device)  # t: 0 → 1
        v = model(x, t)                             # 预测速度
        x = x + v*dt                                # 【公式⑨】欧拉积分 x_{t+dt}=x_t+v·dt
    return x                                  # x ≈ x1 生成样本

model_fm.eval()
imgs = fm_sample(model_fm, (16, 3, 32, 32), steps=50)  # 少步出图(可更少)
imgs = (imgs.clamp(-1,1) + 1) / 2

和 diffusion 的关系：score-based diffusion 的"概率流 ODE"其实是 Flow Matching 的一个特例；DDIM(η=0) 的确定性采样本质也是解 ODE，与 FM 同源。区别在 rectified flow 用直线路径（diffusion 的路径是弯的）→ 更省采样步，常能 few-step 甚至趋近 1-step。

公式 ↔ 代码对应表

把上面代码里标的【①-⑨】和数学公式一一对上（①-⑤ DDPM/DDIM，⑥-⑨ Flow Matching）。
#数学公式代码实现在干嘛
① 前向加噪x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·εab.sqrt()*x0 + (1-ab).sqrt()*eps把干净图按噪声档 t 加噪；训练造样本用
② 训练损失L = ‖ε − ε_θ(x_t, t)‖²F.mse_loss(eps_pred, eps)让网络学会预测"加进去的噪声"
③ DDPM 采样均值μ = (x_t − (1−α_t)/√(1−ᾱ_t)·ε_θ)/√α_t(x-(1-a)/(1-ab).sqrt()*eps)/a.sqrt()反推上一步的均值；再 +σ_t·z 得 x_{t-1}
④ DDIM 反推 x₀x̂₀ = (x_t − √(1−ᾱ_t)·ε_θ)/√ᾱ_t(x-(1-ab_t).sqrt()*eps)/ab_t.sqrt()先估计干净图，再重新加噪到下一档
⑤ DDIM 噪声系数σ = η·√((1−ᾱ_{t-1})/(1−ᾱ_t))·√(1−ᾱ_t/ᾱ_{t-1})eta*((1-ab_p)/(1-ab_t)).sqrt()*(1-ab_t/ab_p).sqrt()η=0→σ=0 确定；η=1→回到 DDPM 随机
⑥ FM 直线插值x_t = (1−t)·x₀ + t·x₁(1-tb)*x0 + tb*x1噪声↔真实图之间的直线路径
⑦ FM 目标速度u_t = x₁ − x₀target = x1 - x0这条直线的方向（常向量）
⑧ FM 训练损失L = ‖v_θ(x_t,t) − (x₁−x₀)‖²F.mse_loss(v, target)教网络在每点该指的速度方向
⑨ FM 采样(ODE)x ← x + v_θ(x,t)·dtx = x + v*dt从噪声顺速度场积分到真实图

5.7 · 公式细讲：③ DDPM 均值 & ⑤ DDIM σ 从哪来 推导

对照表里 ③ 和 ⑤ 只给了结果，这里补"为什么长这样"。记号：a=α_t,ab=ᾱ_t,ab_p=ᾱ_{t-1},eps=ε_θ(x_t,t),1-a=β_t。

③ DDPM 反向均值 mean=(x-(1-a)/√(1-ab)·eps)/√a

三步推出来：

第1步 已知 x₀ 时，反向后验是高斯，其均值（贝叶斯）：
μ̃ = [√ᾱ_{t-1}·β_t/(1−ᾱ_t)]·x₀ + [√α_t·(1−ᾱ_{t-1})/(1−ᾱ_t)]·x_t
第2步 采样时不知道 x₀ → 用预测噪声把前向①反解出估计：
x̂₀ = (x_t − √(1−ᾱ_t)·ε_θ) / √ᾱ_t
第3步 把 x̂₀ 代回 μ̃，用 β_t=1−α_t、ᾱ_t=α_t·ᾱ_{t-1} 化简，x_t 项与 x₀ 项合并塌缩：
μ_θ = (1/√α_t)·( x_t − (1−α_t)/√(1−ᾱ_t)·ε_θ )  ←  就是代码
逐项直觉：/√α_t = 撤销前向这一步对信号乘的 √α_t；−(1−α_t)/√(1−ᾱ_t)·ε_θ = 从 x_t 里只剥掉属于这一小步的那份噪声。其中 1−α_t=β_t 是这步注入的噪声方差，√(1−ᾱ_t) 是累计到 t 的总噪声标准差，比值把网络估的"总噪声方向"缩放成"这一步该减的量"。

⑤ DDIM 的 σ sig=η·√((1-ab_p)/(1-ab_t))·√(1-ab_t/ab_p)

DDIM 用同一个 ε_θ（不重训），通用更新式把 x_{t-1} 拆成三块：

x_{t-1} = √ᾱ_{t-1}·x̂₀(放到t-1档的干净图) + √(1−ᾱ_{t-1}−σ²)·ε_θ(指向x_t的确定性方向) + σ·z(随机)

σ 控制每步注入多少新随机。关键化简：因 ᾱ_t/ᾱ_{t-1}=α_t，故末因子 √(1−ᾱ_t/ᾱ_{t-1})=√(1−α_t)=√β_t。两个极端：

ησ结果
η=0σ=0无随机项，轨迹完全确定（=解概率流 ODE）→ 可跳步(20–50步)、可复现、latent 可插值。DDIM 快的本质
η=1σ²=(1−ᾱ_{t-1})/(1−ᾱ_t)·β_t = β̃_t恰好是 DDPM 的后验方差 → DDIM 完全退化回 DDPM
"噪声预算"视角：t−1 档的总噪声量 1−ᾱ_{t-1} 被拆成"确定性方向项 √(1−ᾱ_{t-1}−σ²)"和"随机项 σ"两部分。σ 拿走多少，确定方向就少多少；σ=0 时预算全给确定方向，ε_θ 精确指回 x_t → 轨迹确定。η 就是"确定 ↔ 随机"的连续旋钮。

5.8 · 从纯噪声开始，怎么就成了"生成"？ 直觉

很多人卡在这："从噪声出发不是没意义吗？" 分两层讲透。

A · 为什么"从噪声开始"有意义

① 训练时对每张真实图在所有档位 t=1..T 加噪、让网络预测噪声（等价于学"去噪方向"/score ∇log p_t）→ 网络在每个噪声档都知道"哪边是数据"。
② 前向设计使 x_T≈N(0,I)（√ᾱ_T≈0）：任意真实图加满噪都变成标准高斯。所以采样时新抽一个 N(0,I)，和"被加满噪的真实图"无法区分，网络照样往回走。
③ 采样 = 从简单先验 N(0,I) 顺着学到的去噪场一步步走回数据流形，终点 x₀ 就是数据分布的一个新样本。
④ 多样性来自初始噪声种子（+η>0 每步 z）。不是"无意义噪声→固定输出"，而是每个噪声种子=一张彩票，模型把它解码成一张具体真实图——本质学到了 N(0,I) → p_data 的传输映射。
不同噪声种子 → 同一个去噪链 → 落到不同真实图（多样性来源）

B · 怎么把它变成"生成任务"（可控）

玩法怎么做例子
无条件生成随机种子 → 反向去噪 → 随机真实样本随便生成一张符合训练集的图
条件生成网络多吃条件 c：ε_θ(x_t,t,c)，用 (图, c) 对训练；采样固定 c文生图 c=文本embedding；类别生成 c=类别；世界模型 c=历史帧+动作
CFG 引导训练随机丢 c(用∅)；采样外推 ε̂=ε_θ(∅)+w·(ε_θ(c)−ε_θ(∅))w>1 加强"贴 prompt"，文生图清晰又切题的关键旋钮
图生图/编辑不从纯噪声，从"加了部分噪声的真实图"起(SDEdit)，只加到中间档 t₀ 再去噪保结构换风格、局部重绘(inpaint 每步用带噪原图替换已知区)
条件生成：把 c 喂进同一套去噪网络，固定 c 就把"随机生成"变成"按需生成"
连回世界模型：Cosmos 这类 WFM 就是"条件生成"的极致——把 c 换成过去帧 + 相机/动作，x₀ 换成未来帧。同一套"从噪声去噪"的机器，条件换成历史，就成了"预测未来"的世界模型。

6 · DDPM vs DDIM vs Flow Matching 三者对照

核心一句：DDPM 立框架(慢/随机)；DDIM 同网络换采样(快/确定)；Flow Matching 换建模对象(学速度场/直线路径, 更省步)。
维度DDPM (2020)DDIM (2021)Flow Matching / Rectified Flow (2022+)
建模对象逐步去噪(马尔可夫链)同 DDPM 网络，换确定性采样连续向量场/速度 v(x,t)
网络学什么预测噪声 ε_θ（同 DDPM，复用）预测速度 v_θ = x₁−x₀
路径加噪扩散(弯曲)（同 DDPM）直线 (1−t)x₀+t·x₁
训练目标‖ε−ε_θ‖²（同 DDPM）‖v_θ−(x₁−x₀)‖²
训练是否共用DDPM/DDIM 共用同一次训练需单独训(学速度)
采样过程逐步 + 每步注 z跳步 + 确定/可调 η解 ODE：x+=v·dt
随机性随机η=0 确定 / η=1→DDPM确定(ODE)
步数~1000（慢）20–50（快几十倍）少步，常 few-step 甚至趋近 1-step
关系score-based SDE概率流 ODE更一般的流框架；diffusion ODE 是其特例
代表/应用DDPMDDIM、Stable Diffusion 采样Rectified Flow、SD3、Flux

6.5 · 代码级对比（DDPM / DDIM / Flow Matching）

同一个 UNet 接口 model(x, t)，"就这几行不一样"。
关键步骤DDPMDDIMFlow Matching
① 造训练样本x_t=√ᾱ·x0+√(1-ᾱ)·ε（同 DDPM）x_t=(1-t)·x0+t·x1
② 网络预测eps=model(x_t,t)（同 DDPM）v=model(x_t,t)
③ 训练 lossmse(eps, ε)（复用 DDPM 权重）mse(v, x1-x0)
④ 采样每步x=μ+σ_t·z 随机x=√ᾱ_p·x̂0+√(1-ᾱ_p)·eps 确定x=x+v·dt 解ODE
⑤ 步数~100020–50少步 / 趋近 1-step
一眼结论：三者共用同一 UNet 接口；DDPM↔DDIM 连权重都共享（只换"④采样"那一行）；Flow Matching 换了"①样本构造/③训练目标/④采样"（学 x1-x0 而非 ε、直线插值、ODE 积分），所以要单独训一个 model_fm。

附 · NeRF & 3D Gaussian Splatting（另一类：3D 重建 / 新视角）

先划清定位（重要）：上面 DDPM/DDIM/FM 是生成模型（学数据分布 → 从噪声采样出新样本）；NeRF / 3DGS 是3D 重建 / 新视角合成——对一个已有场景用多视图图片拟合出 3D 表示，渲染它的新视角（不"造新场景"，是"记住场景并换角度看"）。它们是 world model 3D 一致性的基础工具：Cosmos §5.3 用多视图几何评估 3D 一致性；自驾里 DriveDreamer4D / ReconDreamer 用 3DGS/NeRF 做闭环 4D 重建（生成先验补重建）。

NeRF（2020）：隐式 MLP + 体渲染

F_θ(x, d) → (颜色 c, 体密度 σ)　；　体渲染 C(r) = ∫ T(t)·σ(t)·c(t) dt，　T = exp(−∫σ)
# NeRF: 一个 MLP 表示"整个场景" F(x)->(颜色c, 密度σ)；沿相机光线体渲染积分
class NeRF(nn.Module):
    def __init__(s, L=10, W=256):
        super().__init__(); s.L = L
        din = 3 + 3*2*L                                # 位置编码后的输入维度
        s.net = nn.Sequential(nn.Linear(din,W), nn.ReLU(), nn.Linear(W,W), nn.ReLU(), nn.Linear(W,4))
    def posenc(s, x):                          # Fourier 位置编码，让 MLP 拟合高频细节
        y = [x]
        for i in range(s.L):
            for fn in (torch.sin, torch.cos): y.append(fn(2.0**i * x))
        return torch.cat(y, -1)
    def forward(s, x):
        o = s.net(s.posenc(x)); return o[...,:3].sigmoid(), o[...,3].relu()  # 颜色c, 密度σ

def render_ray(nerf, ro, rd, tn=2., tf=6., N=64):  # 沿光线 ro+t·rd 采样 N 点做体渲染
    t   = torch.linspace(tn, tf, N, device=ro.device)
    pts = ro[...,None,:] + rd[...,None,:]*t[...,:,None]  # 采样点 [光线, N, 3]
    c, sigma = nerf(pts)
    delta = t[1:] - t[:-1]                              # 相邻采样间距
    alpha = 1 - torch.exp(-sigma[...,:-1]*delta)        # 每小段不透明度
    T = torch.cumprod(1 - alpha + 1e-10, -1)            # 透射率(累积“还能透过多少”)
    w = alpha * T                                       # 权重 = 不透明度 × 透射率
    return (w[...,None] * c[...,:-1,:]).sum(-2)     # 【体渲染】C(r)=Σ w·c

def nerf_train_step(nerf, ro, rd, rgb_gt):    # ro,rd:一批光线; rgb_gt:对应真实像素
    rgb = render_ray(nerf, ro, rd)
    return F.mse_loss(rgb, rgb_gt)              # ‖渲染像素 − 真实像素‖² (单场景多视图拟合)

3D Gaussian Splatting（2023）：显式高斯 + 光栅化

场景 = {高斯ᵢ: 位置 μᵢ, 协方差 Σᵢ, 不透明度 αᵢ, 颜色(球谐)}　；　投影(splat) + 按深度 α-blend
# 3D Gaussian Splatting: 一堆“显式3D高斯”表示场景；可微光栅化(投影+α混合)，实时
class Gaussians(nn.Module):
    def __init__(s, N):
        super().__init__()
        s.xyz     = nn.Parameter(torch.randn(N,3))     # 位置 μ
        s.scale   = nn.Parameter(torch.zeros(N,3))     # 各向异性尺度(log) → 协方差 Σ=R·S·Sᵀ·Rᵀ
        s.rot     = nn.Parameter(torch.zeros(N,4))     # 旋转四元数
        s.opacity = nn.Parameter(torch.zeros(N,1))     # 不透明度 α(logit)
        s.sh      = nn.Parameter(torch.zeros(N,3,16))  # 球谐系数(视角相关颜色)

def render(g, cam):                          # 可微光栅化(官方用 CUDA rasterizer)
    mean2d, cov2d = project(g.xyz, cov(g.scale, g.rot), cam)  # 3D高斯 → 投影成 2D 高斯(splat)
    color = eval_sh(g.sh, view_dir(cam))               # 由球谐算该视角的颜色
    order = depth_sort(g.xyz, cam)                      # 按深度排序(近→远)
    return alpha_blend(mean2d, cov2d, color, g.opacity.sigmoid(), order)  # α 混合成图

def gs_train_step(g, cam, gt, lam=0.2):
    img = render(g, cam)
    return (1-lam)*F.l1_loss(img, gt) + lam*dssim(img, gt)  # L1 + D-SSIM (单场景多视图)
    # 训练中周期性 densify(对高梯度高斯分裂/克隆) + prune(剪枝低α) —— 自适应致密化

NeRF vs 3DGS：隐式 MLP vs 显式高斯点；体渲染(每像素查 MLP 上百次,慢) vs 光栅化 splatting(实时)；但都是 per-scene(一个场景训一个) + 多视图 + 可微渲染 + 光度 loss。3DGS 现在是新视角/自驾闭环仿真的主流。

7 · 连回 Cosmos（下一步 Ch5）

Cosmos 用 EDM 框架：把离散步 t 换成连续噪声等级 σ、网络预测干净 x₀（非 ε，等价）、在 latent 上做（非像素）。
• 训练：x_σ=x0+σε → D_θ(x_σ,σ,c) 预测 x0，loss=λ(σ)‖·‖²（就是 train_step 的连续σ+预测x0版）。
• 采样：Cosmos 的 ODE sampler ≈ DDIM(η=0) 连续版；SDE sampler ≈ 带随机项（像 DDPM）。

一句话：DDPM 立框架(慢/随机)；DDIM 同网络换采样(快/确定=解ODE)；EDM(Cosmos 用) 是这条确定性ODE路线的成熟版。→ 进入 Ch5 WFM 预训练 看 Cosmos 的扩散/自回归 WFM 怎么在 latent 上建模。
