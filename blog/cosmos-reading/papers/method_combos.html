Diffusion / Flow Matching × NeRF / 3DGS × World Model：怎么相互结合

Ch1 讲了生成(DDPM/DDIM/FM)与 3D 重建(NeRF/3DGS)、Ch5/6 讲了 world model。它们大量互相结合。本页按"结合模式"分 6 类，逐工作详解（结合了什么·核心机制·例子），每类配一张结合机制示意图。

✅ 机制确证 ~ 合理/记忆边界 ⚠️ 2025+新作待核 生成 3D重建 世界模型
一句话本质：结合都围绕一个逻辑——生成模型(扩散/FM)"无中生有"的能力，补上 3D 重建(NeRF/3DGS)"看不到的地方"（稀疏视角、新轨迹、遮挡、伪影）；反过来 3D 重建给生成几何一致性约束。自驾里就是"世界模型造数据/新轨迹 + 3DGS 重建 → 闭环仿真"。

A · 扩散当"3D 生成器的先验"（SDS）→ text/image-to-3D

把 2D 扩散模型的梯度当监督，去优化一个 NeRF / 3DGS，无需 3D 数据。
2D 扩散模型冻结, 如 Imagen/SD
—SDS 梯度→
优化 NeRF/3DGS可微渲染的3D表示
—渲染360°→
3D 资产
DreamFusionGoogle · 2022✅
2D 扩散 × NeRF（开山）
提出 SDS（Score Distillation Sampling）：优化 NeRF 参数，使其渲染图在被加噪后、冻结扩散模型预测的噪声与真噪声一致。梯度 ≈ w(t)(ε_θ−ε)·∂render/∂θ，不需要任何 3D 训练数据。
例：输入"a DSLR photo of a squirrel"→ 优化出可 360° 环视的 3D 松鼠 NeRF。
Magic3DNVIDIA · 2022✅
SDS × NeRF→Mesh（提速提质）
两阶段：粗阶段用低分辨率 Instant-NGP + SDS 出粗形；细阶段抽成 mesh、用高分辨率 latent 扩散 SDS 精修。比 DreamFusion 快约 2×、分辨率更高。
例：文本 → 高清带纹理 3D mesh，可导入图形管线。
DreamGaussian2023✅
SDS × 3D Gaussian Splatting（提速）
把被 SDS 优化的表示从 NeRF 换成 3D 高斯——因 3DGS 渲染极快，text/image-to-3D 从几小时降到几分钟；再抽 mesh + 纹理精修。
例：一张商品图 → 2 分钟出可用 3D 高斯模型 + mesh。
ProlificDreamer2023✅
VSD 改进 SDS（提质）
SDS 易过饱和/过平滑；提出 VSD（变分 Score Distillation）：把 3D 当成一个分布(粒子)去匹配渲染分布的 score → 细节更丰富、更多样、更真实。
例：同一文本生成更锐利、细节更多的 3D。

B · 扩散当"新视角生成器 / 重建修补"

用扩散补稀疏视角、修重建伪影。
单/少视图+相机位姿
→
扩散模型视角条件
→
新视角 / 修补后
→
3D 重建更稳
Zero-1-to-32023✅
视角条件扩散 → 新视角
把 Stable Diffusion 微调成视角条件：输入"单张图 + 相对相机 (R,T)"→ 生成该视角的新图。于是单图也能做新视角合成 / 提升成 3D。
例：一张椅子正面图 + "右转 30°" → 生成椅子右侧视角。
MVDream2023✅
多视图扩散 → 修 SDS 的"多脸"
多视图扩散：用跨视图注意力一次生成多个一致视角（在 3D 渲染数据上训）；当作 SDS 先验，解决 text-to-3D 的 Janus/多脸问题。
例："a corgi"生成的 3D 不再出现前后都是脸。
ReconFusionGoogle · CVPR2024✅
扩散先验 × 少视图 NeRF
少视图 NeRF 会崩；在新视角处加一个（PixelNeRF 条件的）扩散先验当正则，约束未观测区域 → 3 张图也能重建。
例：只给 3 张照片，重建出可自由漫游的场景。
Difix3D+NVIDIA · CVPR2025~
单步扩散 × 3DGS/NeRF 修伪影
单步扩散模型专门"修"3D 重建在新视角下的伪影/空洞，放进循环里逐步清理，并可蒸馏回 3D 表示 → 新视角更干净。
例：3DGS 大角度新视角的鬼影/毛刺被单步扩散抹掉。

C · 前馈"多视图扩散 → 直接出 3D 高斯"（大重建模型）

把"生成 + 重建"缝成前馈一步，秒级出 3D。
文本/单图
→
多视图扩散一致多视角
→
前馈网络UNet/Transformer
→
3D 高斯秒级
LGM2024~
多视图扩散 → U-Net → 3D 高斯
Large Gaussian Model：多视图扩散出一致视角 → U-Net 前馈预测高分辨率 3D 高斯，不再 per-scene 优化，秒级。
例：一张图 → 5 秒出 3D 高斯模型。
GRM2024~
Transformer → 像素对齐高斯
用 Transformer 从稀疏视角前馈出像素对齐的 3D 高斯，高质高效。
例：4 视角 → 前馈重建 3D。
LatentSplat2024~
latent 空间预测高斯
在 latent 空间预测高斯分布再解码，结合生成先验与前馈重建。
例：两视角外推可泛化的 3D。

D · 世界模型 × 4D 重建（🚗 和自驾主线最相关）

世界模型造"新轨迹"数据，3DGS 重建做闭环仿真。
驾驶世界模型视频扩散
—合成新轨迹视频→
4D GS/NeRF 重建+生成先验监督
→
闭环仿真渲染真实log没有的轨迹
DriveDreamer4DGigaAI · 2024~
世界模型 × 4D 3DGS
用驾驶世界模型合成"新 ego 轨迹"的视频当额外监督 → 训 4D 高斯；于是闭环仿真能渲染真实 log 没走过的轨迹（变道/绕行）。
例：原 log 直行，生成"向左变道"轨迹的多视图视频用于重建+仿真。
ReconDreamerGigaAI · 2024~
世界模型 在线恢复 × 重建
重建渲染"大幅偏离原轨迹"时会退化；世界模型做 online restoration 迭代修复退化渲染 → 支持大机动视角。
例：大角度绕行视角下，模糊/破碎画面被世界模型逐步恢复。
StreetGaussians / DrivingGaussian / OmniRe2024~
动态街景 3DGS 重建
用 3DGS 重建动态城市场景：静态背景 + 动态车辆分别建模（每物体一组高斯）；常与生成结合造仿真/训练数据。
例：把一段行车 log 重建成可编辑、可换视角的 3D 街景。

E · 一个系统内"扩散 × 自回归"结合 → 就是 Cosmos

你正在读的 Cosmos 本身就是两种生成范式的结合。

—快但糊→

→

Cosmos diffusion decoderNVIDIA · 2025✅
扩散 × 自回归（同系统互补）
AR WFM 出离散 token（压得狠→糊）；把一个 Text2Video 扩散模型微调成 decoder，条件于离散 token 生成清晰视频（§5.2.5）。生成质量 = 自回归 + 扩散精修。
例：AR 生成的模糊驾驶片段经扩散 decoder 变清晰锐利。

F · Flow Matching 替换扩散做生成骨架

把生成骨架从扩散换成 rectified flow(FM)，更省采样步。
噪声 x₀
—v(x,t) ODE (少步)→
图像/视频 x₁
Stable Diffusion 3Stability · 2024✅
FM(rectified flow) × MMDiT
用 rectified flow(FM) 训练目标 + 多模态 DiT(MMDiT) 做文生图；相比扩散采样更少步、质量强。
例：文生图，few-step 出高质图。
FluxBlack Forest Labs · 2024✅
大规模 FM Transformer
大规模 rectified flow transformer 文生图，FM 骨架的代表作之一。
例：高保真文生图；FM 路线的工业级落地。
怎么串起来记：①-④(A/B/C) 是"2D 生成先验 → 造/补 3D"（DreamFusion→DreamGaussian→LGM 一路把 text-to-3D 做快做好）；D 是"世界模型 → 4D 重建 → 自驾闭环"（DriveDreamer4D/ReconDreamer）；E 是"同系统里扩散补自回归"(Cosmos)；F 是"换更省步的生成骨架"(FM/SD3/Flux)。趋势：生成与重建深度融合——生成补重建看不到的，重建给生成几何约束。
