Cosmos · CausalConv3d

因果卷积怎么实现 · 交互动图

基于开源 NVIDIA/Cosmos-Tokenizer 的 layers3d.py CausalConv3d 真实实现。核心：时间维只在"过去"侧 pad（首帧复制 k−1 次），空间维对称 pad → 每个输出只看当前+过去、绝不看未来。点 ▶ 播放看卷积核怎么滑。

真实源码（layers3d.py CausalConv3d）

class CausalConv3d(nn.Module):
    def __init__(self, chan_in, chan_out, kernel_size=3, **kw):
        t_k, h_k, w_k = kernel_size            # 时间/高/宽 核大小
        self.time_kernel_size = t_k
        stride = kw.pop("stride", 1)
        # 空间维对称 pad；时间维这里为 0，留给 forward 做因果 pad
        self.pad = (w_k//2, w_k//2, h_k//2, h_k//2, 0, 0)
        self.conv3d = nn.Conv3d(chan_in, chan_out, kernel_size,
                                stride=(stride,1,1), dilation=(dilation,1,1))

    def forward(self, x):                     # x: [B,C,T,H,W]
        # (1) 时间维因果 pad：把“第一帧”复制 (t_k-1) 次，接在最前面
        first_frame_pad = x[:, :, :1].repeat(1, 1, self.time_kernel_size-1, 1, 1)
        x = torch.cat([first_frame_pad, x], dim=2)   # 只在“过去”侧加，不补零
        # (2) 空间维对称 pad
        x = F.pad(x, self.pad)
        return self.conv3d(x)                  # 时间长度 = 输入(左侧已 pad k-1)

关键点（为什么这样就"因果"了）

  • ① 只在过去侧 pad：时间维把首帧复制 k−1 次接在最前（普通卷积是两侧对称 pad）。核滑到 t 时感受野 = [t-(k-1) … t]，全是当前+过去。
  • ② 输出等长：左侧多 pad k−1 个 → 卷积后时间长度 = 原输入（不缩短、不错位）。
  • ③ 用"复制首帧"而非补零：避免序列开头出现人为 0 值边界失真（第一帧没有过去，用它自己顶上）。
  • ④ 空间维照常对称 pad：H/W 无"未来"概念，用 w_k//2, h_k//2 正常两侧 pad。
  • ⑤ 为什么自驾/机器人要因果：在线部署时 t 时刻只有过去+当前帧，模型不能依赖未来；因果卷积保证训练与推理一致（原文："each token is a function of the current and past inputs but not the future ones"）。
说明：动图为教学示意（时间维、kernel=3、stride=1、8 帧），忠实反映 CausalConv3d 的因果 padding 机制；真实模型是 3D 且 factorized（空间(1,3,3) 与时间(3,1,1) 分开卷）。源码：NVIDIA/Cosmos-Tokenizer（Apache-2.0）。
