3. 关键公式

token: t = FSQ(E(o)) ∈ R^{2×32}; flat 64 维
FSQ: q_i = round((z_i + 1)/2 · (L−1)) / (L−1) · 2 − 1, L = 32
PPO: L = E[min(ρ A, clip(ρ,1−ε,1+ε) A)] − c_e·H + c_v·(V−R)², ε=0.2
总损失 = PPO + 0.01·L_recon + 1.0·(L_latent-g1/smpl + L_latent-g1/teleop + L_latent-teleop/smpl) + L_skating

物理意义：FSQ 把连续运动意图压成离散码本，跨编码器共享同一 token 空间；latent 对齐让「机器人/人体/遥操作」三种输入落在同一坐标；skating 惩罚脚接触时的预测滑移。

5. 训练配方

  • 4096 envs；PPO：γ=0.99、λ=0.95、clip=0.2、entropy=0.01、actor LR=2e-5、critic=1e-3、自适应 KL=0.01、max_grad_norm=0.1、24 步/轮、10 万迭代、σ∈[0.001,0.5]。
  • 参考：G1 10 帧@0.1s；SMPL 10 帧@0.02s；三编码器采样 1:1:1；观测噪声 ±0.05；上体增强概率 0.5。
  • 数据：700h 动捕、170 人（145–199cm）、50Hz、1 亿+帧；GMR 重定向；BONES-SEED 142K/288h。

6. 核心代码（带物理意义注释）

# —— 训练一步 ——
obs = build_obs(history=10)                    # 10 帧本体历史：给策略速度/加速度线索
enc = choice(["g1","teleop","smpl"], p=[1/3]*3) # 每环境随机选一种输入，逼共享 token 空间
tok = FSQ(Encoder[enc](obs.tokenizer))         # [B,2,32]；离散化让三种输入可互换
a   = Decoder_dyn(tok.flatten(1), obs.prop)    # [B,29] 目标关节角
adv = GAE(rew, val, γ=.99, λ=.95)              # 优势：平衡偏差/方差
L = ppo_clip(a, adv, clip=.2, ent=.01) \
  + 0.01*recon(Decoder_kin(tok), future10)     # 重建未来：让 token 保留可解码的运动信息
  + 1.0*align(tok_g1, tok_smpl) + 1.0*align(tok_g1, tok_teleop) \
  + skating_loss(feet_pos, contact_mask, dt)   # 脚接触时速度应≈0，防滑步

# —— 部署 50Hz ——
q_des = trt_decoder(trt_encoder(obs), obs.prop)  # 单次前向 <5ms
robot.set_joint_targets(q_des)                   # → PD 1kHz
# VLA 模式：q_des = sonic.decode(vla_tokens[40,64], obs.prop)

7. 推理与部署

  • encoder/decoder 分开导出 ONNX + TensorRT；obs 配置 `encoder.dimension: 64`；可选 fp16。
  • 50Hz 控制、~10Hz 规划（每段 ~100 帧）；ZMQ/ROS2/DDS；29 关节日志。
  • VLA 接口：64 维 token ×40（2.5Hz）→ SONIC 解码 50Hz；动作空间 78 维（64+7+7）。

8. 坑

  • `freq_test` 的频率不是 TRT 推理速度，别当延迟指标。
  • `command_multi_future_nonflat` 源码注释提示时间轴 flatten bug，复现要按 10×58 重排。
  • 训练-部署的观测噪声/延迟要一致；否则 sim2real 抖动。
