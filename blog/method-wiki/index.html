方法卡片

SONIC

S1 全身控制器：三编码器 → FSQ 64 维 token → 解码器 → 50Hz 关节目标；PPO + 辅助损失；700h 动捕、42M、21k GPU 小时。

GR00T（N1 / N1.5 / N1.7 / 2）

VLM + DiT flow matching 动作头；N1.7 用 Cosmos-Reason2-2B、H=40；GR00T 2 升级为 WAM。

Helix

双系统一体：7B VLM（7–9Hz）+ 80M visuomotor（200Hz），单 latent 向量接口，500h 遥操作，时间偏移对齐部署。

π0 / π0.5

单模型 VLA：预训练 VLM + flow matching 动作专家；π0.5 异构协同（多机器人+web+子任务），新家长程操作。

ASTRA（GPT-6 Astra）

通用大模型当策略：Direct 出数值动作 / Hybrid 审阅策略；六域结果、token 与延迟成本、视触觉。

Fast-WAM

WAM 代表：Wan2.2-5B + 1B ActionDiT 联合 flow matching；训练共训、推理只出动作，190ms。

使用约定

  • 证据分级：L3=论文/官方源码与文档逐字；L2=部分正文；L1=摘要或厂商页。每页标注。
  • 代码注释：每段代码后跟「物理意义 / 为什么 / 出处」；公式与代码行一一对应。
  • 流程图：每个方法一张 SVG，标出输入输出、频率、张量形状。
  • 复用：其他页面链接本 wiki，不复制正文；方法更新只改 wiki。
