PART 1 · WORLD MODEL

World Model：对世界的理解

世界模型 = 学「条件未来预测」 P(未来观测 | 历史观测, [动作]) 的环境动态模型；差别只在"预测什么、在哪一层 latent 预测"

🧩 本质 · 条件未来预测

先用 tokenizer / VAE / 自监督 encoder 把观测压成 latent，再在 latent 上学时序动态。主干收敛到四类：扩散 DiT / 自回归 Transformer / RSSM / JEPA。

🏗️ 统一形态 · 一个 backbone + 多 head

backbone（Sampler）预测未来 latent z′；再按消费方分叉：head-M（机器 → latent 直供决策，不渲染）与 head-H（人类 → 扩散 decoder 补细节出像素）。

📈 发展路线图 · WM 正在重走 LLM 的路

双泳道对标下，WM 沿「统一感知 → 数据飞轮 → 自驾 → 具身 → Physical AI」演进，当前处于 ①「GPT 时刻」，终局是 Physical AI（而非 AGI）

PART 2 · WM → VA / WAM

从 WM 到 VA / WAM：AD 与具身如何使用

给 WM 加上 action，就从"预测世界"变成"驱动决策"—— 一阶段读出得 VA，闭环 rollout 得 WAM；同一底座接不同 action，分流为自动驾驶与具身

🔗 WM → +action → VA → WAM · 四步演进

步骤加了什么变成什么关键区别
① WM无 action，只有观测世界预测器 P(z′|z_past)，Sampler 预测未来 latent只"理解/预测世界会怎样"，与动作无关
② +action 条件把动作 a 作为条件注入 Sampleraction-conditioned WM：P(z′|z_past, a)从"看未来"变"看某动作导致的未来"，动作可控
③ VA
vision→action		在 latent 上加 action head一阶段视觉→动作：z →(head-M)→ 动作/规划反应式前馈读出；"检测即预测"、E2E，不走感知→跟踪→预测→规划级联
④ WAM
world-action model		把②的可控预测放进闭环（策略在环）预测"动作→未来" 且 用内部 rollout 做前瞻规划先在"脑内沙盘"试走再择优执行；WAM 内含 WM 的可控 rollout

三者关系：WM ⊂ WAM；VA = latent→action 的快反应读出头（一阶段前馈、无显式 rollout），WAM = 把 WM 当可控仿真器在环规划（model-based）—— 只差"加不加 action、action 是被读出还是被 rollout"。

🧠 一个 backbone + 双 head · 按消费方分叉

输出模态由消费方决定：可预测内容（共享 latent）与感知细节（只为人渲染）干净解耦；head-M 即 VA/WAM 的接口，机器不必先渲染成像素再理解。

🔗 WM→WAM ≡ 二阶段 E2E→一阶段 VA · 同构分流

WM→WAM 等价于 AD 从「感知–规划 二阶段 E2E」走向「一阶段 Vision-Action」—— 两领域同构。Foundation World Model 是共识底座：接不同 action 分流为 AD / Robotics，叠加 language 则在数据闭环中做 caption / mining / triage / auto-label。

PART 3 · INFRA

支撑 Infra · 三大闭环

自动驾驶与具身智能共享同一套研发闭环体系：数据驱动模型进化，工程保障快速交付，测试验证安全可靠

🚗 自动驾驶 (AD)

L4 级自动驾驶：感知、预测、规划、控制的全栈算法研发，覆盖城区/高速/泊车场景。数据来源为车载传感器（Camera / LiDAR / Radar / IMU），通过端到端或模块化架构实现安全可靠的自动驾驶能力。

🤖 具身智能 (Embodied AI)

具身智能体：机械臂操作、移动抓取、双足/四足运动控制。数据来源为 RGB-D 相机、力矩传感器、触觉传感器、关节编码器，通过基础模型（VLA/VLM）+强化学习实现通用操作与移动能力。

SYSTEM ARCHITECTURE

三层大脑架构 · 数据飞轮驱动自迭代

车端小脑保安全、云端大脑强算力、后台 Foundation Model 可蒸馏 —— 车队规模化数据持续回流，驱动整套系统自我迭代升级

🚐 车队规模化数据

规模化车队 7×24 运营，每天回流海量真实路况数据 —— 这是数据飞轮的燃料，车队越大、飞轮转得越快。

🎯 SD = 云端大脑的"标定员"

安全员（SD）的接管与纠正，本质是对云端大脑的在线"标定" —— 每一次人工介入都是高价值监督信号。

♻️ 车端 ↔ 机模 互哺

车端产出素材喂给机模（Foundation Model），机模变强后再蒸馏回车端 —— 越跑越好的正向循环。

🧠 基础模型（Foundation Model）

具身智能研发的核心在于训练通用的 Vision-Language-Action (VLA) 模型，实现从自然语言指令到机器人动作的端到端映射。

视觉编码器 语言理解 动作解码 世界模型
  • 预训练：大规模互联网视频 + 机器人数据联合预训练
  • 微调：特定任务/本体的 LoRA/Adapter 微调
  • 推理：实时动作预测（10~50 Hz）

🔄 Sim-to-Real 迁移

仿真到真实的迁移是具身智能的核心挑战。通过 Domain Randomization、系统辨识和自适应策略弥合 Sim-Real Gap。

Domain Rand System ID Adaptive

  • 动态随机化：延迟/噪声/执行误差注入
