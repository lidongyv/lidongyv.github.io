世界模型主要参考工作与实现方式

整理日期：2026-10-26 ｜ 用途：支撑《一只手，和一个厨房》叙事线中「世界表示 / 世界模型」章节的文献底座。 姊妹篇：world-model-capability-taxonomy.md —— 按「输出任务 × 能力」的功能视角（Marr L1）分类。 核实纪律：所有 arXiv ID 均经 arXiv API / abs 页面逐条核对；未核实的 ID 一律不写，只标注「ID 未核实」。来源见文末。

TL;DR

  1. 定义：世界模型 = 预测「环境在动作/时间作用下如何演化」的模型。当前主流实现分三条路线：潜动力学世界模型（Dreamer/TD-MPC 系，闭环 MBRL）、视频生成式世界模型（自回归 token：Genie/GAIA；扩散 DiT：Sora/DIAMOND/Vista）、结构化 3D/4D 世界模型（3DGS/occupancy/对象运动学：UniWorld/OccWorld/NeuROK）。
  2. 2024→2026 的演化方向：从「像素级视频预测」走向「交互式、可控、结构化」（Genie 3、Cosmos、VerseCrafter、LaLa-World），并开始正面处理物理一致性与闭环长时程（PerpetualWonder、Matrix-Game 4.0）。
  3. 与本叙事线的直接接口： - 吴佳俊「向视频模型借一个世界」= SDS 式 4D 蒸馏（其组内 CHORD / NeuROK / ZeroHSI 一脉；视频扩散模型只贡献分数当先验，不当真值）。 - 「world action models 比 Dreamer 令人印象深刻」→ GAIA-2 / DriveWAM / Genie 3 线 vs DreamerV3 / TD-MPC2 线。 - 「运动学 vs 力学」缺口在文献上成立：主流世界模型的输出本体止于 RGB / occupancy / 点云（几何与外观）；力/触觉输出在 2026 下半年已形成独立子领域（DexTouch-WM、TouchWorld、FeelWorld、ViTacWorld、TacWAM、FAWAM、ForceWAM、CW-WAM 等 8+ 篇，详见姊妹篇 §1-T4），但规模远小于视频世界模型，且力学数据仍需真实采集——「力学数据互联网上不存在」依然成立。

1. 技术路线分类总表

# 路线 核心机制 代表工作 典型用途
1 潜动力学世界模型 VAE 编码观测 → RSSM/Transformer 预测潜状态 → 隐空间「想象」中训练策略 DreamerV3、TD-MPC2、IRIS、DayDreamer MBRL、真机策略、导航
2 自回归 token 视频模型 视频 VQ tokenizer + 因果 Transformer，动作/语言/文本 token 交织预测 Genie 系列、GAIA-1、GenAD 交互环境、驾驶生成
3 扩散视频世界模型 DiT/flow matching，动作条件化去噪生成未来帧 Sora、DIAMOND、Vista、DriveDreamer-2、Cosmos 视频生成、仿真数据
4 JEPA / 潜空间预测 只预测潜表征（不重建像素），从预训练视觉特征上学习 V-JEPA、DINO-WM、LaLa-World、GLAM 表征、零样本规划、导航
5 结构化 3D/4D 世界模型 occupancy / 3DGS / 对象运动学潜空间 + 可微渲染 / SDS 蒸馏 OccWorld、UniWorld、MUVO、ManiGaussian++、NeuROK、CHORD、PerpetualWonder 几何一致、闭环物理
6 VLM/LLM 中心的世界建模 语言状态推理 + 奖励/记忆，把「状态估计+转移预测」装进 LLM VAGEN、PhysMem、LaLa-World Agent、慢脑侧规划

2. 实现方式详解

2.1 潜动力学世界模型（MBRL 线）

  • 原理：图像经编码器 → 低维隐状态；循环网络（Dreamer 系 RSSM）预测隐状态转移与奖励；策略在「隐空间想象」中优化，即 imagination-based MBRL。
  • 代表：DreamerV3（2301.04104，150+ 任务单一配置、Minecraft 钻石）、TD-MPC2（2310.16828，隐式模型预测控制）、IRIS（2209.00588，离散潜 token + Transformer）、DayDreamer（Dreamer 上真机四足/机械臂）。
  • 优点：样本效率高、真机可用、闭环自洽。缺点：隐状态难跨域泛化，视觉保真度低，难扩展互联网数据。
  • 开源：DreamerV3 / TD-MPC2 / IRIS 均有官方代码。

2.2 自回归 token 视频世界模型

  • 原理：VQ 编码器把视频帧离散化为 token，因果 Transformer 逐 token 预测；动作（潜动作/文本/连续动作）作为条件 token 交织。
  • 代表：Genie（2402.15391，2D 平台游戏、从视频学潜动作）、GAIA-1（2309.17080，视频+文本+动作统一 token）、GenAD（2402.11502）。
  • 优点：训练稳定、长序列、天然兼容语言。缺点：token 化损失细节，推理逐 token 慢。
  • 开源：Genie 有官方开源实现；GAIA 系列未开源。

2.3 扩散视频世界模型

  • 原理：DiT（Sora）或 latent flow matching，以过去帧+动作/语言/轨迹为条件去噪生成未来帧；保真度最高。
  • 代表：Sora（OpenAI 官方博客，2024.02，DiT 扩展；技术报告未发 arXiv 版）、DIAMOND（2405.12399，NeurIPS 2024 Spotlight，Atari/CS:GO 扩散世界模型）、Vista（2405.17398，NeurIPS 2024，驾驶多动作条件扩散）、DriveDreamer-2（2403.06845，AAAI 2025，LLM 增强结构化条件）。
  • 优点：视觉保真、条件灵活。缺点：推理慢、物理一致性差、长时程漂移。
  • 开源：DIAMOND、Vista、DriveDreamer-2 开源；Sora 闭源。

2.4 JEPA / 潜空间预测

  • 原理：不重建像素，只预测未来潜表征（V-JEPA：自监督视频特征预测；DINO-WM/Odin：在冻结 DINOv2 特征上建世界模型）。
  • 代表：V-JEPA（2404.08471，CVPR 2024）、DINO-WM（2411.04983，零样本规划）、LaLa-World（2610.27851，2026，语言条件化潜世界模型，规划成本仅为视频生成路线 1/6 训练、13.9× 快推理）、GLAM（2609.14561，导航）。
  • 优点：训练/推理便宜、表示可迁移。缺点：不能直接出视觉，需下游解码。
  • 开源：V-JEPA、DINO-WM、LaLa-World 开源。

2.5 结构化 3D/4D 世界模型

  • 原理：世界状态用 occupancy / 3D Gaussian / 对象运动学潜空间显式表示，动力学在 3D 中演化，再用渲染/蒸馏与视觉对齐。分两类：
  • 几何驱动生成：OccWorld（2311.16038，occupancy 演化）、UniWorld（2308.07234，世界模型预训练）、MUVO（2311.11762，3D 几何多模态）、ManiGaussian++（2506.19842，层次化 3DGS 双手操控）、VerseCrafter（2601.05138，CVPR 2026，4D 几何控制图喂视频扩散）。
  • 从视频蒸馏物理（吴佳俊组一脉）：CHORD（2601.04194，从 2D 视频提取拉格朗日运动，生成多体 4D 动力学）、NeuROK（2605.30347，对象运动学潜空间，即演讲中的「Neural Kinematics」）、PerpetualWonder（2602.04876，物理状态↔视觉表示双向链接的闭环生成）、ZeroHSI（2412.18600，零样本人-场景交互）。
  • 优点：几何/物理一致、可控、可交互。缺点：依赖 3D/4D 数据，渲染与动力学解耦难。
  • 开源：OccWorld、UniWorld、ManiGaussian++ 开源。

2.6 VLM/LLM 中心的世界建模

  • 原理：把 POMDP 的「状态估计 + 转移建模」装进 VLM，用 RL 奖励显式世界建模推理（VAGEN），或在推理期用「先验证后应用」的记忆框架学习物理规律（PhysMem）。
  • 代表：VAGEN（2510.16907，World Modeling Reward + Bi-Level GAE）、PhysMem（2602.20323，测试期物理记忆，砖块插入 76% vs 直接检索 23%）。
  • 优点：语义泛化、免训练扩展。缺点：非毫秒级、接触力学仍靠语言近似。

4. 与本地材料的映射（《一只手，和一个厨房》叙事线）

本地已抓取的论文（papers/ 目录）可直接引用：

吴佳俊组（斯坦福）： - NeuROK（2605.30347）= 演讲中的「Neural Kinematics」：对象运动学潜空间，从静态网格零样本生成可动性/形变 —— 「从物体本身推断可动方式」的论文载体。 - CHORD（2601.04194）：从 2D 视频蒸馏拉格朗日运动生成多体 4D 动力学 —— 「向视频模型借一个世界」的具名实现（distillation-based）。 - PerpetualWonder（2602.04876）：物理状态与视觉原语双向链接的闭环 4D 生成（「我们并没有真的生成视频……视频扩散模型只被用来计算分数」的严格版）。 - TrAct（2608.24101）与 Masked Visual Actions（2607.19343）：动作接口问题——「视觉轨迹/像素空间接口优于裸动作条件化」，即「运动学轨迹如何与视觉预测对齐」。 - WorldScore（2504.00983）：世界生成评测基准（对应演讲中「三个基准均评预测对不对/任务完成没完成」）。 - 另有 VAGEN（2510.16907）、ENACT（2511.20937）支撑「慢脑 VLM 世界建模」侧。

丁文伯组（清华/Xspark）： - DexTouch-WM（2609.20649）：触觉世界模型——人手触觉数据 + 动作重定向监督同一动力学模型。对叙事线的三个直接意义： 1. 它是「力学的 free demonstrations 从哪来」的现有最强回答：人手交互 100 小时是可扩展数据轴（但仍需真实采集，印证「力学数据互联网上不存在」）； 2. 它把世界模型当「策略评测代理环境 + 合成轨迹生成器」用——即触觉侧也可以做「验证器」； 3. 其机制（视频专家 + 轻量触觉专家、anatomy-aware 触觉 token）正好与「快脑 VTLA+TWAM」架构同构。 - GLAM（2609.14561）、ManiGaussian++（2506.19842）：组内在导航/几何侧的世界模型工作。

5. 趋势与开放问题

  1. 控制接口的再设计：动作如何喂给世界模型成为 2025-2026 热点——语言（LaLa-World）、视觉轨迹（TrAct）、像素掩码（Masked Visual Actions）、4D 几何控制图（VerseCrafter）。结论趋同：与视觉空间对齐的接口优于裸动作向量。
  2. 交互式与实时化：Genie 3 的交互记忆、Matrix-Game 4.0 的 60FPS 实时可玩（引擎管状态、视频管外观的混合架构）。
  3. 评测重心迁移：从 FID/FVD 迁移到闭环规划收益、因果一致性（2508.01922）、可控性/动力学分解（WorldScore）。
  4. 物理一致性仍是公认短板：闭环漂移、物体穿透、接触错误（PerpetualWonder 的动机即物理-视觉解耦）。
  5. 触觉/力世界模型从「空白」变为「新兴子领域」：2026 下半年出现 8+ 篇触觉/力世界模型（含 4 篇 WAM 命名），但主流通用世界模型的观测仍止于视觉——「接触层一直没被写进任何一张图」修正为「接触层刚开始被写进图里，且只有触觉社区自己在写」。能力矩阵与误差非对称性分析见姊妹篇。
