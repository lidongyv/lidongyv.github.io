2. Abstract 全文逐字（L25–44）

"Abstract. World models have demonstrated superiority in autonomous driving, particularly in the generation of multi-view driving videos. However, significant challenges still exist in generating customized driving videos. In this paper, we propose DriveDreamer-2, which builds upon the framework of DriveDreamer and incorporates a Large Language Model (LLM) to generate user-defined driving videos. Specifically, an LLM interface is initially incorporated to convert a user's query into agent trajectories. Subsequently, a HDMap, adhering to traffic regulations, is generated based on the trajectories. Ultimately, we propose the Unified Multi-View Model to enhance temporal and spatial coherence in the generated driving videos. DriveDreamer-2 is the first world model to generate customized driving videos, it can generate uncommon driving videos (e.g., vehicles abruptly cut in) in a user-friendly manner. Besides, experimental results demonstrate that the generated videos enhance the training of driving perception methods (e.g., 3D detection and tracking). Furthermore, video generation quality of DriveDreamer-2 surpasses other state-of-the-art methods, showcasing FID and FVD scores of 11.2 and 55.7, representing relative improvements of ∼30% and ∼50%."

LLM 的角色（L80–87）："For foreground generation, a functional library is constructed to finetune a Large Language Model (LLM), enabling it to generate agent trajectories based on user text input. In this process, the previously generated agent trajectories are involved as conditional inputs, which allows the HDMap generator to learn the associations between foreground and background conditions in driving scenes. Building upon the generated traffic structured conditions, we employ the DriveDreamer [59] framework to generate multi-view driving videos."

4.3 UniMVM：多视图统一生成

动机（L383–387）："InDriveDreamer-2, we introduce the UniMVM within the DriveDreamer framework. The UniMVM is designed to unify the generation of multi-view driving videos both with and without adjacent view conditions, which ensures temporal and spatial coherence without compromising generation speed and diversity." 公式（L392，Eq. 2）：p(x1, ...,xK) = p(x1)p(x2|x1)...p(xK|x1, x2..., xK−1)。核心操作（L394–399）："In the proposed UniMVM, we draw inspiration fromtheEq.2toexpandtheview. However, unlikeDrive-WM[62]whichrequires the independent generation of views, UniMVM unifies multiple views as a complete patch. Specifically,weconcatenatethe multi-view video in the order of{FL, F, FR, BR, B, BL}1 to obtain the spatially unified imagex′ ∈ RT ×3×H×KW."（脚注 L401：F:Front, L:Left, R:Right, B:Back）。Eq. (3)（L400）：p(x′) =p(x′ · (1 − m), x′ · m) =p(x′ · m)p(x′ · (1 − m)|x′ · m)。掩码实现三种任务（L403–413）："UniMVM unifies multiple views into a complete patch for video generation without introducing cross-view parameters. Furthermore, various driving video generation tasks can be accomplished via adjusting the mask m. Specifically, when m is set to mask future T − 1 frames, UniMVM enables future video prediction based on the input of the first frame. Configuring m to mask {FL, FR, BR, B, BL} views empowers UniMVM to achieve multi-view video outpainting, leveraging a front-view video input. 4.4 动作条件：轨迹→3D box→直接投影控制

L418–425："Specifically, our approach firstunifythetrafficstructuredconditions,whichresultsinsequencesofHDMaps {Hi}N−1i=0 ∈ RN×3×H×KW and 3D boxes {Bi}N−1i=0 ∈ RN×C×H×KW (N is the frame number of video clip, andC is the category number). Note that sequences of 3D boxes can be derived from agent trajectories, and the sizes of 3D boxes are determined based on the respective agent category. Unlike DriveDreamer, the 3D box conditions inDriveDreamer-2 no longer rely on position embedding and category embedding. 8. 叙事关联【推断】：LLM 语义条件化与「慢脑」

  1. LLM 承担高层语义规划（慢脑候选角色）：LLM 不生成像素，而把自然语言转化为全局交通场景的结构化描述。支持句：L33–34 "an LLM interface is initially incorporated to convert a user's query into agent trajectories"；L623–624 "Leveraging a Large Language Model,DriveDreamer-2 first transfers user queries into foreground agent trajectories."
  2. 语义→符号→几何→像素的多级降维链：慢脑输出不是直接控制快脑的像素，而是经过可执行脚本、轨迹数组、HDMap、3D box 逐级落地，每一级都是可检查的中间表征。支持句：L307–308 "the finetuned LLM can directly output the trajectory array"；L421 "sequences of 3D boxes can be derived from agent trajectories"；L426–428 "We adopt three encoders to embed HDMaps, 3D boxes, and image frames into latent space featuresyH, yB, andyI."
  3. 规划与执行的时间解耦：LLM 一次性生成整段场景的条件序列（N 帧轨迹+地图），扩散模型随后逐帧渲染——对应慢脑低频全局规划、快脑高频执行的分工。支持句：L418–419 "we firstunifythetrafficstructuredconditions,whichresultsinsequencesofHDMaps … and 3D boxes … (N is the frame number of video clip)"。
  4. 高层语义贯通到细粒度物理表现：天气类宏观语义条件联动雨刷摆动、夜间行人等细粒度行为，说明语义层可以"命令"低层视觉动力学。支持句：L1018–1024 "the windshield wipers of the truck are continuously clearing the windshield.   5. 慢脑能力受原语库边界约束：LLM 的语义只能映射到 18 个预定义函数构成的动作原语空间，语义表达能力 = 原语库覆盖度；库可扩展意味着慢脑的"词汇表"是开放的。支持句：L293–296 "the constructed function library encompasses 18 functions, including agent functions … pedestrian functions … and other utility functions"；L825–826 "this function library can be further expanded to meet users' demands for generating scenes."
