2. Abstract 全文逐字（L8–21）

"Abstract—World models for autonomous driving have the potential to dramatically improve the reasoning capabilities of today's systems. However, most works focus on camera data, with only a few that leverage lidar data or combine both to better represent autonomous vehicle sensor setups. In addition, raw sensor predictions are less actionable than 3D occupancy predictions, but there are no works examining the effects of combining both multimodal sensor data and 3D occupancy prediction. In this work, we perform a set of experiments with a MUltimodal World Model with Geometric VOxel representations (MUVO) to evaluate different sensor fusion strategies to better understand the effects on sensor data prediction. We also analyze potential weaknesses of current sensor fusion approaches and examine the benefits of additionally predicting 3D occupancy."

4. 方法逐机制

架构总述（L176–184）："First, we process, encode, and fuse RGB camera data and lidar point clouds. Second, we feed the latent representations of the sensor data to a transition model to derive a probabilistic model of the current state, followed by sampling, while concurrently predicting the probabilistic model of future states and sampling from it. Lastly, we decode both current and future states from the probabilistic models, forecasting raw RGB images, point clouds, and 3D occupancy." 整体框架仿照 MILE（L162–163）："our experiment setup follows the fundamental architecture of MILE [24], which is much reduced in complexity compared to other approaches."

  • 输入模态（L186–191）："We input RGB images from a front camera and point clouds from a top-mounted lidar. The 3D point cloud, comprising up to 60,000 points, is projected into a 2D cylindrical projection for lossless bijective representations. For images I ∈ R3×Hi×Wi, we follow Hu et al [24] and use an input size of 600 × 960 pixels."
  • 观测编码（L192–197）：对 range view 形式 R ∈ R4×Hr×Wr 与图像用预训练 backbone（ResNet18）提特征，"We derive feature maps from different model layers similar to [24] and fuse them, culminating in image features Fc ∈ RC×Hc×Wc and point cloud features FL ∈ RC×HL×WL."
  • 多模态融合（Transformer，L199–219）："we employ the self-attention mechanism of a Transformer [78] to fuse features of different sensors." token 构成（L207–215）："we incorporate the 2D sinusoidal positional embedding … e ∈ RC×HW into each token to introduce spatial inductive biases. The learnable sensor embeddings s ∈ RC×Ns are added, introducing a sensor category… ti(x, y) = fi(x, y) + ei(x, y) + si"。汇总（L215–219）："These tokens from all sensors are concatenated and fed into a Transformer encoder comprising k layers, each consisting of multi-head self-attention, Multilayer Perceptrons (MLP), and layer normalizations."
  • 过渡模型（L229–238）："The deterministic historical variable ht+1 = fθ(ht, st) is modelled by a Gated Recurrent Unit (GRU) [79] fθ, enabling the model to remember past states. The posterior hidden state probability distribution is given by q(st | o≤t, a<t) ∼ Nϕ(ot, ht, at), while the prior hidden state probability distribution, without the input of observed feature ot, is given by p(st | ht, at−1) ∼ Nθ(ht, at−1)." 动作接口（L221–223）："The input consists of fused observation features o0:t and encoded actions a0:t ∈ RT ×Da, based on a simple MLP, assuming access to a policy or motion planner."
  • 2D 潜空间（L239–247）："We utilize the output tokens tnew from the sensor fusion in the form of a two-dimensional latent state as the encoded observations ot for the transition model. Compared to 1D states, we set the stochastic hidden states st, and deterministic historical states ht to shape Ch × (Pj Tj), where Tj is the number of tokens of each output modality. For fθ, we replace all fully connected layers with convolutional layers in order to utilize two-dimensional states. The probability models Nϕ and Nθ are modeled by a transformer decoder."
  • 解码器与生成目标（L256–268）："We decode into camera and lidar data and introduce an optional head for 3D occupancy."（L261–268）："The occupancy decoder is of shape C × X × Y × Z. For camera and lidar data, first, the input is reshaped to C × H0 × W0, where H0 and W0 are determined by the final output resolution H × W. Subsequently, we perform upscaling with convolutional networks similar to [80], [81] to produce a feature map of size Cn × H × W. For camera and lidar, we utilize two-dimensional convolutions, while we employ three-dimensional convolutions for voxels."
  • 训练损失（L280–302）：自监督，无标签："we follow a self-supervised training approach and do not require labels at any point." 多尺度 1/2/4；图像 L1 损失 Limg；点云 "an L2 loss Lp,xyz is applied to minimize the Euler distance and an L1 loss Lp,r is based on range r"；occupancy 用 "a Scene-Class Affinity Loss (SCAL) [42] LV,scal"（L297）。

8. 叙事关联【推断】：3D 几何路线 vs 纯 2D 生成

  1. 行动性动机：几何（occupancy）输出被定义为比原始传感器预测"更可行动"，这是 3D 路线价值的直接表述（L13–14："raw sensor predictions are less actionable than 3D occupancy predictions"）。【推断】该论文认为几何表示的世界模型比纯像素生成更贴近下游规划决策。
  2. BEV 压缩丢高度是 2D 化损失的显式证据（L34："which is an acknowledged bottleneck due to missing height information"）；实验给出反向因果证据（L426–427："Methods with an additional BEV mapping of image features perform worse"），支持"保几何=去 BEV"。【推断】支持 3D 几何路线优于 2D 平面投影式融合。
  3. 2D 潜空间提升相机与 occupancy 但对 lidar 无效（L376–380："The 2D latent state significantly benefits predictions for camera images and spatial voxel occupancies, while lidar predictions do not see any benefit."），且相机复杂度更高被作为解释（L378–380："camera data is much more complex than lidar data"）。【推断】图像生成是最难的任务，几何空间（occupancy/lidar）反而受益于共享表征，说明 3D 几何表征是更好的共享瓶颈。
  4. 反向收益有限（L509–513："we observe only slightly increased performance gains for both modalities when occupancy prediction is included, with a more pronounced benefit for camera predictions under the DRLval setting."）。【推断】occupancy 信号对 2D 生成的提升是"少量、轻微"的，3D 几何路线的收益主要在可行动性而非像素质量。
  5. 预训练权重已隐含几何（L497–501："the pre-trained weights already contain some, however limited, spatial information, indicating that the model partially integrates image and point cloud features to form spatial voxel features even when trained only on these two modalities."）。【推断】像素/点云预测已部分隐式编码了几何，occupancy 只是显式化该信息。
