2) Abstract 全文逐字（L8–30）

"Recent progress in integrating vision-language-action (VLA) models with world modeling has significantly advanced end-to-end autonomous driving by allowing systems to reason about imagined futures instead of merely reacting to current observations. However, most world VLA models generate future frames at the pixel level with plenty of dense visual tokens. Although such generated futures can be visually plausible, they preserve many driving-irrelevant appearance details, i.e., only a small portion of the tokens directly encode critical planning-relevant factors, such as agent geometry, motion dynamics, and interactions. This introduces a significant performance bottleneck. An important question thus arises:what world state should a world VLA model reason over to support planning beyond pixel-level prediction?We argue that planning-oriented world modeling should focus on a compact and structured agent-centric latent state that captures the interactions between objects in the driving scene over time. As such, we introduce AgentWorld, an agent-centric VLA world model that uses discrete agent tokens jointly for reasoning and trajectory planning. Each token is dynamically grounded to a surrounding agent associated with its object's state, such as semantic identity, 3D geometry, motion, and interaction context. AgentWorld learns these tokens through three key processes: explicit geometric grounding, reasoning-oriented supervised fine-tuning, and agent-oriented reinforcement learning. Extensive open-loop and closed-loop experiments under diverse driving scenarios show that AgentWorld enhances planning capabilities, fully exploits visual evidence and agent dynamics, and yields interpretable agent-centric world states."

3) 问题与动机

核心对立：像素级世界状态 vs 紧凑 agent-centric 潜状态。

  • 现状批评（像素级 VLA world model 的瓶颈）：
  • "most prior VLA world models imagine the future frames through pixel-level generation with autoregressive or multi-step diffusion. Although such generated future frames can be visually plausible, they retain numerous task-irrelevant visual details, i.e., texture, lighting, background, and visual continuity."（L39–42）
  • "Only a small portion of tokens explicitly encode / planning-relevant cues, including agent geometry, / motion dynamics, and interactive behaviors. This / introduces a significant bottleneck in VLA world / models."（L42–49；中间夹页眉页脚）
  • 定量证据（Fig. 2）：
  • "existing VLA world models demand far more tokens than the fine-tuned base model, i.e., Qwen2-VL [35], yet bring only slight planning improvement. Moreover, the visual grounding ablation reveals that removing image cues only slightly degrades existing world VLA models, even with their heavy use of dense visual tokens."（L106–112）
  • "This suggests that the visual inputs in these models are not yet fully transformed into planning-relevant reasoning, with many of the visual tokens instead being used for image generation."（L113–115）
  • Fig. 2 数值（txt 中散落，模型-数值对应关系在提取文件中不可复原）："0.96 / 1.22 / 0.26 / 1.15 / 0.83 / 0.32 / 1.07 / 0.45 / 0.62 / 1.30 / 1.16 / 0.14 / 60 / 447 / 653 / 98"（L86–98），坐标轴标注 "Average planning L2 error (m)↓"（L99）、"Average sequences (tokens)↓"（L100）
  • 核心问题句：
  • "As such, the core challenge is not simply how to generate visually plausible future frames, but how to integrate world modeling with VLA through a compact, structured, and task-aligned state. An important question thus arises: what world state should a VLA world model reason over to support planning beyond pixel-level prediction?"（L115–119）
  • 主张与 JEPA 关联：
  • "Motivated by JEPA-style paradigms [36–38], which prioritize predictive abstraction over pixel reconstruction, we argue that planning-oriented world modeling should emphasize a latent world state that captures the temporal interactions among objects in driving scenes."（L120–122）
  • "we align the latent world state with the causal structure of driving, shifting world modeling from future frame generation to structured reasoning about interacting agents."（L127–129）
  • 相关工作对三种现有表征的定性（BEV/occupancy、场景级 latent、语言对齐状态）："Consequently, existing representations either retain excessive low-level details, obscure agent-level causal factors, or lack explicit physical grounding, motivating a compact, interpretable, and agent-centric world state for driving-oriented reasoning."（L189–191）
  • 三大贡献（L149–157）：
  • "We reveal that the bottleneck of existing world VLA models stems from the fact that a considerably large number of visual tokens for future generation are irrelevant to planning, which motivates our design of compact, structured, planning-oriented latent world modeling."（L149–151）
  • "We introduce an agent-centric latent state for planning-oriented world modeling, which represents the driving scene as temporally evolving agents grounded in 3D geometry, motion, semantics, and interaction context."（L152–154）
  • "We propose AgentWorld, an agent-centric world VLA model that instantiates this state with discrete agent tokens. Experiments on open-loop and closed-loop benchmarks show consistently improved planning performance and more interpretable world states."（L155–157）

4) 实现细节（重点）

4.1 形式化与离散 agent token 定义

  • 上下文与规划目标："Let Ht = {o1:t, g} denote the driving context at time t, where o1:t contains historical multi-view observations and ego-status, and g is the navigation goal. The goal of end-to-end autonomous driving is to predict a future ego trajectory τt:t+H."（L243–245）
  • 世界模型+策略分解（Eq. 1，L247）：p(τt:t+H, Ŝ | Ht) = pw(Ŝ | Ht) pπ(τt:t+H | Ht, Ŝ). (1)；"Here, pw denotes a world model that constructs an imagined world state Ŝ from the driving context, while pπ denotes a VLA that predicts the ego trajectory conditioned on both the current context and the imagined state."（L248–250）
  • 世界状态的接口性质："the world state is not merely an auxiliary prediction target, but the information interface through which predictive imagination influences decision-making."（L250–252）
  • 固定 token 集合（Eq. 2，L263–264）："we introduce a fixed set of special agent tokens into the MLLM sequence, Tagent = {⟨agent_1⟩, ⟨agent_2⟩, · · ·, ⟨agent_N⟩}, (2) where N is the maximum number of agent tokens."（L263–266）；N = 20："The number of agents is set to 20."（L1165–1166）
  • agent-centric 潜状态（Eq. 3，L269–270）："S_agent_t = {h1_t, h2_t, · · ·, hN_t}, h_i_t ∈ R^{D_LLM}, (3) where hit is the MLLM hidden state at the position of ⟨agent_i⟩."
  • 动态接地定义："Each token acts as an addressable agent slot that can be dynamically grounded to a surrounding participant or assigned to a 'no-object' state. Through explicit physical grounding, active tokens are encouraged to encode semantic identity, 3D geometry, motion, and interaction context."（L270–273）
  • 规划式（Eq. 4，L275–277）：p(τt:t+H | Ht) = pπ(τt:t+H | Ht, S_agent_t). (4)；"The role of the world model is to construct S_agent_t as a compact, physically grounded, and interaction-aware state, rather than reconstructing all future visual details."（L278–279）

4.2 Agent token 初始化（来自特殊 token 的可学习嵌入）

  • "We initialize agent queries from the learnable embeddings of the special agent tokens, rather than introducing a separate object-query set."（L287–288）
  • Eq. 5（L289）：E_agent = Emb(Tagent) ∈ R^{N×D_LLM}, (5)；Eq. 6（L291）：Q0_t = E_agent Wq = [q^{1,0}_t; · · ·; q^{N,0}_t] ∈ R^{N×d}. (6)
  • "Thus, each special token is itself a learnable agent query. At initialization, these queries are ungrounded latent slots that define where agent-centric world states will be formed in the MLLM sequence, without assuming any fixed correspondence to physical agents."（L292–294）

4.3 多模态路由锚定（Multimodal Routed Anchoring，Fig. 4）

  • 两路互补特征："AgentWorld routes each slot to two complementary features: 4D geometry G0_t from offline VGGT-style features following [88–90] and 2D visual V0_t from the MLLM visual encoder. The geometry branch provides spatial layout, temporal consistency, and motion-related cues, while the vision branch provides appearance and semantic context."（L321–329）
  • 共享路由空间（Eq. 7，L331）：Gt = φg(G0_t), Vt = φv(V0_t). (7)
  • 每层：先适配查询到该模态，再 token-wise 门控，再做交叉注意力（Eq. 8，L334）：R^ℓ_m = CrossAttn_m(γ^ℓ_m ⊙ ψ_m(Q^ℓ_t), φ_m(M_m), φ_m(M_m)), γ^ℓ_m = σ(f_m(Q^ℓ_t)), (8)〔提取文本作 "CrossAttnm"、"Qℓt"，下标粘连〕；"where m ∈ {g, v}, Mg = Gt, and Mv = Vt. The independent gates allow each token to decide how much geometry and vision to use, without forcing the two modalities to compete."（L335–336）
  • 融合更新（Eq. 9，L339）：Q^{ℓ+1}_t = Fuse(Q^ℓ_t, R^ℓ_g, R^ℓ_v). (9)；路由层数 L = 3："we use L = 3 routing layers by default."（L1163–1164）
  • 注入 MLLM："After L routing layers, the resulting grounded queries Q̃t are projected to the MLLM hidden space and inserted into the corresponding ⟨agent_i⟩ positions. The MLLM then contextualizes these tokens, and the hidden states at the corresponding positions serve as the grounded latent states {hit}Ni=1. These states are subsequently supervised by the shared agent head and Hungarian matching."（L340–343）

4.4 物理接地目标（training-time head + 匈牙利匹配）

  • "We ground each agent token by supervising its MLLM hidden state hit with a lightweight training-time head: h_agent(hit) = (p̂it, b̂it, τ̂it), (10) which predicts category/existence, 3D bbox, and future trajectory. Because token order is unordered, predicted slots are matched to ground-truth agents with DETR-style bipartite matching [91]; matched slots receive classification, box, and trajectory losses, while unmatched slots are trained as no-object. This training-time head makes active tokens physically verifiable, leaving the grounded hidden states as agent-centric world states."（L344–351）
  • 接地损失（Eq. 25，L1201）：L_ground = λ_cls L_cls + λ_box L_box + λ_traj L_traj + λ_noobj L_noobj. (25)；"We set λcls = 1.0, λbox = 1.0, λtraj = 1.0, and λnoobj = 0.1 by default. The no-object weight is kept small to avoid dominating the supervision when most agent slots are empty."（L1202–1204）
  • 接地数据格式（Stage 1 模板，Eq. 16 / Fig. 7，L989–991）：<perception>⟨agent_1⟩ · · · ⟨agent_N⟩</perception>. (16)；"No textual description of object category, location, or motion is provided. The model must encode this information in the contextual hidden states of the agent tokens."（L990–992）；"The offline VGGT features are provided as geometry memory for routed anchoring, but the VGGT encoder itself is not trained."（L998–999）

4.5 策略接口与结构化输出

  • "AgentWorld exposes the learned slots through the field, <perception>⟨agent_1⟩ · · · ⟨agent_N⟩</perception>, where the state of each participant is carried by the token hidden state rather than an explicit text description. The policy is trained to output a structured response y = (ξ, a, τ), consisting of a concise agent-grounded rationale , a high-level driving action , and future ego waypoints . This format forces planning to be expressed through addressable participants instead of dense perception text or image-level future prediction."（L353–360）
  • 输出示例（Fig. 5 右栏，L461–465，逐字）：AgentWorld:<perception><agent_1><agent_2><agent_3>…<agent_20></perception><think>Main risk is <agent_3> and <agent_5>, two nearby cars on the right that narrow the ego passing space, with <agent_3> being the closest. <agent_1> is a pedestrian far ahead but has no immediate path conflict. Ego should slow slightly and keepextra right-side clearance.</think><action>KEEP_SPEED, KEEP_LANE</action><answer>[(0.75, 1.75),(0.82, 3.10),(0.90, 4.35),(1.00, 5.55),(1.10, 6.62),(1.22, 7.89)]</answer>
  • 轨迹粒度：6 个路点、0.5s 间隔、3s 时域——"please plan waypoints (0.5s intervals) for the next 3 seconds…"（L452–453）

4.6 三阶段训练（各自损失与数据）

Stage 1：Physical grounding SFT（显式几何接地） - 超参："We first train the agent-token grounding interface for 12 epochs. The trainable modules include the MLLM backbone, the special token embeddings, the multimodal routed anchoring module, and the auxiliary agent head. We use AdamW with a cosine decay schedule and a warmup ratio of 0.03. The learning rate is set to 1.0×10⁻⁴. The per-device batch size is 2 with 8 gradient accumulation steps, giving an effective batch size of 16 per device. Input images are processed with a maximum resolution of 524288 pixels. For multimodal routed anchoring, we use L = 3 routing layers by default. The grounding loss supervises category/existence, 3D bounding box, and future trajectory prediction after Hungarian matching. The number of agents is set to 20."（L1158–1166） - 数据与监督（A.1）："For each selected agent, we store its category, 3D bounding box, velocity or motion state, and future trajectory. During training, the predictions from the agent-token hidden states are matched to these targets using DETR-style bipartite matching. Matched tokens are supervised with classification, 3D box, and trajectory losses, while unmatched tokens are supervised as no-object."（L994–998）

Stage 2：Reasoning-oriented SFT（推理导向 SFT） - 损失（Eq. 11，L365–370）：L_SFT = −Σ_k log p_θ(y⋆_k | y⋆_<k, Ht, S_agent_t), S_agent_t = {hit}Ni=1. (11)；"Each expert response is organized as y⋆ = (ξ⋆, a⋆, τ⋆), where ξ⋆ is a concise rationale over relevant agent tokens, a⋆ is a high-level driving action, and τ⋆ is the expert future trajectory."（L361–363） - rationale 设计："The rationale ξ⋆ is deliberately compact: it does not verbalize all perception results, but only identifies planning-relevant agent tokens, summarizes their interaction risk, and explains the resulting maneuver."（L371–373） - 超参："we train the MLLM to use grounded agent tokens for reasoning and planning for 12 epochs. The multimodal routed anchoring module and auxiliary agent head are frozen. The trainable parameters are the MLLM policy parameters and the special agent-token embeddings. We use AdamW with a learning rate of 5.0×10⁻⁵ and a cosine decay schedule. The batch configuration follows Stage 1, with a per-device batch size of 2 and 8 gradient accumulation steps. Each sample is trained with the structured output format consisting of , , , and ."（L1167–1173） - 渐进去除接地脚手架："To reduce mismatch with the RL stage, we progressively drop the training-time grounding scaffold during SFT: early batches use full grounding inputs, middle batches use partial dropout, and the final SFT phase uses the same MLLM-only format as RL."（L1173–1176）；可选正则（Eq. 27，L1217）：L_Stage2 = L_SFT + η L_ground, (27)；"where η is linearly decayed from 0.1 to 0 as the training gradually shifts to the MLLM-only format. In the final SFT phase, η = 0."（L1218–1219） - Stage 2 数据（A.1）：rationale 由 Stage-1 接地模型的 slot-to-agent 指派生成——"we run the grounding model on the training set, match predicted slots to ground-truth agents, and obtain a mapping from ⟨agent_i⟩ to either a physical agent or no-object."（L1049–1051）；动作标签由专家轨迹派生——"The high-level action is derived from the expert ego trajectory. We classify longitudinal behavior into ACCELERATE, KEEP_SPEED, DECELERATE, or STOP, and lateral behavior into KEEP_LANE, CHANGE_LEFT, or CHANGE_RIGHT. The field contains the expert future waypoints."（L1052–1054）；"We optionally use strong MLLMs to generate concise, agent-grounded driving-risk rationales."（L1072，提示模板见 Fig. 8，L1016–1040）

Stage 3：Agent-oriented RL（GRPO） - 总体："We further optimize AgentWorld with GRPO [39]. Starting from the reasoning-oriented SFT checkpoint, the model samples multiple structured responses for each scene, each containing a concise rationale, a high-level action, and future ego waypoints. These candidates are evaluated by a composite reward that measures format, perception, action, trajectory, and interaction context."（L379–383） - 轨迹/交互奖励语义："The trajectory reward encourages smoothness and imitation of expert behavior following [30], while the interaction reward explicitly evaluates the ego rollout against surrounding agents and penalizes collisions, insufficient clearance, and short time-to-collision. This reward design makes the RL stage agent-oriented: improving the final trajectory requires the policy to account for the dynamic agents represented by the learned tokens."（L383–387） - GRPO 机制："GRPO ranks multiple responses sampled from the same scene by their relative rewards, using the SFT model as a reference to stabilize updates. During RL, only the MLLM policy is updated."（L388–389） - 超参："We further optimize the Stage-2 checkpoint with GRPO for 1 epoch. During RL, only the MLLM policy parameters are updated. The auxiliary agent head is kept frozen and used only as a reward-side generator to decode top-K agent trajectories from the learned tokens; it receives no gradients. The routed anchoring modules are also frozen and are not optimized during RL. We use a learning rate of 1.0×10⁻⁶ and a global batch size of 16. For each prompt, we sample 8 responses to estimate group-relative advantages. The KL coefficient to the SFT reference policy is set to 1.0×10⁻². The reward is a weighted sum of format reward, perception-slot reward, action reward, trajectory reward, and agent interaction reward, with all reward weights set to 1 unless otherwise specified."（L1177–1186） - 推理时去除训练脚手架："At inference time, the reward-side agent head is not required and can be discarded."（L427–428）；"At inference time, it is completely removed, and AgentWorld performs planning with the MLLM and the learned agent-token interface alone."（L1195–1196）；"the final SFT phase adopts the same MLLM-only input-output format used in RL, where the auxiliary grounding heads and routed anchoring modules are no longer required in inference."（L376–378）

RL 奖励明细（A.2，Eq. 20–24） - Format reward："A structural reward of 1.0 is assigned if the response strictly follows ... ... ... ..., and 0 otherwise."（L1086–1087）；"The field must contain only valid special agent tokens {⟨agent_i⟩}Ni=1, without free-form object descriptions or invalid tokens."（L1088–1089） - Perception（slot-alignment）reward（Eq. 20，L1098–1106）：R_percep = I[|T̂_agent| = N] · I[T̂_agent = T_agent], (20)；"where duplicate, missing, or invalid tokens receive zero reward."（L1106–1107） - Meta-Action reward："we compute an F1-based reward: R_action = 2·Prec(M̂, M⋆)·Rec(M̂, M⋆) / (Prec(M̂, M⋆) + Rec(M̂, M⋆) + ε)."〔提取文本分式粘连，L1115–1116；语义=多标签 F1〕；"This balances precision and recall over multi-label driving intents and prevents degenerate behaviors such as always predicting conservative or straight-driving actions."（L1116–1118） - Agent interaction reward（Eq. 21–23，L1119–1146）：最小未来距离 d_min^i = min_m ||p̂^{t+Δm}_ego − p̂^{t+Δm}_i||₂, (21)；TTC 风险 TTC_i = min{Δm | ||p̂^{t+Δm}_ego − p̂^{t+Δm}_i||₂ < d_safe}, (22)；"If no unsafe distance occurs within the horizon, we set TTCi = ∞. The agent reward penalizes collision, insufficient clearance, and short TTC: R_agent = −(1/K) Σ_{i∈I_K} [λ_col I[d_min^i < d_col] + λ_clear (1 − d_min^i/d_safe)₊ + λ_ttc (1 − TTC_i/T_safe)₊]. (23)"〔式中 (·)₊ 为正部截断，提取文本作换行断开〕。"We use the frozen agent head as a reward-side probe to decode the top-K active agent trajectories from the learned tokens."（L1119–1120） - 总奖励（Eq. 24，L1148）：R = λ_fmt R_fmt + λ_percep R_percep + λ_action R_action + λ_traj R_traj + λ_agent R_agent. (24) - 未写数值：λ_col、λ_clear、λ_ttc、d_col、d_safe、T_safe 的具体值——原文未写。轨迹奖励 R_traj 的具体公式——原文未写（仅 "encourages smoothness and imitation of expert behavior following [30]"，L383–384；正文指路 "Detailed rewards are provided in the appendix."，L429，但 A.2 未单列 R_traj 公式）。

4.7 数据管线（A.1）

  • 三原则："First, physical agent states are used only as supervision or reward signals, and are never exposed as textual input to the policy. Second, the field only exposes special agent tokens, while the state of each participant is carried by the token hidden state.   • Influential agent selection（Top-K）：
  • 相对未来轨迹（Eq. 12，L965–966）：r^{t+Δm}_i = p^{t+Δm}_i − p^{t+Δm}_ego. (12)（时域 "within a horizon of H = 3 s"，L964）

5.1 原文 Algorithm 1（逐字，L1290–1305）

Algorithm 1 Top-K Influential Agent Selection
Require: Current sample annotations, ego pose, future horizon H = 3s, number of selected agents K
Ensure: Top-K influential agents AK
1: for each object i in the current sample do
2:   Transform the object box, velocity, and category into the current ego frame.
3:   Extract the future object trajectory Ti from the annotation chain.
4:   Extract the future ego trajectory Tego.
5:   Compute the relative future trajectory r^{t+Δm}_i.
6:   Compute current influence score S_cur^i.
7:   Compute future trajectory influence score S_future^i.
8:   Compute final score S_i = α_i(λS_cur^i + (1−λ)S_future^i).
9: end for
10: Sort all objects by S_i in descending order.
11: Select the top-K objects as AK.
12: return AK
