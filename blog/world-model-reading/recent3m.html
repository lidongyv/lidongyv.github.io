最近三个月进展与实现细节

本页覆盖 10 篇新发布工作（全部已精读、关键引文已 grep 原文验证；笔记与伪代码在 papers/<篇名>-notes.md 第 4/5 节）。 伪代码纪律：原文有 Algorithm 环境 → 逐字提取；无 → 依据正文重建并标注「⚠ 依据原文重建（非原文伪代码）」，每步附原文行号，不发明原文没有的细节。

TL;DR

  1. 两条主线：①「世界模型必须显式建模状态」——Physical Registry（可读的动力学寄存器）、InertialWorld（惯性记忆）、EPM（可执行知觉记忆）、AgentWorld（agent 离散 token）四篇从不同角度做同一件事：把「预测动力学」从隐式视频 token 里拿出来变成显式状态；②「评测开始审判」——FlipTest 证明 11 个视频世界模型学不会因果状态（18.3% < 随机 25%），Roz 证明潜动力学模型不编码质量/形变/摩擦/弹性。
  2. T4 力学线继续壮大：DTWM（手套触觉条件视频世界模型）、TacForeSight（力引导触觉预测，20Hz 实时）。
  3. WAM 设计从「预测未来」进化到「预测什么信号」：DiffWAM 用连续视觉差作显式学习信号，推理零开销（LIBERO 98.8%）。
  4. Genie 4（DeepMind 官方博客，2026-11）：新一代码世界模拟，无 arXiv 论文（同 Genie 2/3 口径，仅官方博客）。

实现细节速查（每篇 4 项：数据 / 架构 / 损失与训练 / 推理）

TacForeSight（力→触觉的先行指标）

  • 数据：双指 Xense 触觉 35×20 3D 形变 @30Hz + 腕部六轴力/力矩 @120Hz；5 任务。
  • 架构：TacForceWM = CNN-Transformer tokenizer + 膨胀因果 1D 卷积力编码器 + AdaLN 潜 Transformer 做 chunk 预测（SIGReg 目标）；策略 = DINOv2-small + 现-未来 cross-attention + 触觉门控通道融合 + flow-matching 头。WM 11.8M 参数/150k 步/2700 幕，策略 68.9M，8×A100。
  • 关键证据：原文 L98-103「abrupt wrist-wrench changes consistently precede fingertip tactile responses … global force signals act as leading indicators of future tactile states」；L573-576 预测触觉潜变量比当前触觉提前约 200ms 出现接触变化。
  • 推理：L128-129「maintaining a real-time inference rate of 20 Hz on an RTX 4090D GPU」——目前触觉世界模型链里明确给出实时推理数字的一篇。

DTWM（触觉注入视频世界模型的「位置」问题）

  • 数据：EgoTouch——头戴 RGB 480×640@30fps + 双手压力手套，20.21h / 43,604 clips（38,600 训练）。
  • 架构：Wan2.2-Fun-5B-InP 预训练 DiT（30 块、d=3072）+ LoRA rank 64；每手 138/147 通道经 σ=1.8 高斯足迹在块 {0,6,12,18,24} 注入 zero-initialized residual（λ=1 buffer）；预测帧令 v_ht=0（t>m）实现 causal。
  • 关键论证：原文 L90-93 提出 indexing mismatch——手套读数按「皮肤 patch」索引、视频按「图像位置」索引，触觉注入必须落在对应手部位置而非全局。
  • 消融铁证：把触觉换成 binary contact（每位置/每手）都更差；训练期触觉使推理无触觉仍优于 vision-only。
  • 训练/推理伪代码：见下方 §伪代码 2（训练 12 步 + 推理 7 步，全部带行号）。

Physical Registry（动力学预测应是显式可读状态）

  • 架构：Tr=8 registry slots（1 编码器上下文 + 7 预测器 rollout），初始化自 observation-conditioned forecast（冻结 V-JEPA 2.1 ViT-g@384px 特征，每 slot 196 token）；与视频 token 共享 dense 双向自注意力共演化；中间 DiT 块（Nano 36→10 等）用 MLP 读头对齐 full-video JEPA 目标，Lalign=−(1/Tr)Σcos，λalign=0.5。
  • PRS 选择器：在 K 步前缀后，用「registry readout 与共享 forecast 的角距离」对候选排序，选 1 条继续 D−K 步——无需外部奖励模型/验证器（原文 L96-98）。
  • 效率代价：每步耗时 1.67×/1.55×；多样性 0.029→0.018（正文自述的代价性事实）。
  • 注意：主文 4.4 的 PRS 数值（38.36/46.68）与 Table 12（39.08/47.67）不一致，原文未解释，笔记已标注。

DiffWAM（WAM：预测什么信号？）

  • 定义：Δf_i = f_i − f_{i−1}（连续观测潜表示之差）作为显式时间变化学习信号（L390）。
  • 架构：三专家共享 Observation Encoder；World/Diff 共享前 N−M 层；单向注意力掩码——各专家只读当前帧表示、专家间阻断（L480-487）；推理时移除 World/Diff 专家、零额外开销（L413-415）。
  • 训练：L = L_world + λ_diff·L_diff + λ_action·L_action（L575；λ 数值原文未写）；Table 9：N=30/M=10、lr 1e-4/1e-5、8×A100、Wan2.2-5B 初始化、约 7B 参数。
  • 消融：+Diff Loss 97.05→97.75、+Diff Expert→98.80（LIBERO）；Only-Diff 96.20 < World+Diff 98.80。
  • 叙事线接口：原文把 WAM 问题从「预测未来」推进到「预测什么信号」（L136-138）——与「轨迹接口 vs 全帧预测」的争论同源。

AgentWorld（规划只需要少量关键 token）

  • 架构：固定 N=20 个离散 ⟨agent_i⟩ token，可动态接地到周边参与者或「no-object」状态；查询=特殊 token 可学习嵌入，经 L=3 层几何门控+视觉门控路由，接地冻结 VGGT 4D 特征与 MLLM 2D 特征；training-time head 预测类别/3D 框/未来轨迹 + DETR 式匈牙利匹配。
  • 训练三阶段：接地 SFT 12ep/lr 1e-4 → 推理 SFT 12ep/lr 5e-5（η:0.1→0 渐进去除接地脚手架）→ GRPO 1ep/lr 1e-6，奖励 R=λfmt·Rfmt+λpercep·Rpercep+λaction·Raction+λtraj·Rtraj+λagent·Ragent（权重均 1）。
  • 关键证据：原文 L106-112——现有 world VLA 用大量稠密视觉 token 但去除图像线索只轻微掉点（visual grounding ablation），证明像素世界状态效率低下。
  • 局限自认（L623-626）：仍依赖显式几何监督而非端到端自发涌现。

SAFER（离线批量制造失败 + 有界碰撞价格）

  • 离线数据配方（核心贡献）：13 个部分训练 Roach checkpoint + 动作噪声 + hold/late-brake 可恢复脚本事件制造失败；专家（策略+价值）任意状态可查询，逐状态标注 (a,v)；CARLA 语料 22.06M 步。原文 L481-482：配方只需「允许可恢复失败的驾驶员 + 可在访问状态上查询的专家」——试验场+安全员即可。
  • 世界模型：chunked latent WM，16 步一次前向；symlog 101-bin 分布头；因子化奖励；K=5 价值集成；BC prior 学恢复动作。
  • 规划：MPPI 135 候选（128 采样+6 prior proposals+1 精确 prior）×2 迭代；J = return − W·ρ̄，W=50，ρ̄∈[0,1] 有界——碰撞预测是「有界价格」而非开关惩罚（L753-754：首步确定碰撞 ≈ 一个好候选的全部折现回报）。
  • 在线 Refine：256 步驾驶/32 更新（UTD 0.125）；只精调 dynamics+scorers+risk，prior/value/encoder 冻结；EMA 慢副本打分防目标漂移。
  • 伪代码：原文 Algorithm 1 逐字见下方 §伪代码 1。

FlipTest（视频世界模型学不会因果状态）

  • 方法：1,680 初始帧（600 最小对 + 600 匹配控制 + 480 稠密 sweep）；10 仿真 + 15 真实任务；11 个视频世界模型；双裁判（Gemini 3.6/3.8 Flash）读生成视频判定结局；指标 = pair accuracy / SS=CFR−SFR / P(event|m)。
  • 结论（全部原文验证）：最强模型 18.3% < 随机 25%；mode collapse 72%（真实）/89%（仿真）——边界两侧预测完全相同；告知结局后 18.3%→73.7%——模型学的是外观而非因果状态；VLM 呈 S 形选择性曲线，代码测量 agent 93.3%/91.3% 接近真界。
  • 对叙事线的意义：这是「运动学 vs 力学」在评测层的独立证据——世界模型不追踪决定未来的状态，而接触状态恰是最决定性的那种状态。

Roz（潜变量不编码质量/摩擦）

  • 方法：10 contrastive（三角品尝三选一、严格不等式）+ 3 continuous（最近邻排序）；物理性质映射：Collision→质量、Deform→形变、Roll/Bowl→摩擦、Bounce→弹性；输入仅需模型吃 256×256 帧/视频 + 潜提取 + 距离函数，单次前向（低成本、可快速迭代）。
  • 结论：图像稳健类任务（bowl/basic color/translation）全员高分，物理记忆类（occlusion/bounce/deform）全员崩溃（L335-337）；DreamDojo 重建 MSE 减半而 Roz 分数恒定（L387-389）——重建目标 ≠ 动力学记忆。
  • 注意：摘要里没有 "AnonWM"，实际模型名是 PantheonWM（笔记已纠正）。

EPM（可执行知觉记忆：记忆随动作演化）

  • 核心：显式知觉状态 m̃ 与神经潜状态 ž 在想象中并步推进（Eq.2）；read-out 进 reward/value/policy；奖励对齐「产生它的转移」——用实测运动推进前一步记忆再配对奖励（Eq.4，防止时序错位毒化训练）；开环记录动作 rollout 沿 prior 前滚 15 步、只训 reward head（Eq.5）。
  • 结果：Memory Maze 13×13 30.37 vs 23.37（+7.00 [3.80,10.21]，6/6 种子）。
  • 触觉实验：concentration / tactile recovery / real tactile frames——但原文自认「does not isolate tactile initialization」（L605-609）。

InertialWorld（惯性作为表征层结构先验）

  • 核心：状态 Sτ=(Gτ,{rτ,k},Bτ)；每步顺序固定 carry → predict → update（L875-876）：carry 用 ξ=Uθ(S,a) 做动作条件坐标传输（速度保持 η=0.90）；predictor 从 carried 状态+Context 预测完整下一视频状态+候选记忆+写门 g；门控合并 M+=(1−g)⊙M̃+g⊙Mnew，默认 g0=0.020（持久化是默认路径）。
  • 架构：0.8B 参数（宽 1280/20 头/15 层）；320 稠密 token + 16 载体 + 64 slot；冻结 FSQ tokenizer；AR8→16→32 课程 + 全 rollout BPTT。
  • 原文澄清（L252-253）：这是「表征惯性」的操作定义，不是硬编码牛顿定律。
  • 结果：RT-1 PSNR 24.37 / CSGO 18.36 / RECON 16.70 全胜基线（36/36 点估计，35/36 显著）。

三个横切观察（对叙事线的直接含义）
