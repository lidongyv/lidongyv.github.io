§0 · 层级声明 + 全局 L1（计算理论）

系统对象 · 全局要算什么 · 全局天然约束 · 用户 8 问映射。
系统对象：面向自驾 + 机器人的统一世界模型 —— vision 为 base、language 为 addition。
  • vision base：GenCeption 式（生成式视频扩散 backbone 反用为前馈感知）做时序预测 + 3D 感知（4D），特征结构化进 memory bank；flow-matching 只是 refine/sampler，不是 vision-base 的核心表征。
  • language（广义条件）：文本描述 + bbox + 3D 描述 + layout(BEV/HDMap) + 轨迹 + 动作/command。
全局要算什么（L1）：学条件生成 p(未来观测 | 历史观测, 条件)，其中历史观测经 vision-base 压成 4D 世界状态并进 memory，条件 = vision(base) ⊕ language(addition)。

L1 · 约束全局天然约束（汇总 4 份 L1；属问题本身、非算法选择）

  • 1. 世界是 4D 连续体 + 物体恒存 + 物理因果；部分可观测 + 自车运动；单目尺度歧义。
  • 2. 成对可得性：能用哪种条件取决于训练集能否提供与观测对齐的该条件（所有"条件获取"路径的根约束）。
  • 3. 时序对齐：几何条件逐帧、文本整段；3D-VAE 把 T 帧压成 T/f latent 后逐帧条件与 latent 错位。
  • 4. 标注成本 ↔ 可控性：结构化条件(框/HDMap)精确但贵；自由文本便宜但粗、噪声大 → prompt following 差。
  • 5. 反事实无真值：真实数据没有"同一场景+被编辑后"的天然对；"编辑后"只能由可重演前向过程(仿真/3D 重建重渲染/资产合成)或一段真实替身片段提供。
  • 6. OOD 无真值：使"无 GT 的 OOD"仍良定义的约束 = 组合性 / 构造性真值(仿真) / 物理几何不变量 / 临界性判据 / "训练内组合、推理外推"。
  • 7. 跨本体统一（自驾↔机器人）、人写 prompt 与训练 caption 分布差、实时时延、长时序记忆一致性。

L2 · 1.4Flow-Matching 与 vision-base 的分层分工（枚举，不选一）[Q5]

分工描述
(a) FM/RF 仅作预训练目标训练用 rectified flow，推理反用为前馈特征（GenCeption 路线）
(b) FM 作 world-model 采样器rollout 未来 latent/帧，表征由独立 encoder 提供
(c) FM 作 refine head粗前馈预测 → flow 细化(depth/occupancy)
(d) FM 作记忆空间动力学采样器在 memory 状态上做动作条件采样，记忆本体保持确定性
(e) FM/扩散作数据引擎合成训练数据，与 vision-base 解耦
(f) 一致性/蒸馏压成 1 步去掉推理期迭代采样
出处：Flow Matching 2210.02747、Rectified Flow 2209.03003；反用为前馈见 GenCeption 2607.09024。

L3 · 1.5实现选项（枚举）

  • 骨干：开源视频 DiT(WAN2.1 2503.20314)/ViT(V-JEPA/DINO)/sparse-conv(点云)/混合。
  • 采样步数：单步前馈 / 少步 / 多步；t 条件：固定 t=0 vs 采样噪声；输出参数化：velocity(取负)/x₀/ε。
  • 稀疏任务接口：learnable token + 原生 3D RoPE + 位置插值 + MLP head（GenCeption）。
  • 任务统一：稠密任务塞进 RGB[0,1] + 单一 L2 loss + 数据配比平衡多任务（GenCeption）。
  • 数据：合成(Blender/RenderPeople/CMU-mocap)+公开合成(TartanAir/Virtual KITTI/MVS-Synth)。
  • 训练稳定：梯度裁剪 + 梯度丢弃；RGB/文本嵌入离线缓存为 latent。
  • 记忆落地：定长队列 / 环形缓冲 / KV-cache / 显存内 voxel-grid vs 外部检索库。算力：TPU v6e / GPU。

§2 · 模块二 · Language/条件的构成、训练获取、caption 训练 [Q1/Q2/Q8]

L1 界定 → L2 条件表征 / 获取路径 / 统一注入 + caption 训练 → L3 实现。

L1 · 2.1界定与约束

本子域不负责生成器 G 本身，只负责条件 c 侧两个子问题：(i) 条件获取（训练时如何得到与观测成对的 c）；(ii) 条件编码与融合。MagicDriveDiT 把驾驶条件形式化为逐帧描述子 S_t={相机位姿 C, BEV道路图 M_t, 3D框 B_t, 整段文本 L, ego轨迹 Tr_t} —— "广义 language = 一组并列条件通道"的典型。为什么需多样条件：纯文本对细粒度/多智能体/几何精度欠定（可控视频综述 2507.16869；驾驶综述 2502.10498 把 command 细分为 Angle/Trajectory/Map/GoalPoint/Text/3DBox）。约束见 §0 第 2/3/4/6/7 条。

L2 · 2.4多模态条件的统一/组合与注入；caption 侧训练 [Q8]

注入方式：cross-attn(文本/框/camera/traj)；加性/ControlNet(BEV/HDMap/depth 栅格)；gated self-attn(DriveDreamer)；训练-free 注意力引导(LVD)。时序对齐：MagicDriveDiT 为 box/traj 设 spatial-temporal encoder(temporal transformer+RoPE 下采样)对齐 T/f latent；文本时序维=1 后 repeat。组合与解耦：条件当集合一起喂；CFG 独立随机 drop 各条件(MagicDriveDiT 15%)。structured caption 作统一中间层：Any2Caption/FullDiT；Cosmos prompt upsampler 归一人写 prompt。
caption 侧训练做法（枚举）[Q8]
  • 冻结预训练文本编码器(T5/CLIP 冻结，只训生成器)；GR-1 冻结 CLIP+MAE。
  • 联合/自训文本塔：StepVideo 双语 Hunyuan-CLIP+Step-LLM。
  • Recaption + 合成/真值混采：DALL·E3 训练用 95%合成+5%GT 并消融混比；SD3 约 50% VLM 合成 caption。
  • structured vs free-form：几何条件由结构化通道承担、文本只补几何未覆盖语义(MagicDriveDiT 特意约束 caption 范围)。
  • instruction 化/prompt 改写：Cosmos prompt upsampler(Mistral-NeMo-12B long-to-short 微调)、Video2World 用 Pixtral-12B。
  • 中性 trade-off：密集 caption 提升 prompt following 但引入幻觉；混采防过拟合合成模式。

L3 · 2.5实现选项

  • 文本编码器：CLIP ViT-L/H/B、T5、T5-XXL/t5-11b(Cosmos, cross-attn 注入冻结)、umT5(Wan/CausVid)、双语 Hunyuan-CLIP+Step-LLM、驾驶微调 LLM(DriveDreamer-2)、caption 蒸馏用 LLaMA2/3。
  • Captioner/LLM：GPT-4o、CogVLM2-Caption+Panda70M+GPT-4、LLaVA、Pixtral-12B、专用 captioner。
  • 注入模块：cross-attn 层、ControlNet 加性分支、gated self-attn、ST box/traj encoder、3D-VAE 对齐下采样。
  • 训练细节：条件独立 dropout+CFG、null 条件、标注插值(ASAP)、"先内容后可控性"渐进训练。
  • 条件来源数据集：nuScenes/Waymo/OpenDV-YouTube 1700h；机器人 RT-1/Bridge/Ego4D/HowTo100M/Something-Something。

§3 · 模块三 · 可控编辑生成 + 训练 GT 构造 [Q3]

L1 核心 tension → L2 控制注入 / GT 配对构造 / 定量控制 → L3 实现。

L1 · 3.1核心 tension

任务：给定描述子 S_t 与噪声生成视频 {I_{c,t}}=G({S_t},z)；"编辑"= 对条件施加扰动 ΔS（增框 / 平移框+20m / 增大帧间位移=更快）。正确性判据不是像素重建，而是"生成内容是否服从注入条件"——在生成视频上跑感知模型反测(mAP/mIoU)+FID/FVD+跨帧跨视一致。GT 良定义来源：①条件↔视频天然对齐(真实日志标注=条件、采集视频=GT，唯一零成本全真)；②"编辑后"无天然真值，只能由可重演过程(仿真/NeRF·3DGS 重建重渲染/3D 资产合成)或"另一段真实片段"补 after；③定量语义(+20m/更快)良定义 = BEV 米制可测量。关键 tension：反事实无真值 ⇒ 要么牺牲"精确成对"(只用真实日志、编辑无 GT，靠分布/可控性间接评)，要么牺牲"全真"(引入仿真/合成/重建换精确 before-after 对)。
