Reconstruction · 以 Neural Turing Machine 接地

视觉图灵机 VTM：把感知·时序·多传感器·E2E·世界模型统一为一台可微读写记忆机

核心一句话：把视觉当 NLP——每一帧是新页、历史是旧书；用 Writer 把新页增量写入持久 Memory Bank，用 Reader 按需索引「记忆＋图像」做多任务 readout 与未来生成，backbone 做状态转移，Critic 做自评价。感知、时序融合、多传感器、E2E、World Model 生成，都是这台机器上「读 / 写 / 转移」的不同用法。面向 L4 真无人，通用于自驾与机器人。

⚠ 诚实边界：本页是 v1 设计思路 / 假说，用于对齐技术判断与实验方向，非既成结果。数学母体为 Neural Turing Machine（Graves et al., DeepMind, arXiv:1410.5401）。
TL;DR 第一性原理 NTM 母体 架构图 表征层 新页/旧书 Reader Writer Memory Bank 感知 readout 双头+生成 WM 六范式 训练信号 3D 加速 SA 通用性 NTM→VTM 映射 14 条映射 与 Plan A/B 待完善细节 可借力技术

TL;DR

视觉在时间上高度连续、极度冗余（新页≈旧页+小 delta），所以正确的表征不是每帧重编码整场景，而是持久记忆 + 增量写 + 按需读，对旧内容引用而非复制——这天然解掉「无限 context」。而 L4 真无人没有人兜底，系统必须是自包含、可自我修正的完整计算过程：读状态→计算→写状态→行动→自评价。这两点合起来，就是一台可微的图灵机，其严格母体正是 Neural Turing Machine：controller + 外部记忆矩阵 + 读/写头（内容+位置寻址）。VTM 把 NTM 从算法玩具搬到视觉连续流，用同一台机器统一：统一感知（检测即预测）、时序融合、多传感器、E2E 规划、World Model 生成、机器人具身。

① 第一性原理：为什么必然是「读写记忆机 / 图灵机」

不是类比，是从两条硬事实演绎出来的。
自然约束 1

视觉连续冗余 → 读写记忆

帧 t+1 ≈ 帧 t + 小 delta（新页几乎含旧页全部信息）。这与语言根本不同：语言里每 token 大体是新信息，视觉里每帧 ~99% 是旧信息。所以「每帧重新 tokenize 整场景」是错的表征（Plan A 每帧 7145 token 且 ∝V·T 线性膨胀、Plan B 每帧 19235 token/最细 14400 主导 O(N²)），正解是持久记忆 + 增量写 + 按需读，只对 delta 花算力、对旧内容引用而非复制。

自然约束 2

L4 真无人 → 图灵机

没有人类兜底，系统必须是自包含、可自我修正的完整计算过程。图灵机是计算的最小完备模型 (磁带, 读头, 写头, 状态转移, 停机/评价)：磁带=Memory Bank、读/写头=Reader/Writer、状态转移=backbone、停机·质量=Critic 自评价。NTM 把这套完全可微，能梯度下降训练——正好承接。

推论：视觉 WM 不该「从零生成」。CG / 文本可以从 0 起，视觉 / 机器人必须从参考帧出发。所以生成＝「读记忆里的参考 + 预测 delta」，而不是凭空画每个像素——这也是本设计与纯生成式 WM 的根本分野。

② NTM 母体：机制与公式（Neural Turing Machine, arXiv:1410.5401）

NTM ＝ controller + 外部记忆矩阵 + 可微读/写头（内容+位置寻址），全程可微、梯度下降训练。它是 VTM 的严格数学母体——用它接地是强化愿景，不是收窄。
记忆矩阵 Mt ∈ ℝN×M：N 个 location（记忆行/槽），每个是 M 维向量。读写头都发出一个归一化权重 wt（Σw=1, w≥0），决定"这次读/写落在哪些槽、各多少"——从锐利单点到弥散多点连续可调。这正是 Reader/Writer 在 Memory Bank 上寻址的原型。
§3.1 读

读＝对记忆的凸组合（软注意力读）

eq.2rt = Σi wt(i) · Mt(i)

读向量 = 各记忆行按权重加权和，对记忆与权重都可微。→ VTM 的 Reader。

§3.2 写＝擦+加

写＝先擦后加（LSTM 门的外存版）

eq.3M̃t(i) = Mt−1(i) · [ 1 − wt(i) et ] eq.4Mt(i) = M̃t(i) + wt(i) at

擦除向量 et∈(0,1)M 抹掉过时内容，加向量 at 写入新内容。→ VTM 的 Writer＝delta 写：这就是「新页更新旧书」的精确算子。

§3.3 寻址（关键：内容 + 位置两条互补机制）

权重 wt 怎么来

eq.5 内容寻址wct(i) = softmaxi( βt · K[ kt , Mt(i) ] ) eq.6 相似度K[u,v] = (u·v) / (‖u‖·‖v‖) （余弦） eq.7 插值门wgt = gt · wct + (1−gt) · wt−1 eq.8 移位卷积w̃t(i) = Σj wgt(j) · st(i−j) eq.9 锐化wt(i) = w̃t(i)γ / Σj w̃t(j)γ

内容寻址（eq.5,6，key kt 与记忆做余弦相似）＝按"长什么样"检索 → VTM 的 Reader 软注意力路（类 table cls）；位置寻址（eq.7-9，插值门 blend 上一帧权重 + 循环移位 + 锐化）＝按"在哪、往哪挪"检索 → VTM 里把它几何化成 3D-prior / ego 位姿寻址（Reader 几何路）。两者并用。

controller（§3.4）：LSTM 或前馈网络，吐出 heads 的全部参数 (k, β, g, s, γ, e, a)——对应 VTM 的 backbone / 状态转移。两条关键性质，正是 VTM 敢下注的依据：① 参数量不随记忆 size 增长（记忆是外挂的，不是塞进权重）；② copy 任务训练长度≤20，泛化到 100+——"外部可寻址记忆 → 学到算法而非把序列记死"，这就是「引用旧页解无限 context」的直接实证。

③ 架构：一台可微读写记忆机

传感器新页 → backbone 状态转移 → Writer 擦+加写入 Memory → Reader 双路索引 → 五个 head（感知 / 机器 / 人 / 生成 / 自评价）。

④ 表征层：Perceiver token + 持续训练的多任务 backbone

Perceiver token（记忆槽的内容）

Memory 的每个槽 = 一个有界、内容寻址的 Perceiver latent token，可携带 语义 / 实例 / 3D / 语言 属性（想法 2）。这是把感知的「为物体付费、与空间分辨率解耦」推广成通用记忆单元——对应 NTM 记忆行 Mt(i)∈ℝM。

backbone 多任务预训练 + 全程持续训练

图像 backbone 在 pretrain 阶段就注入 semantic / ins / 3D / language 监督（想法 3），让 Reader 有东西可读；且在 ft / posttrain 全程继续训练 backbone（想法 7，反 Plan A/B 冻结 tokenizer）——backbone 与 reader/writer/memory 协同适配。图像特征可缓存，充当"参考帧"供按需取细节。

⑤ 把视觉当 NLP：新页 / 旧书

每一帧是新页，历史是旧书。因为视觉连续，新页几乎包含旧书最后一页的全部信息，所以不重编码整场景，而是 Writer 把新增/变化（delta）写入记忆、对旧内容引用。这就是 NTM「参数不随记忆增长 + copy 泛化到 100+」在视觉流上的落地——用引用替代复制，解「无限 context」（想法 4、5）。更高层、长时的决策交给 long-term memory bank（想法 5）。

⑥ Reader（读头）：内容路 + 3D-prior 几何路 双路寻址

核心之一（想法 9）。对应 NTM 内容寻址（eq.5,6）与位置寻址（eq.7-9）的并用。
内容路

软注意力 / 内容寻址

以 task query 为 key kt，与记忆槽做余弦相似（eq.5,6）→ 软权重取记忆（"类 table cls"的内容检索，想法 6）。检索"长什么样"的东西。

几何路

3D-prior / ego 位姿寻址

把 NTM 的循环移位（eq.8）几何化：用相机内外参 / ego 位姿把 3D query 投影回图像与记忆，做确定性 location addressing（想法 6、14），同时拿 语义 + 3D 几何。比循环卷积更强的几何先验。

Reader 不只读记忆，还回图像索引取细节（图中虚线）：当任务要精细几何/语义时，Reader 投影回（可缓存的）图像特征补细节——这就是"从参考帧提取细节，而非每个 token 全背"（想法 13.7）。

⑦ Writer（写头）：erase + add ＝「新页更新旧书」的精确算子

NTM 的写就是擦+加（eq.3,4）：M̃t(i)=Mt−1(i)[1−wt(i)et] 抹过时、Mt(i)=M̃t(i)+wt(i)at 写增量。VTM 直接用它做 delta 写：因连续性，多数是刷新已有槽 + 新增少量（想法 5、9）。擦除向量 et ＝ 遗忘 / 淘汰门（哪些槽该抹）；加向量 at ＝ 新观测增量。多传感器 = 多 Writer 写同一记忆（想法 8）。

⑧ Memory Bank（磁带 / 旧书）

两级记忆

working memory：近帧、高细节，做时序融合（＝StreamPETR memory propagation 的 NTM 版，对应 eq.7 插值门 blend 上一帧权重）。long-term memory：压缩、承接高层 & 长时决策（想法 5）。

坐标系用几何 location addressing 接地

观测者在动，跨帧"引用旧页"需几何对齐。用 ego 位姿把记忆寻址几何化（把 ego-motion warp 纳入 location addressing）——这正是 NTM 位置寻址在物理世界的正确形态。淘汰/漂移/坐标系细节见 ⑳ 待完善细节。

⑨ 感知 readout：检测即预测

多 read head 从记忆读出任务向量（对应 NTM 多读头）——det / occ / lane / depth 都是同一记忆上的 readout（想法 8，兼容后处理）。
检测即预测。感知不是独立前处理，而是 Reader 在记忆上的一次 readout；预测（未来）与感知（当前）共用记忆，天然时序一致。occ 也用 token 生成：用 semantic token 表示占据，Reader 在 SA 时回图像索引——既可"类 table cls"内容检索、也可依 3D prior 投影索引，一次同时拿 语义 + 3D 几何（想法 6）。

⑩ 双头 head-M / head-H + 生成闭环

承接本站 「消费方决定输出模态」：机器吃表征、人看生成。
head-M · 机器

latent 直供决策

读出的 latent z′ 直接给规划 / 控制 / 感知，不渲染（想法 11「wm 提供 RL att」）。避免"表征→像素→表征"的有损往返。

head-H · 人

渲染像素

z′ 过 flow / diffusion decoder 幻化高真实像素（Plan B 的 Wan-VAE+flow 是现成候选）。只在给人看时才付这份算力。

生成闭环＝Writer 预测下一页的 add 向量（WM-Sampler）。训练目标＝新书 vs 旧书的 delta（想法 10）：预测"相对记忆的新增 / 不可预测部分"，天然稀疏——正好呼应「可预测内容（记忆已知 → head-M）与不可预测细节（head-H 幻化）干净解耦」。闭环（dream）可微，梯度回流 Reader/Writer/Memory（想法 10；NTM 本就全可微，是直接先例）。

⑫ 训练信号统一：E2E att + RL att + 闭环可微 + Critic

同一台机器，多种训练信号（想法 11）——E2E 与 WM 不是两个模型，是同一 reader/memory 的两种训练方式。
  • E2E-att（监督）：模仿 / 示教给 Reader、head-M 提供"该注意什么"的梯度。
  • RL-att（梦里 RL）：policy 在 WM「梦」里学"该注意记忆哪部分"，reward 塑形（Dreamer / TD-MPC2 谱系）。
  • 自监督生成目标＝新书 vs 旧书 delta：预测相对记忆的新增，天然稀疏、聚焦不可预测处（想法 10）。
  • 闭环可微：dream rollout 端到端可微，梯度回流 Reader/Writer/Memory（想法 10；NTM 全可微为先例，训练技巧见 ⑳）。
  • Critic 自评价（想法 11）：评自身状态/输出 → ① 数据配平（挖不确定/出错场景）② WM 数据生成（多生成这些场景）→ 喂回训练。外部锚（真实数据/人工/独立信号）为待补细节。

⑬ 3D 加速的 Self-Attention

视觉的 SA 起手就基于 3D 做加速，而非 vanilla 全注意力（想法 14）：用 token 的 3D 位置把注意力限制到几何邻域（体素局部 / Plücker 射线相对位置编码——Plan A 的 Plücker 是现成一路），O(N²)→稀疏，同时把几何当归纳偏置。它也正是 Reader 几何路（⑥）与 NTM 位置寻址（eq.7-9）的实现底座。

⑭ 通用性：自驾 + 机器人

这套"读写记忆 over 3D-grounded token"的抽象与本体无关（想法 12）：机器人只是换传感器 / 动作空间，同一台 Reader/Writer/Memory 机器照跑。面向世界交互，是通向 Physical AI 的统一底座——与本站发展路线图（阶段①先统一感知 → ④具身）一致。

度量

delta 的度量空间

把"新旧书 delta"放在任务 / latent 空间而非纯像素，让算力自动流向高惊奇的关键事件。候选：surprise = reader 任务头预测误差 / 特征空间距离。

记忆

有界记忆的淘汰准则

有界即有损，需 saliency / 不确定度 / 任务相关性驱动的写入 & 淘汰（＝Writer 的 erase 门 et），并可显式刻画"记住 / 忘了什么"。long-term memory 承接长时保持。

接口

head-H latent 接口

slot latent ↔ 稠密渲染 latent 对齐。候选：(a) VTM 兼带一路稠密 latent 供渲染；(b) 学 slot→grid 反 tokenizer / 神经渲染器；(c) 复用 Plan B Wan-VAE+flow 作起点再演进。取哪条由你定。

绑定

slot ↔ 物体（物体恒存）

delta 写预设 slot 与实体稳定对应，需显式绑定 / 匹配（借鉴 Slot Attention/SAVi、StreamPETR query 传播、匈牙利匹配）。

优化

闭环可微的训练技巧

全 BPTT 穿长 rollout 易不稳。候选：截断 BPTT / stop-gradient / Dreamer 式短程 + 目标网络——目标（梯度回流 memory）不变，技巧要选对（NTM 是先例，DNC 为后继）。

对齐

Critic 的外部锚

避免自评自训塌缩：Critic 需真实数据 / 人工 / 独立信号锚定后再驱动配平与 WM 生成。

⑲ 可借力的现成技术（把机制落到实处）

  • NTM / DNC：可微外存的数学母体与优化教训。
  • StreamPETR / Sparse4D(v2) / PETRv2 / BEVFormer-temporal：已实现"引用记忆而非重编码"的时序感知——reader/writer/memory 的工程起点与对照。
  • Perceiver-IO / Set Transformer（inducing points）：有界 latent 瓶颈（但非时序持久）——VTM 的增量正是"让它有状态"。
  • Slot Attention / SAVi(++) / STEVE：视频 object-token 与绑定机制先例。
  • Dreamer(RSSM) / Transformer-XL / Compressive / Memorizing Transformer："引用旧页 + 压缩长上下文"的真实技术。
  • OccWorld / GAIA-1&2 / DriveDreamer / Vista / MUVO：occ / 驾驶世界模型定位对照。
  • SLAM 回环 / 3DGS 持久场景：漂移 / 持久记忆的现成解，别重造。
