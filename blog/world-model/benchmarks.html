核心结论：能上 90+ 的几乎只有「分类 / ReID-Rank1 / 单目标 VOS / 指代理解 / 阈值深度」——都是封闭集、全局判别、单实例任务；而实例/全景分割(54–60)、开放词汇(16–23)、零样本检测(47)、相机 3D-MOT(34) 仍困在 30–70——密集预测 / 长尾 / 开放集 / 多实例。自动驾驶纯相机感知清一色未饱和：SSC(19)、单目 3D 检测(22)、Waymo 占用(21)、相机 3D-MOT(34)、nuScenes 占用(48)、6DoF 未见位姿(60)、3D 车道线(66)。SOTA 越低 = 数据越稀缺/越难刷 = World Model 数据引擎的靶区。 几何视觉(立体/深度/MVS/NVS/法向/光流/场景流/室内重建)多以物理误差(px·mm·dB)度量，其中立体匹配·MVS·NVS·场景流仍留明显空间——正是 WM 赖以成立的 3D 结构与多视几何一致性能力。
2026-07 全领域扩表至 780+（7+12 个 agent 跨 CVPR/ICCV/ECCV/ICLR/NeurIPS/AAAI + PapersWithCode 全量扫描、逐条核实）：新增交互/具身感知（手-物位姿·HOI·抓取·affordance·铰接·导航·操作）、人脸/属性、安全/异常（异常/深伪/伪造）、遥感/专域、以及几何/3D、驾驶闭环、视频生成等——其中交互/具身与开放集普遍未饱和（HOI 48、抓取 novel 30、MP3D 导航 47、开放词汇分割 16–23、跨库深伪 87–95），正是面向具身与灵巧手的下一片 WM 数据引擎靶区。
