Proposal · 灵巧手 & 交互

灵巧手与交互：手锚定尺度 × 交互帧相对表述

两个针对灵巧操作的本质判断，最后合成一条命题：①手是"在视野内的公制标尺"——纯视觉恢复 metric 的手-物相对 3D，需要一个在视野内的已知尺度锚；②动作应以"交互原点/接触帧"为中心做相对表述，而非全局/身体坐标系。两者共视时天然合一。

⚠ 方案/假说，用于对齐研究方向；相关工作为公开方法，具体接法需实验验证

① 手 = 在视野内的公制标尺（采集任务的本质区别）

单目 3D 本质是尺度不可解（ill-posed up to scale）。一张图里"大而远"和"小而近"完全等价，没有已知尺寸的参照就恢复不了绝对 metric scale（SfM 只能恢复到相似变换）。人靠站在地上当标尺估深度；自驾 BEV 靠已知相机高度 + 地平面反投影拿尺度。操作场景里，手就是那把随身的公制尺——它已知尺寸/运动学，且和被交互物共视在同一帧，比地面更贴近交互点（桌面近距场景里地面标尺失效）。
本质的采集分野——但"必须在 view 里"要加一个限定：
  • 纯视觉、无本体感知（尤其从人类视频学）：手在视野里几乎必要——没有 proprioception，可见的手是唯一的尺度+位姿锚。这让本判断在"从 egocentric/网络视频学灵巧操作"这条大数据路线上尤其有力。
  • 机器人有 proprioception：正运动学直接给出手的 3D 位姿，不看手也知道 → 严格说非必要；但共视仍高价值——给出免标定的手-物相对几何，不依赖 camera↔base 外参精度/漂移。
精炼表述："从纯视觉恢复 metric 的手-物相对 3D，需要一个在视野内的已知尺度锚；手（或地面/已知物）就是那个锚。无 proprioception 时，手在视野内近乎必要。"
相关工作：HOI 重建用手锚定尺度（DexYCB · HO-3D · OakInk · ContactPose）；MANO 参数化手模型给已知尺寸；NOCS 给物体规范尺度；BEV 用相机高度当尺度；单目 metric 深度（Metric3D · UniDepth）在无锚点时依旧吃力。

② 交互原点 / 物体中心 + 手做 relative formulation

现状：多数具身工作的动作空间仍用全局 / 机器人 base / 末端执行器坐标系；物体中心更多在感知里，较少进动作表述。
三个硬收益：① 不变性→泛化（"抓把手"天然相对物体定义，换位置是同一 formulation）；② 数据效率（同技能塌缩、方差骤降）；③ 可等变（动作随物体帧一致变换，可上 SE(3)-equivariance）。
把"物体中心"再推一步 → 用"交互原点/接触帧"：对铰接/接触密集任务（开门、拉抽屉、拧阀门），真正的不变中心是功能点/接触点/铰链轴，不是物体质心。以接触帧为原点比"物体几何中心"更精确、更可迁移——这正是你说的"交互原点"，建议明确为接触点/功能轴优先。
相关工作：Transporter Networks（object-centric pick-place）· kPAM（关键点功能帧）· NDF / R-NDF / TAX-Pose（物体相对 SE(3)，少样本迁移）· SE(3)-equivariant 策略（EDF · EquiBot · Equivariant Diffusion Policy）· Where2Act / VAT-Mart（铰接功能/affordance）。

交互帧要先估出来

canonical pose / 关键点 / descriptor field 的估计误差会传导；NDF 类用等变特征缓解。

挑战

动态跟踪

操作中物体在动 → 交互帧要在线跟踪，不能只估一次。

挑战

执行落地仍需外参

object-frame 动作最终要转回 base/相机帧执行 → 仍需 object↔robot 外参。收益在表示与学习，非消灭标定。

③ 合成：两点其实是一件事

点① 让你在一帧里同时拿到手与物的 metric 相对几何；点② 就把动作建成"相对交互帧"的表述。手+物共视 → 直接回归手相对物的变换（免全局标定）→ 天然就是 object/interaction-centric 的 relative formulation。合成命题：
手锚定尺度 × 交互帧相对表述 ×（可选）SE(3) 等变 —— 一套"纯视觉、免标定、可迁移"的灵巧操作表示，尤其吃得下人类视频这个大数据源（无 proprioception 也能学）。
和"按消费方分叉"那条 proposal 接上：这个"手锚定 + 交互帧的相对表征"，正是 head-M（机器消费方） 该吐给下游策略的那种 latent——自带尺度、自带交互帧、跨本体不变，不需要先渲染成像素再重编码。
诚实边界：本页是方案 / 假说，用于对齐研究方向，非既成结果。所引相关工作（DexYCB/HO-3D/OakInk/MANO/NOCS/Transporter/kPAM/NDF/TAX-Pose/EDF/EquiBot/Where2Act/VAT-Mart 等）为公开方法；"手锚定 + 交互帧相对 + 等变"三者的具体接法与稳定性需实验验证。示意图为概念示意、非精确几何。与本站 原创方案、路线之争 互为呼应。
