Routes · 路线之争

世界模型的不同路线：李飞飞 / LeCun / NVIDIA Cosmos / 其他

"世界模型"不是一条路，而是被不同学派各自定义。核心分歧在三个轴：①在什么空间建模（像素 / 抽象表征 / 显式3D）· ②生成还是预测判别 · ③为谁服务（数据引擎/仿真 · 规划 · 空间交互 · 视觉统一）。本页横向对比主流路线，并纳入新论文 Vision as Unified Multimodal Generation 作对照。与「方法全景」互补：那页按方法/范式罗列 33 个工作，本页按学派/人物的技术哲学分野。

✅ 确证（已读/公开立场明确） ~ 公开但细节/闭源待核 ◆ 本次新增 reading
一句话本质：大多数"世界模型"想建模世界的动力学（给定观测+动作，预测下一刻）；分歧在于——LeCun 认为要在抽象表征里预测（别造像素）；NVIDIA/Sora/Wayve 直接生成像素/视频当仿真与数据引擎；李飞飞 押注显式 3D 空间（空间智能）；DeepMind Genie 造可交互可玩世界；Dreamer 在隐空间"做梦"训 RL。而 SenseNova-Vision 走一条相邻但不同的路：把所有视觉任务统一成一次多模态生成（不是建世界动力学，而是统一视觉表达）。

逐路线详解

非生成·表征预测（JEPA）Yann LeCun · Meta✅
核心主张：别在像素里建世界
世界模型应在抽象表征空间做联合嵌入预测（JEPA），用能量式目标，不重建像素、不做自回归像素生成——因为像素级细节大多不可预测且浪费算力。服务理解与规划。
代表：I-JEPA(图) · V-JEPA / V-JEPA 2(视频, 2025，面向理解+预测+规划) · DINO-WM。立场：LeCun 长期公开反对"纯生成式=世界模型"。
空间智能 · 3D 世界李飞飞 · World Labs~
核心主张：智能的下一步是"空间智能"
押注显式/隐式 3D：从单图/文本生成几何一致、可交互、可持久漫游的 3D 世界，而非仅 2D 视频。融合生成 + 3D 重建（NeRF/3DGS 谱系）。
代表：World Labs(2024 创立；李飞飞/Justin Johnson/Ben Mildenhall/Christoph Lassner) 的 Large World Models。~：创业公司、多为官方 blog/demo，产品细节待核。
生成式视频 WFMNVIDIA · Cosmos✅
核心主张：生成即数据引擎 + 仿真
大规模生成式世界基础模型：扩散 WFM + 自回归 WFM + 视频 tokenizer，动作/相机可控，为 Physical AI（机器人/自驾）造训练数据、做闭环仿真。预训练通才 → 后训练专才。
代表：Cosmos (2025)。源码级精读见 Cosmos 精读教学（Tokenizer/WFM 各章）。
交互可玩世界Google DeepMind · Genie~
核心主张：学出"可玩"的世界
从海量视频无监督学出潜在动作，生成逐帧可交互的世界（按动作展开下一帧），可当 agent 的训练场/游戏引擎。
代表：Genie 1(2024) → Genie 2 → Genie 3。~：技术 blog/论文，能力边界随版本演进。
视频 = 世界模拟器OpenAI · Sora~
核心主张：够大的视频生成 = 隐式世界模型
大规模视频生成，官方称"world simulators"——隐式学到部分物理/一致性。动作可控弱，更偏内容生成。是否算"真世界模型"业界有争议（LeCun 一派持否定）。
代表：Sora (OpenAI, 2024, 技术报告)。
RL 隐空间想象D. Hafner · DeepMind✅
核心主张：在"梦"里训练策略
用 RSSM 在隐空间建模动力学，agent 在"想象轨迹"里训练 → 极高样本效率。是最早成体系的"世界模型"用法。
代表：Dreamer V1/V2/V3（V3 一套超参跨 150+ 任务、无人类数据挖到钻石）· TD-MPC2。
自驾生成式 WMWayve / GigaAI 等✅
核心主张：造自驾数据 + 闭环仿真
多视图驾驶视频生成，条件于驾驶动作，造长尾/危险场景、渲染新轨迹做闭环仿真。动作可控性来自车队真实数据自带的驾驶控制。
代表：GAIA-1/2(Wayve) · Vista · DriveDreamer(4D) · MagicDrive · Panacea。逐方法见 方法全景 E/F 类。
◆ Vision as Unified Multimodal GenerationSenseTime(商汤) · arXiv 2607.06560 · 2026-07-07✅ 已核
本次新增 reading · 相邻对照路线："视觉即统一多模态生成"
把计算机视觉整体形式化为"统一多模态生成"：异构视觉任务全部用一个统一多模态模型的原生「文本+图像」生成空间来表达，无任务专用架构/预测头。模型 SenseNova-Vision 用自然语言指令 + 可选视觉提示指定任务/目标区域/解码约定，输出：符号结果→文本、稠密空间预测→图像、组合任务→图文混合。配套构建 SenseNova-Vision Corpus（把各类 CV 标注转成"指令-响应"样本）。一个模型覆盖检测/OCR/关键点/分割/深度/法向/点图/相机位姿，并支持语言定义的任务变体（类别+颜色+区域组合）。
作者：Xiaoyang Han, Jianhua Li … Zhongang Cai 等。
为什么纳入对比：它不建模世界动力学（不预测"动作后世界怎么变"），而是把所有视觉任务统一成一次生成——正对应本站发展路线图 ① 里说的"unified vision model / 一个 task formulation"。它是"通用视觉"方向的一个具体实例，与世界模型是相邻但不同的赛道：世界模型问"未来会怎样"，它问"用一个模型把所有视觉任务一次答完"。

◆ SenseNova-Vision
商汤·统一视觉		off-the-shelf 预训练统一多模态模型无任务专用头：符号→文本 / 稠密→图像 / 组合→图文所有视觉任务 = 统一多模态生成，语言指令定义任务起于预训练统一多模态模型主训 SenseNova-Vision Corpus（CV 标注→指令-响应）+ 多模态数据保能力✅
横向读 5 个维度看出的分野：① Backbone 高度收敛到扩散 DiT 与自回归 Transformer 两大类（RSSM/JEPA 是少数派）；② Head 最本质的分叉是生成像素/3D（Cosmos/Sora/GAIA/Marble）vs 预测表征（V-JEPA2）vs 预测价值（Dreamer）；③ Task Formulation 从"纯生成"走向"动作条件"（GWM-1/Oasis/GAIA/Dreamer）是共同演进方向；④ Pretrain 几乎都靠海量视频自监督（Dreamer 例外=在线 RL）；⑤ Post-train 是把通才变专才的关键——Cosmos/GWM-1/GAIA 都靠后训练落到自驾/机器人/具身，正对应本站路线图②③④。
怎么串起来看：如果把"视觉能力"分两问——"看懂/统一表达"（SenseNova-Vision 这类统一视觉生成）与 "预测未来/可交互"（世界模型）——那么 统一视觉模型是底座，世界模型是在其上加"动作→未来"的动力学。LeCun 强调后者要在表征里做；生成派(Cosmos/Sora/Genie/World Labs)强调直接造出可看/可交互/可漫游的世界。这也解释了本站路线图的顺序：先把统一视觉模型刷到 SOTA（①），再往上叠世界模型的动作可控与闭环（②③④）。
