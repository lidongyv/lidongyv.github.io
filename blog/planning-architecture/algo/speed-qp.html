OSQP 分段-jerk 纵向速度优化

路径形状定下来后，在这条路径上求速度曲线 s(t)：状态 [s,v,a]、jerk 为段间控制，在 5 s / 51 点上解一个凸二次规划（OSQP），同时满足舒适、跟车安全（RSS / IDM）、限速与准时停车。是 SpeedOptimizer 阶段。

解决的问题

横向只决定了「车走哪条线」，但「在这条线上多快走、何时让、何时停」是另一个维度。纵向速度规划要同时满足：

  • 舒适：加速度、jerk 在限内，避免顿挫。
  • 跟车安全：与前车保持安全距离 —— 用 RSS（最坏制动假设）+ IDM（期望车头时距）双重软上界，更鲁棒。
  • 限速 / 让行 / 停车：服从地图与曲率限速，对让行/停车障碍按时减速到点。
  • 实时：10 Hz 必须毫秒级出解 —— 建成凸 QP，OSQP 保证快且全局最优。
⚙️

实现

PiecewiseJerkSpeedProblem · OSQP

调用链：SpeedCorridorConstructor 给出 SVT 边界 + 沿 s 的限速 → SpeedOptimizer 逐时刻从 SVT 取可通行 [s_lower, s_upper]，按障碍决策算出三组上界（硬 / RSS 软 / IDM 软）和 v 上界，构造 QP 交 OSQP。

决策变量与目标（min ½zᵀPz+qᵀz）
z = [ s₀..sₙ₋₁, v₀.., a₀.., e(slack) ] // 目标逐项 ∑ 10·(sᵢ−s_ref)² 贴合参考 s ∑ |κ(sᵢ)|·vᵢ² 曲率限速 ∑ aᵢ² + ∑ jᵢ² 加速度/jerk 平滑 ∑ (RSS/IDM/v/a slack)² 软约束惩罚
约束
// 初始状态(来自 stitch 末点) s₀,v₀,a₀ = 固定 // 运动学连续性(梯形积分) vᵢ₊₁−vᵢ−½Δt(aᵢ+aᵢ₊₁)=0 sᵢ₊₁−sᵢ−Δt·vᵢ−Δt²/3·aᵢ−Δt²/6·aᵢ₊₁=0 // 盒约束 + 软上界 sᵢ∈[s_lo,s_hi] 0≤vᵢ≤v_max a,j∈[min,max] sᵢ+eₖ≤s_follow

跟车上界：YIELD/FOLLOW/STOP 时硬上界 s_upper−basic_buffer；RSS 软上界含反应时间 ρ 与前后车制动距离差；IDM 软上界 s₀+v·T+v·Δv/(2√(ab))。输出后处理：强制单调 sᵢ=max(sᵢ,sᵢ₋₁), vᵢ=max(vᵢ,0)；低速到点触发滞回 → GenerateComfortStopProfile 直接给停车曲线、绕过 QP。
