横向走廊 · Nudge 决策

为横向优化器准备「每个 s 处横向 l 能落在哪个区间」：把车道边界、lidar freespace、路沿 curb、OCC 占据、动静态障碍逐层合成，并在过程中决定对每个障碍往左绕 / 往右绕 / 让行，最终裁出带 buffer、按车宽收缩的 final_soft_lb/ub 交给 CiLQR。

解决的问题

优化器要避障，但不能直接吞下杂乱的原始感知。横向走廊把多源信息「翻译」成优化器能用的横向可行区间 + 避障方向：

  • 统一异构来源：地图车道、freespace、路沿、OCC 栅格、障碍框，量纲/语义各异，要合成统一的 l ∈ [lb, ub]。
  • 先定避障方向：对每个障碍预判往左还是往右绕（nudge），避免优化器在两侧间反复横跳。
  • 留安全裕度：加 nudge buffer、按车宽 shrink、保证最小走廊宽，给下游留容错。
⚙️

流程：InitSLBoundary 采样 → ConstructKinematicBoundary（最小转弯半径在 Frenet 法向投影）→ ConstructLaneBoundary（地图车道 + OCC/freespace/curb）→ 静/动障碍（NudgePreDecider 出 LEFT/RIGHT/YIELD）→ MergeFinalBound（按优先级合并）→ UpdateFinalBound（加 buffer、运动学裁剪）→ PostProcessSLBoundary（最小宽、车宽 shrink）。各层结果分层存进 SLBoundPoint。
