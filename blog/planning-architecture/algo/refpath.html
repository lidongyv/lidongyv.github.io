粗参考路径 (Reference Path)

在 Frenet 坐标下快速生成一条「贴目标车道、绕开障碍」的横向曲线 l(s)：先用五次多项式暖启动，再用 OSQP 分段-jerk QP 平滑（默认）。它既是 CiLQR 精修的初值打底，也是 keep / borrow / change 等多模态候选的来源。

解决的问题

非线性优化器（CiLQR）和图搜索都对初值敏感 —— 没有好的暖启动，迭代慢、易陷局部最优。粗参考路径就是为此而生：

  • 给打底初值：快速产出一条满足车道约束、绕障的 l(s)，作为 CiLQR 的参考与起点。
  • 提供多模态候选：同一帧并行生成 保持 / 借道 / 换道 等多条参考路径，交给 ReferenceTrajectorySelector 选优。
  • 解耦决策与精修：把「往哪偏、绕哪侧」的 nudge 决策放在这一层先定，精修层只管把它做平滑可行。
⚙️

实现

RefathOsqpOptimizer (默认)

每个生成器（以 KeepInLane 为例）的流程：

步骤做什么类 / 算法
① Frenet 初值自车 Cartesian → Frenet，得 [s,ds,dds]/[l,dl,ddl]CartesianToFrenetExt
② 暖启动曲线起点 (l,dl,ddl) → 终点 (end_l,0,0) 的五次多项式Quintic
③ nudge 决策逐障碍 LEFT/RIGHT/YIELD 预决策，生成分层 SL 边界NudgePreDecider
④ 凸平滑默认对 l(s) 解分段-jerk QP；enable_ilqr_refpath=true 时改用 CiLQROSQP
// 五次多项式暖启动（满足两端 l, dl, ddl 边界） l(s) = a₀ + a₁s + a₂s² + a₃s³ + a₄s⁴ + a₅s⁵ // OSQP 分段-jerk：状态 [l, dl/ds, ddl/ds²]，与纵向同一套内核 min ∑ wₗ(l−l_ref)² + w_dl·dl² + w_ddl·ddl² + w_dddl·dddl² s.t. 初值 + 连续性 + SL 软走廊

5 类生成器按场景分流：KEEP_INLANE / KEEP_BORROWLANE（借道）/ CHANGE_INLANE（换道，用目标参考线）/ PARKING / E2E。参考 l_ref 即各自的 goal.end_l。
