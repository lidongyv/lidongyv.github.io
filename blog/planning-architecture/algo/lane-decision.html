借道 / 换道 / Gap 决策

决定「什么时候变道、要不要借道绕障、汇入选哪个空隙」——这些离散横向决策直接改写参考线与走廊，需要在安全（后车 / gap）与效率（少堵、跟导航）之间权衡。由 LaneGuider + LaneBorrowDecider + GapManager 三件套协作。

3 件套
换道/借道/Gap
≤15 m/s
借道速度上限
±80 m
Gap 考虑范围

借道确认/退出滞回
🎯

解决的问题

横向优化器只会「在给定参考线和走廊里求最优路径」，但「该不该换到隔壁车道、前方死车要不要借对向道绕、并线插哪个空当」是上游的离散决策，决定了优化器看到的参考线与走廊长什么样。

  • 换道：跟导航（必须换）与图效率（换了更快）之间权衡，且要确认目标车道安全。
  • 借道：本车道被静障/死车堵住时，临时借相邻或路外空间绕行，过后回原车道。
  • 选 Gap：汇入/换道时在目标车道车流里挑一个安全又省时的空隙，并把它告诉速度搜索。
⚙️

实现

LaneGuider · LaneBorrowDecider · GapManager
换道 · LaneGuider
Precheck → ObstacleTracer → HardEndDecider → Evaluator
Evaluator 综合 Deviation（跟导航）+ Efficiency（效率）+ Pullover（靠边） 代价，输出 LC 状态机：KEEP / PREPARE / CHANGE / HOLD / FINISH / CANCEL。CHANGE 切到目标参考线、end_l→0；HOLD 保持原线 end_l=±0.5。
借道 · LaneBorrowDecider
触发 → available LEFT/RIGHT
条件：非换道态 + 车速 ≤ 15 m/s + 非路口 + 前方 blocking/dead_car（3 帧滞回确认）。效果：把走廊上/下界扩展到相邻车道（无邻道再加 off-lane 宽），但仍用原车道参考线。
汇入 · GapManager
枚举 gap → 推演 → 选最优
目标车道 ±80 m 障碍排序 → 枚举 gap → 对 (v_diff, acc) 采样用 AdcPathSample 推演自车轨迹 + SafetyChecker + 代价 → 选最优 gap → 注入 HTS 作目标 s 启发。

多模态选优：上述决策并行产出 keep / prepare / change / borrow 多条参考路径，最终由 ReferenceTrajectorySelector 选一条。开 enable_multi_gap_search 时每个 gap 还各跑一次 HTS。
