Hybrid A* 泊车搜索

泊车场景独立于行车主链路：在狭窄空间、含倒车 / 换向的非完整约束下，用 Hybrid A* 在 (x,y,θ) 连续空间做运动学扩展 + Reeds-Shepp 解析连接，搜出无碰撞几何路径。由 ParkingRefLineGenerator 调用，不经 CiLQR / QP 横向优化。

解决的问题

泊车与行车是两类问题：行车沿车道走、横纵解耦即可；泊车要在极窄空间里精确对位，且往往必须倒车、来回打方向（换向）。这让普通的车道参考线 + 横向优化失效：

  • 非完整约束：车不能横向平移，转弯半径受限，路径必须满足自行车模型。
  • 离散机动：前进/倒车、多次换向是组合搜索问题，凸优化无法表达。
  • 强碰撞约束：车位四周都是墙/车，要逐点检查车体多边形不碰撞。

因此泊车用 Hybrid A*：在栅格化的 (x,y,θ) 空间用运动学可行的弧段扩展节点，配 Reeds-Shepp 解析段在近目标时一蹴而就。

// 状态：连续 (x,y,θ) + 网格索引 Δθ = Δs · tan(δ) / L_wb x' = x + 圆弧/直线积分(Δs, θ, δ) // 前进/倒车 ±step，多档转向角 δ
代价 g
g = 路径长 × (倒车 / 换向 / 转向 / 转向变化 惩罚) + ESDF clearance 净空惩罚
启发 + 解析展开 + 碰撞
  • 启发：优先 Reeds-Shepp 距离（含倒车的最短曲线），否则 Manhattan。
  • 解析展开：近目标时用 RS / LineArc 一段直接 shot 到终点（shot_distance 内触发）。
  • 碰撞：GridMapCollisionDetector + lidar freespace + OCC + 静态障碍 + 车位 U 型约束。

与主链路关系：Hybrid A* 不在 proc_ppl Optimizer 内，由 ParkingRefLineGenerator::RunSearch 调用，搜索结果转成 parking_reference_line 后再进 DataPreprocessor → CoarseTrajectoryGenerator → ParkingRefPathGenerator，且 Optimizer 横向跳过 CiLQR，直接透传搜索路径。
