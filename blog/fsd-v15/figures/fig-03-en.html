Encoder

Universal Vision Encoder (UVE) × L

self-attention / FFN · F: N × D @ 18 Hz (Musk) · temporal features are carried here

Tokenizer

4D scene token S × D (compact implicit)

Fixed size; a V14 explicit instance token can be kept in parallel. All tasks train together by default, no task prompt. Once UVE is strong enough, the explicit token and its perception head are dropped together.

↓
TRAININGfour task sets · no task prompt
Set A / 4D dense

4D video prediction (basic)

NVS / 3DGS / depth are sub-tasks of the same set; trains the NVS decoder and geometric consistency.

Set B / 4D sparse

AD perception

object detection · tracking · occupancy · segmentation · TLD · depth/flow.

Set C / Planner

Planner

multi-modal trajectory prediction · agent prediction · interaction / RL / closed-loop.

Set D / Language

Language

caption · caption-based style transfer · pose as language · instance inpainting; interacts with the other three sets.

INFERENCEonly trajectory + lightweight NVS
Planner

Trajectory + Safety → action

multi-modal trajectory and safety are the two planner submodules; output is steer + accel.

NVS decoder / lightweight

any-view NVS

conditioned on the 4D UVE scene token + any camera pose; temporal features read UVE directly.

Spatial SRTemporal SR

Optional / removed first

V14 explicit token + perception head

Kept while UVE is weak; dropped once it is strong. Inference keeps only trajectory + lightweight NVS.
