Lossy interface

实例列表是有损的：它把场景表达成实例集合，非实例语义会丢失；scene token 通过重建保留这些信息。

V15 / SCENE-CENTRIC

隐式 4D 场景是接口

HYPOTHESIS
Input

7 cams · 36 Hz

same pixels, more general encoder

↓
Encoder

UVE · general pretrain

internet video + fleet + 4D NVS

↓
Compact token

one dominant 4D scene token

forced to carry geometry + appearance + dynamics

4D NVS gradient instance queries (optional)
↓
Interaction

trajectory head ↔ scene token

fixed-size tensor, cheaper attention, easier fusion

↓
Action

steer + accel

aux heads can be dropped at inference

Why it matters

如果场景 token 能重建任意新视角，它就必须编码遮挡、深度和动态一致性——这些恰好是规划需要的。
