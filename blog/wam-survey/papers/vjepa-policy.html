V-JEPA Policy：在预测性视觉潜空间上构建有效 WAM

V-JEPA Policy: Building Effective WAMs on Predictive Visual Latents
arXiv:2609.37250 ｜ 清华 / 中科院等 ｜ 2026-09 ｜ 代码对比页 ｜ arXiv

核心贡献

中文：指令条件的未来潜预测器 + 流匹配动作专家从零联合训练；0.9B 总参/0.6B 可训；分布偏移下优于视频生成式 WAM。

English: An instruction-conditioned future-latent predictor and a flow-matching action expert are jointly learned from scratch; 0.9B total / 0.6B trainable; beats video-generative WAMs under distribution shift.

原文断言（摘要）+ 中译

原文（Abstract，verbatim）we introduce V-JEPA Policy, a simple framework that builds a WAM on the latent space of a frozen V-JEPA 2.1 encoder.
中译（译者译，非论文原文语言）我们提出 V-JEPA Policy——一个在冻结 V-JEPA 2.1 编码器的潜空间上构建 WAM 的简洁框架。

核心机制（原文 + 中译）

原文（论文方法节，verbatim）We encode the task instruction with a frozen T5 encoder and concatenate the resulting text tokens with one state token projected from q_t to form a conditioning sequence.
中译（译者译）用冻结 T5 编码指令，把文本 token 与一个由 q_t 投影的状态 token 拼接成条件序列。

物理意义冻结 V-JEPA 2.1 提供预测性视觉潜；动作专家以未来潜的逐层 K/V 为条件。
为什么这么做不必继承完整视频生成器：预测潜足够支撑 WAM，省参数。
方法出处论文 §3.1（L2）；ViT-L 0.3B + predictor 0.5B + action 0.1B。
优势与代价优势：0.9B 总参、分布偏移下更强；代价：依赖编码器质量，预测器与动作专家需联合训练。

# 冻结编码器 + 未来潜预测器 + flow-matching 动作专家（§3.1）
ctx   = VJEPA21.encode(obs)                       # 冻结 ViT-L，tubelet=2
cond  = concat(T5(instruction), proj(q_t))        # 文本 + 1 个 proprio token
Z_hat = predictor(ctx, cond, mask_queries)        # 单次前向预测未来潜
kv    = predictor.layerwise_kv                    # 逐层 K/V 作为动作条件
a     = action_expert.sample(cond=kv, steps=10)   # 0.1B DiT，流匹配
