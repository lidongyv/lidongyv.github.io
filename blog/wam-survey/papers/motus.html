物理意义光流是像素级「动作痕迹」，压成 14 维潜动作后，动作预训练不再依赖动作标签。
为什么这么做互联网视频没有动作标签；用光流当代理动作，可把大规模视频转成动作预训练数据。
方法出处论文 §4.1/§4.2（L2）；仓库 thu-ml/Motus 可查实现；DPFlow→DC-AE→14 维。
优势与代价优势：一模型五模式、潜动作可跨本体；代价：光流在遮挡/透明物体上不可靠。

代码类型：论文伪代码（按 §4.1/§4.2 结构化）。仓库 thu-ml/Motus（README 与 config 可见）；真实执行动作为 14 维 qpos。

# 潜动作构造（论文 §4.2；L2）
flow   = DPFlow(video_pair)                  # 光流
rgb    = flow_to_rgb(flow)                   # 转 RGB 图
tokens = DC_AE(rgb)                          # 4 × 512 tokens
z_act  = proj(concat(tokens))                # 14 维潜动作（10% 标注数据弱监督）

# 三专家 MoT + UniDiffuser 调度器（§4.1）
h_text = Qwen3_VL(prompt)                    # 理解专家
h_vid  = Wan2_2_5B(video_latents, cond=h_text)   # 生成专家
a      = ActionExpert(h_vid, z_act)          # 动作专家
