Rolling-WAM：滚动想象的世界动作模型

Rolling-WAM: World Action Models with Rolling Imagination
arXiv:2609.30247 ｜ USC / TRI 等 ｜ 2026-09 ｜ 代码对比页 ｜ arXiv · 项目页

核心贡献

中文：维护错峰噪声的视频-动作块滑动窗口：每步只完全去噪最近的块、部分精炼更远的块；稳态重规划提速 4.5×。

English: Maintains a sliding window of video-action chunks at staggered noise levels; fully denoises the imminent chunk each step while partially refining farther ones; 4.5x steady-state replanning speedup.

原文断言（摘要）+ 中译

原文（Abstract，verbatim）We present Rolling-WAM, a formulation that distributes joint denoising across successive replanning cycles.
中译（译者译，非论文原文语言）Rolling-WAM 把联合去噪分摊到连续的多个重规划周期上。

核心机制（原文 + 中译）

原文（论文方法节，verbatim）At each step, a rolling noise schedule fully denoises the imminent action chunk for execution, while partially refining farther-future chunks.
中译（译者译）每一步的滚动噪声调度完全去噪即将执行的动作块，同时部分精炼更远的未来块。

物理意义错峰噪声把「想象未来」的成本摊到多个控制周期：近端块先干净可执行，远端块继续演化。
为什么这么做每周期从头去噪整段未来太慢；滑动窗口复用上一周期结果。
方法出处论文 §III（L2，03b 笔记）；参数 K=16/W=5/N=10/ρ=5。
优势与代价优势：4.5× 重规划提速；代价：窗口/噪声调度敏感，跨 chunk 动作不可见。

代码类型：论文伪代码（按 §III 结构化）。参数 K=16/W=5/N=10/ρ=5 来自 L2 笔记 03b；真机 G1 78-D（64 SONIC + 7×2）。

# 错峰噪声 + 滑动窗口（§III；参数见 03b 笔记）
def rolling_step(window, obs, K=16, W=5, rho=5):
    for j, chunk in enumerate(window):                # j=1..W
        σ = rho * (j/W) / (1 + (rho-1) * (j/W))       # 近端低噪声、远端高噪声
        chunk.add_noise(σ)
    for _ in range(2):                                # 稳态每周期 2 步
        video, action = denoise_joint(window, obs, N=10)
    window.pop(0); window.append(new_chunk(action))
    return action[:K]                                 # 执行 16 步
