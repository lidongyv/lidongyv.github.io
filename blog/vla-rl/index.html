核心结论速览

  1. A 的表达 = BEV waypoint 是车场景共识（控制量只有 DriveGPT4 一家）；实现分「数值回归头」与「数值转文本 token 自回归」两路。
  2. V 的显式监督是三档光谱而非二元：全显式（可 debug、贵）→ 半显式 → 零显式 compact token（数据便宜、黑盒）；EMMA 证明纯自监督可行但依赖大预训练+大数据。
  3. L 的位置决定架构：输入指令 / 输出 meta-action 决策 / 全文本化 / 仅训练期蒸馏（VLP 推理零开销）；语言中间层能涨点（EMMA +3.0%/+1.5%）。
  4. 语言输入是把双刃剑：ICR-Drive 与 Language2Drive 证明当前驾驶 VLA 的指令跟随不可靠——必须固定词典 + 成对反事实评测。
  5. RL post-training 的成熟配方：SFT → 冻结 backbone + LoRA/动作头 + 可验证奖励（PDMS）+ GRPO/PPO/TD3 + KL + Best-of-N；遥操接管当负样本（ConRFT）。
