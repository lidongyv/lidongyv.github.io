CVPR 2026   Finalist

NuWa: Deriving Lightweight Class-Specific Vision Transformers for Edge Devices

Ziteng Wei ⋅ Qiang He ⋅ Bing Li ⋅ Feifei Chen ⋅ Hai Jin ⋅ Yun Yang
CVF 官方 PDF ⬇Scholar

摘要 Abstract

Vision Transformers (ViTs) often need to be compressed for deployment on resource-constrained edge devices like drones and smart vehicles. However, existing model compression methods ignore that many edge devices only require the knowledge of specific classes for their applications. As a result, the derived all-class ViTs retain redundant knowledge and perform suboptimally on these classes. We discovered that simply replacing the calibration dataset with class-specific data does not suffice to address this issue, as these methods face two fundamental limitations. First, they overlook the existence of class-detrimental weights, which interfere with specialization, while removing them can improve class-specific performance. Second, the diversity of target classes and resource constraints on edge devices demand numerous customized models. Existing methods are time-consuming and computationally expensive, thus unscalable. In this work, we present NuWa, a cost-efficient method that addresses these challenges by deriving small ViTs from base ViTs for edge devices with specific class requirements. NuWa performs self-knowledge purification to prune class-detrimental weights and efficiently derives compact ViTs through closed-form optimization. Without post-pruning retraining, the derived edge ViTs surpass the base ViT in class-specific accuracy and accelerate inference. Comprehensive experiments demonstrate that NuWa outperforms state-of-the-art training-free pruning methods on class-specific tasks by up to 29.00\% in accuracy. Compared with the best-performing training-dependent pruning method, NuWa achieves a 33.69× pruning speedup and reduces pruning cost by up to 99.83\%, with only a 0.61\% average accuracy loss.

📝 精读笔记

灵魂一句
边缘设备（无人机/智能车）往往只需识别少数特定类，但通用 ViT 压缩方法保留了全类知识、在目标类上反而次优。NuWa 发现 ViT 里存在"类有害权重"——剪掉它们能让模型在目标类上更准（less is more / "免费午餐"），且常规重要性指标找不到它们。NuWa 用 自知识净化(SKP) 学二值 mask 自动找并剪掉这些权重得到"又小又更准"的 anchor model，再用闭式优化(OFP，SVD+最小二乘) 免重训快速压到目标算力。比训练型剪枝快 33.69×、省成本最高 99.83%，精度仅掉 0.61%。
问题 & 动机
两个被忽视的事实：① 类无关知识浪费容量——智能车只需认行人/车/交通标志，花/鸟知识无用且拖累目标类性能；现有结构化剪枝只追求"减小尺寸"，是 class-agnostic 的。② 即使换成 class-specific 校准数据也不够，因为现有方法有两大硬伤：(a) 忽视类有害权重（它们的目标=让剪枝后模型模仿原模型，天然假设"剪枝必掉点"，永远超不过 base）；(b) 时间/算力贵——类多、设备资源各异 → 需大量定制模型，而现有法要搜配置+重训（图 3：单模型剪+重训 ~5 小时、$30-90），无法规模化。
核心方法（+关键公式）
两步（图 5）：
① SKP 自知识净化：冻结 base ViT，在每个 MLP 的下采样权重 W₂ 前嵌入可学习 mask 向量 M⁽ˡ⁾ 与控制因子 β⁽ˡ⁾，二值化构造剪枝空间——M_bin[i]=1 当 M[i]≥第⌊eₗ·σ(β)⌋大值，否则 0（式3）；M_bin[i]=0 即剪掉 W₁ 第 i 行 + W₂ 第 i 列。用 STE(直通估计器)解二值化不可导，仅用原任务 loss L_T + class-specific 数据 D_S 训练（更新 <0.05% 参数、batch=1），自动识别并剪类有害权重 → 得 anchor model V_A（式5-6）。
② OFP 闭式快速剪枝：MHA 剪 QK/VO 维（这俩是 W_QK=W_QᵀW_K、W_VO=W_VᵀW_Oᵀ 的中间维、与输入无关→剪枝结果可跨所有子任务共享）→ 转成低秩逼近 min‖W_QK−W'_QK‖_F（式7），由 Eckart-Young 定理用 SVD 求闭式最优解（式8），按能量比 ρ 自适应定保留维度（式9）；MLP 按均值激活保 top-e' 神经元 + 闭式最小二乘补偿 W₂'=W₂HᵀH_r(H_rᵀH_r)†（式12）。全程无重训。
关键结果
6 模型(DeiT-B/S/T、ViT-L、Swin-T)×4 数据集(ImageNet/CIFAR-100/10/COCO)。最震撼：SKP 的 anchor model 平均剪 22.61% 却把类特定精度提升 15.84%（无重训），几乎追平"全量微调"的 DeiT-Base（如 |S|=10：97.67 vs 微调 97.80）。vs 训练-free 最强(Numerical Pruning)在剪枝率 0.60 时高出 29.00%、比 base ViT 高 20.60%。vs 训练-dependent 最强(X-Pruner/RECAP/MDP)：免重训即达其 99.35–100.23% 精度，轻量微调(10 epoch)再反超 2.00–2.82%；效率 33.69× 加速、精度仅掉 0.61%。
亮点
① 提出并实证 "类有害权重" 这一新现象（图1：随机剪 DeiT-Base 的 MLP 神经元竟提升 25 类精度），且证明 magnitude/activation/gradient/Taylor 四种常规指标都抓不到（图4）；② SKP 让"剪枝后超过 base"成为可能（打破"剪枝必掉点"假设）；③ 闭式解免重训（SVD+最小二乘）把定制成本从小时级降到分钟级；④ MHA 的 QK/VO 剪枝结果跨子任务共享，大规模部署省冗余计算。号称首个 class-specific ViT 派生方法。
疑问
① 高剪枝率(0.60)+大子任务(|S|=50)时 NuWa 免重训会掉到 85.83（低于部分基线），需 FT 才稳——免重训的甜区在中低剪枝率；② 依赖每个子任务跑一次 SKP（虽轻），子任务极多时累积成本如何？原文未给 SKP 在超大规模子任务下的总开销曲线；③ "类有害权重"的机理（为何存在、是否过拟合 artifact）论文以实证为主、理论解释较浅；④ 主要在分类(+检测)验证，分割/生成等密集任务是否同样有"类有害权重"未测。

📚 背景知识（外部，非本文原文）
① ViT 的 MHA + MLP：Transformer block=多头注意力(MHA，每头有 W_Q/W_K/W_V/W_O)+前馈 MLP(W₁ 升维到 eₗ 个神经元、W₂ 降回)。剪枝即减少头/QK-VO 维/MLP 中间维。NuWa 主要剪 MLP 神经元与 MHA 的 QK/VO 维。
② 结构化 vs 非结构化剪枝 / 量化 / 蒸馏：非结构化剪枝(剪单个权重)与低比特量化需专用推理基建，不通用于异构边缘设备；知识蒸馏需合适 student 且从头训贵。结构化剪枝(剪整行/列/维)产出规则形状、易部署、可继承 base 参数→NuWa 选它作基础。
③ training-free vs training-dependent 剪枝：前者按重要性指标(magnitude/activation/gradient/Taylor)剪、不重训→快但目标=模仿 base、永超不过 base；后者剪中/后重训→能注入类知识但慢且贵。NuWa 想兼得：免重训 + 能超 base。
④ STE / Eckart-Young 定理 / 校准集：STE(直通估计器)=前向用二值化、反向用连续梯度代理，解二值 mask 不可导。Eckart-Young 定理=秩-k 截断 SVD 给出 Frobenius 范数下最优低秩逼近——NuWa 据此把"剪 QK/VO 维"变成 SVD 闭式解。校准集=剪枝时用来估激活/重要性的少量数据(NuWa K=128 张)。
② §1 Introduction · problem → solution → why 闭环
problem：边缘设备只需特定类，但 (a) class-agnostic 压缩(图2a)缺定制→次优；(b) class-specific 剪+重训(图2b)仍留类有害知识且耗时。关键反常发现(图1)："pruning certain weights can increase the accuracy of DeiT-Base on these 25 classes"——随机剪 MLP 神经元竟提升特定类精度，揭示类有害权重存在，且常规重要性指标抓不到(图4)。
solution：NuWa(图2c)=① SKP 冻结 V_B、嵌可学习 mask+控制因子，"Without additional regularization terms, V_B can leverage the original task loss L_T and class-specific data D_S to identify and prune the class-detrimental weights autonomously" → 得更小更准的 anchor model V_A；② V_A 不一定满足资源约束 → 把 MHA/MLP 剪枝形式化为优化问题求闭式解(OFP)免重训快速压到目标。
why：① SKP 是"发现 ViT 内免费午餐"——既然有害权重存在，剪掉就是净赚(更小+更准)；② 闭式解(analytical solution)避开重训，可复用中间结果，新类/新剪枝率不必从头剪——这正是大规模异构边缘部署的刚需。
③ §3 Method · 核心机制 + 关键公式
SKP 构造剪枝空间（式3-4）：每个 MLP 在 W₂ 前嵌 mask M⁽ˡ⁾∈ℝ^{eₗ} 与控制因子 β⁽ˡ⁾∈ℝ。二值化 M_bin[i]=1 if M[i]≥Sel_{⌊eₗ·σ(β)⌋}(M) else 0（Sel_k=第 k 大值，σ=sigmoid）；σ(β) 控制保留比例。M_bin 进前向(式4)，=0 即剪 W₁ 第 i 行+W₂ 第 i 列。β 初始化 5.0(σ≈1)保证嵌入后等价原模型(function-preserving)。只对 MLP 做 SKP(经验上比也做 MHA 好)。
SKP 净化（式5-6）：STE 解二值不可导——M_bin 的梯度 G 当 M 的代理梯度、⟨M_bin,G⟩当 β 的代理梯度；用 D_S 在原任务 loss L_T 下训 M、B；最后按 M_bin 剪 MLP 得 anchor model V_A。更新 <0.05% 参数、batch size 1(小 batch 让探索更充分)→ 极高效。
OFP 剪 MHA（式7-9）：剪 QK 与 VO 维(比剪整头压缩潜力大)。因 W_QK=W_QᵀW_K、W_VO=W_VᵀW_Oᵀ 是两次乘法的中间维、与输入 X 无关 → 剪枝结果可跨所有子任务共享。min‖W_QK−W'_QK‖_F 是低秩逼近 → SVD 闭式(式8)；按平均能量比 ρ(保留奇异值能量/总能量)自适应定 q'/v'(式9)，调 ρ 平衡 MHA/MLP 剪枝强度。
OFP 剪 MLP（式10-12）：各 block 剪到相近大小 e'(式10，避免某 block 过剪)。前向 V_A 于 D_S 得每神经元均值激活，保 top-e' 个(索引 I_r)；为补偿剪枝损失，闭式最小二乘 min‖HW₂ᵀ−H[I_r]W₂'ᵀ‖_F → W₂'=W₂HᵀH_r(H_rᵀH_r)†(式12，†=伪逆)、W₁'=W₁[I_r]。基于式8/12 即可免重训派生边缘 ViT V_E。

②′ §2 Related Work · 结构化剪枝两类 + 本文定位
为什么选结构化剪枝当地基：低比特量化与非结构化剪枝 “often require specialized infrastructure for inference, which limits their applicability to framework-diverse edge devices”；知识蒸馏 “does not always provide a suitable student model with an appropriate size”。结构化剪枝 “produces regularly shaped models that are easy to deploy on diverse edge devices and can transfer knowledge from the parameter space of the base ViT for initialization”——规则形状、易部署、可继承 base 参数，故 NuWa 以它为基础(且可与量化/蒸馏叠加)。
两类结构化剪枝都不够（本文靶子）：① training-free(Magnitude/Wanda-sp/Numerical)按重要性指标剪、不重训——但 “their objective is to make the pruned models mimic the base model”，且 “inherently assume that pruning always leads to accuracy degradation”，所以 “the derived models can never surpass the base model on target classes”。② training-dependent(X-Pruner/DC-ViT/RECAP/MDP)剪中/后重训、能注入类知识——但 “still fail to remove class-detrimental weights”，且 “retraining often takes a long time and incurs excessive computational overhead”，不可规模化。NuWa 要两者兼得：免重训 + 能超 base。
Q&A · "class-detrimental weights" 是什么？为何重要性指标找不到？
定义：在类特定派生场景下，存在一类权重——把它们剪掉反而提升模型在目标类上的精度(Fig 1：随机剪 DeiT-Base 的 MLP 神经元，25 类精度从 baseline 意外上升)。直觉：base ViT 为"全类"训练，含大量服务非目标类 \(S^c=Y\setminus S\) 的知识；这些权重在只关心 \(S\) 时不仅冗余，还会把输入误分到非目标类、挤占容量 → 对目标类"有害"。
为何常规重要性指标抓不到：magnitude / activation / gradient / Taylor 这些指标衡量的是"权重对整体/原任务输出的贡献大小"，目标是"剪掉贡献小的、尽量不掉点"。但"类有害权重"往往对原全类任务贡献不小(所以指标值不低、不会被剪)，却专门有利于非目标类。Fig 4 实测：用 class-specific 数据算这四种指标去剪，精度都无法超过 base。所以必须换思路——让模型自己在类特定 loss 下学出该剪谁(SKP)。
③′ §3.1 Preliminaries · MHA/MLP 公式（LaTeX）
MHA（式1）：输入 \(X\in\mathbb{R}^{N\times d}\)(N 个 d 维 patch token)，第 \(l\) 块第 \(h\) 头的注意力：
\[ A^{(l,h)}=\mathrm{Softmax}\!\Big(\tfrac{XW_Q^{(l,h)\top}W_K^{(l,h)}X^\top}{\sqrt{q_l}}\Big)\,XW_V^{(l,h)\top}W_O^{(l,h)\top} \]
权重 \(W_{Q|K}^{(l,h)}\in\mathbb{R}^{q_l\times d}\)、\(W_V^{(l,h)}\in\mathbb{R}^{v_l\times d}\)、\(W_O^{(l,h)}\in\mathbb{R}^{d\times v_l}\)。MLP（式2）：对 \(e_l\) 个神经元加权求和：
\[ \mathrm{MLP}^{(l)}(X)=\sum_{i=1}^{e_l}\phi\big(XW_1^{(l)}[i]\big)\otimes W_2^{(l)\top}[i] \]
\(W_1^{(l)}\in\mathbb{R}^{e_l\times d}\)、\(W_2^{(l)}\in\mathbb{R}^{d\times e_l}\)、\(\phi\)=GELU、\(\otimes\)=外积。子任务：\(Y\)=base ViT 的全类集，目标子集 \(S\subset Y\)，类特定数据 \(D_S\)，要派生边缘 ViT \(V_E\) 只感知 \(S\)。
④ §3.2 SKP · 构造剪枝空间 + 二值化（LaTeX Eq3/4）
思路：没有先验告诉哪些权重是"类有害"、有多少个，所以学二值 mask 自动找。冻结 base ViT \(V_B\)，在每个 MLP 的下采样权重 \(W_2^{(l)}\) 前嵌入可学习 mask 向量 \(M^{(l)}\in\mathbb{R}^{e_l}\) 与控制因子 \(\beta^{(l)}\in\mathbb{R}^1\)，二值化构造剪枝空间（式3）：
\[ M^{(l)}_{bin}[i]=\begin{cases}1,& M^{(l)}[i]\ge \mathrm{Sel}_{\lfloor e_l\times\sigma(\beta^{(l)})\rfloor}(M^{(l)})\\[2pt] 0,& \text{otherwise}\end{cases} \]
\(\mathrm{Sel}_k(v)\)=向量 \(v\) 第 \(k\) 大值、\(\sigma\)=sigmoid——即 \(\sigma(\beta^{(l)})\) 决定每层保留比例(可学)。
掩码进前向（式4）：\[ \mathrm{MLP}^{(l)}(X)=\sum_{i=1}^{e_l}\phi(XW_1^{(l)}[i])\otimes\big(M^{(l)}_{bin}[i]\cdot W_2^{(l)\top}[i]\big) \]
\(M^{(l)}_{bin}[i]=0\) 即剪掉 \(W_1\) 第 \(i\) 行 + \(W_2\) 第 \(i\) 列(结构化)。\(\beta^{(l)}\) 初始化 5.0(\(\sigma(5.0)\approx1\))保证嵌入掩码前后等价(function-preserving)。只对 MLP 做 SKP(经验上比同时做 MHA 更好)。
④′ §3.2 SKP · STE 净化 + anchor model（Eq5/6）
STE 解不可导：二值化不可导，用 straight-through estimator——\(M^{(l)}_{bin}\) 的梯度 \(G^{(l)}\) 作 \(M^{(l)}\) 的代理梯度，内积 \(\langle M^{(l)}_{bin},G^{(l)}\rangle\) 作 \(\beta^{(l)}\) 的代理梯度。用类特定数据 \(D_S\) 在原视觉任务 loss \(L_T\)(如 cross-entropy)下更新 \(M=\{M^{(l)}\}\)、\(B=\{\beta^{(l)}\}\)——无需任何额外正则项，模型自主识别并剪类有害权重。
剪枝得 anchor（式5/6）：\( W_1^{(l)}=W_1^{(l)}[I(M^{(l)}_{bin})],\ W_2^{(l)}=W_2^{(l)}[:,I(M^{(l)}_{bin})] \)，其中 \( I(v)=\{i\mid v[i]\ne 0\} \)。得到更小且在目标类更准的 anchor model \(V_A\)(原文称"发现 ViT 内的免费午餐 / free lunch")。极其高效：SKP 只更新 \(V_B\) 不到 0.05% 的参数，且小 batch(=1)能让 \(V_B\) 在剪枝空间探索更充分(Fig 10)。
⑤ §3.3 OFP · 剪 MHA（低秩近似 + SVD，Eq7/8/9）
为什么剪 QK/VO 维而非整头：① 细粒度维度比剪整头压缩潜力更大；② \(W_{QK}=W_Q^\top W_K\)、\(W_{VO}=W_V^\top W_O^\top\in\mathbb{R}^{d\times d}\) 是两次乘法的中间维、与输入 \(X\) 无关 → 剪枝结果可跨所有子任务共享，大规模部署省冗余计算。以 QK 为例，形式化为(式7)：
\[ \min_{W_Q',W_K'}\ \big\|W_Q^{(l,h)\top}W_K^{(l,h)}-W_Q'^{(l,h)\top}W_K'^{(l,h)}\big\|_F^2,\quad q_l'\lt q_l \]
这是低秩逼近 → SVD 闭式最优：由 Eckart-Young 定理，秩-\(q_l'\) 截断 SVD 给出 Frobenius 范数下最优逼近(式8)：\( W_Q'=(U_{QK}[:,:q_l']\Sigma_{QK}[:q_l',:q_l'])^\top\sqrt{q_l'/q_l} \)、\( W_K'=V_{QK}[:,:q_l']^\top \)(VO 维同理)。能量比 \(\rho\) 自适应定维度（式9）：保留奇异值能量占比，剪到满足 \( \frac{1}{H_l}\sum_{h=1}^{H_l}\big(\sum_{i=1}^{q_l'-1}\sigma_{QK}^{(l,h,i)2}\big/\sum_{i=1}^{q_l}\sigma_{QK}^{(l,h,i)2}\big)\lt\rho \)；调 \(\rho\) 即平衡 MHA 与 MLP 的剪枝强度(\(\alpha\) 越大、最优 \(\rho\) 越小、越多剪给 MHA)。
⑤′ §3.3 OFP · 剪 MLP（闭式最小二乘，Eq10/11/12）
均匀分配 + 选神经元（式10）：为避免某些 block 过剪，各 block 剪到相近大小 \( e_l'=\min(e_l,\lfloor(\sum_{i=1}^{L}e_i-e_{prune})/L\rfloor) \)。前向 \(V_A\) 于 \(D_S\) 得每神经元均值激活 \(a_i^{(l)}\)，并采 \(K\) 张图取块激活特征 \(H^{(l)}\in\mathbb{R}^{(KN)\times e_l}\)；保留激活最高的 top-\(e_l'\) 神经元(索引 \(I_r^{(l)}\))。
闭式补偿（式11/12）：为最小化剪枝带来的知识损失，解最小二乘 \( \min_{W_2'}\ \|H^{(l)}W_2^{(l)\top}-H^{(l)}[I_r^{(l)}]W_2'^{(l)\top}\|_F^2 \)，闭式解：
\[ W_1'^{(l)}=W_1^{(l)}[I_r^{(l)}],\qquad W_2'^{(l)}=W_2^{(l)}H^{(l)\top}H_r^{(l)}\big(H_r^{(l)\top}H_r^{(l)}\big)^{\dagger} \]
其中 \(H_r^{(l)}=H^{(l)}[I_r^{(l)}]\)、\(\dagger\)=Moore-Penrose 伪逆。基于式8/12，NuWa 不重训即可把 \(V_A\) 压成目标算力的边缘 ViT \(V_E\)。
Q&A · 为什么闭式解能免 retraining？中间结果怎么复用？
免重训的本质：training-dependent 方法剪完要靠 SGD 重训"恢复"精度；NuWa 把"剪哪些 + 剩下的权重怎么调"直接写成有解析解的优化问题——MHA 是低秩逼近(SVD 给全局最优)、MLP 是线性最小二乘(伪逆给全局最优)，一步算出最优补偿权重，无需迭代训练。复用(大规模部署的关键)：派生时间分 P1/P2/P3——P1(MHA 的 SVD)data-free，可跨不同子任务和剪枝率复用；P2(SKP + 一次前向取激活/特征)可跨不同剪枝率复用；P3(MLP 式12)不可复用但开销可忽略。所以服务 \(N\) 子任务×\(M\) 设备时，绝大部分计算被摊薄 → 这正是 33.69× 加速、99.83% 降本的来源。

📌 全文一页总结（problem → method → experiment → takeaway）
problem：边缘设备只需特定类，通用 ViT 压缩保留冗余类知识→目标类次优；class-specific 剪枝又漏掉"类有害权重"且重训慢贵不可规模化。
method：NuWa=SKP(冻结 base，学二值 mask+STE，用原任务 loss 自动识别并剪类有害 MLP 权重→更小更准 anchor)+OFP(MHA 的 QK/VO 维 SVD 低秩闭式解、可跨子任务共享；MLP top 激活+最小二乘补偿闭式解)，全程免重训。
experiment：6 模型×4 数据集；anchor 仅 SKP 剪 22.61% 升 15.84% 精度≈全量微调；比训练-free 高达 +29.00%、比训练-dependent 快 33.69× 且精度仅掉 0.61%。
takeaway：剪枝不一定掉点——存在"类有害权重"，剪掉是免费午餐；把剪枝转成闭式优化(SVD+最小二乘)可免重训快速定制。
诚实边界：高剪枝率+大子任务免重训会掉点(需 FT)、类有害权重的机理解释偏实证、密集任务未验证。
