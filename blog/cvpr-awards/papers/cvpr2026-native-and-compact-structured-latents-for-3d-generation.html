Native and Compact Structured Latents for 3D Generation

Jianfeng XIANG ⋅ Xiaoxue Chen ⋅ Sicheng Xu ⋅ Ruicheng Wang ⋅ Zelong Lv ⋅ Yu Deng ⋅ Hongyuan Zhu ⋅ Yue Dong ⋅ Hao Zhao ⋅ Nicholas Jing Yuan ⋅ Jiaolong Yang
arXiv PDF ⬇arXiv 摘要Scholar
一句话：清华×微软 4B image-to-3D，field-free 稀疏体素 O-Voxel + SC-VAE(16×) + flow-matching DiT，任意拓扑 + 完整 PBR，最高 1536³。

摘要 Abstract

Recent advancements in 3D generative modeling have significantly improved the generation realism, yet the field is still hampered by existing representations, which struggle to capture assets with complex topologies and detailed appearance. This paper present an approach for learning a structured latent representation from native 3D data to address this challenge. At its core is a new sparse voxel structure called O-Voxel, an omni-voxel representation that encodes both geometry and appearance. O-Voxel can robustly model arbitrary topology, including open, non-manifold, and fully-enclosed surfaces, while capturing comprehensive surface attributes beyond texture color, such as physically-based rendering parameters. Based on O-Voxel, we design a Sparse Compression VAE which provides a high spatial compression rate and a compact latent space. We train large-scale flow-matching models comprising 4B parameters for 3D generation using diverse public 3D asset datasets. Despite their scale, inference remains highly efficient. Meanwhile, the geometry and material quality of our generated assets far exceed those of existing models. We believe our approach offers a significant advancement in 3D generative modeling.

📝 精读笔记

灵魂一句
把 3D 资产直接编码成 field-free 稀疏体素 O-Voxel（同时存几何+材质），用高压缩 SC-VAE（16×） 压成 compact 的 native structured latent，再上 4B flow-matching 做 image-to-3D——任意拓扑 + 完整 PBR、最高 1536³、推理秒级。是 TRELLIS/SLAT 的"原生 3D 输入 + 更省 token"升级版。
问题 & 动机
现有 3D 表示三大硬伤：① field-based(SDF/Flexicubes) 建不了 open/non-manifold/enclosed 拓扑；② 多数只管 shape、忽略 appearance/material；③ SLAT[xiang2025structured] 虽联合几何+外观，但靠 multiview 2D 特征输入 + 纯渲染监督，复杂结构/材质捕获不足。
核心方法（三件套）
① O-Voxel：omni-voxel，编码 geometry+appearance；Flexible Dual Grid 处理任意拓扑、PBR 材质(含 opacity 半透明)、与 mesh 秒级双向转换(optimization-free + rendering-free)；② SC-VAE：residual autoencoding 做 16× 空间下采样，1024³ 全纹理资产 → ~9.6K latent token；③ 4B flow-matching DiT：latent 空间 image-to-3D，512³ ~3s / 1024³ ~17s / 1536³ ~60s(H100)。

① Abstract（摘要）— 讲解
原文大意：3D 生成的真实感最近大涨，但仍被"表示"卡脖子——现有表示难捕获复杂拓扑 + 细节外观。本文从 native 3D 数据学一个 structured latent：核心是新的稀疏体素结构 O-Voxel(omni-voxel，同时编码几何+外观)，能 robust 建模任意拓扑(开/非流形/全封闭)、捕获超越纹理色的完整表面属性(如 PBR 参数)；基于它设计 Sparse Compression VAE 给出高压缩率的 compact latent；在该 latent 上训 4B flow-matching 模型做 3D 生成；推理高效，几何+材质质量远超现有。
逐句拆解：
1) 卡在"表示"：3D 生成真实感涨了，但 representation 仍是瓶颈(复杂拓扑+细节外观捕不住)。
2) native 3D 数据：直接从 3D 资产学 latent，而非 SLAT 那样从 multiview 2D 渲染特征——"native"是相对 SLAT 的关键词。
3) O-Voxel = omni-voxel：一个稀疏体素结构同时编码 geometry+appearance(几何+外观一体)。
4) 任意拓扑：open(开面)/non-manifold(非流形)/fully-enclosed(全封闭内部)——这些正是 field-based(SDF) 的死穴。
5) PBR 参数：不止 RGB 纹理，还有 metallic/roughness/opacity 等物理材质 → 可重光照。
6) SC-VAE：高空间压缩率 → compact latent(token 少)。
7) 4B flow-matching：大模型在 latent 空间做生成，公开 3D 数据训。
8) 高效+高质：推理快，几何/材质远超现有。
一句话抓 Abstract：TRELLIS.2 = native 3D 输入 → O-Voxel(几何+PBR、任意拓扑) → SC-VAE 16× 压缩成 compact latent → 4B flow-matching 生成，又快又比现有强。
📚 背景知识（外部，理解 TRELLIS.2 必备）
① 前作 SLAT / TRELLIS（Xiang 2024，本文一作前作）：SLAT=Structured LATent，把 3D 资产编码成"稀疏体素位置 + 每个 active voxel 的 latent 特征"。其 latent 来源=从 multiview 渲染图提 DINOv2 特征、反投影聚合到 voxel（间接、靠 2D 渲染）。TRELLIS 在 SLAT 上用 rectified flow 生成，可解码成 3D Gaussian / Radiance Field / Mesh。本作(TRELLIS.2)三点升级：SLAT 从 multiview 2D 建(间接)→本作从 native 3D 建(直接)；SLAT token 多(压缩率低)→本作 SC-VAE 16× 压缩、token 少(1024³→~9.6K)；SLAT 复杂几何/材质捕获弱→O-Voxel 任意拓扑 + 完整 PBR。
② flow-matching（Lipman 2023）：与 diffusion 同类但更简洁的生成范式。学一个 velocity field v_θ(x,t)，把高斯噪声分布连续"流"到数据分布。训练用直线插值 x_t=(1−t)·x_0+t·x_1(x_0 噪声/x_1 数据)，网络回归 velocity (x_1−x_0)；推理从噪声沿 velocity field 用 ODE 积分(少步)到数据。比 diffusion 路径更直、步数更少、训练更稳。本作=4B flow-matching DiT 在 latent 空间做 image-to-3D。
③ SDF/Flexicubes 为何建不了开放面/非流形/封闭：SDF=每点到表面的有符号距离(内负外正)，表面=零等值面。"符号"要求 well-defined 内外→几何必须 watertight(水密)+manifold(流形)。开放面(纸/布，无体积)没内外→符号未定义；非流形(三面共一边)内外歧义；全封闭内部结构被"内部"符号吞掉、提不出。Flexicubes(Shen 2023)是可微 iso-surface 提取(改进 Dual Marching Cubes)，但底层仍是 grid+等值面思路→继承同样的拓扑限制。O-Voxel 的 "field-free"(无场)就是不用 SDF/符号、直接用 mesh 与体素边的交点(Hermite data)+Dual Contouring 变体→任意拓扑。
Q&A · flow-matching DiT 是什么实现的（§3.3，提前问）
DiT 通用：Diffusion Transformer(Peebles&Xie 2023)——把 latent 当 token 序列、用纯 Transformer(self-attn+FFN)做 backbone 替代 U-Net，timestep/条件用 AdaLN 注入；flow-matching 下 DiT 输出 velocity field v_θ(把噪声"流"到数据)。
本作实现(§3.3)：full DiT + flow-matching，extend SLAT/TRELLIS。三阶段三个 sparse DiT：① sparse structure(预测体素 occupancy 布局，哪些 voxel active)→② geometry(active voxel 内 geo latent)→③ material(PBR latent，条件=image+生成的 geo latent，对齐几何)。前两阶段沿用 SLAT，material 阶段是本作新增。token=active voxel 的 latent(稀疏体素结构本身就规整、可 transformer 处理)。
架构细节(§3.3/§4)：AdaLN-single 调制(PixArt)+RoPE 位置编码(better scalability + 跨分辨率泛化)；受益 SC-VAE 高压缩→丢掉 SLAT 的 conv packing + skip connection → vanilla-style sparse DiT(更简单高效)；image 条件用 DINOv3-L 特征；classifier-free guidance drop 0.1。每个 DiT ~1.3B(width 1536 / blocks 30 / heads 12 / MLP 8192)，3 个共 ~4B。渐进训练 512³(32³ latent)→1024³(64³ latent)，conditioning image→1024；32 H100，bs 256，AdamW lr1e-4/wd0.01。
Q&A · DiT/flow/SC-VAE 实现细节 7 问
1 AdaLN 怎么做：标准 LayerNorm y=γ⊙norm(x)+β 的 γ/β 是固定学习参数；AdaLN 让 γ/β 由条件(timestep t + image c)经一个小 MLP 动态算出。原始 DiT 用 AdaLN-zero(额外 gating α 初始化 0→残差初始为恒等、稳训练)；本作用 AdaLN-single(PixArt，全局共享一组 base modulation + 每层小偏移，省大量参数)。
2 DiT 输出怎么监督(flow-matching loss)：采 x_0~N(0,I)噪声、x_1~data latent、t~U(0,1)；直线插值 x_t=(1−t)x_0+t·x_1；目标速度=dx_t/dt=x_1−x_0；loss=E‖v_θ(x_t,t,c)−(x_1−x_0)‖²(MSE 回归)。即监督 DiT 输出"从噪声指向数据的速度"。
3 ODE 积分怎么实现(推理)：从 x_0~N(0,I) 解 dx/dt=v_θ(x,t,c) 从 t=0→1；最简 Euler：x←x+Δt·v_θ，分 N 步(如 25-50)，每步调一次 DiT 算速度；可用高阶 solver(Heun/DPM-solver)少步高精度。比 diffusion 步数少。
4 RoPE：Rotary Position Embedding(Su 2021 RoFormer)——不是加性 PE，而是按位置旋转 Q/K 向量(每对维度旋转角=位置×频率)；旋转内积性质让 q_m·k_n 只依赖相对位置 m−n→天然相对位置、外推/跨分辨率泛化好、不增参数。3D 下对 voxel (x,y,z) 坐标各分一段维度旋转。
5 SC-VAE 怎么实现(§3.2)：fully sparse-conv U-VAE(非 transformer)。① Sparse Residual Autoencoding(借 DC-AE)：下采样把每 voxel 8 个 children 聚到 channel(stack 8C→avg_groups→2C)、上采样 channel→space(unstack→dup)，non-param shortcut 缓解高压缩优化难；② Early-pruning upsampler(xcube)：上采样前预测 child mask ρ∈{0,1}^8 跳过 inactive，省时省内存；③ ConvNeXt-style residual block(1 conv + wide point-wise MLP 替代 2 conv)。两阶段训练：S1 直接 O-Voxel 重建(dual vertex v 用 MSE、face flag δ/mask ρ 用 BCE、mat 用 L1)+KL；S2 加 rendering loss(渲 mask/depth/normal 用 L1+SSIM+LPIPS，相机放浅 near plane 切过表面→逼模型捕内外结构)。16× 空间下采样。
6 图像哪来给 DINO：训练=每个 3D 资产在 Blender 渲 16 views(随机 FoV+光照)当 image prompt(3D↔渲染图自动配对，自监督式)；推理=用户给的任意真实图 或 AI 生成图(eval 用 100 张 AI 图保证训练-测试不重叠)。图过 DINOv3-L 提特征做 conditioning。
7 为什么三个 DiT：三阶段条件链：① sparse structure(预测 occupancy 布局，哪些 voxel active)→② geometry(active voxel 内几何 latent)→③ material(PBR latent，条件=image+生成的 geometry)。必须先定 sparse layout 才能在其上生成 geo/mat(sparse DiT 需知 token 在哪)；shape/material 用两个 decoupled VAE 做 sequential→支持"给定 shape 补 material"的应用。前两阶段沿用 SLAT，material 阶段本作新增。
Q&A · RoPE / Early-pruning / 动态图 / SC-VAE / TRT 深入
RoPE 工作原理：把 Q/K 向量维度两两配对(每对看成复平面一个点)，位置 m 的 token 第 i 对旋转角 m·θ_i(θ_i=10000^(−2i/d)，不同对不同频率)，旋转矩阵 [[cos,−sin],[sin,cos]]。关键：旋转矩阵性质 R(mθ)ᵀR(nθ)=R((n−m)θ)→内积 q_m·k_n 只依赖相对位置 (n−m)。钟表类比：每 token 是指针、位置把它转 m 刻度，两指针"夹角"(内积)只取决于刻度差=相对位置，绝对转多少不影响。好处=相对位置感知 + 外推/跨分辨率好 + 零参数。3D 对 (x,y,z) 各分一段维度旋转。
Early-pruning Upsampler 实现：上采样把 coarse voxel→8 children 之前，一个小预测头输出该 coarse voxel 的 child mask ρ∈{0,1}^8(logits→sigmoid→阈值)，只对 active child 做后续 sparse conv、inactive 直接丢；训练用 O-Voxel 真实 occupancy 的 BCE 监督 ρ(式6 λ_ρ 项)。避免在空 child 上浪费算力/显存。
计算图固定吗：不固定——sparse conv + early-pruning 让 active voxel 数数据依赖，每次前向 tensor shape/算子规模都不同→动态计算图，这是稀疏体素网络的固有特性。
SC-VAE 数据流(1024³ 例)：O-Voxel@1024³(active voxels，每个带 f^shape+f^mat)→encoder 4 次 2× 下采样(1024→512→256→128→64)=16×→latent 在 64³ sparse grid(~9.6K active token)。每次下采样=Sparse Residual Autoencoding(8 children stack 到 channel 8C→avg_groups 降 2C 的 non-param shortcut)+ConvNeXt 式 residual block(1 conv + wide point-wise MLP)。decoder 镜像上采样(64³→1024³)，每步=early-pruning 预测 child→channel→space(unstack)→sparse conv，末端重建 dual vertex v / face flag δ / material。训练 S1=O-Voxel 重建(v→MSE、δ/ρ→BCE、mat→L1)+KL；S2=+rendering loss(相机浅 near plane 切表面捕内外)。
三个 DiT 串行(非并行) + TRT：⚠️ 纠正：三个 DiT 是串行条件链(structure→geometry→material，后者依赖前者输出)，不是并行。TRT 难点不在"三个"(可分别转、串行调用)，而在 sparse conv + 动态 shape + 自定义算子：active voxel 数据依赖→动态 shape(TRT 偏好固定 shape，需 dynamic-shape profile 或分桶)，submanifold sparse conv TRT 不原生支持→需自定义 plugin。本文用 Triton 优化的 submanifold conv(非 TRT)。原文未讨论 TRT 部署，此为工程推断。
Q&A · 用途/价值 & 与 World Model 的关系
用途(澄清误解)：这是 image-to-3D 生成(一张图→造全新 3D 资产)，不是"重建已有物体"；论文里 reconstruction(Table1)只是评测 VAE 压缩保真(中间环节)。价值=3D 内容创作降本(游戏/影视/AR/电商/3D 打印)，卖点=生成资产自带完整 PBR + 任意拓扑 → 直接进渲染/游戏引擎、美术不用返工材质。跟自驾感知不直接相关，间接可作仿真/合成数据工具。
与 World Model 关系(诚实)：TRELLIS.2 不是 world model——静态 3D 资产生成，无时间/动态/action/预测(world model 核心是 dynamics rollout)。三层间接关联：① 技术栈共享(flow-matching DiT + AdaLN/RoPE，很多视频/世界模型也用)；② 可作 3D world model/仿真的资产&场景构建工具(先造 3D 物体、再在其上做 dynamics)；③ structured 3D latent 是紧凑空间表示思路，可能启发 spatial/3D-aware world model 的状态表示——但需补时间维度。本质区别：world model 管"世界怎么演化"，本文管"造一个静态 3D 物体"。
② §1 Introduction·逐段
问题(递进)：3D 生成靠 latent 3D 表示 + 大模型快速进步，但"缺能忠实捕获任意 3D 资产全谱信息、又能被网络处理成 latent 的表示"。现有大模型用 iso-surface field(SDF/Flexicubes)→open/non-manifold/enclosed 限制；多数只管 shape 忽略 appearance/material；SLAT 联合几何+外观但靠 multiview 2D 输入 + 纯渲染监督→复杂结构/材质捕获不足。
O-Voxel(解法)：“field-free” sparse voxel，omni-voxel 编码几何+外观。几何=Flexible Dual Grid 处理任意拓扑、无损预处理、保 sharp edge/normal 不连续；外观=任意表面属性，实现 PBR(含 opacity 半透明)。
双向转换：optimization-free + rendering-free——mesh→O-Voxel 单 CPU 几秒，O-Voxel→surface+material 几十 ms。
SC-VAE + 生成：sparse VAE 学 native structured latent(vs SLAT 的 multiview 2D)，residual autoencoding 16× 下采样，1024³ 全纹理资产→~9.6K token、重建超现有；4B flow-matching，512³~3s/1024³~17s/1536³~60s(H100)，几何+材质超现有，全开源。
Q&A · 输入是 mesh 还是 image？（两段式 pipeline，关键澄清）
不矛盾——两个阶段、输入不同：
阶段A 表示 + SC-VAE 训练(输入 mesh)：mesh →(秒级)O-Voxel→ SC-VAE encode → latent → decode → O-Voxel → mesh。用大量 3D 数据集(mesh)学一个好的 latent 空间。Intro line19 的 “mesh→O-Voxel 几秒” 就是这步(处理 3D 训练数据)，跟生成无关。
阶段B 生成(输入 image)：image → DINOv3 特征 → flow-matching DiT → 生成 latent → SC-VAE decode → O-Voxel → mesh。这才是推理实际用法 = image-to-3D。
类比 Stable Diffusion(同为两段式)：SD=①训 VAE(image↔latent) ②训 diffusion(text→latent→image, VAE decode)。本文=①训 SC-VAE(mesh/O-Voxel↔latent) ②训 DiT(image→latent→3D, VAE decode)。对应关系：mesh 之于 SC-VAE = image 之于 SD-VAE(都是 VAE 的训练数据)；image 之于 DiT = text 之于 SD-diffusion(都是生成条件)。O-Voxel/latent 是连接两阶段的桥梁。
Q&A · joint training？latent space 怎么对齐
不是 joint training，两段式：先训 SC-VAE 学好 latent 空间(随后冻结)，再 “Built upon the learned latent space”(§3.3 line172)训 flow-matching DiT；§4 也分开训(VAE 16 H100 / 生成 32 H100)。同 SD/SLAT 标准范式——VAE 先收敛、把 latent 空间定下来，DiT 再学生成；joint 训不稳(latent 一直变、生成模型追不上移动靶)。
DiT↔VAE latent 怎么对齐(其实无需额外步骤)：共享同一个 VAE——DiT 的训练 target 就是 VAE encoder 把训练数据(O-Voxel)编码出的 latent(当 x_1)，DiT 生成的 latent 再用同一个 VAE decoder 解码成 3D。同进同出 → 天然对齐。VAE 的 KL 正则把 latent 拉近标准高斯，正好让 flow-matching 能从高斯噪声流到 latent 分布。
shape/material 两个 latent 怎么对齐：两个 SC-VAE，material VAE 在上采样时条件于 shape VAE 的 subdivision structures(line168)→空间对齐；生成阶段 material DiT 又条件于 image + 已生成的 geometry latent(line176)→ 原文 “ensures their spatial alignment under arbitrary topology”。
image 条件怎么进(跨模态对齐)：image 过 DINOv3 提特征，经 cross-attn/AdaLN 注入 DiT；靠训练数据配对(资产的渲染图 ↔ 该资产的 latent)让 DiT 学条件分布 P(3D latent | image)，是"学出来的"对齐，非显式约束。
Q&A · SC-VAE 怎么训练 & compact latent 怎么做到
训练(§3.2.2 两阶段)：S1 低分辨率快速稳定——直接 O-Voxel 重建(dual vertex v→MSE、face flag δ/pruning mask ρ→BCE、material→L1)+KL(式6)；S2 高分辨率加 rendering loss(渲 mask/depth/normal 用 L1+SSIM+LPIPS；相机浅 near plane 切表面捕内外)(式7)。
防 overfit / 保泛化(综合手段，论文未专门强调)：① KL 正则→latent 近高斯、规整平滑(防过拟合到不规整分布)；② perceptual rendering loss(LPIPS)→感知级监督而非纯 voxel L2 死记；③ 大数据(Trellis-500K + Objaverse-XL/ABO/HSSD)；④ 渐进两阶段。证据=评测在 unseen 测试集(Toys4K + Sketchfab，“unseen during training”)重建仍超 baseline。注：VAE 真正难点其实是 rate-distortion 权衡(压得狠↔重建糊)，不只 overfit。
compact 怎么做到(16×，1024³→~9.6K token)：核心=Sparse Residual Autoencoding(借 DC-AE [chen2024deep])——高压缩 VAE 难训是因空间大幅压缩成信息瓶颈、梯度难优化；DC-AE 用 non-param residual shortcut 在下/上采样把空间信息"搬"到 channel(8 children→channel)而非丢弃→高压缩仍可训、梯度流畅、信息不丢。叠加：① 16× 空间下采样(4 次 2×，1024³→64³)；② O-Voxel 本身稀疏(只表面附近 active)+early-pruning→token 只计 active voxel(~9.6K)，远少于 dense 1024³；③ rendering loss 保压缩后质量。Table1：~9.6K token 反超用更多 token 的 baseline=既 compact 又高保真。
Q&A · SC-VAE 训练带不带 skip connection
要区分两种 skip：
① block 内 residual shortcut → 有：Sparse Residual Autoencoding 的 non-param shortcut(space↔channel 重排，line130)+residual block 本身的残差。
② U-Net encoder→decoder 长 skip → 没有(生成 VAE 的硬约束)：它是 U-shaped VAE following SD/LDM VAE[rombach2022]，decoder 只从 latent 解码。
为什么生成 VAE 不能有 enc→dec skip：生成时 DiT 只产出 latent、没有原始 O-Voxel 输入去跑 encoder，若 decoder 依赖 encoder 的 skip 特征→生成时这些 skip 输入根本不存在、无法解码；且 skip 会让信息绕过 latent bottleneck→latent 不自包含、不 compact，违背"compact latent for generation"。所以 decoder 必须只吃 latent。
论文依据 & 边界：line124 “U-shaped VAE design [rombach2022]”(SD VAE 即无 enc-dec skip 的 bottleneck AE)；line130 residual shortcut 明确是 “within downsampling and upsampling blocks”(块内、非跨 enc-dec)；line180 “discard … skip connection” 说的是 DiT 丢掉 SLAT 的 skip、不是 VAE。enc-dec skip 有无论文未明写，但生成 VAE 范式 + compact latent 目标 → 推断无 enc-dec skip。
③ §3.1 O-Voxel·field-free 的几何机制（QEF 求 dual vertex）
表示定义（式1）：O-Voxel 把一个 3D 资产存成稀疏体素上的特征元组 \( f=\{(f^{shape}_i,\ f^{mat}_i,\ p_i)\}_{i=1}^{L} \)，其中 \(f^{shape}_i\) 编码局部几何、\(f^{mat}_i\) 编码材质、\(p_i\in\{0,1,\dots,N-1\}^3\) 是第 \(i\) 个 active voxel 的整数坐标；不与资产相交的空 voxel 设 inactive——这就是"稀疏"：只在表面附近存东西。
灵感 = Dual Contouring，但去掉了"场"：原文 “This formulation is inspired by Dual Contouring (DC)… The original DC was designed to process discretized scalar fields such as SDFs. Different from DC, we do not utilize any field representation.” DC 靠检测网格边上 SDF 的符号翻转找交点；O-Voxel 直接用 mesh 表面判定边是否相交、并取交点+法向(Hermite data)。不用 SDF 的"符号" = field-free → 不要求 watertight/manifold → 能表示 open / non-manifold / 全封闭内部。
核心公式 QEF（式2，每个 active voxel 闭式解一个 dual vertex \(v\)）：
\[ \min_{v\in voxel}\ e(v)=\sum_i d_{\Pi,i}^2+\lambda_{bound}\sum_j d_{L,j}^2+\lambda_{reg}\,d_{\hat q}^2 \]
① \(d_{\Pi,i}^2=(n_i\cdot(v-q_i))^2\) 是 DC 原有项——\(v\) 到"由交点 \(q_i\)、法向 \(n_i\) 决定的切平面"的平方距离，让 dual vertex 贴合表面、保 sharp edge；② \(\lambda_{bound}\) 项 \(d_{L,j}^2=\|(v-o_j)-((v-o_j)\cdot d_j)\,d_j\|^2\) 惩罚 \(v\) 到 mesh 边界边的距离——专为 open surface 设计(把顶点拉到开放边缘)；③ \(\lambda_{reg}\) 项 \(d_{\hat q}^2=\|v-\bar q\|^2\) 把 \(v\) 拉向交点均值 \(\bar q\)，平滑分布 + 稳定 QEF 防奇异。原始 DC 只有第①项；本文加②③两项是 field-free 处理任意拓扑的关键。
\(f^{shape}_i\) 三件套：dual vertex \(v_i\in\mathbb{R}^3_{[0,1]}\)(局部表面位置) + edge intersection flags \(\delta_i\in\{0,1\}^3\)(X/Y/Z 三条预定义边是否相交，决定 quad 怎么连邻居) + splitting weights \(\gamma_i\)（正实数，控 quad 自适应劈成三角形，沿用 Flexicubes 拓扑规则）。双向转换 optimization-free + rendering-free：mesh→O-Voxel 单 CPU 几秒，O-Voxel→surface 几十 ms，跳过 SDF 求值 / flood-fill / 迭代优化。
③′ §3.1.2 材质（volumetric PBR）+ 采样/重建机制
材质特征（式3，6 通道）：\( f^{mat}_i=(c_i,m_i,r_i,\alpha_i) \)——\(c_i\in\mathbb{R}^3_{[0,1]}\) base color、\(m_i\in\mathbb{R}_{[0,1]}\) metallic、\(r_i\in\mathbb{R}_{[0,1]}\) roughness、\(\alpha_i\in\mathbb{R}_{[0,1]}\) opacity。标准 PBR metallic-roughness 工作流；关键是带 opacity \(\alpha\) → 能建半透明(玻璃)，原文 “a capability not present in previous methods”。
Texture→O-Voxel：把 voxel center 投影到每个相交三角形、用 UV+mipmap 采材质，按点到面距离 加权平均(权 \(w=1-d\))。O-Voxel→Texture：对每个 query 点(mesh 顶点 or texel 对应 3D 表面点)用邻近 voxel 属性做 trilinear interpolation，重建 mesh 直接可渲染、无需后处理。这就是"几何+材质一体" omni-voxel 的落地。
③″ §3.3 生成建模公式化（rectified flow / CFM loss）
训练目标（附录式9，Conditional Flow Matching）：前向用直线插值 \( x(t)=(1-t)x_0+t\,\epsilon \)（\(x_0\)=data latent、\(\epsilon\sim\mathcal{N}(0,I)\)、\(t\in[0,1]\)），网络 \(v_\theta\) 回归速度场：
\[ L_{CFM}(\theta)=\mathbb{E}_{t,x_0,\epsilon}\big\|\,v_\theta(x(t),t)-(\epsilon-x_0)\,\big\|_2^2 \]
即监督"从 data 指向 noise 的速度 \(\epsilon-x_0\)"(rectified flow 直线路径)；推理时从 \(\epsilon\) 沿 \(v_\theta\) 用 ODE 反向积分到 \(x_0\)。timestep 用 \(\mathrm{logitNorm}(1,1)\) 采样(沿用 TRELLIS)。
三阶段三个 sparse DiT（串行条件链）：① sparse structure(预测 voxel occupancy 布局)→② geometry(active voxel 内几何 latent)→③ material(PBR latent，条件 = image + 已生成 geometry latent，保证空间对齐)。每个 DiT \(\approx\)1.3B(width 1536 / 30 blocks / 12 heads / MLP 8192)，三个共 \(\approx\)4B；SC-VAE \(\approx\)800M(354M enc + 474M dec)。AdaLN-single 注入 timestep、cross-attn 注入 DINOv3-L 图像特征、RoPE + QK-Norm 稳注意力；得益 16× 高压缩，丢掉 TRELLIS 的 conv packing + skip → vanilla 稀疏 DiT。

⑤ §4.4 消融（Table 3，两个设计逐个验证，256³）
① Sparse Residual Autoencoding（高压缩命门）：替成 average pooling + 最近邻上采样后——16×(f16c32)：MD 1.032→1.747(+69%)、PSNR 27.26→26.73(−0.5dB)；32×(f32c128)：MD 1.405→7.394(+526%)、PSNR 26.65→25.01(−1.6dB)。压得越狠、residual AE 越关键(它把空间信息搬到 channel 而非丢弃，缓解高压缩的梯度难题)。
② Optimized Residual Block（ConvNeXt 式：1 conv + wide point-wise MLP 替 2 conv）：换回标准 residual block——MD 1.032→1.198(+16%)、PSNR 27.26→26.67(−0.6dB)，而 耗时几乎不变(28.6ms→29.6ms)。证明"宽 MLP 替第二个 conv"在不加成本下提质。结论：两个设计都为"高压缩下仍高保真"服务，互补。
📌 全文一页总结（问题→方法→实验→takeaway）
问题(§1)：3D 生成被"表示"卡脖子——field-based(SDF/Flexicubes)建不了 open/non-manifold/enclosed；多数只管 shape 不管 material；SLAT 联合几何+外观但靠 multiview 2D 输入 + 纯渲染监督、复杂结构/材质捕获弱。
方法(§3)：① O-Voxel——field-free 稀疏体素，Flexible Dual Grid 用改进 QEF(加 boundary 项保 open surface + reg 项稳)闭式解 dual vertex，存几何 \(f^{shape}=(v,\delta,\gamma)\) + PBR \(f^{mat}=(c,m,r,\alpha)\)，与 mesh 秒级双向转换；② SC-VAE——全稀疏卷积 U-VAE，Sparse Residual Autoencoding(空间↔channel 重排) + early-pruning + ConvNeXt block 实现 16× 压缩(1024³→~9.6K token)，两阶段训(重建 loss → +rendering loss，相机浅 near plane 切表面捕内外)；③ 4B flow-matching——三个 vanilla 稀疏 DiT(structure→geometry→material 条件链)，CFM loss \(\|v_\theta-(\epsilon-x_0)\|^2\)。
实验(§4)：重建 MD / Normal PSNR 全面碾压(Ours 1024 与 TRELLIS 同 9.6K token 但 PSNR +12.8dB、MD 低约 4 个量级)；生成 CLIP/ULIP-2/Uni3D 全项第一 + 用户偏好 66.5%；消融证 residual AE(32× 时去掉 MD +526%)与 opt. block(+16%)都关键；推理 1536³ 仅 60s。
Takeaway：① field-free 是拓扑自由的根——抛弃 SDF 符号、直接用 mesh 交点 + QEF，才敢碰 open / 非流形 / 封闭；② "native 3D 输入 + 16× 高压缩"双赢——比 SLAT 的 multiview 2D 更直接、token 更少还更准，证明 compact latent 不必牺牲保真；③ 把 material 当独立生成阶段(条件于 image+geometry)是拿 Best Student 的差异化——一体产出几何 + 完整 PBR、直接进引擎免返工；④ 局限诚实：voxel 分辨率上限会让贴近的双层面/小细节 aliasing、解码偶有小洞需 mesh 后处理补，O-Voxel 暂不含 part-level / 语义结构。
