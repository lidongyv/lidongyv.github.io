CVPR 2026   Finalist

GeoViS: Geospatially Rewarded Visual Search for Remote Sensing Visual Grounding

Peirong Zhang ⋅ Yidan Zhang ⋅ Luxiao Xu ⋅ Jinliang Lin ⋅ Zonghao Guo ⋅ Fengxiang Wang ⋅ Xue Yang ⋅ Kaiwen Wei ⋅ Lei Wang
arXiv PDF ⬇arXiv 摘要Scholar

摘要 Abstract

Recent advances in multimodal large language models (MLLMs) have led to remarkable progress in visual grounding, enabling fine-grained cross-modal alignment between textual queries and image regions. However, transferring such capabilities to remote sensing imagery remains challenging, as targets are often extremely small within kilometer-scale scenes, and queries typically involve intricate geospatial relations such as relative positions, spatial hierarchies, or contextual dependencies across distant objects.To address these challenges, we propose GeoViS, a Geospatially Rewarded Visual Search framework that reformulates remote sensing visual grounding as a progressive search-and-reasoning process. Rather than directly predicting the target location in a single step, GeoViS actively explores the global image through a tree-structured sequence of visual cues, integrating multimodal perception, spatial reasoning, and reward-guided exploration to refine geospatial hypotheses iteratively. This design enables the model to detect subtle small-scale targets while maintaining holistic scene awareness.Extensive experiments on five remote sensing grounding benchmarks demonstrate that GeoViS achieves precise geospatial understanding and consistently surpasses existing methods across key visual grounding metrics, highlighting its strong cross-domain generalization and interpretability.

📝 精读笔记

灵魂一句
把遥感视觉定位（visual grounding）从“一步直接回归框”改成“像人一样多步搜索 + 推理”：用 MCTS 在大图里逐级 zoom-in/zoom-out 找最可能含目标的子区域，搜索由 geospatial reward（QA 语义 + IoU 几何）打分引导，最后把搜到的子区域当 visual cue 做 conditional grounding；全程靠一个统一的 VisualRAG 模型（Qwen2.5-VL-3B 微调）兼任“奖励/动作/定位”三职，不用 RL、不用外部检测器。
问题 & 动机
遥感 grounding 两大难：① top-down 视角→复杂空间关系（多实体 + 相对位置 + 空间层级 + 远距上下文依赖），现有 one-shot 预测缺层级空间建模；自然域的 CoT/RL 多步推理要 “substantial human involvement to construct large-scale reward datasets”，复杂且贵。② km 级大图、目标极小→极端尺度悬殊，导致 effective resolution（目标像素占全图比例）极低；放大输入/切 patch “do not change the effective resolution”。preliminary exp（§4.6）发现：正确解读 geospatial context + 给个候选区域当额外视觉输入（提 effective resolution）= visual cues，能大幅涨点。
核心方法（两阶段 + 关键公式）
阶段一 Visual Search（MCTS）：建模为 MDP M=(S,A,T,R)；UCT 选择 a*=argmax[Q(s,a)+c·√(lnN(s)/(N(s,a)+ε))]（式3）。结构化文本 T̂=Φ(T)={o,p,r}（object/position/relation，式4）。动作 A={zoom-in, zoom-out}：zoom-in 把当前区域切 3×3 选一格 R_{i,j}（式5），zoom-out 放大 λ>1（式6）。奖励 r_t=α·r_QA+(1−α)·r_IoU∈[0,1]（式7）：r_QA=对 o/p/r 三元素 binary verify 的正例比例，r_IoU=预测主目标框 B_t 与虚拟中心框 B_c 的 IoU。阶段二 Conditional Grounding：用搜到的最优子区域 I(s*) 作条件 B=G(I_g,T | I(s*))（式8）。一个 VisualRAG 模型（init Qwen2.5-VL-3B）兼任 reward/action/grounding，4 个 atomic op 联合训练。
关键结果
5 个 RS benchmark 全 SOTA，原文称关键指标 “5–15% improvements”。DIOR-RSVG Pr@0.5 79.8（vs 最强 RS MLLM GeoGround 77.7 / EarthGPT 76.7；vs 最强通用 Qwen3-VL-4B 51.1）；VRSBench 68.5（vs SkySenseGPT 63.5）；OPT-RSVG 70.3；RSVG-HR 51.5；GeoChat 23.7。消融：effective resolution 从 Global-only 71.2 → Global+Local 82.9（+11.7 Pr@0.5）。
亮点
① 无 RL、无外部检测器——对比 V*/DyFo 靠强检测器、DeepEye/Mini-o3 靠 RL+昂贵 rollout，本文把搜索拆成简单 atomic ops + reward 评估→可从现有 benchmark 高效造数据；② reward 同时管语义(QA)+几何(IoU)；③ 一个 VisualRAG 模型统一搜索/动作/定位，interpretable step-wise；④ 跨数据集泛化强（Table 5）。
疑问 / 边界
① 与 specialist 模型仍有差距（DIOR 79.8 vs LQVG 83.4、RSVG-HR 51.5 vs LQVG 87.4），论文定位是 “approaching specialist”；② MCTS 推理（10 simulations × depth 5）显著增加推理成本，论文未给推理时延/吞吐对比（需查）；③ 最优 α=0.1（QA 仅占 0.1、偏 IoU 几何），与 Table 4 中 rIoU 单加(73.2)>rQA 单加(71.2)一致；④ GeoChat 仅 23.7（噪声 auto-generated 指令），论文称 “competitive” 实则偏低。

① Abstract（摘要）— 逐句精讲

第 2 句（两大难，全文靶子）："transferring such capabilities to remote sensing imagery remains challenging, as targets are often extremely small within kilometer-scale scenes, and queries typically involve intricate geospatial relations such as relative positions, spatial hierarchies, or contextual dependencies across distant objects." —— 搬到遥感难在两点：① 目标在千米级场景里极小；② query 含复杂地理空间关系（相对位置/空间层级/远距上下文依赖）。Intro 就展开这两难。
第 3-4 句（核心范式）："we propose GeoViS, a Geospatially Rewarded Visual Search framework that reformulates remote sensing visual grounding as a progressive search-and-reasoning process. Rather than directly predicting the target location in a single step, GeoViS actively explores the global image through a tree-structured sequence of visual cues, integrating multimodal perception, spatial reasoning, and reward-guided exploration to refine geospatial hypotheses iteratively." —— 把 grounding 从"一步出框"改成"树状（MCTS）逐步搜索 + 推理"，用 reward 引导、迭代细化空间假设。这是从 one-step regression 到 search-and-reasoning 的范式转变。
第 5 句（战果）："Extensive experiments on five remote sensing grounding benchmarks demonstrate that GeoViS achieves precise geospatial understanding and consistently surpasses existing methods ... highlighting its strong cross-domain generalization and interpretability." —— 5 个 benchmark 一致超越，且强调跨域泛化 + 可解释（搜索路径可视）。一句话抓 Abstract：遥感目标小、关系复杂 → 把 grounding 改成 reward 引导的 MCTS 视觉搜索 + 条件定位，5 数据集 SOTA、可解释、可跨域。
📚 背景知识（外部，非本文原创，理解 GeoViS 必备）
① Visual Grounding：给一张图 \(I\) + 一句文本 \(T\)，定位 \(T\) 描述的图像区域（输出 bounding box \(B\)），是 vision-language 的基础能力。② Effective Resolution（本文最关键概念）：原文定义为 "the proportion of pixels representing the target relative to the whole image"——目标像素占全图的比例。遥感目标极小 → 该比例极低 → 全局编码后细节丢失。关键洞见：单纯放大输入或切 patch 不改变 effective resolution，只有把"含目标的局部区域"当额外输入，才真正提升它。③ MCTS（Monte Carlo Tree Search）+ UCT：四步循环——Selection（按 UCT 选子节点，平衡 exploitation \(Q(s,a)\) 与 exploration）→ Expansion（施加动作生成新节点）→ Simulation（评估该区域得 reward）→ Backpropagation（累积 reward 上传更新路径节点值）；多次 rollout 后搜索树收敛到高 reward 区域。④ 前作 visual search（被本文区分）：V* 把搜索当 LLM 预测的 visuomotor 操作（crop/zoom/shift）；DyFo 是 training-free MCTS、靠外部 detector；DeepEye/Mini-o3 用 RL 学序贯 glimpse / 蒸馏 o3 的 zoom 行为。共同毛病：依赖强检测器或 RL + 昂贵 rollout，遥感难部署/难泛化。本文 = 视觉搜索但不靠 RL / 外部检测器，用 atomic op + reward 评估，数据可从现有 benchmark 构造。
② §1 Introduction — problem → 现有不足 → solution → why 闭环
problem（两个 fundamental challenges）：(1) 复杂空间关系：原文 "the top-down perspective of remote sensing imagery introduces complex spatial relationships"，Fig.1 例——要先找出所有 baseball field、比大小定"最大"、再用与 tennis court 的位置关系定位。(2) 极端尺度悬殊："remote sensing images typically span kilometer-scale areas, while objects of interest such as aircraft or ships occupy only a small fraction of the scene"。
现有不足（为什么旧法不行）：① one-shot 法——"existing approaches typically perform one-shot prediction over the entire image, lacking hierarchical spatial modeling and thus struggling with such complex queries"；② 自然域的 CoT/RL 多步推理——"usually demand substantial human involvement to construct large-scale reward datasets for training"（贵）；③ 放大输入/切 patch——"these strategies do not change the effective resolution"（治标不治本，小目标仍丢判别细节）。
solution + why（被预实验 §4.6 逼出来）：预实验（Table 3）发现 grounding 在两条件下大涨——"(i) correctly interpret the geospatial context expressed in the textual description, and (ii) incorporate a candidate region that is likely to contain the target as an additional visual input to increase the effective resolution"，二者合称 visual cues。而"自动在大而杂的遥感场景里发现可靠 visual cues"正是核心挑战 → 所以做 reward 引导的搜索来自动找这两个 cue。
Q&A · 为什么 effective resolution 是核心？放大输入为何没用？
定义回顾：effective resolution = 目标像素 / 全图像素。一架飞机在 km 级图里可能只占几十像素，占比 \(\lt 0.1\%\)。为什么放大输入/切 patch 没用：把整张图 resize 放大，目标和背景同比例放大，目标占比（= effective resolution）不变；切 patch 虽减小了"分母"，但若不知道目标在哪一块，盲切既可能切丢目标、也无法对每块都全分辨率送入（算力爆炸）。GeoViS 的解法本质：先用带语义 + 几何 reward 的搜索定位到"很可能含目标"的子区域 \(I(s^\star)\)，再把这个子区域当额外视觉输入——此时目标在该子区域里占比大幅提高，effective resolution 被动态提升。Table 3 直接证明：Global only 71.2 → Global+Local 82.9 Pr@0.5（+11.7）。[点评] 把"分辨率不够"重新定义成"目标占比不够"，再用搜索动态提升占比，是本文最锋利的 framing。
③ §3.1 总体设计 — 两阶段 + VisualRAG
reformulate：原文 "We reformulate the task as a geospatially rewarded visual search problem"，拆成两阶段顺序流程：① Visual Search——reward 引导的层级搜索，在全局图上逐步逼近"最可能含目标"的子区域；② Visual Grounding——用搜到的子区域作 visual cue，在全局图上做条件定位。统一核心 = VisualRAG 模型：一个 MLLM 同时承担 (1) reward 评估、(2) action 引导（预测 MCTS 的 zoom 动作）、(3) grounding 推理（出最终框）。原文："By sharing this model across search and grounding, GeoViS achieves coherent, step-wise reasoning over geospatial imagery and effectively bridges exploration, verification, and final localization."
④ §3.2 Visual Search — MDP 形式化 + MCTS（公式 1/2/3）
MDP：把搜索建成 \(\mathcal{M}=(\mathcal{S},\mathcal{A},\mathcal{T},\mathcal{R})\)；状态 \(s_t\) = 全局图内的一个候选区域（坐标 + 多模态特征），动作转移 \[ s_{t+1}=\mathcal{T}(s_t,a_t) \quad\text{(式1)},\qquad r_t=\mathcal{R}(s_t,a_t)\quad\text{(式2)} \]reward \(r_t\) 反映区域与文本的语义相关度，引导策略奔向 text-consistent 区域。
MCTS（UCT 选择，式3）：\[ a^*=\arg\max_{a\in A(s)}\Big[\,Q(s,a)+c\sqrt{\tfrac{\ln N(s)}{N(s,a)+\varepsilon}}\,\Big] \]\(Q(s,a)\) 是动作平均回报（exploitation），根号项是 exploration 奖励（访问越少越鼓励探），\(c\) 平衡两者。流程：Selection（UCT）→ Expansion（施加动作生成新节点）→ Simulation（grounding 模型评该区域得 \(r_t\)）→ Backpropagation（累积 reward 上传）。原文："the search tree gradually converges toward regions with higher expected rewards, effectively narrowing the search space from global to local in a self-guided manner."
⑤ §3.2.2 Action Space — 结构化 query + zoom（公式 4/5/6）
结构化 query（式4）：遥感 query 常是组合语义（靠属性 + 关系而非显式名字），故先把 \(T\) 解析成结构表示 \[ \hat T=\Phi(T)=\{o,p,r\} \]（\(o\)=目标物 object，\(p\)=空间属性 position，\(r\)=对其它实体的关系 relation），给区域级动作提供可解释指引。两个动作（coarse-to-fine）：① zoom-in——把当前区域切 \(3\times3\) 网格、按 \(\hat T\) 选一格：\(s_{t+1}=\mathcal{T}_{in}(s_t,a_t)=R_{i,j}(s_t)\)（式5，聚焦细部）；② zoom-out——按 \(\lambda\gt 1\) 放大：\(s_{t+1}=\mathcal{T}_{out}(s_t,a_t)=\lambda\cdot s_t\)（式6，当过度局部时找回全局上下文）。两动作在每个节点都评估，使搜索树层级平衡局部探索与全局推理。
⑥ §3.2.3 Reward Design — QA + IoU 双项（公式 7）
两项加权（式7）：\[ r_t=\alpha\,r_{QA}+(1-\alpha)\,r_{IoU},\qquad r_t\in[0,1] \]① QA reward \(r_{QA}\)：VisualRAG 对 \(o/p/r\) 三语义元素做 binary 验证（该区域是否含此物/此属性/此关系），取正例归一比例 \(\in[0,1]\)——概念级语义一致。② IoU reward \(r_{IoU}\)：VisualRAG 预测主目标框 \(B_t\)，与"虚拟中心框 \(B_c\)"（区域中心、宽高各取一半）算 IoU——几何对齐，鼓励目标在区域里居中且紧凑（说明这个区域框得准）。\(\alpha\) 调语义↔几何配比。
Q&A · 为什么 reward 要"语义 QA + 几何 IoU"两项？
单项的盲区：只用 \(r_{QA}\)（语义）——一个大区域可能"确实包含"目标及其关系（QA 全对），但目标只占角落一点点，框得很松，搜索不会继续往里收；只用 \(r_{IoU}\)（几何）——某区域里有个居中紧凑的物体，但它可能根本不是 query 要的那个（语义错）。两项互补：\(r_{QA}\) 保证"找对东西"，\(r_{IoU}\) 保证"框得准且该往里收"。原文消融（Fig.4）：\(\alpha\) 从 0（纯 IoU）到 1（纯 QA），"Both reward terms contribute positively ... while excessive emphasis on either term degrades performance. The optimal result occurs at α = 0.1"。注意 \(\alpha=0.1\) 偏向 IoU（QA 只占 0.1 权重）——与 Table 4 中"加 \(r_{IoU}\) 比加 \(r_{QA}\) 涨得多（73.2 vs 71.2）"一致：几何信号对收敛更关键，但语义仍不可或缺。
⑦ §3.3 Visual Grounding — 条件定位（公式 8）
条件于搜到的子区域：搜索返回累计 reward 最高的节点 \(s^\star\) 后，做条件定位：\[ B=G(I_g,T\mid I(s^\star)) \]与传统"直接从 \((I_g,T)\) 预测"不同，GeoViS 额外条件于搜到的候选区域 \(I(s^\star)\)。原文："the subregion I(s⋆) serves as a prior regional visual cue that constrains the search space and enhances the effective resolution of the target area." —— 子区域既约束搜索空间、又提升目标区 effective resolution，让模型聚焦相关细节后把位置投回全局图。
⑧ §3.4 VisualRAG 模型 — 三能力 + 四原子操作
结构：标准 MLLM（image encoder + projection + LLM backbone），输入全局图 \(I_g\)、候选区 \(I(s_t)\)、结构化文本 \(\hat T=\{o,p,r\}\)。三能力：(1) Reward Evaluation——评 \((o,p,r)\) 三元组语义正确性 + 区域空间一致性，出统一 reward；(2) Action Guidance——评候选子区、推下一步最优动作 \(a_t\in\{1,\dots,9\}\)（即 MCTS 的 policy 信号，对应 \(3\times3\) 九格）；(3) Grounding Reasoning——基于当前区域 + 文本预测全局图内目标位置。训练用 4 个 atomic operations：QA reward（语义验证）/ IoU reward（区域级定位的空间监督）/ Zoom-in action（\(3\times3\) 格选择）/ Conditional grounding（用全局 + 子区域联合预测框）。一个模型贯通"探索—验证—定位"，且这些原子操作的训练数据可直接从现有 RS benchmark 构造（不用 RL rollout）。

📌 全文一页总结（problem → method → experiment → takeaway）
① problem：遥感 visual grounding 两大难——目标在 km 级场景里极小（effective resolution 极低） + query 含复杂地理空间关系；one-shot 预测做不好、缺层级建模，自然域 CoT/RL 多步推理又依赖昂贵人标 reward 数据与外部检测器。
② method：reformulate 成"geospatial reward 引导的视觉搜索 + 条件定位"两阶段：(a) MCTS(UCT) 用 zoom-in（\(3\times3\)，式5）/ zoom-out（式6）在大图搜子区域，query 先结构化成 \(\{o,p,r\}\)（式4），reward = \(\alpha r_{QA}+(1-\alpha)r_{IoU}\)（式7）；(b) 用最优子区域作 visual cue 做条件 grounding \(B=G(I_g,T\mid I(s^\star))\)（式8）；统一 VisualRAG（Qwen2.5-VL-3B）兼任 reward/action/grounding、4 atomic op 训练，不用 RL / 外部检测器。
③ experiment：5 benchmark 全 SOTA——DIOR 79.8 / VRSBench 68.5 / OPT-RSVG 70.3 / RSVG-HR 51.5 / GeoChat 23.7 Pr@0.5，"5–15% 提升"；消融证明 effective resolution（71.2 → 82.9）、各 atomic op（69.5 → 74.5）、跨域泛化（VRSBench 49.0 vs 微调 39.3）均有效，最优 \(\alpha=0.1\)。
④ takeaway（≥3 条 + 适用边界）：
• Takeaway 1：遥感小目标 grounding 的瓶颈本质是 effective resolution（目标占比） 而非输入分辨率——放大输入无效，"搜索 + 局部区域作 cue"才能动态提升它。
• Takeaway 2：把 grounding 重构成 MCTS 视觉搜索 + 条件定位，并用"语义 QA + 几何 IoU"双 reward 引导，可在不依赖 RL / 外部检测器下实现可解释的渐进定位（搜索路径可视）。
• Takeaway 3：把搜索拆成可训练原子操作，训练数据能从现有 benchmark 直接构造，且学到的推理 pattern 可跨数据集迁移（明显超过同源微调）。
• 适用边界 / 诚实点：① GeoViS 仍低于 specialist 上界（RSVG-HR 51.5 vs LQVG 87.4、OPT 70.3 vs LPVA 78.0），与专用检测式模型尚有差距；② MCTS 推理成本（10 simulations × depth 5 的多次前向）相对 one-shot 的额外开销论文未量化 [推测：推理更慢]；③ GeoChat 偏低（23.7），对话式/噪声指令仍是弱项；④ Table 3 的 Global+Local 是用 GT 附近裁剪的动机上界，GeoViS 靠搜索逼近、未必达到该上界。
