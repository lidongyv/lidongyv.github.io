📝 精读笔记

灵魂一句
先指出统一理解+生成的 MLLM 一直用的 spatial visual token（图块按光栅顺序排）是"不可能语言"（缺语言的递归结构、打乱顺序 LLM 收敛几乎不变），再用扩散的 timestep 造出有递归结构的离散视觉 token：DDT（Discrete Diffusion Timestep）token——第 t 个 token 专门补偿"加噪到 t 步时丢失的那部分视觉属性"，token 序列随 t 递归展开、coarse→fine。基于它训出 DDT-LLaMA，在理解+生成上同时刷新 MLLM SOTA（且 tokenizer 只在 ImageNet 上训）。
问题 & 动机
MLLM 想用同一个 next-token-prediction 统一"理解"（many-to-one 抽象细节，多张柯基→"corgi"）和"生成"（one-to-one 保细节）。但所有现有法都用 spatial token。作者借 [Kallini 2024] 的"impossible language"检验发现（Fig.1 右）：打乱 spatial token 顺序，LLM 收敛几乎不受影响——这与人类语言相反（打乱语言顺序性能应骤降）。根因：spatial token 缺语言的递归结构（语言可递归嵌套，"a man"→"a man [[walking] in the park]"）⇒ 对 LLM 是"无法掌握的语言"。
核心方法 + 关键公式
① DDT 递归 token 定义：扩散前向逐步加噪，把不同图像"塌缩"成相似的噪声（渐进丢失区分属性）。学一个展开的离散 token 序列补偿这种丢失：f₀(x₀)=∅（无丢失），训练 DM 用 xt + 前 t 个 token 重建 x₀；递归关系 f_{t+1}(x₀)=(f_t(x₀), V_{t+1})，新增 token V_{t+1} 只补 x_{t+1} 比 x_t 多丢的那部分属性；t=T 时 x_T 纯噪声、所有属性丢光，f_T(x₀) 即整图 token 序列。② Tokenizer 架构（§3）：encoder=transformer + T 个 learnable query（输出长度=T，仿 SD3 双 transformer 处理 query/image 再 join attention）；quantizer=VQ，码本 |C|=65536、维度 m=16、cosine 最近邻 + EMA + 死码重置；decoder=MMDiT，吃量化 token 重建 x₀。训练损失（式1）：L=E‖d(tϵ+(1−t)x₀, t, (V₁..V_t)) − x₀‖²（Rectified Flow 采样 xt=tϵ+(1−t)x₀）+ commitment loss。③ DDT-LLaMA（§4）：图→1D 递归离散序列，与文本 token 拼接、[BOV]/[EOV] 分隔，从 LLaMA3-8B 初始化、词表扩 65,536 个视觉码，统一 LM 目标（式2）。两阶段：Stage1 预训练（Laion+Coyo 200M 图文对、10% 纯文本防遗忘、512 Ascend 910B NPU 约两周）；Stage2 指令微调。推理：出 [BOV] 后连续 T 次预测出 {V₁..V_T} → 喂 decoder 经 T 步 DDPM 去噪成图（时刻 t 只给前 t 个 token、其余 mask 为 0）。
关键结果
T2I 生成（GenEval overall）：0.66，超所有 MLLM（SEED-X 0.49 / Emu3 0.54）甚至专用 SDXL 0.55，逼近 SD3 0.74 / DALL-E3 0.67；尤擅 color/counting/position。图像编辑（Table 2）：zero-shot 全面超 MLLM、且超专用编辑模型（MagicBrush CVS 92.4）。理解（Table 3）：encoder-free（无 CLIP） 仍强——NoCaps 124.2 / Flickr 88.5 / VQA 76.4 / GQA 66.3 / OKVQA 65.9，超不少"只做理解"的 MLLM。重建+类条件生成（Table 4）：ImageNet 重建 PSNR 21.7（>同 token 数的 spatial tokenizer），类条件 FID 6.1（< MoVQ 7.1 / VQGAN 15.8）。递归性证据：counterfactual interpolation（替换子集 token 只改对应属性=语义融合，VQGAN 则是 CutMix 区域拼接）；扩展子集解码（token 越多属性越全，contour/color→完整结构）；DDT token 让文本困惑度训练中下降而 VQGAN 上升（Fig.9a）。
亮点
① 用"impossible language"诊断出 spatial token 的根本缺陷（无递归结构）——重新定义"视觉该用什么 token 喂 LLM"；② 巧借扩散 timestep 造出 coarse→fine、属性级解耦的递归 token；③ 解耦性有多组实证（插值/扩展解码/困惑度/AB test）；④ encoder-free（不靠 CLIP）也能强理解；⑤ 仅用 ImageNet 训 tokenizer 就同时刷新理解+生成。
疑问 / 边界（原文标注）
① 美学质量不如 Emu3 等：自认因 tokenizer 仅在 ImageNet 256×256 训、开放域重建弱，限制了 T2I 上限。② TwoObj 偏弱：训练 caption 很少用"生成两个物体"这种简单 prompt 格式。③ 每图 token 数大（Fig.8 到 480），推理要 T 次自回归 + T 步 DDPM，速度正文未计时。④ 训练吃 512 NPU 两周（大算力）。⑤ scaling law 只是"preliminary indications"（Fig.7），递归性结论偏定性实证。

📖 逐段精读 · 笔记

批量精读初稿（基于本地 PDF 全文，PyMuPDF 提取）。原文英文原句引用 + 中文指路 + 追问 why。最后更新 2026-06-21。
① Abstract（摘要）— 逐句精讲
原文（目标）：“Recent endeavors in Multimodal Large Language Models (MLLMs) aim to unify visual comprehension and generation by combining LLM and diffusion models, the state-of-the-art in each task, respectively.” → 大背景：MLLM 想把"理解"（LLM 强）和"生成"（扩散强）统一进一个模型。
原文（病灶）：“Existing approaches rely on spatial visual tokens, where image patches are encoded and arranged according to a spatial order (e.g., raster scan). However, we show that spatial tokens lack the recursive structure inherent to languages, hence form an impossible language for LLM to master.” → 核心论断：现有法用空间 token（图块按光栅扫描排），但它缺语言的递归结构，对 LLM 是"不可能语言（impossible language）"。
原文（解法）：“we build a proper visual language by leveraging diffusion timesteps to learn discrete, recursive visual tokens. Our proposed tokens recursively compensate for the progressive attribute loss in noisy images as timesteps increase, enabling the diffusion model to reconstruct the original image at any timestep.” → 用扩散 timestep 造递归离散视觉 token；每个 token 补偿"随 t 增大而渐失的视觉属性"，使扩散模型能在任意 t 重建原图。
原文（结论）：“This approach allows us to effectively integrate the strengths of LLMs in autoregressive reasoning and diffusion models in precise image generation ... a new SOTA for multimodal comprehension and generation simultaneously.” 逐句抓 Abstract：空间 token 非语言 → 用 timestep 造递归 token（补属性丢失）→ LLM 自回归推理 + DM 精确生成 → 理解+生成同时 SOTA。
📚 背景知识（外部，非本文原文，理解 DDT 必备）
① 统一理解+生成的 MLLM 三条路线：cascading（LLM 规划→DM 生成，两段独立，如 LLaVA-Plus）；tokenization（把图像量化成离散 token，单 transformer 纯 next-token，如 SEED/Emu3/VILA-U）；混合（一个 transformer 里掺 AR + diffusion，如 Transfusion[67]/Show-o[58]）。本文属 tokenization 路线，但换掉了 token 的"语言性"——这是它与 Emu3 等同路线工作的根本区别。
② spatial token / VQGAN：把图像切 patch、VQGAN/VQ 编码成离散码、按光栅顺序（raster scan, row by row）排成 1D 序列喂 LLM。问题=这个顺序只是"空间排布"，token 间是平铺的网格邻接，不是语言那种可递归嵌套的层级关系。
③ "impossible language"检验（Kallini 2024 [26]）：真语言里 token 顺序极重要，打乱后 LLM 收敛/困惑度应骤变；反之若打乱某种 token 序列的顺序对 LLM 收敛几乎无影响，说明它不具备语言的结构性。本文借此判定：spatial token "非语言"（Fig.1 右，打乱顺序收敛曲线几乎重合）、DDT token "像语言"（Fig.1 左，打乱后明显变差）。
④ many-to-one vs one-to-one（两任务的本质冲突）：原文 “Comprehension pursues a many-to-one mapping that abstracts visual details (e.g., many photos of corgi dogs result in recognition of 'corgi'). On the other hand, generation finds a one-to-one mapping that preserves visual details.” —— 理解要抹掉细节做抽象、生成要保住细节做还原，目标相反，这正是统一框架的难点。
⑤ 扩散 / Rectified Flow / VQ / MMDiT：扩散前向逐步加噪 x_t；Rectified Flow（[36]）用直线插值 x_t=tϵ+(1−t)x₀（t∈[0,1]，t=1 纯噪声）；VQ（[54]）=把连续特征量化到码本最近码（commitment loss 拉近编码器输出与所选码、EMA 更新码本）；MMDiT=SD3（[16]）的多模态 Diffusion Transformer（双流处理两种模态再 join attention）。
② §1 Introduction — problem → solution → why 闭环
problem（两层）：① 任务层——理解（many-to-one 抽象细节）与生成（one-to-one 保真细节）目标冲突；② token 层——现有 MLLM 全用 spatial token，经 impossible-language 检验发现它"非语言"：原文 “when we train an LLM to model spatial token sequences in Figure 1 right, the order of tokens has minimal impact on the convergence of the LLM, deviating from phenomenons observed in human language.” 根因 “spatial tokens lack the recursive structure that characterizes languages”（语言可递归嵌套：“one can extend 'a man' by recursively embedding phrases to get 'a man [[walking] in the park]'”）⇒ 与自然语言无法在 LLM 内互相增强 ⇒ MLLM 生成不如 SDXL、理解不如 LLaVA-1.6。
solution（Intro 即给 method）：DDT tokenization——原文 “We aim to learn an expanding sequence of discrete tokens to make up for the incremental attribute loss as t increases.” 给定 x₀，编码器 f 出 t-specific 序列 f_t(x₀)，初值 f₀(x₀)=∅（无属性丢失）；训练 DM 用 x_t + f_t(x₀) 重建 x₀；递归 f_{t+1}(x₀)=(f_t(x₀), V_{t+1})，新 token V_{t+1} 只补 x_{t+1} 比 x_t 多丢的属性；t=T 时 x_T 纯噪声、属性全失，f_T(x₀) 即整图 token 序列、编码全部属性。
why（为什么递归 token 更好）：递归 = coarse→fine 的属性层级，天然像语言的嵌套结构 ⇒ LLM 能像学语言一样学它（Fig.1 左、Fig.9a 文本困惑度训练中下降）；属性解耦 ⇒ 编辑只改对应 token、保其余（Fig.6 counterfactual interpolation、Fig.9b A/B test）。★ Intro 已自包含闭环。
三点贡献（原文）：(i) 提出 DDT，靠"恢复扩散过程丢失的视觉属性"学离散递归视觉 token；(ii) 用 DDT token 把 LLM 与扩散模型整合成对理解+生成都有效的 MLLM；(iii) tokenizer 仅在 ImageNet 上训，却在多模态理解+生成（图像生成/编辑/视觉理解）同时刷新 SOTA，超过用 Laion/Coyo 大规模数据训 tokenizer 的 MLLM。
②′ §2 Related Work — cascading vs tokenization vs 混合
cascading（[19,20,25,49]）：各模态独立预训练的 encoder/decoder，用投影层融合。代表 EMU2[49]=预训练 LLM + EVA-02-CLIP-E 做理解 + 级联 SDXL-初始化扩散做生成。tokenization（[9,32,39,51,55-57,69]）：把视觉/文本都转离散空间，单 transformer 纯 next-token，去掉扩散/组合式。混合：TransFusion[67]/Show-o[58] 在一个 transformer 里掺扩散 + 自回归。原文批判：“most of them focus on spatial tokens for vision ... These spatial tokens lack the traits of human language, resulting in an inability to seamlessly integrate with human natural language within an MLLM to mutually enhance each other.” → 所以 “existing MLLMs still lag behind specialized architectures like SDXL in visual generation tasks and LLaVA-1.6 in visual comprehension tasks.” 这就是本文要补的缺口。
③ §3 Diffusion Timestep Tokenizer — Encoder（learnable query + 仿 SD3 双流）
三件套总览（原文）：“1) an encoder f that maps a noise-free image x0 to a sequence of continuous features (V̂1,...,V̂T); 2) a quantizer that assigns each continuous feature V̂i to its token embedding Vi ∈ C in a fixed size dictionary C; 3) a Diffusion Model (DM) d as a decoder that reconstructs x̂0 = d(xt, t, (V1,...,Vt)).” 三件套端到端用重建损失训。
Encoder（§3）：transformer + T 个 learnable query token（query 数 = 期望输出 token 数 T）。输入 = 无噪图（patchify+flatten 成 ViT 式 image token） + T 个 query token；query 上加 1D 正弦 PE、image token 上加 2D 正弦 PE；仿 SD3 用两个独立 transformer 分别处理 query 与 image token、再 join 做 attention；最后只保留变换后的 query token 作输出 (V̂1,…,V̂T)。直觉：T 个 query 像 T 个"探针"，各自去图像里抽取"第 t 步该补的那层属性"。
③′ §3 Quantizer（VQ，|C|=65536）+ Decoder（MMDiT）
Quantizer（VQ，[54]）：固定码本 C，|C|=65536、每条 dim m；先用 linear 把编码器输出投到 m 维，再在 C 里找与每个特征 cosine 相似度最大的码 Vi。用 EMA 变体（把码本条目逐步移向匹配它的编码输出的簇心）稳训练。提升码本利用率两招：① 用小 m=16（据 [60] 经验）；② 监控死码（很少被匹配的条目）并把它重置成当前 batch 里的随机码（据 [62]）。
Decoder（DM，MMDiT）：沿用 SD3 的 MMDiT，三处改动（原文）：“1) Instead of inputting text tokens, we input a sequence of quantized tokens; 2) We use a linear layer to project the m-dimensional vector to the latent dimension of the MMDiT; 3) We do not use pooled token embedding as in SD3.” 给定 t、噪图 x_t、前 t 个 token，输出重建图。
③″ §3 训练损失（式1）— 递归性是怎么被"逼"出来的（全文最妙处）
重建损失（式1）：L = E[ ‖ d( tϵ + (1−t)x₀, t, (V₁,…,V_t) ) − x₀ ‖² ]，按 Rectified Flow 采样 x_t = tϵ + (1−t)x₀；外加 commitment loss Σ ‖编码输出 − 所选码‖² 拉近两者。递归性的"逼"法：训练第 t 步时只给前 t 个 token (V₁,…,V_t) 当条件去重建原图，而 x_t 已丢掉"加噪到 t 步"对应的属性。由于第 t−1 步已能用 (V₁,…,V_{t−1}) 补到 x_{t−1}，第 t 个 token V_t 被迫只承担"x_t 比 x_{t−1} 多丢的那一层属性" → token 序列自然形成 coarse→fine 的递归展开（大噪声的 token 管粗结构/语义，小噪声的 token 管细节）。这就是 DDT 递归结构的来源。
③‴ 具体化：DDT 递归 token 走一遍（t=1…T）
给定无噪图 x₀，编码器一次出 T 个 query 特征 → VQ 量化成 (V₁,…,V_T)。t=T（最大噪声 x_T≈纯噪声，属性全失）：要从纯噪声重建原图，得给全部 T 个 token —— 所以全序列编码"全部属性"。某中间 t：x_t 还保留图像的"低频/粗结构"（噪声只盖住了细节），只需前 t 个 token 补回"被噪声盖住的那部分"，故 V_t 专补这一层。t→1：x₁ 几乎是原图、只缺最精细纹理，V₁ 补最细的细节。所以读 token 序列 = 从"该图最稳健的粗属性"逐步加到"最精细细节"，正像语言的 "a man → a man walking → a man walking in the park" 式递归加细。
④ §4 DDT-LLaMA — 词表扩 65536 + 两阶段 + 推理
架构：把图转成"1D 递归离散序列，像 LLM 能读的外语"；视觉 token 与文本 token 拼接，用 [BOV]/[EOV] 标出视觉段；从 LLaMA3-8B 初始化、词表扩 65,536 个视觉码。统一 LM 目标（式2）：p(y) = Σ log P_θ(y_i | y_{<i})，图文都是离散 token ID、共享预测头、交叉熵监督。
两阶段训练：Stage1 预训练——对齐 DDT token 与文本，数据 Laion[46]+Coyo[6] 200M 图文对，格式 “[BOS] <caption> [BOV] <DDT tokens> [EOV] [EOS]”，掺 10% 纯文本防遗忘；跑在 512 张 Ascend 910B NPU、约两周。Stage2 指令微调——监督微调，格式 “USER: <Instructions> ASSISTANT: <Answers>”、只对 Answer 算损失。推理：预测出 [BOV] 后连续做 T 次 next-token-prediction 得 {V₁,…,V_T} → 喂 decoder 经 T 步 DDPM 去噪成图；时刻 t 只给前 t 个 token、其余 (T−t) mask 为 0（与训练一致）。
Q&A · 几个 why 追问
1 为什么扩散 timestep 天然能造"递归"token？扩散前向是个"按重要性逐步抹掉属性"的过程——先丢细节、后丢粗结构（大噪声把不同图塌缩成相似噪声）。把"第 t 步丢了什么"一一对应到"第 t 个 token 补什么"，token 序列就自带一个 coarse→fine 的天然顺序（recursive coordinate）。这比人为给 spatial token 排光栅顺序"有意义"得多。
2 为什么训练只给前 t 个 token 是关键？若每步都给全部 T 个 token，模型没有动机让"第 t 个 token 只补第 t 层属性"——token 职责会纠缠。只给前 t 个 + 让 x_t 已丢了 t 步属性，等于给每个 token 强加"边界职责"（你只负责这一层增量），递归结构才被逼出来。这是 DDT 设计的命门。
3 为什么属性解耦对"编辑"特别有用？编辑=只改一个属性（颜色/季节/某物体）、保其余。DDT token 各管一层属性 → 改对应 token、其余不动即可（Fig.6：换 DDT 子集只改对应属性=语义融合；换 VQGAN token 则是 CutMix 式区域拼接，因为 spatial token 各管一个空间块而非一类属性）。
4 encoder-free 还能强理解，为什么？DDT-LLaMA 不挂 CLIP 这类预训练视觉编码器（“an encoder-free MLLM without pretrained encoders such as CLIP”），图像直接走 DDT token。能强理解的原因：DDT token 本身"像语言"，与文本在同一 LM 目标下互相增强（Fig.9a 文本困惑度训练中下降即证据）——token 选对了，不靠 CLIP 也能对齐语义。

⑤′ §5.2 图像编辑（Table 2）+ §5.3 理解（Table 3）
编辑（zero-shot，EVR/MA5K/MagicBrush）：Ours EVR L1 14.5 / CVS 85.5、MA5K L1 14.2 / LPIPS 29.6、MagicBrush L1 7.1 / CVS 92.4，全面超 MLLM（SEED-X-Edit 等），且超专用编辑模型（InsPix2Pix/MGIE/UltraEdit）。原文：“excels at preserving image fidelity, which is rarely seen in prior work ... achieves a great trade-off between fidelity and editability.”
理解（Table 3，8B，encoder-free 无 CLIP）：NoCaps 124.2 / Flickr30K 88.5 / VQAv2 76.4 / GQA 66.3 / OKVQA 65.9 / VizWiz 57.3 / MME 1378.9 / SEEDBench 67.9 / POPE 86.9，超 SEED-LLaMA/VILA-U/LaVIT/Emu3 等生成型 MLLM，且不少指标超只做理解的 MLLM。原文强调 “DDT-LLaMA is an encoder-free MLLM without pretrained encoders such as CLIP”。
⑤″ §5.4.1 重建 + 类条件生成（Table 4）— "token 选对了本身就涨点"
Table 4（ImageNet 256×256）：重建 PSNR↑：VQGAN 18.9 / VQGAN-LC 20.8 / MoVQ 21.5 / Ours 21.7；类条件生成 FID↓：VQGAN 15.8 / RQ-Transformer 7.6 / MoVQ 7.1 / Ours 6.1。关键对照：在同一自回归范式下，把 spatial tokenizer 换成 DDT tokenizer，重建更准 + 生成 FID 更低 → 证明收益来自"token 选得对"，而非更大模型/更多数据。
⑥ §5.4 递归性/解耦的多组实证 + scaling law
① Counterfactual Interpolation（Fig.6）：替换一张图 token 序列里的一个子集为另一张图的对应 token。VQGAN token → 实际是 CutMix（两图区域拼接，因 spatial token 各管一个空间块）；DDT token → 只改被替换 token 对应的那类属性、其余不变，得两图的语义融合（证明属性解耦）。
② 扩展子集解码（Fig.8）：只把 MLLM 自回归采样的前 t 个 token（t 从 1 到 480）喂 decoder。随 t 增大，图像属性渐进恢复：先出 contour/color，再逐步补全到完整结构 → 直接可视化"token 序列是 coarse→fine 递归"。（t 最大到 480 说明每图 DDT token 数 T≈480。）
③ 文本困惑度（Fig.9a）：多模态预训练中，用 DDT token 训练 → 文本生成困惑度下降；用 VQGAN token 训练 → 上升。说明 DDT token 与文本"互不打架、反而互助"，更适合统一自回归建模（“like a foreign language that LLMs can read”）。
④ A/B test（Fig.9b）+ scaling（Fig.7）：同 Gemma2-2B 骨架、同 200M 预训练 + 同编辑微调，DDT-Gemma 在 65 个编辑案例胜出 vs MoVQ-Gemma 仅 10 胜。Scaling：2B→8B、训练量 50%→75%→100%，视觉质量随规模提升（原文称 “preliminary indications of scaling laws”，定性）。
⑦ 局限 & 诚实边界（原文自陈 + 推断）
① 美学质量不如 Emu3 等：原文自认 tokenizer 仅在 ImageNet 256×256 训，“its performance in reconstructing open-domain images is inferior to that of baseline methods (e.g., the EMU3 tokenizer MOVQ), which restricts our capability in T2I generation.” ② TwoObj 偏弱：训练 caption 很少用"生成两个物体"这种简单 prompt 格式。③ 推理偏重：每图 T≈480 个 token → 要 T 次自回归 + T 步 DDPM 去噪，正文未给推理计时[推测较慢]。④ 算力大：Stage1 预训练吃 512 张 Ascend 910B NPU 约两周。⑤ scaling law 仅"preliminary indications"（Fig.7），递归性结论以定性实证为主（插值/解码/困惑度/AB）。
📌 全文一页总结（问题→方法→实验→takeaway）
问题(§1)：统一理解+生成的 MLLM 用 spatial token，但它经 impossible-language 检验是"非语言"（无递归结构、打乱顺序对 LLM 收敛无感），与自然语言无法在 LLM 内互相增强 → 生成不如 SDXL、理解不如 LLaVA-1.6；底层还有 many-to-one（理解）vs one-to-one（生成）的目标冲突。
方法(§3-4)：DDT tokenization——用扩散 timestep 定义递归 token，第 t 个 token 补偿"加噪到 t 步丢失的属性"，f_{t+1}=(f_t, V_{t+1})，coarse→fine 属性解耦；tokenizer = transformer encoder（T 个 learnable query + 仿 SD3 双流）+ VQ（|C|=65536, m=16, EMA + 死码重置）+ MMDiT decoder，训练损失（式1）只给前 t 个 token 重建逼出递归性；DDT-LLaMA 从 LLaMA3-8B 扩 65536 视觉码、两阶段统一 next-token 训练，推理用 DM 经 T 步 DDPM 解码。
实验(§5)：GenEval 0.66（MLLM 最高、超 SDXL、近 SD3）、编辑超专用模型、encoder-free 理解强（NoCaps 124.2 / POPE 86.9）、ImageNet 重建 PSNR 21.7 / 类条件 FID 6.1 均超 spatial tokenizer；counterfactual interpolation / 扩展解码 / 文本困惑度 / A/B test 四组实证 token 递归且属性解耦。
Takeaway：① 把"视觉该用什么 token 喂 LLM"重述为"要造有递归结构、像语言的 token"——扩散 timestep 是天然的递归坐标；② "只给前 t 个 token 重建"是逼出递归性的命门；③ token 选对了，同范式同算力下就涨点（Table 4），且 encoder-free 也能强理解；④ 边界=美学受 ImageNet-only tokenizer 限、TwoObj 弱、推理 T 步偏重、算力大、scaling 仅初步。
