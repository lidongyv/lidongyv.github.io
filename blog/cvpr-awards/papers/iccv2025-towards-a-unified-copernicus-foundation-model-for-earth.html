Towards a Unified Copernicus Foundation Model for Earth Vision

摘要 Abstract

见上方 arXiv / CVF 链接。

📝 精读笔记

灵魂一句
一篇遥感/对地观测(EO)基础模型的"数据+模型+benchmark"三件套工作：① Copernicus-Pretrain——18.7M 对齐图像、覆盖全部主力 Copernicus Sentinel 卫星(S1~S5P)+DEM，从地表一路到大气；② Copernicus-FM——用动态超网络(hypernetwork)把"任意光谱/非光谱传感器"统一成 patch token、再把元数据(经纬/面积/时间)用 Fourier 编码注入，MIM + 持续蒸馏预训；③ Copernicus-Bench——15 个分层下游任务。还顺手证明 EO grid embedding 能桥接气候预测。核心是"用一个模型吃下异构卫星 + 把图像外的元数据也喂进去"。
问题 & 动机
现有 EO 基础模型三大短板：① 传感器单一——多盯高/中分辨率的 S1/S2/Landsat（只看地表），漏掉低分辨率但近每日全球覆盖的 S3/S5P（含大气、海洋变量，对气候关键）；② 架构僵硬——多为固定模态定制，DOFA 等虽能处理任意光谱通道但处理不了非光谱变量（大气成分/高程），也不用元数据；③ 评测面窄——benchmark 多是 RGB/MS/SAR 的地表任务、缺粗尺度与大气任务。本文要做"统一、可扩展、多模态"的下一代 EO FM，并打通 EO↔天气/气候。
核心方法（关键机制 + 公式）
① 光谱超网络（spectral hypernet，承自 DOFA[62]）：每个通道的中心波长 λ + 带宽 δ 经 Fourier 编码（式1 FE(x)=[cos(2πx/ω_i),sin(2πx/ω_i)]，式2 ω_i log 间隔）→MLP+多头注意力→动态生成 patch embedding 的卷积核 K_conv∈R^{D×C×p×p}；借 FlexiVit[7] 把核 resize 成各模态合适的 patch size（解决分辨率差异炸显存）。② 变量超网络（variable hypernet，本文新增）：非光谱模态（S5P 大气/DEM 高程）没有波长这种公共属性→直接把变量名（如 "Sentinel-5P NO2"）用冻结 LLM(Llama 3.2) 离线编码成 D 维向量，同样生成卷积核（零额外开销）。③ 元数据 Fourier 编码：经纬(Loc)/面积(Area)/时间(Time) 各 Fourier 编码→MLP→加到 position encoding；缺失时用可学 token，训练随机 drop（drop 0.7）。④ 训练：MAE 式 MIM（mask 0.7）+ 辅助持续蒸馏（从 DINOv2 蒸 RGB 权 0.1、从 SoftCon 蒸 S1/2 权 0.2）。
关键结果
消融（Tab.2）：逐项加组件持续涨，元数据编码增益最大（EuroSAT-S1 OA +22.4、AQ-O3 RMSE ↓758.8），尤其利好非光学模态。Benchmark（Tab.4，冻结编码器）：Copernicus-FM 在多数任务追平/超 SoftCon/CROMA/DOFA，S3/S5P 任务大幅提升——AQ-O3-S5P RMSE 789.4 vs DOFA 1755.6（≈2.2×）、LC100Seg-S3 mIoU 24.1 vs DOFA 16.5；并在 11/15 任务超过监督训练（且更少参数/迭代）。气候（Tab.5）：EO grid embedding 当地理特征预测气候参数，温度 RMSE 1.98(embed+coord) vs 8.36(raw coord) vs 3.67(SatCLIP)。
亮点
① "任意模态"是真任意：光谱靠波长/带宽、非光谱靠 LLM 编码变量名——一个统一框架吃下 SAR/多光谱/大气/高程；② 把图像外的元数据正式当一等公民，且消融证明它是最大增益来源（遥感里地理/时间信息本就含大量先验）；③ 首次证据：跨模态联合预训对地表与大气任务都涨，打破"地表 vs 大气"数据孤岛；④ EO↔气候桥：grid embedding 比纯坐标、甚至比专门的 location encoder(SatCLIP) 更能预测气候，开了 EO 进气候模型的口子；⑤ 数据/模型/benchmark 全开源。
疑问 / 待查
① 范围受限（作者自承 limitation）：只覆盖 Sentinel 系列、时间跨度约 1 年；② benchmark 多为冻结编码器 + 线性/UPerNet 探针，全量微调下与 baseline 的差距是否保持，正文未给（需查附录）；③ 部分任务（如 DFC2020-S2、Flood-S1、BigEarthNet-S2）Copernicus-FM 并非最优（SoftCon/CROMA 更好）——"全能"在专精单模态上仍有取舍，论文表述为"comparable to or better than"；④ 蒸馏依赖 DINOv2/SoftCon 等外部 teacher，其贡献与可得性是隐性依赖；⑤ climate 实验只预测 10 年均值/标准差（静态气候态），非真正的天气预报（原文明确为 future work）。

📖 逐段精读 · 笔记

从 Abstract 起逐段精读（批量精读初稿，供后续 review/深化）。基于 CVF 官方 PDF 全文。最后更新 2026-06-21。
① Abstract（摘要）— 逐句精读
原文逐句引用 + 中文指路：
1) "Advances in Earth observation (EO) foundation models have unlocked the potential of big satellite data to learn generic representations from space." → 背景：EO 基础模型已能从海量卫星数据学通用表示。
2) "However, most existing efforts remain limited to fixed spectral sensors, focus solely on the Earth's surface, and overlook valuable metadata beyond imagery." → 三大痛点：① 固定光谱传感器；② 只看地表；③ 忽视影像外的元数据。
3) 三大组件："1) Copernicus-Pretrain, a massive-scale pretraining dataset that integrates 18.7M aligned images from all major Copernicus Sentinel missions, spanning from the Earth's surface to its atmosphere; 2) Copernicus-FM, a unified foundation model capable of processing any spectral or non-spectral sensor modality using extended dynamic hypernetworks and flexible metadata encoding; and 3) Copernicus-Bench, a systematic evaluation benchmark with 15 hierarchical downstream tasks."
4) 价值："greatly improve the scalability, versatility, and multimodal adaptability of EO foundation models, while also creating new opportunities to connect EO, weather, and climate research." → 提升可扩展性/通用性/多模态适配，并打通 EO 与天气/气候研究。
一句话抓 Abstract：面向下一代 EO 基础模型的"数据(18.7M 对齐图/全 Sentinel 任务/地表到大气) + 模型(dynamic hypernetwork 吃任意光谱/非光谱传感器 + 元数据编码) + 基准(15 个分层下游任务)"三件套，首次把地表与大气观测打通，并桥接 EO↔气候。代码 github.com/zhu-xlab/Copernicus-FM。
📚 背景知识 A — EO 基础模型 & Sentinel 任务谱系（外部）
Earth Observation(EO) 基础模型：用自监督从海量无标注卫星影像学通用表示，再迁移到土地覆盖、变化检测、大气等下游任务。Copernicus/Sentinel 系列卫星（欧盟 ESA）：Sentinel-1=SAR 雷达(10m,全天候)、Sentinel-2=多光谱反射率(10m,13 波段,地表)、Sentinel-3=多光谱辐亮度(300m,21 波段,近每日全球,海陆)、Sentinel-5P=大气成分(1km,NO2/CO/SO2/O3 等痕量气体)。本文痛点：现有数据集/模型大多只用高/中分辨率 S1/2(看地表)，排除了低分辨率但时序丰富、对气候关键的 S3/S5P。
📚 背景知识 B — DOFA / dynamic patch embedding / hypernetwork / FlexiViT（外部，理解§4必备）
hypernetwork(超网络)：一个网络动态生成另一个网络的权重。DOFA[62]（本文的直接前身）提出 wavelength-conditioned dynamic patch embedding——用超网络根据每个通道的中心波长动态生成 patch embedding 卷积核权重，从而一个统一架构处理任意光谱波段/通道数。局限：只支持光谱传感器、忽略元数据。FlexiViT[7]：一个模型支持任意 patch size——通过 resize 卷积核权重适配不同 patch 大小。本文借它解决"不同模态分辨率差异巨大→显存/算力爆炸"的问题。Copernicus-FM = DOFA + 非光谱(variable hypernetwork) + 元数据 + FlexiViT 式动态 patch size。
📚 背景知识 C — MIM/MAE / continual distillation / DINOv2 / ERA5（外部）
MIM(masked image modeling)/MAE：随机 mask 掉部分 patch、让模型重建被遮的 patch，是视觉自监督主流。continual distillation(持续蒸馏)：用强力专用/通用基础模型(teacher)的特征作锚点，引导/精修被训模型的隐空间(student)，加速收敛、提升表示质量。DINOv2[44]：强力自监督视觉基础模型(常作 teacher)。ERA5[29]：ECMWF 的再分析(reanalysis)数据集，气候/天气研究最常用之一，提供全球网格化的温度/降水/气压/风等参数——本文刻意让 Copernicus-Pretrain 的 0.25° 网格与 ERA5 对齐，为桥接 EO↔气候铺路。
② §1 Introduction — problem（EO 基础模型的三维局限）
problem（原文明确三维）："the evolution of EO foundation models faces critical limitations in three dimensions: sensor diversity, model flexibility, and evaluation breadth."
① sensor diversity："current pretraining datasets predominantly focus on high- to medium-resolution sensors like Sentinel-1/2 and Landsat ... This excludes lower-resolution but temporally rich missions like Sentinel-3 and Sentinel-5P, which provide near-daily global coverage ... critical for climate studies."
② model flexibility："most existing EO foundation models adopt rigid architectures tailored to one or more specific sensor modalities ... While recent efforts introduce some spectral flexibility, they still lack mechanisms to handle non-spectral variables."
③ evaluation breadth："current foundation model evaluation benchmarks primarily focus on surface applications using RGB, multispectral, or SAR sensors, while overlooking coarse-scale sensors and atmospheric tasks."
② §1 Introduction — solution（三大协同贡献）
solution：原文 "we introduce three synergistic contributions"——
① Copernicus-Pretrain："one of the largest and most diverse EO pretraining datasets to date, comprising 18.7 million aligned observations from all major operational Copernicus Sentinel missions (Sentinel-1 to Sentinel-5P) ... enables holistic modeling of Earth system interactions by integrating atmospheric variables and coarse-scale observations."
② Copernicus-FM："a unified foundation model capable of processing any spectral or non-spectral sensor using dynamic hypernetworks. With additional support for metadata integration."
③ Copernicus-Bench："a comprehensive evaluation benchmark with 15 downstream tasks hierarchically organized across preprocessing (e.g., cloud removal), base applications (e.g., land cover classification), and specialized applications (e.g., air quality estimation)."
② §1 Introduction — why（三个新前沿方向）
原文三个 open new frontiers："(1) scaling EO pretraining to unified multimodal datasets, breaking the traditional silos between surface and atmospheric observations; (2) verifying that dynamic architectures can overcome sensor heterogeneity, a longstanding challenge in multi-source remote sensing; and (3) providing the first evidence that joint cross-modal pretraining enhances performance on both surface and atmospheric tasks."——分别对应数据(打破地表/大气壁垒)、模型(动态架构克服传感器异质)、实验(首次证明跨模态联合预训练同时增益地表与大气任务)。更远的愿景："using compressed EO embeddings ... in addition to geographical coordinates to support climate modeling."(用 EO embedding + 坐标支持气候建模)。

③ §3.1 数据采集流程（ERA5 网格 + Gaussian 采样）
网格对齐 ERA5：原文 "we divide the globe into ∼1M 0.25° × 0.25° grid cells following the coordinate mapping of ERA5. Each cell thus covers a surface area of about 28 km × 28 km."；用 land mask + 海岸线 0.5° buffer 滤出约 393K 陆地网格。
采集策略：用 Google Earth Engine 下载锚定 2021 年的影像。S3/5P/DEM 直接覆盖整个 cell(96×96 / 28×28 / 960×960)；S3 滤掉亮像素>20%的云块、随机下 8 张；S5P 选 NO2/CO/SO2/O3 四变量、滤全 NaN、下 12 个月均值图。S1/S2 数据量太大且冗余，故按 Gaussian sampling(围绕 top-10K 人口城市、std 50km)采 ~1M 个 location，每个下 4 季节 264×264 patch；另加 40K 极地 location。再按中心位置归入 0.25° grid。最后做质检去 corrupted/NaN 主导图。原文动机："To optimize the diversity of the data, we do not directly conduct uniform sampling ... but follow a Gaussian sampling strategy."
④ §4 Copernicus-FM 总览（统一 hypernetwork 框架）
三大设计：原文 "uses unified hypernetworks to dynamically patchify different modalities into patch tokens, integrates metadata as Fourier encodings added to the patch tokens, and performs masked image modeling (MIM) with auxiliary continual distillation as the training objectives."。输入：一个 grid 的全模态各采一图 → 8 张不同空间/通道尺寸的图。难点：如何用单一架构吃下"光谱(S1/2/3)+非光谱(S5P 大气、DEM 高程)+巨大分辨率差异+可选元数据"。答案 = 两个 hypernetwork(spectral + variable) 生成 patch embedding 卷积核 + 统一 Fourier 元数据编码 + MIM+蒸馏训练。
④ §4.1 Spectral Hypernetwork（式1-2 Fourier 编码 → 动态卷积核）
核心：一张光谱图 \( X \in \mathbb{R}^{C\times H\times W} \)，每通道有中心波长 \( \lambda \in \{\lambda_1,...,\lambda_C\} \) 与带宽 \( \delta \in \{\delta_1,...,\delta_C\} \)(取自传感器光谱响应)。先用 Fourier 编码把一个波长/带宽值编成 D 维向量——式1：\[ \mathrm{FE}(x)=\left[\cos\frac{2\pi x}{\omega_i},\ \sin\frac{2\pi x}{\omega_i}\right],\quad \forall\, 0\le i式2 频率 log 间隔：\[ \omega_i=\exp\!\left(\log\omega_{\min}+i\cdot\frac{\log\omega_{\max}-\log\omega_{\min}}{D/2-1}\right) \]
生成卷积核：波长/带宽各一套 Fourier 编码 → \( V_\lambda, V_\delta \in \mathbb{R}^{C\times D} \) 相加成 \( V_{spec} \in \mathbb{R}^{C\times D} \)；follow DOFA 经 MLP + multi-head attention 得权重 \( M_w \in \mathbb{R}^{C\times p^2 D} \) 与偏置 \( M_b \in \mathbb{R}^{C\times D} \)，reshape 成卷积核 \( K_{conv} \in \mathbb{R}^{D\times C\times p\times p} \)。关键改进：原文 "the significant resolution gaps between our input modalities will lead to exploded memory and compute costs. To tackle this issue, we adapt the idea of FlexiViT to dynamically reshape the kernel weights into a suitable patch size for each modality."——借 FlexiViT 把核动态 reshape 成每模态合适的 patch size \( K'_{conv} \)，再做卷积 patchify。
④ §4.1 Variable Hypernetwork（LLM 编码非光谱模态）
痛点：spectral hypernetwork 能处理任何"有光谱响应"的模态，但 S5P 大气成分、DEM 高程没有波长/带宽这种公共元属性。
解法：原文 "we propose to directly encode their variable names using modern large language models (LLMs) with general scientific knowledge ... we use one frozen LLM encoder to encode the variable names of non-spectral inputs into D-dimensional vectors. This is done as a preprocessing step through one-time inference offline, thereby introducing zero additional cost."——用冻结的 LLM(实现用 Llama 3.2)把变量名(如 "Sentinel-5P NO2")编码成 D 维 \( V_{var} \)，离线一次性推理、零额外成本；之后同 spectral 分支经 MLP+attention 生成卷积核权重/偏置并 reshape 到模态特定 patch size。这把"语言里的科学知识"巧妙引入非光谱模态的 patch embedding。
④ §4.1 Metadata Integration（geolocation / area / time 统一 Fourier 编码）
三类元数据：原文 "we consider three common types of metadata for one input image: geolocation, spatial coverage, and time."
① geolocation：图像中心经纬度各编成 D/2 维再拼成 \( Loc \in \mathbb{R}^D \)；② spatial coverage：由 GSD 与 patch size 算出 patch 面积(km²)编成 \( Area \in \mathbb{R}^D \)；③ time：采集日期与参考日期的天数差编成 \( Time \in \mathbb{R}^D \)。都用式1-2 的 Fourier 编码(各自值域)，经 MLP 后扩到 patch 维、加到位置编码 \( P \in \mathbb{R}^{N\times D} \) 上。缺失处理：原文 "we introduce a learnable token for each metadata when it is unavailable. We simulate such metadata-missing scenarios by randomly dropping part of the metadata during each iteration."——缺失时用可学 token，训练时随机 drop(概率 0.7)模拟缺失，增强鲁棒。
④ §4.2 训练目标（MIM + 持续蒸馏）
双目标(follow DOFA)：① MIM——MAE 式逐模态 masked 重建：patch token 随机 mask、过 encoder + 轻量 Transformer decoder 重建被遮 patch；用类似 patch embedding 的动态 patch predictor，末端用全连接层(因在展平 patch token 上重建)。② auxiliary continual distillation(小 loss 权重)——原文 "using powerful single-modal or general-domain foundation models to serve as an anchor to guide and refine the latent space. For example, we distill S2-derived RGB representations from a frozen DINOv2 encoder with a cosine-similarity loss."。好处："improve the out-of-the-box representation quality of MIM-based pretraining, reduces compute cost with faster convergence, and implicitly boosts the model's general knowledge."
④ §4.3 实现细节
ViT-Base、在 220K 全模态 grids 上预训练 100 epochs；数据增强=resized cropping + 水平翻转。各模态 patch size：S1/2 用 16×16、S3 用 8×8、S5P 用 4×4、DEM 用 64×64。用 Llama 3.2 编码变量名。Fourier 值域：波长 [1e2,1e9]、带宽 [1,1e9]、经纬度 [1e-4,720]、patch 面积 [1e-3,5.1e8]、时间 [1,365.25]。元数据 drop 概率 0.7、MIM masking ratio 0.7。蒸馏：RGB 从 DINOv2(权重 0.1)、S1/2 从 SoftCon(权重 0.2)。

⑤ §5 Copernicus-Bench（15 任务 · 三级分层）
结构：原文 "15 datasets with varied Sentinel modalities organized into three application levels: preprocessing, base applications, and specialized applications."
• L1 预处理(2 个)：S2/S3 云检测(Cloud-S2 seg 4 类、Cloud-S3 seg 5 类 new)。
• L2 基础应用(8 个)：S1/2/3 的土地覆盖分类/分割——EuroSAT-S1/S2(cls 10 类)、BigEarthNet-S1/S2(cls 19 类)、LC100Cls-S3(cls 23 类 new)、DFC2020-S1/S2(seg 10 类)、LC100Seg-S3(seg 23 类 new)。
• L3 专门应用(5 个)：Flood-S1(变化检测 3 类)、LCZ-S2(局地气候区 cls 17 类)、Biomass-S3(回归 new)、AQ-NO2-S5P / AQ-O3-S5P(空气质量回归 new)。
15 个中 9 个改自现有许可数据集、6 个新建(填补 S3/S5P 的 ML-ready 空白)。

⑥ §6 桥接 EO 与气候（grid embeddings + Table 5）
思路：因 Copernicus-Pretrain 网格与 ERA5 对齐，Copernicus-FM 编码的 grid embeddings(对一个 grid 各模态 model-encoded 图简单平均得到)可作"语义丰富的地理表示"支持气候建模。任务：预测 6 个气候参数(2m 气温、年总降水、地表气压、海平面气压、10m 风速 u/v 分量)的 10 年均值与标准差，用 10K 全球 grid、线性回归、ERA5 为目标。
Table 5 结果（气温 Avg RMSE↓ 为例）：Coord.(raw) 8.36 → Coord.(Fourier 编码) 3.99 → Embed.(grid embedding) 2.66 → Embed.+coord. 1.98(最优)；甚至优于专门的 EO 位置编码器 SatCLIP 3.67。原文 "combining grid embeddings with coordinates yields the best overall performance, demonstrating the complementary nature of spatial context and EO-derived semantic features ... even when compared against location encodings from a specialized location encoder trained on EO images, the grid embeddings still outperform."——证明 EO embedding 对气候研究有独特价值；作者已据此扩出 0.25° 全球 embedding 数据集，展望接入中期天气预报。
📌 全文一页总结（problem → method → experiment → takeaway）
problem：EO 基础模型在三维受限——传感器多样性(只用 S1/2 看地表、漏掉 S3/S5P 大气)、模型灵活性(架构僵化、只支持光谱、忽略元数据)、评测广度(基准只覆盖地表光学/SAR)。
method：三件套——① Copernicus-Pretrain：18.7M 对齐图/312K 个 0.25° grid(对齐 ERA5)/8 模态(S1-S5P+DEM，地表到大气)，S1/2 用 Gaussian 采样、S3/5P 覆盖全 cell；② Copernicus-FM：spectral hypernetwork(波长/带宽 Fourier 编码生成动态卷积核，式1-2，FlexiViT 式动态 patch size) + variable hypernetwork(冻结 LLM 编码非光谱变量名，零额外成本) + 统一 Fourier 元数据编码(geo/area/time，可学 token 处理缺失) + MIM+持续蒸馏(DINOv2/SoftCon teacher)；③ Copernicus-Bench：15 任务三级(预处理/基础/专门)，6 个为 S3/S5P 新建。
experiment：消融(Tab.2)显示 metadata encoding 增益最大(EuroSAT-S1 +22.4、AQ-O3 RMSE 降 758.8)；Benchmark(Tab.4)11/15 任务超监督训练且 S3/S5P 大幅领先(AQ-O3-S5P RMSE 1755→789.4)；气候(Tab.5)grid embedding+坐标预测气候参数最优(气温 RMSE 1.98)、超 SatCLIP。
takeaway：① 动态 hypernetwork(光谱+变量名 LLM)是统一异质传感器(光谱/非光谱/任意分辨率)的有效路径；② 影像之外的元数据(尤其地理位置)极其重要，是非光学模态性能的最大单一增益来源；③ 跨模态联合预训练首次被证明同时增益地表与大气任务，打破二者壁垒；④ EO grid embedding 含独特语义、可桥接 EO↔气候，开启统一"地球系统"基础模型方向。
🧐 疑问 / 局限（含 [推测]）
① 原文明确限制："the scope of this work is restricted to the Sentinel series and a temporal range of about 1 year"——只覆盖 Sentinel + ~1 年(锚定 2021)，跨卫星扩展与长时序未做；② [推测] grid embedding 用"各模态简单平均"得到，较粗糙——未学专门的跨模态融合/时序聚合，气候应用上限可能被低估；③ Table 4 中 SoftCon/CROMA 在 S3/S5P 任务为"–"(不支持)，与 Copernicus-FM 的对比在这些任务上缺同类多模态强 baseline，[推测] 优势部分来自"别人压根做不了"而非纯粹更强；④ DOFA 是 spectral-only baseline 却在 S5P(非光谱)有值，[推测] 是把 S5P 当单通道光谱硬塞，对比口径需谨慎；⑤ [推测] 用 frozen LLM(Llama 3.2)编码变量名虽"零额外成本"，但变量名表述/语言先验可能引入偏差，且仅靠名字区分模态对细粒度物理差异的刻画有限；⑥ [推测] 预训练仅 ViT-Base/100 epochs，更大模型/更长训练的 scaling 行为正文未充分探。
