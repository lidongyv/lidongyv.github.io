CVPR 2026   Finalist

Learning Latent Concepts for Detecting Out-of-Distribution Objects

Ting Peng ⋅ Junhao Dong ⋅ Yew-Soon Ong
CVF 官方 PDF ⬇Scholar

摘要 Abstract

Detecting out-of-distribution (OOD) objects is indispensable for safely deploying object detectors in the wild. Current approaches enable the unknown-aware ability by regularizing the instance-level feature space, such as outlier synthesis. Despite the general efficacy, it is challenging to truly learn the concept of `unknown' under the absence of real unknown data. In this paper, we propose UNO-Adapter, a simple yet highly effective framework tailored for OOD object detection. Our key insight is that in object detection, where in-distribution~(ID) and OOD objects may coexist within the same context, we need global abstraction and reasoning to help the detector learn their differences, i.e., unknown injection. UNO-Adapter consists of two key steps: unsupervised concept discovery and neural concept binder. The former introduces an object-centric learning paradigm to abstract and model the holistic image, including both ID and OOD, obtaining sparse and compressed slot-based representations with relational constraints. The latter dynamically combines slots with object candidates extracted by the detector, binding the concept of unknown to the de facto detector. During inference, we introduce an image-guided OOD object score to reinforce the distinction between ID and OOD. Experiments on standard benchmarks demonstrate the superiority of the proposed method. In particular, UNO-Adapter reduces the FPR95 by up to 11.96% compared to the previous best OOD object detection method.

📝 精读笔记

灵魂一句
UNO-Adapter：不动检测器(权重/结构/loss 全不改)，外挂一个"给检测器注入‘unknown’概念"的适配器来做 OOD 物体检测(OOD-OD)。核心洞察：检测场景里 ID 与 OOD 物体共存于同一画面，光看 instance 级特征不够，要像人一样做全局抽象+关系推理。三步：① UCD 无监督把整图抽象成稀疏 object-centric 的 slot(概念)；② NCB 推理时按相似度把 slot 绑到检测器的 query/instance 特征上(免训练)；③ image-guided OOD score 用重建一致性+分位数打分区分 ID/OOD。BDD-100K 上 FPR95 最多降 11.96%。
问题 & 动机
现有 OOD 方法多为图像二分类设定(scoring function / 训练正则 / outlier synthesis)，搬到 OOD-OD 水土不服——OOD-OD 里 ID/OOD 同图共存。已有 OOD-OD 大多只在 instance 级特征上合成 outlier(VOS/SIREN/DFDD)，依赖检测器自带定位；一旦 instance 特征不准→① OOD 定位差 ② ID/OOD 决策边界扭曲。原文点题：模型 “only focusing on localized features without considering the broader contextual relationships and causal dependencies”。本文反问 “How can we devise a unified framework that imitates the human vision process for detecting OOD objects?”——人靠对比+关系推理形成概念，而非死记单个物体。
核心方法（关键公式）
① UCD（无监督概念发现）：基于 slot attention(+DINOSAUR 重建 DINO 特征)。slot 更新 ŝ_i=Σ_j α_ij·W_V·x_j(式2)；新增 importance score π_i^init=sigmoid(h_θ(s_i))(式3) + relational matrix W_ij=softmax_j((Uv_i)ᵀ(Vv_j)/√d)(式4)→π_i=Σ_j W_ij·π_j^init；再用 信息瓶颈(VIB) 精炼：σ'_i=σ_i(1−π_i)(式6)、z_i=µ_i+ε⊙σ'_i(式7)、加权 KL(式8)，L_UCD=L_recon+βL_KL(式9)。得到稀疏、解耦的 slot codebook。② NCB（神经概念绑定，免训练）：按归一化 importance 给每个 slot 分配 query 数 m_i=⌊π̂_i·M⌋(式10)，融合 Q_i={q…}+s''_i·π̂_i(式11)拼成 Q_fused(式12)——slot 补全局、query 管定位。③ OOD score：score=γ·cos(f̂_t,f_t)·Φ_τ(z_i)(式14)，f̂_t=SlotDecoder 重建的图级特征 vs DINO 特征 f_t、γ=max_i sigmoid(g_l(o_i))(式13) 校准、Φ_τ 分位数(τ=80%)替代易过自信的 MaxLogit。
关键结果
OOD-OD(Deformable DETR backbone)：BDD-100K→MS-COCO AUROC 97.61 / FPR95 9.88、→OpenImages 99.04 / 3.80(均 SOTA)；比次优 WFS FPR95 降 11.96%(COCO)/4.03%(OpenImages)。PASCAL-VOC→COCO 91.68/32.61。消融(Table3)：裸 baseline 88.92/28.60 →+UCD 94.69/14.25 →+UCD+NCB 97.61/9.88。OOD score 拆解(Table5)：MaxLogit 46.85/96.52 →+Φ_τ 80.30/57.36 →+γcos·Φ_τ 91.68/32.61。还在 OWOD(Table2)和 ImageNet OOD 分类(Table4)上验证可扩展。开销(Table6)：仅微调 0.1h、推理 11.54s(SIREN 要 retrain 2.1h)。
亮点
① "外挂不改检测器"：不动权重/结构/loss，NCB 与 OOD score 都在推理时工作→可即插到 MSP/Energy/SIREN/SAFE 上都涨点；② 把 object-centric slot(全局) 与 检测器 query(定位) 互补绑定，是本文新意；③ 用 信息瓶颈给 slot 去冗余、用 importance 加权调制 KL，让 slot 稀疏可判别。BDD-100K 是自动驾驶数据集，论文也把 autonomous driving 列为目标高风险场景。
疑问 / 待深挖
① UCD 只在 PASCAL-VOC 上训一次就 “kept fixed across different datasets”，跨域(VOC→BDD 驾驶场景)slot 概念是否真迁移、靠什么保证，原文未深究；② 式8 写成 “L_KL=½π_i(µ_i+σ'_i²−2log(σ'_i²)−1)”，标准 KL 应是 µ_i²，疑为排版漏平方(需对照原式)；③ slot 数 S、分位 τ 固定跨数据集，Fig5 称 “stable within a certain range”，但最优值与敏感区间的具体数原文图里未给文字数值。

📖 逐段精读 · 笔记

批量精读初稿（基于本地 PDF 全文提取，45K 字符）。结构：Abstract 逐句 → 背景 → Intro 闭环 → Method 公式 → 实验数值表 + 全文总结。
① 摘要 Abstract — 逐句精讲
任务与痛点：“Detecting out-of-distribution (OOD) objects is indispensable for safely deploying object detectors in the wild.” 现有做法靠在实例级特征空间做正则（如 outlier synthesis），但“it is challenging to truly learn the concept of 'unknown' under the absence of real unknown data.” —— 没有真实未知数据时，很难真正学到「未知」这个概念。
核心洞察（本文方法 UNO-Adapter）：“in object detection, where ID and OOD objects may coexist within the same context, we need global abstraction and reasoning to help the detector learn their differences, i.e., unknown injection.” 即检测场景里 ID 与 OOD 同框出现，需要全局抽象与推理，把「未知」概念注入到现成检测器。两步：unsupervised concept discovery（无监督概念发现，object-centric 的 slot 表示 + 关系约束）+ neural concept binder（把 slot 与检测器抽出的候选目标动态绑定）。推理期再加一个 image-guided OOD object score 强化 ID/OOD 区分。
结论数字：“UNO-Adapter reduces the FPR95 by up to 11.96% compared to the previous best OOD object detection method.” 一句话抓摘要：不改检测器、不加任务专属训练目标，用 slot 概念建模把「未知」注入现成检测器，FPR95 最多降 11.96%。
📚 背景知识（外部，读懂全文必备）
① OOD detection vs OOD-OD：传统 OOD 检测是二分类图像级问题（基于训练好的 ID 分类器判一张图是否 OOD），方法有 scoring function（MSP/Energy/MaxLogit/KNN）、训练期正则、outlier synthesis。但 OOD object detection (OOD-OD) 更难：“ID and OOD samples often appear within the same context during test time”，模型要同时定位+分类新物体。
② Outlier synthesis（被对比的主流路线）：VOS 估计类条件分布、从低似然区采样合成虚拟离群点；[51,54] 用 diffusion 合成特征；SIREN 在单位超球面上塑形表示。本文批评：这些大多扩展分类思路、依赖实例级特征，“If the instance-level feature extraction is inaccurate, it can lead to … poor localization of OOD objects … distorted decision boundaries”，因为只看局部特征、忽略场景的上下文关系与因果依赖。
③ Object-centric learning / Slot Attention / DINOSAUR：把场景表示为「distinct objects 的组合」。Slot Attention 引入一组向量 slots 学解耦的物体表示，但更适合合成数据；DINOSAUR 改成「重构预训练自监督编码器（DINO）的深层特征」而非像素，能用到真实数据——本文采用它。本文指出其两短板：不考虑 slot 重要性差异与彼此关系、表示仍冗余含噪。
④ Information Bottleneck (IB) / VIB：IB 目标 \(\min_S I(S';Y)-\beta I(S';X)\)——在「保留任务相关信息」与「压缩冗余」间权衡。VIB（深度变分 IB）用神经网络给可解近似：把输入编码成分布 \(q(s|x)\)（均值 \(\mu\)、方差 \(\sigma^2\)），用 reparameterization 采样。本文借它做 slot refinement。人类类比：作者反复强调“humans … abstract concepts through comparison and reason about their relationships”，本文就是模仿这种全局抽象+关系推理。
② §1 Introduction — problem → solution → why 闭环
problem：开放世界部署会遇到 OOD；现有 OOD-OD 多是「分类思路 + 实例级特征」，依赖检测器内建定位，一旦实例特征不准就定位差 + 决策边界扭曲，因为“only focusing on localized features without considering the broader contextual relationships and causal dependencies”。
solution：核心提问“How can we devise a unified framework that imitates the human vision process for detecting OOD objects?” 主张：好的 OOD 检测器“must not only recognize individual objects but also understand the latent concepts that define the relationships between them.” 于是 UNO-Adapter——“capture and model key elements of the image independently of the detection model, and then bind these elements to the detector's internal features, without requiring a retraining process.” 三件套：UCD（抽 sparse object-centric slots）→ NCB（按相似度把 slot 与实例特征绑定）→ image-guided OOD score（重构保全局一致）。
why 这样设计：① 不改检测器权重/结构、不加任务专属损失——可插到 DETR、Faster R-CNN 之上，迁移性强；② UCD 用 relational modeling + information bottleneck，“encouraging task-relevant abstraction while reducing redundancy”，得到紧凑解耦的 slot codebook 把物体与背景噪声分开；③ slot 有全局理解但定位差、实例特征定位好但全局弱，NCB 取长补短。贡献：提出注入「未知」的 OOD-OD 框架；slot 概念发现 + slot-instance 绑定；显著超 SOTA（“reduces the FPR95 by 8.0% on BDD-100K”），并扩到 OWOD 与 OOD 图像分类。
③ §2 Related Work — 定位与差异
OOD detection 两条线：(1) scoring function——confidence-based、energy-based、distance-based、gradient-based；(2) 训练期正则——lower confidence、high energy；外加引入真/合成离群点（OE 用真实离群、MCD/UDG 用无标注离群、NPOS 非参密度估计增多样性、Dream-OOD 用 text-to-image diffusion）。但“mostly designed for image classification”。OOD-OD：VOS、[51/54] diffusion 特征合成、SIREN 超球面表示、[11] 借辅助视频。本文差异：“we propose to inject the concept of unknown without changing the detector's original weights or architecture.” —— 别人改 pipeline/加模块，本文外挂注入。
④ §3.1 问题设定（Preliminaries）
形式化：图像 \(x\in X\)、框 \(b\in\mathbb{R}^4\)、类别 \(y\in Y\)（\(K\)-way）。先在 ID 数据 \(D=\{(x_i,b_i,y_i)\}_{i=1}^N\) 训检测器。测试时判 ID/OOD，建模为二分类：预测 \(p(g|x^*,b^*)\)，\(g{=}1\) 为 ID、\(g{=}0\) 为 OOD。框架三问：(1) 无标注下如何发现局部模式与全局关系（UCD）？(2) 如何把概念与检测器内部特征绑定（NCB）？(3) 推理时如何判 OOD（OOD Score）？可建在 DETR / Faster R-CNN 上，亦可退化到图像分类（整图当单物体）。
⑤ §3.2 UCD（一）— 粗 slot 表示（式1/2）
动机：模仿人「先抓显著区域与整体结构」。原始 slot attention 两难：固定 slot 数不灵活、slot 间交互不足导致孤立表示丢关系。本文提动态 slot attention。给特征集 \(X=\{x_1,\dots,x_N\},\ x_j\in\mathbb{R}^{d_x}\)，学 \(S\) 个 slot \(s_i\in\mathbb{R}^{d_s}\)，交叉注意力 \[\alpha_{ij}=\mathrm{softmax}_i\!\left(s_i^\top W_Q x_j/\sqrt{d_s}\right)\quad(1)\] slot 更新 \(\hat{s}_i=\sum_{j=1}^N \alpha_{ij}W_V x_j\)（式2），多轮迭代后收敛为离散的物体级表示。
⑥ §3.2 UCD（二）— 关系正则 + slot 精炼（IB/VIB，式3-9）
重要性分数（关系建模）：轻量网络 \(h_\theta\) 给初始重要性 \(\pi_i^{init}=\mathrm{sigmoid}(h_\theta(s_i))\)（式3）；关系矩阵 \(W_{ij}=\mathrm{softmax}_j\big((Uv_i)^\top(Vv_j)/\sqrt{d}\big)\)（式4），最终 \(\pi_i=\sum_j W_{ij}\pi_j^{init}\)，加权 slot \(s'_i=\pi_i\cdot s_i\)。
基于 IB 的精炼：用 VIB 对每个 slot 编码 \(\mu_i=h(s_i),\ \sigma_i=h(s_i)\)（式5），用重要性自适应缩放方差 \(\sigma'_i=\sigma_i(1-\pi_i)\)（式6，越重要→方差越小→保真度越高），重参数化 \(z_i=\mu_i+\epsilon\odot\sigma'_i,\ \epsilon\sim\mathcal{N}(0,I)\)（式7），解码 \(s''_i=g(z_i)\)。加权 KL \[\mathcal{L}_{KL}=\tfrac{1}{2}\pi_i\big(\mu_i+\sigma_i'^2-2\log(\sigma_i'^2)-1\big)\quad(8)\] 总损失 \(\mathcal{L}_{UCD}=\mathcal{L}_{recon}+\beta\mathcal{L}_{KL}\)（式9），\(\mathcal{L}_{recon}=\|s''_i-s'_i\|^2\)。直觉：“When a slot has high importance (\(\pi_i\) close to 1), it contributes more … enforcing a stronger constraint … to maintain information fidelity.” 结果是离散、稀疏、解耦的概念 codebook，把物体与背景噪声分离。
⑦ §3.3 Neural Concept Binder（推理期绑定，式10-12）
slot 与检测器（DETR 的 query）来自两个独立网络，NCB 按相似度自适应融合、无需训练。先归一重要性 \(\hat{\pi}_i=\mathrm{softmax}(\pi)_i\)，按比例给每个 slot 分配 query 数 \(m_i=\lfloor\hat{\pi}_i\cdot M\rfloor\)，最后一个 slot 补齐 \(m_N=M-\sum_{i=1}^{N-1}m_i\)（式10）。融合：被分配的 query 集 \(Q_i=\{q_{k_i},\dots,q_{k_i+m_i}\}+s''_i\cdot\hat{\pi}_i\)（式11），拼接得 \(Q_{fused}=[Q_1;Q_2;\dots;Q_N]\in\mathbb{R}^{M\times D}\)（式12）。直觉：“Slot representations have strong global understanding … but lack precise localization, whereas instance-level features excel at localization but have limited global comprehension.” 绑定取长补短，且“requires no training and preserves the original feature spaces”。
⑧ §3.4 Inference-Time OOD Score（式13/14）
image-guided：把 query 当 slot、用 slot 重构解码器重建所有目标的倒数第二层特征得图级特征 \(\hat{f}_t=\mathrm{SlotDecoder}(o_1,\dots,o_N)\)，与固定 DINO backbone 的 \(f_t\) 算余弦相似——“a high similarity suggests a low likelihood that contains OOD objects”。校准因子修小目标误判：\(\gamma=\max_i \mathrm{sigmoid}(g_l(o_i))\)（式13）。分位数策略取代易过自信的 MaxLogit：\(\Phi_\tau(z_i)\)=logits 分布的 \(\tau\) 分位阈值。综合得 \[score(o_i,b_i)=\gamma\cdot\cos(\hat{f}_t,f_t)\cdot\Phi_\tau(z_i)\quad(14)\] 前两项是图级引导。（\(\tau{=}1\) 时退化为 MaxLogit。）
⑨ §4.1 实验设置 + 实现细节
数据：ID 用 PASCAL-VOC（20 类，16,551 训 / 4,952 验）与 BDD-100K（10 类，69,853 训 / 10,000 验）；OOD 用 MS-COCO 与 OpenImages（人工核对剔除 ID 类）。OWOD 按 [26] 把 COCO/VOC 分 4 个不重叠任务。指标：FPR95↓（ID TPR=95% 时 OOD 假阳率）、AUROC↑、mAP；OWOD 另报 U-Recall。实现：检测器 Deformable DETR（ImageNet-1K 预训、ResNet-50 backbone、transformer 用 DINO-ViT-b16 初始化）；slot 用 DINOSAUR 框架；仅在 PASCAL-VOC 训、跨数据集固定；refinement=三个两层 MLP（重要性 + VIB 编/解码），\(U,V\) 为 256 维 FC，\(\beta=0.5\)，Adam lr \(10^{-5}\)、30 epochs、batch 64。

⑬ 亮点 / 疑问 / 局限
亮点：① 外挂式「概念注入」——不动检测器权重/结构、无任务专属损失，天然即插即用（Table 1 “w/ ours” 行全面提升）；② 用 object-centric slot + 关系约束 + IB 显式建模「全局抽象与关系」，正中 OOD-OD「ID/OOD 同框」痛点；③ 推理期 OOD score 把图级重构一致性（\(\cos(\hat f_t,f_t)\)）+ 校准 \(\gamma\) + 分位 \(\Phi_\tau\) 三者相乘，缓解 MaxLogit 过自信；④ 又快又好（推理 11.54s，FPR95 大降）。
疑问/局限：① UCD 仍需在 PASCAL-VOC 上训 30 epoch，并非完全免训——只是「不重训检测器」；slot 表示质量受 DINOSAUR/DINO 上限约束。② [推测] slot 数 \(S\) 固定，对极拥挤场景（远超 \(S\) 个物体）是否够用、关系矩阵 \(W_R\) 复杂度 \(O(S^2)\) 在大 \(S\) 时的代价，文中未深究（仅给 Fig 5 稳定性）。③ OOD score 含多个超参（\(\tau\) 默认 80%、\(\gamma\)、\(\beta{=}0.5\)），跨域固定虽方便但[推测] 极端域偏移下未必最优。④ 主结果基于 Deformable DETR；Faster R-CNN 结果在附录，[推测] 不同检测器迁移强度可能有别。⑤ image-guided score 依赖固定 DINO backbone 的特征，对 DINO 覆盖差的领域（医学/遥感）效果存疑。
📌 全文一页总结（≥3 takeaway）
problem：OOD object detection 中 ID/OOD 同框出现，现有「分类思路+实例特征+outlier 合成」忽略全局上下文与关系，导致定位差、决策边界扭曲。
method：UNO-Adapter=UCD（动态 slot attention + 关系重要性 \(\pi_i\) + 基于 VIB 的 slot refinement，式1-9）抽稀疏解耦概念 → NCB（按归一重要性把 slot 与 DETR query 自适应绑定，免训练，式10-12）→ inference-time OOD score \(\gamma\cdot\cos(\hat f_t,f_t)\cdot\Phi_\tau(z_i)\)（式14）。全程不改检测器。
experiment：OOD-OD（Table 1）BDD→COCO FPR95 21.84→9.88（降 11.96%）、BDD→OpenImages 99.04/3.80；OWOD（Table 2）U-Recall/mAP 全面超 Prob/ASGS；ImageNet 分类（Table 4）Near/Far 双超 OODD；消融证三模块与 OOD score 各项均有效，且推理仅 11.54s。
takeaways：(1) 把「未知」当作需要全局抽象+关系推理的「概念」来学，而非纯靠实例级 outlier 合成；(2) object-centric slot + 信息瓶颈给出稀疏解耦 codebook，是分离物体/背景噪声的关键；(3) 外挂注入、零检测器改动带来即插即用与低成本，FPR95 最多降 11.96% 并扩展到 OWOD/分类。
limitation：UCD 仍需训练、slot 数固定、OOD score 多超参跨域固定、依赖 DINO 特征、主结果限于 Deformable DETR。
