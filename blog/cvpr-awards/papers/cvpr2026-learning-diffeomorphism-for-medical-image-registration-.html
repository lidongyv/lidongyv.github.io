Learning Diffeomorphism for Medical Image Registration with Time-Embedded Architectures Using Semigroup Regularization

Mohammadjavad Matinkia ⋅ Nilanjan Ray
CVF 官方 PDF ⬇Scholar

摘要 Abstract

Diffeomorphic image registration (DIR) seeks topology-preserving transformations and is fundamental in medical imaging. Existing DIR methods rely on integration schemes (e.g., scaling-and-squaring) and multiple regularizers to enforce invertibility. We introduce **SGDIR**, a continuous-time registration framework, parameterized by known time-embedded backbones, that models diffeomorphisms using only a single semigroup-based regularization, eliminating explicit integration and auxiliary constraints. We mathematically prove that this formulation directly learns the flow of an underlying ODE, inherently enforcing inverse and cycle consistencies. We evaluate on eight 2D and 3D MR and CT datasets. Under strict semigroup enforcement, our model achieves near-perfect diffeomorphism (near-zero folding) and significantly outperforms existing diffeomorphic methods, while remaining competitive with leading non-diffeomorphic deformable models. When the regularization is relaxed, the same architecture functions as a deformable method and substantially surpasses state-of-the-art non-diffeomorphic approaches in registration accuracy. These results demonstrate that continuous-time deformation modeling, guided solely by our semigroup-based regularization, yields a unified framework capable of both rigorously diffeomorphic mapping and state-of-the-art deformable registration.

📝 精读笔记

灵魂一句
医学图像配准要“形变可逆不撕裂（diffeomorphism 微分同胚）”，传统做法靠 scaling-and-squaring 数值积分 + 一堆手工正则（Jacobian/平滑/逆一致/循环一致）。本文 SGDIR 把这一切砍成一条规则：只用“半群(semigroup)正则” ϕ_t∘ϕ_s=ϕ_{t+s}——并数学证明只需一个“部分半群”约束就足以逼网络学出某个 ODE 的流(flow)，从而把可逆性/循环一致/拓扑保持变成模型固有性质，不需积分、不需辅助正则；同一架构调一个 λ 就能在“严格微分同胚(近零折叠)”与“高精度 deformable SOTA”之间切换。
问题 & 动机
DIR 要求形变 ϕ 光滑可逆（|J_ϕ|>0、不折叠不撕裂，否则拓扑非法）。现代做法：参数化速度场 v、用 scaling-and-squaring 积分重建形变 ϕ_1，再叠加多个手工正则（Jacobian 罚、平滑罚）逼可逆；逆一致/循环一致也是显式加 loss 强加的、非固有。既贵又拼凑，且“先假设速度 ODE 再积分”而非从原理推出。
核心方法（半群 + 关键公式）
背景关键等价：DIR 把 ϕ 看成连续流 {ϕ_t}、建模为自治 ODE dϕ_t/dt=v(ϕ_t), ϕ_0=Id（式1）；本文指出 ODE ⟺ 半群性质 ϕ_t∘ϕ_s=ϕ_{t+s}（式5），且可微则有逆 ϕ_t⁻¹=ϕ_{−t}（式6）。SGDIR：① 参数化 ϕ_t(x;θ)=x+t·F(x,t;I_f,I_m,θ)（式9，F=time-embedded UNet/DiT，天然 ϕ_0=Id）；② 连续时间相似度 L_sim^t=−NCC(ϕ_{t−1}[I_f], ϕ_t[I_m])（式8，由“moving 正向到 t = fixed 反向到 1−t”的对应推出，式7）；③ 部分半群正则 L_sg^t=‖ϕ_{2t−1}−ϕ_t∘ϕ_{t−1}‖₂+‖ϕ_{2t−1}−ϕ_{t−1}∘ϕ_t‖₂（式10，第二项保对称）；④ 定理1：满足该组合律 + ϕ_0=Id 的 ϕ_t 是 exponential map = 解 ODE 的单参数微分同胚；⑤ 总 loss L=E[L_sim^t+λ·L_sg^t]（式12），λ 大=严格微分同胚、λ 小=可形变。
关键结果
8 个 2D/3D MR/CT 数据集。微分同胚 setting(λ=10⁵)：折叠率 |J|<0% 普遍 ~0.0（近完美微分同胚）、Dice 仍超现有微分同胚法且媲美 deformable。放松(λ=10⁴)：变 deformable、精度超 SOTA。OASIS DiT λ=10⁵ Dice 86.53/折叠 0.0（最强对手 84.63），λ=10⁴ Dice 88.09；AbdomenCTCT UNet Dice 53.64(折叠 0.0)→56.57，比最佳对手 +5%；LungCT TRE 2.37→2.23（降 ~10%）。计算：无积分→推理快 ~2×、显存约一半。
亮点
① 从“半群一致性”first-principles 推出微分同胚，而非假设速度 ODE + 积分；② 一条 partial semigroup 正则替掉 scaling-and-squaring + 所有辅助正则（Jacobian/平滑/逆一致/循环一致）；③ 逆/循环一致固有（对所有 t∈[−1,1]、无需显式建模逆）；④ 同架构一个 λ 统一“严格微分同胚 ↔ deformable SOTA”；⑤ 架构无关(UNet/DiT 都行)、任意时刻可查、无迭代采样、更快更省。
疑问 / 边界
① 半群正则用双线性插值组合形变网格（式10），组合/插值误差未单独量化；② DiT 变体参数量大（68.6M vs UNet 12.8M）、训练显存 16GB+；③ λ 需调（10⁵ 严格但精度略降、10⁴ 精度高但有少量折叠 ~0.4%），无单一“全能”λ；④ 定理1“部分半群⇒ODE flow”完整证明在附录（本笔记据正文转述、未独立校验数学细节）；⑤ 仍是无监督相似度(NCC)驱动，极端低对比/大形变 case 表现需看 supplementary。

📖 逐段精读 · 笔记

批量精读初稿（基于本地 CVF PDF 全文）：① Abstract 逐句 ② Intro 闭环 ③ Method 推导+公式 ④ 实验/消融数值表 + 全文一页总结。最后更新 2026-06-21。
① Abstract 逐句精讲（verbatim 引用 + 中文指路）
原文①：“Diffeomorphic image registration (DIR) seeks topology-preserving transformations and is fundamental in medical imaging. Existing DIR methods rely on integration schemes (e.g., scaling-and-squaring) and multiple regularizers to enforce invertibility.”
在说什么：DIR=求保拓扑（可逆、不折叠不撕裂）的形变；现状靠积分(scaling-and-squaring) + 多个正则强行可逆。这正是本文要砍掉的两样东西。
原文②：“We introduce SGDIR … that models diffeomorphisms using only a single semigroup-based regularization, eliminating explicit integration and auxiliary constraints. We mathematically prove that this formulation directly learns the flow of an underlying ODE, inherently enforcing inverse and cycle consistencies.”
在说什么：核心=只用一条半群正则、去掉积分与辅助约束；并数学证明这逼模型学出某 ODE 的流 → 逆一致 / 循环一致固有（不是外挂 loss）。
原文③：“Under strict semigroup enforcement, our model achieves near-perfect diffeomorphism … When the regularization is relaxed, the same architecture functions as a deformable method and substantially surpasses state-of-the-art non-diffeomorphic approaches.”
在说什么：一个权重 λ 两副面孔——严格→近零折叠的微分同胚 SOTA；放松→超 SOTA 的 deformable。
一句话抓 Abstract：用半群约束让普通 time-embedded 网络"天生微分同胚"，一套框架兼顾严格微分同胚与高精度 deformable。
📚 背景知识（外部，非本文原创，理解 SGDIR 必备）
① 微分同胚 / Jacobian 行列式：diffeomorphism=光滑、可逆、逆也光滑的映射 → 保拓扑。判据=形变 \(\phi\) 的雅可比行列式处处 \(|J_\phi|\gt0\)（保定向）；\(|J|\lt0\) 的体素=折叠（解剖非法），论文用 \(|J|\lt0\%\) 当"折叠率"指标，越低越好。
② 速度场 / 流 / ODE / scaling-and-squaring：把形变看成随时间 \(t\) 演化的流 \(\phi_t\)，由平稳速度场 \(\mathbf{v}\) 驱动：\( \frac{d\phi_t}{dt}=\mathbf{v}(\phi_t) \)（式1）。scaling-and-squaring=积分平稳速度场的经典数值法：先取极小步 \(\phi_{1/2^N}=x+\mathbf{v}/2^N\)（式2），再反复自组合 \(N\) 次得 \(\phi_1\)（式3）。本文要免掉这步。
③ 半群性质 / exponential map：semigroup：\(\phi_0=\mathrm{Id}\) 且 \(\phi_t\circ\phi_s=\phi_{t+s}\)（先变 \(s\) 再变 \(t\) = 一次变 \(t+s\)）。它与"\(\phi_t\) 是某自治 ODE 的流"等价；可微时自动有逆 \(\phi_t^{-1}=\phi_{-t}\)。一参数子群 \(\{\phi_t\}\) 由 exponential map 生成 → 必为微分同胚。这是 SGDIR 的数学根基。
④ 逆一致 / 循环一致：inverse consistency=A→B 的形变与 B→A 互逆；cycle consistency=A→B→A 回到原点。医学配准必备，前作多显式加 loss 强加；本文靠半群自动满足。
⑤ time-embedded 架构 + 指标：借扩散模型的时间嵌入网络（temporal UNet、Diffusion Transformer DiT [Peebles & Xie]），把 \(t\) 当条件输入 → 任意时刻可查形变、无需迭代采样。指标：Dice(分割重叠↑)、TRE(关键点配准误差↓)、HD95(95% Hausdorff↓)、SSIM↑、ASSD↓、\(|J|\lt0\%\)(折叠率↓)。
② Introduction · problem → 现有不足 → solution → why 闭环
problem：原文 “Most modern DIR frameworks parameterize velocity fields and reconstruct deformations via scaling-and-squaring integration, coupled with multiple handcrafted regularizers (e.g., Jacobian penalties, smoothness constraints).”
现有不足：① 连续时间/扩散类（DiffuseMorph/DiffuseReg）虽引入连续时间，但 “still rely on auxiliary constraints rather than deriving diffeomorphism from first principles”；② 逆/循环一致 “are often enforced explicitly rather than being inherent to the model”；③ 扩散类还需 iterative sampling + 固定时间网格、计算贵。
solution + why：原文 “Unlike prior ODE-based registration, we do not assume a velocity ODE, rather we derive it emergently from semigroup consistency.” 只用部分半群正则，证明这个更弱条件就足以保证模型学出 ODE 流 → 固有可逆 / 循环一致 / 拓扑保持。why 半群就够："\(\phi_t\) 是自治 ODE 的流" \(\Longleftrightarrow\) "\(\{\phi_t\}\) 满足半群律"（式1↔式5），半群可微即蕴含 \(\phi_t^{-1}=\phi_{-t}\)（式6）→ 双射 → 微分同胚。把半群当 inductive bias 训进网络，微分同胚结构就"免费"得到。
③ §2 Related Work · 三范式谱系（SGDIR 的坐标）
三范式：① traditional（SyN/NiftyReg/B-Splines/LDDMM 优化变分目标，精度高但算力贵；DARTEL 用 Lie 代数 + S&S）；② instance-optimization（IDIR/DNVF/NePhi 用隐式表示在连续坐标空间学形变/速度场；NODEO 用 neural ODE + 连续时间求解器）；③ learning-based（VoxelMorph 开创 CNN 配准；SYMNet 对称速度 + S&S；LapIRN/cLapIRN/PULPo 多分辨率；TransMorph/TransMatch/H-ViT 用注意力；CorrMLP 用 MLP + 相关图）。本文区别：用 time-embedded 架构学"任意时刻可即时查询"的连续形变，无 iterative sampling（区别于扩散类），且微分同胚来自半群一致性而非外挂正则。
④ §3 Background · ODE ≡ 半群（式1–6 推导）
形变 = 连续流：\(\phi:\Omega\to\mathbb{R}^3\) 把 moving \(I_m\) 对齐 fixed \(I_f\)；DIR 要 \(\phi\) 光滑保定向双射 \(|J_\phi|\gt0\)。看成流 \(\{\phi_t\}_{t\in[0,1]}\)，\(\phi_0=\mathrm{Id}\)。自治 ODE（式1）：\[ \frac{d\phi_t}{dt}=\mathbf{v}(\phi_t),\quad \phi_0(x)=x \] 实践中估 \(\mathbf{v}\) 再用 S&S 恢复 \(\phi_1\)（式2–3），嵌入配准损失（式4）\( \mathcal{L}=\mathbb{E}[\mathcal{L}_{sim}(I_f,\phi_1[I_m])+\mathcal{L}_{reg}(\phi)] \)。
关键等价（式5–6）：式1 等价于对形变族施加半群性质 \[ \phi_0=\mathrm{Id},\qquad \phi_t\circ\phi_s=\phi_{t+s},\ \forall t,s \] 半群闭合保证时间一致（变到 \(t+s\) = 先变 \(s\) 再变 \(t\)）；每个 \(\phi_t\) 可微则蕴含 \( \phi_t^{-1}=\phi_{-t} \)（式6）→ 双射 + 微分同胚结构。这就是"不用 S&S、不用辅助正则"的理论入口。
⑤ §4 Method · 参数化 + 连续时间相似度（式7–9）
对称连续性（式7）：时间连续 \(\phi_t,\ t\in[-1,1],\ \phi_0(x)=x\)。由轨迹连续性，"moving 正向到 \(t\)" 与 "fixed 反向到 \(1-t\)" 必对应同一物理点，用逆恒等式得 \[ \phi_{1-t}^{-1}[I_f]=\phi_{t-1}[I_f]=\phi_t[I_m] \] 连续时间相似度（式8）：\( \mathcal{L}^t_{sim}=-\mathrm{NCC}(\phi_{t-1}[I_f],\phi_t[I_m]),\ \forall t\in[0,1] \)（NCC=归一化互相关）。
参数化（式9，巧妙保证恒等初值）：\[ \phi_t(x;\theta)=x+t\,\mathbf{F}(x,t;I_f,I_m,\theta) \] \(\mathbf{F}\)=time-embedded 网络（UNet 或 DiT），同时以两图为条件。关键：因式里乘了 \(t\)，\(t=0\) 时 \(\phi_0(x)=x\) 自动满足式1 的恒等初值——不需额外约束。
⑥ §4 Method · 部分半群正则（式10–11，本文核心）
为何"部分"：对任意时间对 \((t,s)\) 强加完整半群律 “is intractable in practice”。故只在 \(s=t-1\) 这条切片上加可计算的部分正则（式10）：\[ \mathcal{L}^t_{sg}=\|\phi_{2t-1}-\phi_t\circ\phi_{t-1}\|_2+\|\phi_{2t-1}-\phi_{t-1}\circ\phi_t\|_2 \] 第二项强制对称性（\(\phi_t\circ\phi_{t-1}=\phi_{t-1}\circ\phi_t\)）；组合 \(\circ\) 用双线性插值形变栅格实现。其极小点满足组合律（式11）\( \phi_{2t-1}=\phi_t\circ\phi_{t-1}=\phi_{t-1}\circ\phi_t \)。
⑦ §4 Method · Theorem 1 + 总目标（式12）
定理1（全文理论支柱）：“The deformation \(\phi_t(x)\) satisfying the composition rule of Eq.(11) and \(\phi_0(x)=x\) is an exponential map, or equivalently, a one-parameter diffeomorphism solving the autonomous ODE of Eq.(1).” —— 即只要满足部分组合律 + 恒等初值，就必是解某自治 ODE 的单参数微分同胚（证明在附录 §7）。这把"加一条部分正则"升级成"严格保证微分同胚"。
总目标（式12）：\[ \mathcal{L}=\mathbb{E}_{(I_f,I_m)\sim\mathcal{D},\,t\sim\mathrm{Uni}(0,1)}\big[\mathcal{L}^t_{sim}+\lambda\,\mathcal{L}^t_{sg}\big] \] 训练时均匀采样图像对与时间 \(t\)；\(\lambda\) 控微分同胚强度（大→严格流一致、小→deformable 灵活）。对比前作：以往只在端点 \(\phi_1/\phi_1^{-1}\) 显式建双向场；本文对所有 \(t\in[-1,1]\) 自动双向一致、无需显式建逆。
Q&A · 为什么"部分"半群就够，不用全时间对？
全半群律要对所有 \((t,s)\) 成立，训练里枚举不可行。本文只在 \(s=t-1\)（即 \(\phi_t\circ\phi_{t-1}=\phi_{2t-1}\)）这一族切片上加约束 + 对称项，而 Theorem 1 证明这个更弱条件 + \(\phi_0=\mathrm{Id}\) 已足以推出 \(\phi_t\) 是 exponential map（解自治 ODE 的单参数群）。一旦是单参数群，全半群律与可逆性 \(\phi_t^{-1}=\phi_{-t}\) 自动成立——所以"部分"在数学上等价于"全部"，但计算上可行。这是本文最漂亮的一步。
Q&A · 同一个架构怎么靠 λ 切换两副面孔？
\(\lambda\) 是式12 里半群正则的权重。大 \(\lambda\)（\(10^5\)）=严格逼模型满足组合律 → 由 Theorem 1 得到近乎完美的微分同胚（\(|J|\lt0\%\) 近 0），代价是少量精度让步；小 \(\lambda\)（\(10^4\)）=放松半群约束 → 网络获得 deformable 自由度、Dice/TRE 更高，但允许少量折叠。Table 6 给出连续谱：\(\lambda\) 从 \(10^5\to0\)，OASIS Dice 85.90→79.80、折叠率 0.0003→7.86——同一套权重、只调 \(\lambda\) 就在"严格微分同胚"与"高精度 deformable"间平滑滑动，这是 Abstract "unified framework" 的实证。
⑧ §5 实验设置（8 数据集 / 指标 / 变体）
数据：8 个公开 2D/3D 医学库——OASIS、CANDI、LPBA40、Mindboggle101、IXI（脑 MRI）、ACDC（心脏 2D，ED↔ES 帧）、Learn2Reg LungCT + AbdomenCTCT（胸腹 CT）。指标：Dice、TRE、HD95、SSIM、ASSD、\(|J|\lt0\%\)。变体：4 个=UNet/DiT × {\(\lambda=10^5\) 微分同胚, \(\lambda=10^4\) deformable}。对手：经典(SyN)、学习型微分同胚(SYMNet/LapIRN/NePhi/PULPo/TransMorph-diff/CycleMorph/GradICON/R2Net)、ODE(NODEO)、deformable(H-ViT/TransMorph/CorrMLP/DiffuseMorph/DiffuseReg/SACB-Net/TransMatch/VoxelMorph)。硬件 RTX 3090(24GB)。

⑭ 四点贡献 + 结论金句（原文 verbatim）
Contributions（原文逐条）：① “a continuous-time registration framework that enforces diffeomorphism using only the semigroup property, removing scaling-and-squaring and all auxiliary regularizers”；② “We mathematically prove that our partial semigroup regularization compels the model to learn an ODE flow, inherently yielding inverse and cycle consistency and near-perfect diffeomorphism”；③ “strict enforcement yields remarkable diffeomorphic stability (near-zero folding), while relaxed enforcement becomes a deformable model that surpasses state-of-the-art non-diffeomorphic methods”；④ “Experiments across eight 2D and 3D MR/CT datasets demonstrate that SGDIR outperforms existing diffeomorphic methods and significantly improves topology preservation over deformable methods, without sacrificing accuracy.”
架构无关性（重要立场）：原文强调 “our goal is not to introduce a new architecture; rather, we show that even standard backbones become inherently diffeomorphic when trained under our semigroup constraint. Thus, SGDIR is architecture-agnostic and decoupled from integration schemes or handcrafted regularizers.” —— 卖点不是新网络，而是训练约束：把任意 time-embedded backbone（UNet 或 DiT）放进半群约束里，它就"天生微分同胚"。这也解释了为何论文同时给 UNet 与 DiT 两套结果。
结论（原文）：“SGDIR achieves diffeomorphic behavior intrinsically through temporal consistency”，并定位为 “a principled and versatile paradigm for diffeomorphic/deformable image registration”。核心张力在于 “strict regularization yields a state-of-the-art diffeomorphic model with minimal topology violations, whereas relaxing the constraint produces a highly flexible deformable variant that surpasses leading deformable methods”。
📌 全文一页总结（problem → method → experiment → takeaway）
problem：微分同胚配准长期靠 scaling-and-squaring 积分 + 一堆手工正则（Jacobian/平滑），逆/循环一致还得显式加 loss，连续时间扩散类又贵又非"第一性原理"。
method：SGDIR——参数化 \(\phi_t(x;\theta)=x+t\,\mathbf{F}(x,t;\cdot)\)（time-embedded UNet/DiT，天然 \(\phi_0=\mathrm{Id}\)）+ 连续时间 NCC 相似度（式8）+ 单条部分半群正则（式10）；Theorem 1 证"组合律 + 恒等初值 ⇒ exponential map=解自治 ODE 的单参数微分同胚"，故可逆/循环一致/拓扑保持固有，无 S&S、无辅助正则。
experiment：8 个 2D/3D MR/CT 库；微分同胚档（λ=10⁵）Dice 比领先微分同胚法 +2.5%、折叠率近 0；deformable 档（λ=10⁴）超所有 deformable SOTA（OASIS 88.09、AbdomenCTCT +5%、LungCT TRE −10%）；推理近 2× 快、显存约一半。
Takeaway：① 把"微分同胚"从"外挂积分 + 一堆正则"重述为"满足一条部分半群一致性"，理论更干净（Theorem 1 是灵魂）；② 同一架构靠 \(\lambda\) 在严格微分同胚 ↔ 高精度 deformable 间平滑切换；③ 任意时刻可即时查询、无 iterative sampling → 快。诚实边界：部分半群的充分性依赖附录 Theorem 1 证明（正文只给结论）；deformable 档（λ=10⁴）仍有少量折叠（非严格微分同胚）；λ 需按需选档（过小则折叠暴涨）；DiT 参数量较大(68.6M)。
