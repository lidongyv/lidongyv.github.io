CVPR 2026   🥈 Best Paper 提名

SAM 3D: 3Dfy Anything in Images

Xingyu Chen ⋅ Fu-Jen Chu ⋅ Pierre Gleize ⋅ Kevin J Liang ⋅ Alexander Sax ⋅ Hao Tang ⋅ Weiyao Wang ⋅ Michelle Guo ⋅ Thibaut Hardin ⋅ Xiang Li ⋅ Aohan Lin ⋅ Jia-Wei Liu ⋅ Ziqi Ma ⋅ Anushka Sagar ⋅ Bowen Song ⋅ Xiaodong Wang ⋅ Jianing &quot;Jed" Yang ⋅ Bowen Zhang ⋅ Piotr Dollár ⋅ Georgia Gkioxari ⋅ Matt Feiszli ⋅ Jitendra Malik
arXiv PDF ⬇arXiv 摘要Scholar
一句话：Meta 单图→3D 生成式重建基座模型，human-&-model-in-the-loop 标注突破 3D 数据壁垒，真实物体人评胜率≥5:1。

摘要 Abstract

We present SAM 3D, a generative model for visually grounded 3D object reconstruction, predicting geometry, texture, and layout from a single image. SAM 3D excels in natural images, where occlusion and scene clutter are common and visual recognition cues from context play a larger role. We achieve this with a human- and model-in-the-loop pipeline for annotating object shape, texture, and pose, providing visually grounded 3D reconstruction data at unprecedented scale. We learn from this data in a modern, multi-stage training framework that combines synthetic pretraining with real-world alignment, breaking the 3D "data barrier". We obtain significant gains over recent work, with at least a $5:1$ win rate in human preference tests on real-world objects and scenes. We will release our code and model weights, an online demo, and a new challenging benchmark for in-the-wild 3D object reconstruction.

📝 精读笔记

灵魂一句
SAM 系列的“单图 → 3D”基座模型：给一张自然图 I + 一个物体 mask M，生成式地预测该物体的完整 3D 几何 S、纹理 T 与相机系下布局 (R, t, s)。真正的创新不在网络（沿用 Trellis 的 two-stage latent flow matching），而在用 human-&-model-in-the-loop (MITL) 数据引擎 + LLM 式多阶段训练打穿 3D “数据壁垒”：合成预训练 → 半合成中训 → 真实后训 (SFT + DPO + 蒸馏)。真实物体人评胜率 ≥5:1、场景 6:1，并开源 code/weights/demo + 新基准 SA-3DAO。
问题 & 动机（root cause = 数据，不是模型）
原文：“A fundamental challenge for learning such models is the lack of data: specifically, natural images paired with 3D ground truth are difficult to obtain at scale.” → 单图 3D 重建的根本瓶颈是数据：自然图 ↔ 3D 真值的配对极难规模化。已有 SOTA（Trellis、Yang 2024b）只在孤立合成物体上训，遇到自然场景里远距离/重遮挡物体就崩。why 难：普通标注员造不出 3D mesh（专业艺术家一个都要数小时），不像画框/标 “cat” 那样容易。两个 insight 让其可行：① 合成场景（把渲染的 3D 模型贴进真实图，inspired by Dosovitskiy 2015）；② 人虽不能“造”3D，但能从一组候选里“选”最像的并对齐 pose（或判定全不行）——把“生成 3D”难题转成“选择/排序”易题（best-of-N，即 SAM 的 promptable 标注思想搬到 3D）。
核心方法（架构 + 关键公式）
两段式架构（§2.2, Fig 2）：① Geometry model——1.2B MoT (Mixture-of-Transformers) flow transformer，建模 p(O, R, t, s | I, M)：coarse voxel O∈R64³ + 6D 旋转 R + 平移 t + 尺度 s；② Texture & Refinement model——600M sparse latent flow transformer，建模 p(S, T | I, M, O)，精修几何 + 合成纹理；latent 由共享同一 encoder 的两个 VAE decoder（Dm mesh / Dg 3D Gaussian）解码。输入编码：DINOv2 提 4 组 conditioning tokens（cropped 物体 + 其 mask、full image + 其 mask），可选 pointmap（iPhone LiDAR / 单目深度）。
关键公式 — 多模态 rectified conditional flow matching（式1）： LCFM = Σm∈M λm · E‖vm − vθm(xτm, c, τ)‖²，M = {S, R, t, s}，条件 c = (I, M)；线性插值 xτm = τ·x1m + (1−τ)·x0m（x1=真值 / x0~N(0,I) 噪声），目标速度 vm = ẋτm = (x1m − x0m)。关键洞察（原文）：“flow matching objective is sufficient … without explicitly enforcing geometric constraints” —— 几何先验随数据/算力规模增大可被隐式学到，无需显式几何 loss。
训练范式（§3, Fig 4，LLM playbook 搬到 3D）：Step1 Pretraining（孤立合成物体 Iso-3DO，2.7M mesh×24 视角，2.5T token）→ Step1.5 Mid-training（render-paste 半合成 RP-3DO，61M 样本/2.8M mesh，2.7T token；学 mask-following / 遮挡鲁棒 / 布局）→ Step2 Post-training（MITL 真实数据 SFT + DPO 偏好对齐 + shortcut 蒸馏，0.5T token）。数据引擎飞轮（§3.2, Fig 5）：Stage1 选物体+mask → Stage2 best-of-N (N=8) 选/评候选（model-in-the-loop）→ Stage2.5 最难者交专业艺术家 (Art-3DO) → Stage3 对齐 pose 到 2.5D 点云；模型越训越强，最终 ~80% 标注数据由 SAM 3D 自产。
关键结果（数字）
① 人评胜率：物体 5:1、场景 6:1（Fig 8）。② SA-3DAO 真实物体（Table 2）：F1@0.01 0.2344 vs 最强 baseline Hi3DGen 0.1629（+44%）；Chamfer 0.0400 vs 最强 baseline TripoSG 0.0844（不到一半）。③ 布局（Table 3）：联合生成 shape+layout 把 ADD-S@0.1 从 ~2% 拉到 77%。④ 蒸馏：NFE 25→4，1-step 38×、4-step 10× 加速。⑤ 消融（Table 4）：每个训练阶段几乎单调提升 F1（0.135→0.171→0.203→0.216→0.233→0.234）。
亮点 — 为何获 Best Paper 荣誉提名（个人解读）
① 把 3D 重建从“孤立合成物体玩具基准”推向 in-the-wild 自然图（遮挡/杂乱/远距），且是 shape+texture+layout 一体的 foundation model；② 数据范式创新：MITL best-of-N 把“人造 3D”难题转成“人选 3D”易题（SAM promptable 思想），+ LLM 式多阶段训练（pretrain/mid/post + DPO + 蒸馏）首次在 3D 跑通，打穿数据壁垒；③ 全开源（code/weights/demo）+ 贡献新基准 SA-3DAO（1000 张真实图 + 艺术家 3D，作为人类上界）；④ 数据飞轮可持续自增强（Elo 近线性增长、80% 数据自产）。
疑问 / 诚实边界
① 分辨率受限（O∈R64³，每 voxel ≤32 splats）→ 手/脸/薄结构易失真（原文 Limitations 明说）；② 逐物体预测、不建模物理交互（接触/穿插/共面）→ 多物体场景几何关系无保证；③ “5:1 / 6:1” 是人评胜率而非绝对质量，主结论多基于 preference test；④ 评测重 perceptual/preference，绝对几何精度（Chamfer 0.04）与真实尺度的关系原文未深挖。

📖 逐段精读 · 笔记

批量精读初稿（基于 arXiv 2511.16624v2 全文 PDF）。原文引用 + 逐句指路，数值均核对原文表格。最后更新 2026-06-19。
① Abstract（摘要）— 原文逐句讲解
原文：“We present SAM 3D, a generative model for visually grounded 3D object reconstruction, predicting geometry, texture, and layout from a single image.” → 一句话定义：visually grounded（视觉锚定）的生成式单图 3D 重建，一次输出三样——geometry（几何）、texture（纹理）、layout（相机系下的位姿+尺度）。“visually grounded” 是关键词：重建必须锚定到图里那个具体物体，不是凭空生成一个相似 3D。
原文：“SAM 3D excels in natural images, where occlusion and scene clutter are common and visual recognition cues from context play a larger role.” → 卖点是自然图（不是干净的孤立物体渲染图）；这里遮挡/杂乱普遍，必须靠上下文识别线索补全看不见的部分。why 这是难点：前作都在孤立物体上训，自然图直接崩——这正是 SAM 3D 要攻的场景。
原文：“We achieve this with a human- and model-in-the-loop pipeline for annotating object shape, texture, and pose, providing visually grounded 3D reconstruction data at unprecedented scale.” → 怎么做到的？不是新网络，而是新数据引擎：human-&-model-in-the-loop (MITL) 标注 shape/texture/pose，拿到“前所未有规模”的真实图↔3D 配对数据。这是全文的灵魂句——把论文从“又一个 image-to-3D 模型”抬升到“解决了 3D 的数据壁垒”。
原文：“We learn from this data in a modern, multi-stage training framework that combines synthetic pretraining with real-world alignment, breaking the 3D ‘data barrier’.” → LLM 式多阶段训练：合成预训练打底 + 真实世界对齐收尾，明确喊出“breaking the 3D data barrier（打穿 3D 数据壁垒）”。
原文：“We obtain significant gains over recent work, with at least a 5:1 win rate in human preference tests on real-world objects and scenes. We will release our code and model weights, an online demo, and a new challenging benchmark…” → 结果：真实世界人评 ≥5:1 胜率；全开源 code/weights/demo + 新基准 SA-3DAO。一句话抓 Abstract：数据引擎（MITL）+ LLM 式多阶段训练 → 打穿 3D 数据壁垒 → in-the-wild 单图 3D，人评碾压、全开源。
📚 背景知识（外部、非本文原文，理解 SAM 3D 必备）
① 前作 SLAT / Trellis（Xiang 2025，本文架构基座）：SLAT = Structured LATent，把 3D 资产编码成“稀疏体素位置 + 每个 active voxel 的 latent 特征”；Trellis 在 SLAT 上用 rectified flow 生成，可解码成 3D Gaussian / Radiance Field / Mesh。SAM 3D 的关系：直接沿用 Trellis 的 two-stage latent flow matching 与共享 VAE 的多解码器思路；本文的差异不在表示，而在“喂什么数据 + 怎么多阶段训”——把 Trellis 从孤立物体推到自然图，并额外预测 layout (R,t,s)。
② flow matching / rectified flow（Lipman 2023 / Liu 2022）：与 diffusion 同类但更直的生成范式。训练用直线插值 xτ=(1−τ)x0+τ·x1（x0 噪声、x1 数据），网络回归常速度 v=x1−x0；推理从噪声沿 velocity field 用 ODE 积分到数据。本文式1 就是它的多模态版（shape/R/t/s 各一项 λm 加权）。
③ Mixture-of-Transformers (MoT)（Liang 2025a）：多模态 Transformer 的一种——不同模态走各自的 transformer 权重（FFN/部分 attn 投影按模态分流），但在 self-attention 层共享上下文做跨模态交互。本文用它把 shape token 与 layout (R,t,s) token 分两流处理，靠 attention mask 控制谁能看谁。好处（本文用法）：可单独冻结/微调某一模态（如只训 layout），又能在前向中让 rotation “看到” shape——因为旋转只有锚定到几何才有意义。
④ DPO / Diffusion-DPO（Rafailov 2023 / Wallace 2024）：Direct Preference Optimization，给一对“偏好 xw / 不偏好 xl”样本，直接优化模型更偏向 xw（无需训独立 reward model 再 RL）。Diffusion-DPO 把它搬到扩散/流模型上、对 velocity 预测的误差差做 logistic 监督。本文用它对齐“人类偏好的对称性/封闭性”这类 flow matching loss 抓不住的属性。
⑤ Shortcut Models（Frans 2024）：一种 few-step 蒸馏：网络额外吃一个“步长 d”输入，d=0 退化为普通 flow matching、d>0 学“一步跨 2d 的平均速度”自洽目标——同一个模型既能多步高质、又能少步快推，且训练比 consistency distillation 稳。本文用它把 Geometry model 的 NFE 从 25 压到 4。
⑥ 6D 连续旋转表示（Zhou 2019）：四元数/欧拉角在 SO(3) 上不连续（有跳变/双覆盖），不利于网络回归；6D 表示取旋转矩阵前两列、用 Gram-Schmidt 正交化恢复 R，连续可微、优化更顺。本文 layout 的 R∈R6 即此，消融见 Table 10。
⑦ DINOv2（Oquab 2023）：自监督视觉特征提取器，给图像产出语义丰富的 patch token。本文用它编码 cropped/full 图 + mask，作为 conditioning（识别线索就来自这里）。哲学背景（Roberts 1963 / Koenderink 1992，原文引用）：“recognition enables 3D reconstruction”——一旦图案被识别成已知物体，其 3D 形状与位姿就能恢复；且能泛化到新物体，因为新物体由见过的“部件”组成。这是 SAM 3D 敢用单图 + 识别线索补全遮挡的理论根基。
② §1 Introduction — problem → solution → why 闭环
problem（递进）：计算机视觉传统靠 multi-view 几何拿 3D，但人类单图就能感知深度/形状（Koenderink 1992 的 surface normal probe 实验）。核心洞察（Roberts 1963）：“recognition enables 3D reconstruction”——识别出物体即可恢复其 3D。学这种模型的根本障碍是数据：自然图 ↔ 3D 真值难规模化配对；已有强方法（Trellis、Yang 2024b）只在孤立物体上训，自然场景里远/遮挡物体就崩。
core solution（Intro 已把 method 自然语言版给出）：两个 insight 解锁数据——① 合成场景（渲染 3D 模型贴进真实图）；② 人不能造 3D 但能从候选里选最像的 + 对齐 pose。据此设计数据引擎 + LLM 式多阶段训练：先在大规模渲染合成物体上 supervised pretraining（学 shape/texture 的“词汇表”）→ 用“贴图”半合成数据 mid-training → 用 MITL pipeline + 3D 艺术家做 post-training 并对齐人类偏好。原文：“synthetic pretraining generalizes, given adequate post-training on natural images.”
why 这套能work（virtuous cycle）：标注员从模块（计算式 + 检索式）产出的多个 3D proposal 里选，难例 route 给艺术家；vetted 标注反哺训练，更强的模型再回灌数据引擎 → “This virtuous cycle steadily improves … 3D annotations, labeling rates, and model performance.” 数据生成本身是对齐的副产品。
贡献列表（原文 4 点）：① SAM 3D —— 预测 shape/texture/pose 的 3D foundation model，开源 code/weights/demo；② MITL pipeline 标注 shape/texture/pose，提供前所未有规模的 visually grounded 3D 数据；③ 通过 LLM 式 pretrain + post-train 的新框架利用该数据，跨越 3D 与 text/image/video 之间数量级的数据鸿沟；④ 发布真实世界 3D 物体重建挑战基准 SA-3DAO（1000 张 image↔artist-mesh，专业艺术家作为“人类上界”）。
③-a 问题形式化 + 两段式架构（§2）
原文形式化：拍照把 3D 物体映到 mask M 下的 2D 像素（lossy），SAM 3D 求逆——建模条件分布 p(S, T, R, t, s | I, M)，训一个生成模型 q 去逼近 p。架构（§2.2, Fig 2）：沿用 Trellis 的 two-stage latent flow matching。① Geometry model 先联合预测 coarse shape O∈R64³ 与 layout (R∈R6 6D 旋转, t∈R3, s∈R3)；② Texture & Refinement model 从 O 抽 active voxel，精修几何 + 合成纹理。与 Trellis 的差异（原文）：“Unlike Xiang et al. (2025) that reconstructs isolated objects, SAM 3D predicts object layout, creating coherent multi-object scenes.”
输入编码（DINOv2，4 组 token）：① cropped 物体（按 mask 裁）+ 其 mask → 高分辨率聚焦视图；② full image + 其 mask → 全局场景上下文/识别线索（裁剪视图没有的）。可选 pointmap P（iPhone LiDAR 或单目深度估计 Yang 2024a / Wang 2025a）→ 可与其他 pipeline 集成。
③-b MoT 几何模型细节（§C.1）
token 化：shape 在 16³×8 的 coarser latent 里 denoise 64³ voxel（following Trellis）；layout 直接在参数空间 (R,t,s) denoise（维度小）。引入模态专属输入/输出投影把 shape 与 layout 都映到 dim=1024 共享特征空间——结果 4096 个 shape token + 1 个 (R,t,s) token 输入 MoT。MoT = 两个 transformer：一个专管 shape token，另一个（参数共享）管 layout。why 两流 + 共享 self-attn：① 可只训某一模态（数据常只标了 shape）、可冻结 shape 只微调 layout；② joint self-attn 做跨模态交互，“rotation is only meaningful when anchored to the predicted shape”——旋转必须看到几何才有意义。
③-c 训练目标：多模态 rectified flow matching（式1）
式1： LCFM = Σm∈M λm · Eτ,x₀‖vm − vθm(xτm, c, τ)‖²，其中 M={S,R,t,s}、c=(I,M)。目标概率路径 xτm=τx1m+(1−τ)x0m（x1=真值、x0~N(0,I)），目标速度 vm=ẋτm=x1m−x0m，λm 为各模态权重。追问 why 不加几何 loss：原文“flow matching objective is sufficient … without explicitly enforcing geometric constraints”，且发现几何 loss 的价值随数据/算力增大而下降——几何先验可被规模隐式学到。优化器 AdamW（无 weight decay）。
③-d 三阶段训练 + token 预算（§3, Table 1）
Step1 Pretraining（Iso-3DO）：2.7M Objaverse-XL+授权 mesh，各渲 24 视角的孤立居中物体；学准确 shape/texture，2.5T training token。Step1.5 Mid-training（RP-3DO）：把带纹理 mesh 用 alpha 合成“render-paste”进自然图——一子集是 occluder-occludee 对（学遮挡补全），一子集把真实物体换成相似位置/尺度的合成物体（拿到精确 3D 真值）；61M 样本 / 2.8M unique mesh，学 mask-following / 遮挡鲁棒 / layout，2.7T token。Step2 Post-training：MITL 真实数据 SFT + DPO + 蒸馏，最终一轮 0.5T token。
③-e 数据引擎：把“造 3D”变“选 3D”（§3.2, Fig 5）
核心难点（原文）：多数人造不出 mesh（艺术家也要数小时），但给选项时能选出最像的——“This fact forms the foundation of our data collection.” 流程：从当前模型采样候选 → 标注员选最佳 + 按 rubric 打分 r → r>α 的成为训练样本，差的成为 DPO 负例。冷启动：初模型好候选少，先借一组已有 learned/retrieval 模型组成 ensemble 产候选；随训练推进，SAM 3D 自己最终产出约 80% 标注数据。四阶段：Stage1 选 (I,M)；Stage2 在 N=8 候选里 best-of-N 选/评 (S,T)（model-in-the-loop，用模型先筛再人筛把有效 N 放大）；Stage2.5 最难者交艺术家 → Art-3DO；Stage3 相对点云对齐 (R,t,s)。
③-f Post-training 三件套：SFT → DPO → 蒸馏（§3.2.2 / §C.3 / §C.4）
SFT：先用较噪的非专家标注 MITL-3DO，再用小而精的艺术家 Art-3DO——后者对齐艺术家审美，抑制常见 failure（floaters 漂浮物、bottomless 无底、缺对称）。DPO（式2）：follow Diffusion-DPO，给同条件 c 下偏好对 (xw, xl)，对 Δ = [‖vw−vθ(xτw)‖² − ‖vw−vref(xτw)‖²] − [对 l 的同式] 做 −E log σ(−βT w(τ)·Δ)；只用 SAM 3D 自产的负例（剔除 retrieval/multi-view 等 OOD 负例）。追问 why DPO：对称/封闭这类人敏感属性 flow matching loss 抓不住，需偏好级监督。蒸馏（shortcut, 式4）：从训好的 ckpt 初始化、再 finetune ~4K 步（75% flow matching + 25% shortcut），把 NFE 25→4；蒸馏阶段新增的 step-size embedder 末层权重/偏置初始化为 0。
3D 解码器（§2.2 / §C.6）：Texture & Refinement 的 latent 可由一对 VAE decoder Dm（mesh）/ Dg（3D Gaussian splats）解码；两者分开训但共享同一 VAE encoder、共享同一 structured latent 空间（following Trellis）。纹理 VAE 用“de-lighted rendering”（环境光）消除前作渲染图的反射/阴影伪影（如物体底部恒黑）。

📌 全文一页总结（problem → method → experiment → takeaway）
Problem：单图 3D 重建的瓶颈是数据——自然图 ↔ 3D 真值难规模化配对，前作只在孤立合成物体上训、遇自然场景遮挡/杂乱就崩。
Method：① 架构沿用 Trellis two-stage latent flow matching（1.2B MoT Geometry 预测 coarse voxel O∈R64³ + layout (R,t,s)；600M sparse latent transformer 做 Texture & Refinement；共享 VAE 解 mesh/Gaussian），训练目标=多模态 rectified flow matching（式1）。② 真正的杀招是 MITL 数据引擎（把“造 3D”转成“从 N=8 候选里选 3D + 对齐 pose”，模型最终自产 80% 数据）+ LLM 式多阶段训练（Iso-3DO 预训 2.5T tok → RP-3DO 中训 2.7T tok → MITL SFT + DPO + shortcut 蒸馏 0.5T tok）。
Experiment：真实物体人评 5:1、场景 6:1；SA-3DAO F1@0.01 0.2344（+44% vs 最强 baseline）、Chamfer 0.0400（< 一半）；layout ADD-S@0.1 ~2%→77%；消融显示每个训练阶段几乎单调增益、去 Art-3DO 掉得最狠；蒸馏 25→4 步、38×/10× 加速。
Takeaway：SAM 3D 的贡献不是某个新模块，而是把“LLM/SAM 的数据飞轮 + 多阶段对齐”范式成功移植到 3D，打穿了 3D 数据壁垒，并以 foundation model + 开源 + 新基准 SA-3DAO 的形式交付——这正是其获 CVPR 2026 Best Paper 荣誉提名的核心价值。边界：分辨率 64³ 限制（手/脸/薄结构失真）、逐物体预测不建模物理交互、结论多基于人评偏好。
