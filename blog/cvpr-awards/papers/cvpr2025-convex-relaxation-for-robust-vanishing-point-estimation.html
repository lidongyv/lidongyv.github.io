📝 精读笔记

灵魂一句
第一次把凸松弛（convex relaxation）引入曼哈顿世界的消失点（vanishing point, VP）估计：用一个 truncated multi-selection error 把"线-VP 关联 + 三个 VP 定位 + 外点剔除"联合写成 QCQP，再松弛成凸 SDP；并提出迭代求解器 GlobustVP 逐个 VP 求解，同时拿到全局最优 + 抗外点 + 快（York Urban 38 线、100%/100%、0.23 像素、~50ms）。代码开源 wu-cvgl/GlobustVP。
问题 & 动机
曼哈顿世界=场景只有 3 个互相正交的主方向。VP 估计要同时做两件耦合的事：把每条线关联到某个 VP（line-VP association）+ 定位每个 VP。原文：“The challenge lies in the coupling relationship between line association and vanishing point estimation, which leads to numerous local minima.” 现有三类各有硬伤：局部法（EM/Hough/RANSAC）需好初值或穷举采样、无全局保证；全局法（Branch-and-Bound）有保证但"exponential time cost in the worst case"、慢；学习法无最优性保证、跨数据集泛化差。结论原文：“a globally optimal, outlier-robust, and sufficiently fast vanishing point estimation algorithm remains missing.”
核心方法 + 关键公式
① VP 几何（式1-3）：平行 3D 线交于 VP，约束 vᵀl=0（v=消失点、l=图像线，齐次）；归一化后 dᵀn=0（d=3D 线方向≡VP，n=投影平面法向≡图像线），曼哈顿先验 ⇒ D=[d₁;d₂;d₃] 正交。② Truncated multi-selection error（核心创新）：距离矩阵 ([DN; c·1ₘᵀ])²∈R⁴ˣᵐ——(DN)² 是各 VP 到各线的点线距离，第 4 行常数 c²=外点阈值；置换矩阵 Q∈R⁴ˣᵐ 每列是该线的标签（VP1/VP2/VP3/Outlier）。Primal Problem：min_{D,Q} ⟨([DN;c1ₘᵀ])², Q⟩ s.t. Qᵀ1₄=1ₘ（每线恰一个标签）、(Q)²=Q（0/1 二值）、D 正交。"Truncated"=外点误差被截断成常数 c²（不引偏置）；"Multi-selection"=既分内/外点、又指明属哪个 VP。③ 凸松弛 QCQP→SDP（式4-7）：一般 QCQP min xᵀCx s.t. xᵀAᵢx=bᵢ，令 X=xxᵀ（秩1 PSD）⇒ min trace(CX) s.t. trace(AᵢX)=bᵢ, X⪰0, rank(X)=1；丢掉非凸的 rank=1 即得凸 SDP。强对偶常成立 ⇒ "solving the relaxed problem is equivalent to solving the original one"，多项式时间拿全局最优。④ GlobustVP 迭代解：Full SDP 规模随线数三次方增长太贵 ⇒ 每次只解一个 Single Block SDP 找一个 VP+其内点（其余当外点），剔除内点后重复 3 次；最后 Manhattan Post-Refinement：min Σᵢ Σ_{j∈lᵢ}(dᵢᵀnⱼ)² s.t. D 正交，把三 VP 拉回互相正交。大规模时借 SDRSAC 策略每次随机采样固定 6 条线。
关键结果
真实数据 York Urban (YUD) 角精度 AA@10°=96.1%，three thresholds 全部第一，显著超学习法与传统法。合成数据：外点比例 >20% 时 RANSAC/J-/T-Linkage 崩，Quasi-VP 在 40% 崩，GlobustVP 始终稳；效率上比 BnB 快很多、精度远超 RANSAC（RANSAC 最快但精度低）。超参：最大内点阈值 c=0.03、每次采样 6 条线为最佳 trade-off。诚实点：SU3 数据集上 GlobustVP（80.2/86.8/92.4）competitive 但输给在 SU3 上训练过的 NeurVPS（93.2/95.2/97.8）、PARSAC——因为它无训练、靠几何，跨域反而更稳。
亮点
① 把"全局最优 + 抗外点 + 快"这三个此前无法兼得的属性同时拿到；② truncated multi-selection error 优雅地用一个 ⟨距离², Q⟩ 把关联/定位/外点剔除一锅端；③ 迭代 Single Block SDP 避开 Full SDP 的三次方爆炸；④ 无需训练 → 天然跨数据集泛化（对比学习法过拟合训练域）；⑤ 提供 tight relaxation（zero duality gap）证明（SM）。
疑问 / 边界（原文标注）
① 全局最优是"mild conditions"下：Single Block 的 tight relaxation 证明只在 “noise-free and outlier-free conditions” 下给（Remark 4.3.1.2），且依赖 distinguishability assumption（内点到对应 VP 距离 < 阈值 < 到其他 VP 距离）；Full SDP tightness 证明在 SM。② 实现是 MATLAB+MOSEK、笔记本 CPU，~50ms；更大规模/GPU 加速原文未讨论。③ SU3 输给学习法（已如实报告）。④ precision/recall 完整曲线、YUD 逐图 F1 都在 SM，正文只给 AA 表。

📖 逐段精读 · 笔记

批量精读初稿（基于本地 PDF 全文，PyMuPDF 提取）。原文英文原句引用 + 中文指路 + 追问 why。最后更新 2026-06-21。
① Abstract（摘要）— 逐句拆解
原文：“Determining the vanishing points (VPs) in a Manhattan world ... consists of jointly inferring the line-VP association and locating each VP.” → 任务定义：VP 估计 = 联合做两件事——(i) 把每条图像线关联到某个 VP（line-VP association）、(ii) 定位每个 VP。关键词 jointly：两件事互相耦合（要定位 VP 得先知道哪些线属于它，反之亦然）。
原文：“Existing methods are, however, either sub-optimal solvers or pursuing global optimality at a significant cost of computing time.” → 二元困境：要么次优（局部法快但无保证），要么全局但慢（BnB）。本文要打破这个 trade-off。
原文：“we employ a 'soft' association scheme, realized via a truncated multi-selection error ... reformulated into a quadratically constrained quadratic programming (QCQP) problem, which is then relaxed into a convex semidefinite programming (SDP) problem.” → 方法主线（三级火箭）：soft 关联（truncated multi-selection error）→ 重写成 QCQP → 凸松弛成 SDP。
原文：“a globally optimal outlier-robust iterative solver (called GlobustVP), which independently searches for one VP and its associated lines in each iteration, treating other lines as outliers.” → 求解器 GlobustVP：逐个 VP 求解，每轮只找一个 VP + 它的内点，其余线全当外点。
逐句抓 Abstract：soft 关联误差（外点截断 + 多选标签）→ QCQP → 凸 SDP（多项式时间全局最优）→ 逐 VP 迭代解（避开 Full SDP 的规模爆炸）→ 全局最优 + 抗外点 + 快三者首次兼得。代码开源 github.com/wu-cvgl/GlobustVP。
📚 背景知识（外部，非本文原文，理解 GlobustVP 必备）
① 消失点 / 曼哈顿世界：3D 空间中一组平行线投影到像平面会汇聚于一点=VP（“two parallel lines ... intersect at a point in the image projection space”）。曼哈顿世界（Coughlan-Yuille / Straub [36]）：人造环境主要由 3 组互相正交的平行线构成（墙、地、天花板的棱），故只有 3 个互相正交的主方向/VP。VP 估计应用广：SLAM、相机标定、结构理解。
② 点线对偶 + vᵀl=0 的来历：射影几何里点 p 在线 l 上 ⟺ pᵀl=0（齐次坐标）。VP v 是它那组平行线的公共交点，所以 v 落在每条该组线 l 上 ⟺ vᵀl=0（式1）。归一化坐标下 v=Kd、l=K⁻ᵀn（K=内参），代入得 dᵀn=0（式2-3）：d=3D 线方向（≡VP）、n=该图像线对应的投影平面法向。dᵀn 就是"方向 d 与平面法向 n 的偏离"=点线距离的代数量。
③ QCQP / SDP / 凸松弛（本文数学核心）：QCQP=目标与约束都是二次型的优化，一般非凸、NP-hard。提升技巧（lifting）：二次项 xᵀCx=trace(Cxxᵀ)，令新变量 X=xxᵀ（对称、半正定 X⪰0、且 rank(X)=1）→ 目标线性化成 trace(CX)、约束线性化成 trace(AᵢX)=bᵢ。此时唯一的非凸约束是 rank(X)=1。丢掉 rank=1 → 得到凸 SDP（式7），可用内点法（MOSEK）多项式时间求全局最优。若松弛"tight"（zero duality gap），SDP 解=原 QCQP 解。这是把 NP-hard 组合问题变可解的标准武器。
④ 五类对比范式（§2 Related Work）：EM=交替更新关联与 VP（陷局部最优、依赖初值）；Hough voting=高斯球分 bin 累积投票找主方向（受量化影响、出伪 VP）；RANSAC/J-/T-Linkage=随机采样假设 VP 看内点共识（随机、无全局保证、不满足正交约束）；BnB=在 SO(3) 旋转搜索空间分支定界，有全局保证但最坏指数时间（Quasi-VP=BnB+RANSAC 混合，只到 quasi-global）；学习法（Zhai/NeurVPS/CONSAC/Lin/PARSAC）=端到端但泛化受限训练域。本文=凸松弛，第一次用在 VP。
⑤ SDRSAC 采样（Le 2019，本文 [18]）：SDP 求解时间随问题规模三次方增长 → m 条线全上太贵。SDRSAC 的思路=每次只随机采样固定条数的线喂给 SDP，把单次问题规模钉死 → 大规模下省时。本文沿用，实验定为每次采 6 条线。
② §1 Introduction — problem → solution → why 闭环（Intro 已自包含）
problem：原文 “The challenge lies in the coupling relationship between line association and vanishing point estimation, which leads to numerous local minima. This characteristic makes an algorithm with a global optimality guarantee particularly valuable.” 关联与定位耦合 → 大量局部最优 → 全局最优保证特别可贵。但现有三路都有硬伤：局部法无保证、全局法（BnB）指数慢、学习法不泛化。结论原文：“a globally optimal, outlier-robust, and sufficiently fast vanishing point estimation algorithm remains missing.”
solution（Intro 即给出 method 骨架）：“we propose a novel truncated multi-selection error formulation that enables joint optimization of three vanishing points and their corresponding line association labels (e.g., VP1, VP2, VP3, Outlier).” → 写进 Primal Problem → 重写成 Full QCQP → 松弛成 Full SDP；再用 GlobustVP “solves one Single Block SDP Problem in each iteration to identify a vanishing point and its corresponding inlier line set, which is then excluded”；最后 Manhattan Post-Refinement 保正交。
why（为什么这样能同时拿三性）：凸 SDP ⇒ 全局最优（多项式时间，不像 BnB 指数）；truncated 误差把外点误差钉成常数 ⇒ 抗外点且不引偏；迭代 Single Block + 6 线采样 ⇒ 避开 Full SDP 的三次方规模 ⇒ 快。★ 即 Intro 已闭环，§3-4 只是数学化。
四点贡献（原文）：① soft 关联（truncated multi-selection error）联合估 VP 位置 + 线关联；② 首次把凸松弛把 QCQP 重写成凸 SDP；③ 迭代器 GlobustVP 每个 VP 子问题独立解（对应 Full SDP 的一个子块），mild conditions 下全局最优；④ 合成+真实数据全面验证。
③ §3.2 几何（vᵀl=0 → dᵀn=0 → 曼哈顿正交）
式1-3：vᵀl=0（VP 在其线上，齐次）；归一化坐标 dᵀn=0，v=Kd、l=K⁻ᵀn。why 用归一化坐标：把内参 K 消掉，后续推导只跟 d（3D 方向）和 n（平面法向）打交道，更干净。曼哈顿先验：三个 d 互相正交、组成 3×3 正交阵 → 给优化注入强约束、提稳定性（原文 “Leveraging this Manhattan world prior constraint can enhance the stability”）。
④ §3.3 凸松弛模板（X=xxᵀ 的 lifting + 丢 rank 变凸）
逐步（式4-7）：① 原 QCQP：min xᵀCx s.t. xᵀAᵢx=bᵢ。② trace 技巧：xᵀCx=trace(Cxxᵀ)。③ 令 X=xxᵀ → min trace(CX) s.t. trace(AᵢX)=bᵢ, X⪰0, rank(X)=1（式6，与原问题完全等价）。④ 丢掉 rank(X)=1（唯一非凸约束）→ 凸 SDP（式7）。why 这步是魔法：rank=1 把解锁死在"秩一矩阵=某向量外积"上（非凸流形）；丢掉后可行域变成凸的 PSD 锥与线性约束的交 → 凸优化 → 局部最优即全局最优、内点法多项式时间。原文：“researchers have found that strong duality properties still hold for many problems ... solving the relaxed problem is equivalent to solving the original one.”
⑤ §4.1 Truncated Multi-selection Error（全文最妙的建模，逐步拆）
第一步 距离矩阵：VP 阵 D=[d₁ᵀ;d₂ᵀ;d₃ᵀ]∈R³ˣ³、线阵 N=[n₁,…,nₘ]∈R³ˣᵐ。DN∈R³ˣᵐ 的第 (i,j) 元 = dᵢᵀnⱼ = VPᵢ 到线 j 的点线距离（带符号）。逐元平方 (DN)²=各 VP 到各线的距离²。再在底部堆一行常数 c·1ₘᵀ → 得 ([DN; c1ₘᵀ])²∈R⁴ˣᵐ：第 j 列 = [d₁ᵀnⱼ, d₂ᵀnⱼ, d₃ᵀnⱼ, c]²，前 3 个是到三 VP 的距离²、第 4 个是外点的固定"距离" c²。
第二步 置换/选择矩阵 Q∈R⁴ˣᵐ：每列是 one-hot 标签——线 j 属于 {VP1, VP2, VP3, Outlier} 中哪一类。Primal Problem：min_{D,Q} ⟨([DN;c1ₘᵀ])², Q⟩ s.t. Qᵀ1₄=1ₘ（每列恰一个 1）、(Q)²=Q（0/1 二值）、D 三行单位且两两正交（6 个二次约束）。⟨dist², Q⟩ 内积 = 对每条线，按它的标签从那 4 个候选里"选出"一个误差再求和。最小化 → 每条线自动选最小者：若到某 VP 距离 < c 就归该 VP（取该距离²），若到三个 VP 都 > c 就归 Outlier（误差恰好 c²）。
三点 Remark（原文）：(i) "Truncated"=外点距离全超阈值时误差截断成常数 c²（“set its error to zero, and add a penalty term of c²”），不随外点具体位置变 → 不引偏（不把外点往任何 VP 拉）；(ii) "Multi-selection"=不仅分内/外点，还指明属哪个 VP；(iii) 当所有外点到所有真 VP 距离都 > c²，Primal 的全局最优 = 最大内点集 + 最优 VP。Fig.2 worked example（c=0.03）：line1→VP2、line2→VP1、line3/4=outlier、line5→VP2、line6→VP3。
⑤′ 具体化：truncated multi-selection error 的一个数值例子
设 c=0.03。某条线 j 到三个 VP 的点线距离 dᵢᵀnⱼ 分别是 (0.005, 0.21, 0.33)：平方后 (2.5e-5, 0.044, 0.109)，加上外点项 c²=9e-4 → 该列候选误差 = [2.5e-5, 0.044, 0.109, 9e-4]。min-选择会挑最小的 2.5e-5（VP1） → 线 j 标 VP1、Q 列=[1,0,0,0]。
换一条外点线 k，到三 VP 距离 (0.12, 0.15, 0.20)：平方 (0.0144, 0.0225, 0.04)，外点项仍 9e-4 → 候选 [0.0144,0.0225,0.04, 9e-4]，最小是第 4 项 9e-4（Outlier） → 线 k 标 Outlier、误差封顶 c²。关键：外点 k 不论实际偏多远，误差都只记 c²，不会把任何 VP 往 k 拉——这就是 truncated 的"无偏"。
⑥ §4.2 Full QCQP → Full SDP（lifting ω + 丢 rank(W)=1）
为什么要 lift 成 ω？目标 ⟨dist²,Q⟩ 同时是 D（藏在 dist² 里）和 Q 的函数——是双线性/高次耦合，不是标准二次型。引入 D=[d₁;d₂;d₃;1]∈R¹⁰ 和 ω=[D; vec(Q)⊗D]∈R^{10(1+4m)}（Kronecker 积把每个标签位 [Q]ᵢ,ⱼ 与 D 绑成 ωᵢ,ⱼ=[Q]ᵢ,ⱼD），就能把目标写成单个二次型 ωᵀCω（C 是块对角辅助阵，式10-11：{Cᵢ,ⱼ}=nⱼnⱼᵀ 编码距离、[C₄,ⱼ]=c² 编码外点惩罚）。这样才能套 §3.3 的 QCQP→SDP 模板。
Full SDP（式12）：提升 W（≈ωωᵀ），约束把 Q 的"每列一个 1"和"二值"翻译成 W 的块等式、把 D 正交翻译成 trace 约束，丢掉唯一非凸的 rank(W)=1 → 凸 SDP。原文：“The SDP problem can be globally solved using any off-the-shelf solver in polynomial time. Furthermore, we provide a proof of tight relaxation (i.e., zero duality gap) in SM ... solving Full SDP Problem is equivalent to solving Primal Problem.”——tight 证明在 SM（正文未给完整证明）。
⑦ §4.3 GlobustVP（Single Block SDP + Alg.1 + Post-Refinement）
为什么不直接解 Full SDP？原文 “the optimization time for SDP methods grows cubically with the problem size”——Full SDP 规模是 10(1+4m)，随线数 m 三次方爆炸，大场景算不动。
Single Block SDP（式13-14）：每轮只求一个 VP——构造二切片张量 C：C∗,∗,1=diag([0, n₁n₁ᵀ,…,nₘnₘᵀ])（该 VP 到各线距离），C∗,∗,2=diag([0, c²I₃,…])（外点常数项）。解出 W、round 恢复一个 VP dᵢ、收集其内点 lᵢ 并从线集中移除，把其余线全当外点。这样把"同时找 3 个 VP"降成"顺序找 1 个"，规模骤降。
Alg.1 流程：for i=1:3 → 构 Cᵢ → 解 Single Block SDP 得 Wᵢ → round 出 dᵢ → 收内点 lᵢ、从 n 移除 → 循环；3 轮后收集剩余线为 outlier，再 Manhattan Post-Refinement（min Σᵢ Σ_{j∈lᵢ}(dᵢᵀnⱼ)² s.t. D 三行单位+两两正交）联合精修三 VP。
两点 Remark：(i) distinguishability assumption——只要"内点到对应 VP 距离 < 阈值 < 到其他 VP 距离"，Single Block SDP 就能稳定找到内点最多的 VP；(ii) Single Block 本身不依赖曼哈顿假设也能给最优内点集，正交先验只在 Post-Refinement 注入，精修后保持 Full SDP 的最优性。大规模加速：借 SDRSAC 每次随机采 6 条线（“not the main contribution”但实用，Fig.5）。
Q&A · 几个 why 追问
1 为什么凸 SDP 能保证全局最优、BnB 不能快？SDP 凸 → 可行域是凸集、无虚假局部最优 → 内点法多项式时间必达全局最优；BnB 在 SO(3) 旋转空间分支定界，靠上下界剪枝，最坏要遍历指数个分支（“exponential time cost in the worst case”）。本文用凸性把"全局最优"和"快"统一了。
2 truncated 为什么"不引偏"？外点误差被钉成常数 c²，与外点的具体几何位置无关 → 优化时外点不会把任何 VP 往自己方向拽（普通最小二乘里一个远外点能严重拉偏估计）→ 抗外点的本质。
3 rounding 怎么从 W 恢复 VP？tight 时 W 近似秩 1（≈ωωᵀ）→ 取其主特征向量 reshape 回 d、再单位化。原文 Alg.1 只写 “Round Wi and recover one vanishing point”，rounding 细节在 SM（正文未展开，属诚实边界）。
4 每轮只采 6 条线会漏掉 VP 吗？不会——多轮随机采样 + 内点共识能覆盖；Fig.4 显示 F1 在采样数=6 后稳定、runtime 在 6 最低，故 6 是 trade-off 最优。
5 为何无训练反而跨域更稳？纯几何 + 凸优化，没有学到的权重 → 没有训练域偏置；学习法（NeurVPS 等）在 SU3 训练 → SU3 上高分，但换到 YUD（真实城市图）就掉。
📚 评测指标（读懂下面表格，原文 §5.1.1 定义）
precision=Nc/(Nc+Nw)（正确判为内点 / 所有判为内点；Nw=错判内点数）；recall=Nc/(Nc+Nm)（正确判为内点 / 所有真内点；Nm=漏判内点数）；F1=2·P·R/(P+R)（合成实验主指标）。consistency error（一致性误差，真实图主指标）=图像线端点到"虚拟线 v"的距离，v 由估计 VP 与该线中点确定——衡量"线真的指向估计的 VP 吗"，越小越好（Fig.1 报 0.23 px）。AA@θ（角精度，跨数据集主指标）=估计主方向与真值方向夹角 < θ 的比例，θ∈{3°,5°,10°}，越高越好。

⑨ §5 合成实验 — 超参 + 抗外点 + 效率（消融式分析）
(i) 阈值 c（Fig.3，固定 120 线/σ=1/30% 外点）：c 从 0.0003→1，F1 随 c 增大而降（c 太大 → 更多外点被误判内点）；runtime 在 c=0.03 最低（太小 SDP 难收敛、太大解空间乱）→ 定 c=0.03。
(ii) 采样线数（Fig.4，120 线/σ=3/20% 外点）：采样数 3→10，runtime 在 6 最低、F1 在 6 后稳定 → 定每次采 6 条线（trade-off 最优）。
(iii) 抗外点（Fig.6，60 线/σ=3，外点 0%→70%）：RANSAC/J-Linkage/T-Linkage 在外点 >20% 急剧崩；Quasi-VP 在 40% 开始崩；BnB 总体能扛但偶发不收敛拉低精度；GlobustVP 全程稳健（F1 始终高），抗外点最强。
(iv) 效率 vs 线数（Fig.5，σ=3/20% 外点，60→135 线）：RANSAC 最快但 F1 最低；GlobustVP runtime 远低于 BnB、F1 远高于 RANSAC → 在"精度-效率"平面上占最佳折中。Fig.7 单图：GlobustVP 在某 YUD 图 100%/100% precision/recall、0.41 px 一致性误差，全面优于 RANSAC/J-/T-Linkage/BnB/Quasi-VP。
⚠️ 诚实边界：precision/recall 完整曲线、各 baseline 完整对比、YUD 逐图 F1 与一致性误差、Full/Single SDP 的 tight relaxation 完整证明、rounding 细节——均在 SM，正文只给 AA 表 + 4 张图。实现为 MATLAB + MOSEK，笔记本 i5 CPU（无 GPU），代表性 runtime ~50ms（Fig.1）。
📌 全文一页总结（问题→方法→实验→takeaway）
问题(§1)：曼哈顿世界 VP 估计需联合做"线-VP 关联 + VP 定位"，两者耦合致大量局部最优；现有法在"全局最优 / 抗外点 / 快"三者间只能取其二（局部法无保证、BnB 指数慢、学习法不泛化）。
方法(§4)：提出 truncated multi-selection error——距离矩阵 ([DN;c1ₘᵀ])²（前 3 行=到三 VP 距离²、第 4 行=外点常数 c²）配 4×m one-hot 标签阵 Q，Primal=min⟨距离²,Q⟩（每线自动选最近 VP 或归外点、外点误差截断成 c² 不引偏）；lift 成 ω=[D;vec(Q)⊗D] 写成 Full QCQP，凸松弛（丢 rank=1）成 Full SDP（tight 证明在 SM）；迭代器 GlobustVP 每轮解 Single Block SDP 找一个 VP+内点并剔除，3 轮后 Manhattan Post-Refinement 注入正交先验，大规模用 SDRSAC 采 6 线避三次方爆炸。
实验(§5)：YUD AA@10°=96.1% 全场第一（比次优高 10.4 点）；抗外点远超采样类（RANSAC 等 20% 即崩，本文全程稳）、效率远超 BnB；SU3 上无训练仍超所有传统法，仅输给在 SU3 训练的学习法——印证无训练 = 跨域稳健。
Takeaway：① 凸松弛首次进 VP 估计，用一个可证 tight 的 SDP 同时拿下全局最优 + 抗外点 + 快，破解此前的三选二困境；② truncated multi-selection error 用一个 ⟨距离²,Q⟩ 把"关联 + 定位 + 外点剔除"一锅端，外点截断保无偏；③ Single Block 迭代 + 6 线采样避开 Full SDP 三次方规模；④ 无需训练 → 天然跨域稳健；⑤ 边界=全局最优是 mild conditions（distinguishability）下、tight 证明与 rounding 细节在 SM、实现为 CPU/MATLAB、SU3 上输给同域训练的学习法（已如实报告）。
