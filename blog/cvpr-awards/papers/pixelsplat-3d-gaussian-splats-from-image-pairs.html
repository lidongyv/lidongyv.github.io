pixelSplat: 3D Gaussian Splats from Image Pairs for Scalable Generalizable 3D Reconstruction

David Charatan ⋅ Sizhe Lester Li ⋅ Andrea Tagliasacchi ⋅ Vincent Sitzmann
MIT · Simon Fraser University · University of Toronto
arXiv PDF ⬇arXiv 摘要Scholar
一句话：把"每场景优化的 3DGS"变成"一次前向预测的 3DGS"——用一个前馈网络从两张图直接预测 3D 高斯辐射场，免去逐场景优化、泛化到新场景；核心是预测深度上的稠密概率分布并用重参数化技巧让"采样高斯中心"可微，绕开稀疏表示的局部最小值。实时渲染、比 light field transformer 快约 2.5 个数量级，RealEstate10k / ACID 上 SOTA。

摘要 Abstract（原文）

We introduce pixelSplat, a feed-forward model that learns to reconstruct 3D radiance fields parameterized by 3D Gaussian primitives from pairs of images. Our model features real-time and memory-efficient rendering for scalable training as well as fast 3D reconstruction at inference time. To overcome local minima inherent to sparse and locally supported representations, we predict a dense probability distribution over 3D and sample Gaussian means from that probability distribution. We make this sampling operation differentiable via a reparameterization trick, allowing us to back-propagate gradients through the Gaussian splatting representation. We benchmark our method on wide-baseline novel view synthesis on the real-world RealEstate10k and ACID datasets, where we outperform state-of-the-art light field transformers and accelerate rendering by 2.5 orders of magnitude while reconstructing an interpretable and editable 3D radiance field.

📝 精读笔记（要点）

为什么读它（与 World Engine 的关联）
在精读 World Engine 时讨论到"3DGS 是每场景过拟合、不泛化"——pixelSplat 正是"不过拟合 / 可泛化"路线的代表作：训练一个网络在很多场景上学，推理时一次前向从稀疏图像预测高斯，无需逐场景优化。与 vanilla 3DGS 互为对照。
灵魂一句
3DGS 从"优化问题"变成"回归问题"：网络吃一对图像 → 直接吐出一组 3D 高斯（辐射场），实时可渲、可泛化、可编辑。
要解决的问题
Generalizable novel view synthesis from sparse (两张) image observations——稀疏视角下的可泛化新视角合成，且要前馈、实时。
核心机制（摘要级，细节待逐节精读）
稀疏且局部支撑的表示容易陷入局部最小值（高斯中心放不对）。pixelSplat 的解法：预测 3D 上的稠密概率分布，再从该分布采样高斯中心；通过重参数化技巧（reparameterization trick）让这个采样可微，从而能把梯度反传穿过 splatting 表示。
结果
实时 + 显存高效；渲染加速约 2.5 个数量级；在真实数据集 RealEstate10k / ACID 的 wide-baseline 新视角合成上超过 SOTA 的 light field transformer；重建出可解释、可编辑的 3D 辐射场。

①½ Introduction 闭环：解决什么 / 怎么解 / 怎么验证
解决什么问题
We investigate the problem of generalizable novel view synthesis from sparse image observations.
可泛化的稀疏视图新视角合成。困境"既要又要"：可微渲染/NeRF 质量好但慢且费显存；light-field transformer 快些但仍非实时、且黑盒不可编辑；3DGS 实时+可编辑但只能单场景优化(要几十张图)。目标=把 3DGS 的好处带进"前馈、仅两张图、跨场景泛化"。卡在两个硬骨头：①尺度歧义(SfM 位姿只到任意尺度 s_i)；②局部最小值(直接回归高斯位置会陷；单场景那套不可微剪枝在"需反传"的泛化设定里用不了)。
怎么解决
两难点对应两设计：
• 尺度歧义 → §4.1 多视图极线 transformer：跨视图找对应 + 关联三角化出的深度(含尺度)，把 per-scene 尺度推断出来。
• 局部最小值 → §4.2 概率分布参数化 + 重参数化：位置用 encoder 预测的稠密概率分布隐式表示、采样得高斯中心；重参数化(α=ϕ_z)让采样可微。原文精辟一句：When receiving a gradient that would increase the opacity of a Gaussian at a 3D location, our model increases the probability that the Gaussian will be sampled at that location again.
怎么验证
真实数据 RealEstate10k + ACID 宽基线新视角合成，对比 SOTA light field transformer，三维度全赢：质量↑、训练+渲染成本↓、产出显式可编辑 3D；首次证明 3DGS 可端到端可微、单次前向从一对图预测。
诚实标注：渲染加速口径三处不一——abstract 说 2.5 数量级、related work 说 3 数量级、Table 1 实测比次快 baseline 省约 650×(≈2.8 数量级)。
② pixelSplat 是怎么做的（method 逐节）
整体流程：两张参考图 I, Ĩ → 各自编码出特征 → epipolar encoder(跨视图对齐, 解尺度歧义) → 逐像素概率式预测高斯(解局部最小值) → 所有像素的高斯并集 = 3D 辐射场 → splatting 渲染新视角；端到端用渲染 loss 训练。它要克服两个难点，对应两个核心设计。
难点1 · 尺度歧义 → §4.1 Epipolar Encoder
SfM 重建的相机位姿带一个每个场景任意的尺度 s_i，模型预测的 3D 位置必须和它一致。解法是两视图极线注意力：
对 I 里每个像素 u: 其相机射线在 Ĩ 上投影成"极线 ℓ" 沿 ℓ 采样 {ũ_l}; 用 u 与 ũ_l 三角化算出"I 坐标系下的深度 d̃" —— 该深度由两相机位姿算出, 天然编码了场景尺度 s_i 极线 cross-attention: query=u 特征; key/value=极线采样点(特征 ⊕ 深度的位置编码) → 注意力找到正确对应点, 把"对应深度的位置编码"加权吸进 u 特征 → 每个像素特征都编码了"与 s_i 一致的深度" 再接 per-image self-attention: 把深度传播到"在 Ĩ 里没有极线对应"的像素
一句话：极线注意力 = 跨两图做"对应点匹配 + 记住对应深度"，恢复出尺度自洽的深度（消融证明这步对 3D 结构化新视角合成"绝对关键"，约 +1dB PSNR）。
难点2 · 直接回归位置陷局部最小值 → §4.2 概率式预测高斯
逐像素对齐高斯：每像素 u 拿特征 F[u] 预测一个高斯 (μ位置, Σ协方差, α不透明度, S球谐颜色)。最关键是 μ 怎么参数化：
❌ Baseline(陷局部最小值)：直接回归深度 d → μ=o+d·d_u（且反传时用不了 3DGS 的"生成/剪枝"启发式，不可微）。
✅ pixelSplat：不回归"一个深度"，而是预测"深度上的离散概率分布" p_ϕ(z) 再采样。
Algorithm 1 · 逐像素高斯的概率式预测(原文): 输入: 深度桶 b∈R^Z, 像素特征 F[u], 相机原点 o, 射线方向 d_u 1: (ϕ, δ, Σ, S) = f(F[u]) # 预测 深度概率ϕ / 桶内偏移δ / 协方差Σ / 球谐S 2: z ~ p_ϕ(z) # 从离散概率分布采样一个"深度桶"索引 z 3: μ = o + (b_z + δ_z)·d_u # 用"桶深度 b_z + 偏移 δ_z"反投影出高斯中心 4: α = ϕ_z # 不透明度 = 被采中那个桶的概率 5: return (μ, Σ, α, S)
为什么避开局部最小值：直接挪一个点容易卡住；改成"在很多深度桶上铺概率再采样"，梯度能流到所有桶，模型能"发现"正确深度而不被困。不透明度=概率 → 低置信高斯自动半透明（可微的"软剪枝"）。采样离散本不可微 → 用重参数化技巧让梯度穿过采样（摘要的 reparameterization trick）。
训练 & 与 World Engine 的对照
训练：两图各自逐像素预测高斯 → 两图高斯并集 = 场景辐射场 → 从新视角 splatting 渲染 → 和真值图比（光度 loss）。端到端在 RealEstate10k / ACID 上训。
对照：World Engine 的 3DGS 是每场景优化的数字孪生；pixelSplat 是一个网络前馈预测高斯、跨场景泛化——核心创新即上面两招（极线编码恢复尺度 + 概率深度&重参数化避开局部最小值）。
难点2 续 · §4.2 重参数化技巧：怎么让「采样一个深度桶」可微（本页核心补全）
③-1 先问：到底什么东西不可微？我们要算的是哪个梯度？
To train our model, we need to backpropagate gradients into the probabilities of the depth buckets ϕ. This means we need to compute the derivatives ∇ϕµ of the mean µ with respect to probabilities ϕ. Unfortunately, the sampling operation z∼pϕ(z) is not differentiable.
要训练「预测深度概率的网络 f」，必须把梯度传回深度桶概率 ϕ。按常规得算「高斯中心 μ 对 ϕ 的导数 ∇ϕμ」——但 μ 是先采样桶 z∼p_ϕ(z) 再反投影得到的，而采样这一步对 ϕ 不可微（z 是离散抽样结果），链路在这里断了。
③-2 pixelSplat 的解法：不修 μ 那条路，另开一条「α 旁路」
Inspired by variational autoencoders, we overcome this challenge via a reparameterization trick. Accordingly, we set the opacity α of a Gaussian to be equal to the probability of the bucket that it was sampled from ... We then set α = ϕz ... This means that in each backward pass, we assign the gradients of the loss L with respect to the opacities α to the gradients of the depth probability buckets ϕ, i.e., ∇ϕL = ∇αL.
关键不是"把 μ 对 ϕ 变可微"（μ 那条路依旧是断的），而是另开一条可微旁路：把被采中那个桶的概率 ϕ_z 直接当作这个高斯的不透明度 α（令 α := ϕ_z）。α 是 alpha 混合权重，渲染对它天然可微，于是渲染 loss 的梯度顺着 α 流回 ϕ_z——因为 α=ϕ_z 是恒等映射，所以 ∇ϕ_z·L = ∇α·L。预测 ϕ 的网络 f 就这样被训练起来。
梯度怎么流（核心一图）: 预测 ϕ = (ϕ_1 .. ϕ_Z) ← softmax 出的 Z 个深度桶概率 | +-- 采样 z~p_ϕ(z) → 取桶深 b_z(+偏移 δ_z) → μ = o+(b_z+δ_z)·d_u → 渲染 | ✗ 断点: 离散采样不可微, μ 对 ϕ 没有梯度 | +-- 令 α := ϕ_z ────────────────────────────► 渲染(alpha 混合) ✓ 可微: ∇ϕ_z·L = ∇α·L ← 梯度只从这条旁路回到 ϕ 对照原文 Eq.(7): μ = o + (b_z + δ_z)·d_u, z ~ p_ϕ(z), (ϕ, δ) = f(F[u]) near/far 之间按 disparity 把深度切成 Z 个桶 b∈R^Z; δ∈[0,1]^Z 是桶内偏移
③-3 为什么这样就能学对深度？（原文给的直觉）
... consider the case where sampling produces a correct depth. In this case, gradient descent increases the opacity of the Gaussian, leading it to be sampled more often. This eventually concentrates all probability mass in the correct bucket ... Now, consider the case of an incorrectly sampled depth ... gradient descent decreases the opacity of the Gaussian, lowering the probability of further incorrect depth predictions.
• 采到对的深度 → 渲染像真值 → 梯度抬高 α=ϕ_z → 这个桶概率变大 → 以后更常被采 → 概率质量逐渐集中到正确桶，最终形成不透明实体面。
• 采到错的深度 → 渲染不像 → 梯度压低 α=ϕ_z → 这个桶概率变小 → 减少后续错误预测。
一句话：用「这次采到的桶好不好」反过来调「以后采到它的概率」。
③-4 追问：这严格算「重参数化」吗？粗选桶 vs 细调偏移（精读者辨析）
【以下为精读者分析，非原文原话，供参考】
• 和标准 VAE 重参数化的差别：VAE 是对连续高斯 z=μ+σ·ε（把随机性挪到与参数无关的噪声 ε 上）使其可微；这里是离散桶采样，pixelSplat 并没有把离散采样改写成可微变换，也没用 Gumbel-Softmax，而是把"选桶的概率"搬到一个连续可微量 α 上、靠渲染 loss 训练它——精神上更接近 REINFORCE / score-function（用样本好坏调采样概率）。原文措辞也是"inspired by ... reparameterization trick"（受其启发）。
• 两级精度分工（很漂亮）：「选哪个桶 z」是离散、粗定位 → 靠 α=ϕ_z 旁路训练；「桶内偏移 δ_z」是连续、细定位 → μ 对 δ_z 常规可微（∂μ/∂δ_z = d_u）。两套手段合起来：既能靠概率分布跳出局部最小值，又保留连续亚桶分辨率。
• α=ϕ_z 顺带是「可微软剪枝」：低概率桶 → 低 α → 近乎透明 ≈ 被删掉，替代了 3D-GS 里不可微的 spawn/prune 启发式（原文指出 back-propagate through the representation 时用不了那些启发式）。
• 实证：相比直接回归 μ 的 baseline，这套"概率深度 + 可微采样"带来 PSNR 提升——原文 §4.2 说 ≈1 dB、§5.3 / Table 2 实测 ≈1.5 dB（26.09→24.62，详见下方 ④）。
④ 实验 & 消融（§5）— 用数字证明两大设计
④-1 主结果（Table 1）
Our method outperforms the baselines on all metrics, with especially significant improvements in perceptual distance (LPIPS). ... our method's cost to infer a single scene (encoding) and then render 100 images (decoding) ... is about 650 times less.
在 RealEstate10k / ACID 上全指标超过 baseline（Du et al. / GPNR / pixelNeRF），感知距离 LPIPS 提升尤其明显；对只被单个参考视图观测到的区域也能正确推 3D 结构。成本：编码 1 个场景 + 渲染 100 张图，比次快的 baseline 省约 650×，训练时每条 ray 显存也低得多——这正是"前馈预测"相对"逐场景优化 / light field transformer"的核心优势。

三个问题、三条结论：
• Q1a 极线编码 = 尺度歧义的解药：去掉后 26.09→19.89(−6.2dB)，出现重影/运动模糊（深度预测错）。掉得最狠——跨视图极线对齐是 3D 结构化新视角合成的命门。
• Q1b 极线编码不只"找对应"，还要"用深度"：只喂图像特征、不喂三角化深度的位置编码 → 24.97(−1.1dB)，说明它靠三角化出的场景尺度深度解位姿尺度歧义。
• Q2 概率采样(即 ③ 的重参数化) = 避开局部最小值：改成直接回归深度/μ → 24.62(−1.5dB)，掉进局部最小值、出现斑点(speckling)。这就是 ③ 讲的"概率深度 + α=ϕ_z 可微采样"的实证价值。
诚实标注一个原文数字差异：关于概率采样的收益，原文 §4.2 说"≈1 dB PSNR boost"，而 §5.3 消融正文与 Table 2 给的是"≈1.5 dB"（26.09→24.62 = 1.47dB）。以 Table 2 精确值为准 → 约 1.5 dB。
Limitations（§C）：模型是两图各自出高斯再取并集、并不真正融合多视图；反光面常呈半透明、离分布视角下高斯呈"广告牌(billboard)"状——与原始 3D-GS 同类失败模式。Conclusion 亮点：作者把"稠密概率分布 + 重参数化反传"视为通用框架，展望结合 diffusion 做生成、或去掉相机位姿以支持大规模训练。
📚 背景：3D-GS 拟合 ≈ GMM 拟合（为什么会陷局部最小值）【外部知识】
原文 §3 点出：The fitting of a 3D-GS model is closely related to the fitting of a Gaussian mixture model ... famously non-convex and generally solved with EM ... However, the EM algorithm still suffers from local minima and is not applicable to inverse graphics.
• GMM：数据由 K 个高斯混合生成 p(x)=Σ π_k N(μ_k,Σ_k)，用 EM 解(E 步算责任度、M 步更新参数)，非凸、陷局部最小值、对初始化敏感。
• 类比 3D-GS：一堆 3D 高斯拟合场景 ≈ 拟合 GMM，同样非凸易陷局部最小值；更糟的是 inverse graphics 只有图像、没有 GT 3D 密度，连 EM 都用不了。
• 所以 pixelSplat 才用"深度上的离散概率分布 + 重参数化"避开——它走的是 GMM/分类分布那一支思路，与 MoE 无关(MoE 是稀疏扩容，形似神异)。
⑤ §4.1 / §4.2 代码级实现（基于论文公式的伪代码，非官方逐行）
§4.1 极线编码（解尺度歧义）
F = image_encoder(I) # ResNet-50 + ViT-B/8 → 特征图 [H,W,C] F_t = image_encoder(I_t) for u in pixels(I): ell = epipolar_line(u, cam_I, cam_It) # u 的射线投到 I_t 上成极线 u_ts = sample_on_line(ell, L) # 极线采样点 {ũ_l} d_ts = triangulate(u, u_ts, cam_I, cam_It) # ★I 坐标系深度: 由两位姿算出→含尺度 s_i s = concat(F_t[u_ts], gamma(d_ts)) # Eq2: 特征 ⊕ 深度位置编码 q, k, v = Wq @ F[u], Wk @ s, Wv @ s F[u] += Attention(q, k, v) # Eq3: 极线 cross-attn + skip F = F + SelfAttention(F) # Eq4: 把深度传播到无极线对应的像素 # 关键: 深度是"几何三角化"得到(不是网络猜)→天然带尺度, 这才真正解了尺度歧义
§4.2 概率式高斯预测（Algorithm 1，含重参数化）
# b: 深度桶 [Z] (near/far 间按 disparity 离散, Eq6) def predict_gaussian(F_u, o, d_u, b): phi, delta, Sigma, S = f(F_u) # phi=深度概率(softmax,[Z]); delta=桶内偏移([0,1]^Z) z = categorical_sample(phi) # z ~ p_phi(z) ← 离散采样, 对 phi 不可微 mu = o + (b[z] + delta[z]) * d_u # 反投影出高斯中心 (Eq7) alpha = phi[z] # ★重参数化核心: 不透明度 = 被采桶的概率 return Gaussian(mu, Sigma, alpha, S) # 反向: mu 那条断(z 离散); 但 alpha=phi[z] 让梯度经 alpha 回流到 phi (∇phi = ∇alpha) # 训练: 两图各像素预测 → union → splatting 渲染新视角 → 光度 loss → 端到端反传
要点：§4.1 靠几何三角化的深度解尺度(不是猜)；§4.2 靠 α=ϕ_z 旁路让离散深度采样可微(选桶=粗定位、δ=桶内细定位)。官方代码：github.com/dcharatan/pixelsplat。
数据集：RealEstate10k / ACID — 开放场景，非 object-level
RealEstate10k, a dataset of home walkthrough videos downloaded from YouTube, as well as ACID, a dataset of aerial landscape videos. Both datasets include camera poses computed by SfM software.
• RealEstate10k(Zhou 2018)：YouTube 房产漫游视频，室内外，场景级 / unbounded。
• ACID(Liu 2021, Infinite Nature)：航拍海岸 / 自然风景视频，同样场景级。
• 都是开放场景(scene-level)，不是 object-level(不像 ShapeNet/DTU/CO3D 以单物体为中心、尺度已归一)。正因是 SfM 真实开放场景、每场景尺度 s_i 任意，才必须有 §4.1 极线编码解尺度。评测 256×256、取两帧作 reference 重建中间帧。

⑥-1 mono depth 还是 bin cls 吗？（是）
是，始终是深度桶分类(bin cls)：DepthPredictorMonocular 用 Linear 出 pdf=softmax(Z 个深度桶) + offset=sigmoid(桶内偏移)，采样桶 index → depth=disparity_to_depth((index+offset)/s)(视差空间均匀分桶)，opacity=pdf_i(=α=ϕ_z)。
"Monocular" 的真意：这个 depth head 只吃单像素特征、不显式建 cost volume——跨视图匹配已由 epipolar cross-attention 融进特征。等于用 attention 替代传统 MVS/stereo 的 plane-sweep cost volume，再接一个轻量单目 bin-cls 深度头。
⑥-2 采样在"另一张 context 图"上；极线=near/far 投影两端；深度是均匀采样(修正)
• 采样在另一张 reference/context 图上(不是 target 渲染视角)：射线从当前图每像素发出，投影到其他 context view 采样。
• 极线表征：不解基础矩阵，而是把射线在 near/far 深度处的点投影到另一图 → 极线 = xy_min(near)到 xy_max(far)的斜线段(未 rectify)。
• 修正前面伪代码：官方主流程是"沿射线在视差空间均匀采深度→投影得极线点"(depth→point)，不是"先采极线点再三角化反解深度"；真三角化 get_depth(两射线求交)仅用于给采样点算深度做位置编码。
⑥-3 是时序(视频)训练集，为什么不用 stereo matching 数据集
是视频序列(RealEstate10k/ACID)，view_sampler_bounded 从同一视频取间隔 gap 帧的两帧作 context、target 夹中间作渲染监督。不用 stereo 数据集：① 用渲染 loss 自监督，需 context 之外的第三视角当监督目标——视频有连续多帧，stereo 只有左右两图无中间视角；② 不需要 GT 深度(光度自监督)，stereo 的核心价值(GT 视差)用不上；③ 视频调 frame gap = 任意基线，规模大场景多样(泛化)；④ 视频 SfM 位姿 up-to-scale 正是 §4.1 要解的卖点，stereo 位姿已标定反而用不上。
⑥-4 overlap 依赖与三层兜底
pixelSplat 需两图足够 overlap(共视视角间插值，近 stereo 设定)。小/无 overlap 的兜底：① 数据层面 view_sampler 只喂同视频有共视的两帧(不喂无关图)；② self-attention in-paint 把有对应区域深度传到无对应像素；③ depth 头是 monocular 的，无对应时退化为单目预测。退化代价 ≈ No-Epipolar 消融 26.09→19.89(−6.2dB)(掉但不崩)。无 overlap 超出设定边界(尺度歧义无解)，该用单图 3D / diffusion 生成。
