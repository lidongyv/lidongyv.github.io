Customized Fusion: A Closed-Loop Dynamic Network for Adaptive Multi-Task-Aware Infrared-Visible Image Fusion

Zengyi Yang ⋅ Yu Liu ⋅ Juan Cheng ⋅ Zhiqin Zhu ⋅ Yafei Zhang ⋅ Huafeng Li
arXiv PDF ⬇arXiv 摘要Scholar

摘要 Abstract

Infrared-visible image fusion aims to integrate complementary information for robust visual understanding, but existing fusion methods struggle with simultaneously adapting to multiple downstream tasks. To address this issue, we propose a Closed-Loop Dynamic Network (CLDyN) that can adaptively respond to the semantic requirements of diverse downstream tasks for task-customized image fusion. Specifically, CLDyN introduces a closed-loop optimization mechanism that establishes a semantic transmission chain to achieve explicit feedback from downstream tasks to the fusion network through a Requirement-driven Semantic Compensation (RSC) module. The RSC module leverages a Basis Vector Bank (BVB) and an Architecture-Adaptive Semantic Injection (A2SI) block to customize the network architecture according to task requirements, thereby enabling task-specific semantic compensation and allowing the fusion network to actively adapt to diverse tasks without retraining. To promote accurate semantic compensation, a reward-penalty strategy is introduced to reward or penalize the RSC module based on task performance variations. Experiments on the M3FD, FMB, and VT5000 datasets demonstrate that CLDyN not only maintains high fusion quality but also exhibits strong multi-task adaptability.

📝 精读笔记

灵魂一句
红外-可见光图像融合要同时服务多个下游任务（检测/分割/显著性），但现有 task-aware 融合只在训练过的任务上好、换任务就退化。CLDyN 建一条语义传输链形成闭环：把多个下游任务网络(DTN)的语义特征反馈给融合网络，由 Requirement-driven Semantic Compensation (RSC) 模块按任务需求动态定制网络架构做“任务特定语义补偿”，让冻结的融合网络无需重训就能适配多任务；再用 reward-penalty 策略按“补偿前后任务性能变化”奖惩 RSC。RSC 极轻量（0.46M 参数、跨任务共享）。
问题 & 动机
红外（突出热目标）+ 可见光（纹理丰富）融合能提升场景表示、利于检测/分割/SOD。现有 task-aware 融合两类：① loss-driven（设计任务相关 loss 引导，如 SeAFusion/TDAL/MetaFusion/TDFu）；② task semantic-guided（直接注入任务特征，如 DetFusion/UAAFusion/MRFS/SAGE）。但都只在 DTN 训过的任务上表现好，换 untrained DTN 就退化（Fig1a）——缺乏对多样任务语义需求的自适应响应。
核心方法 + 关键公式
两阶段。Stage1：训 Vision-guided Fusion Network (VFN)——FEB 提特征 + FRB 重建，融合 loss ℓf=‖If−max(Iir,Ivi)‖₁ + λ‖∇If−max(∇Iir,∇Ivi)‖₁（式1，像素+Sobel 梯度，max 融合策略）。Stage2：冻结 VFN，引入闭环：
· 语义传输链（§3.3）：冻结 VFN 出多模态特征 + 初始融合 If（式2）→喂第 n 个任务网络 Γn 得任务输出 + 语义特征 Fdn（式3）→RSC 按 Fdn 对 Fir/vi 做任务特定补偿（式4）→补偿特征替换原特征重注入 VFN，生成任务定制融合图 Inf←s（式5）。
· Reward-Penalty（§3.3）：补偿后任务性能↑则 reward（GT 监督 ℓr），否则 penalty ℓp=max(0, c(ŷf←s)−c(ŷf))（式6）防有害漂移；ℓcl=ℓr+δℓp（式7），用 CAGrad 缓解任务间梯度冲突。
· RSC 模块（§3.4）= Basis Vector Bank (BVB) + 2(L−1) 个 Architecture-Adaptive Semantic Injection (A2SI)。A2SI：M 个分支按任务语义自适应选卷积配置（4 个正交原型 p=[p1,1,p3,1,p3,2,p3,3]，Softmax 选配置，式8）；BVB：4 sub-bank × 32 个正交基向量（e2=256），按 cosine 相似度选基（式9-10）→生成任务特定卷积核 W（式11）→多分支并行卷积聚合注回（式12）。
关键结果
融合质量（Tab1，M3FD/FMB/VT5000，5 指标）：Ours 多数第一（注：用补偿前的视觉主导融合图比较）。vs “task network retraining”（Tab2）：多数最高/接近最高，但可训练 params 仅 0.46M、FLOPs 174.06G（对比法 46.52M/183.82G）——OD 0.6304 / Seg mIoU 60.34 / SOD mFβ 0.8129 / Em 0.9087。vs “joint training”（Tab3）：IRFS/MRFS/SMiF 只在训过的单任务好、其他退化；Ours 跨任务一致优且 params 远少（对比 39.95–134.97M）。cross-detector（Tab4）：换 DETR 不重训 RSC，VFN+RSC 比 VFN 在 DETR(0.561→0.581)、YOLOv5(0.6076→0.6304) 都升。
亮点
① 闭环优化机制 + 语义传输链——把下游任务的语义需求显式反馈给融合网络做动态补偿，冻结主干、无需重训即适配多任务；② RSC 用 BVB + A2SI 动态定制架构（任务特定卷积核 + 自适应感受野，类 hypernetwork）；③ reward-penalty 用“补偿前后性能差”约束、防补偿漂移；④ 极轻量（RSC 0.46M 参数、跨任务共享），比对比法参数少 1–2 个数量级。
疑问
① 任务集是“fixed task set”：RSC 训一次支持固定任务集内多任务；对完全没见过的新任务类型（如深度估计）能否泛化原文未验（只验了换检测器 DETR/YOLOv11 这类同任务换网络）→ 诚实边界。② 并非全项第一：Tab2 里 OD（0.6304 vs OCCO 0.6320）、Em（0.9087 vs IRFS 0.9091）实为第二，论文表述为“ranking second, very close”。③ 原文 §4.5 命名疑似笔误：标题“Effectiveness of the Penalty Loss ℓr”自相矛盾（penalty 应是 ℓp，ℓr 是 reward），Model II 描述也含混 → 需查原文/勘误。④ 复杂场景退化：假设正常天气，雨/暗/噪声下掉点（附录 Tab13 + limitation 自承）。（注：IR+可见光多模态融合与自驾感知相关，但本文对标的是融合方法，不与自驾基线硬比。）

① Abstract（摘要）— 逐句精讲
原文大意：红外-可见光图像融合（IVIF）要整合互补信息以利鲁棒视觉理解，但现有融合方法难以同时适配多个下游任务。为此提出闭环动态网络 CLDyN，能自适应响应不同下游任务的语义需求做「任务定制」融合。核心是一个闭环优化机制：建立一条「语义传输链」，通过 Requirement-driven Semantic Compensation（RSC）模块实现「从下游任务到融合网络的显式反馈」。RSC 用 Basis Vector Bank（BVB）+ Architecture-Adaptive Semantic Injection（A2SI）按任务需求定制网络架构，从而做任务专属语义补偿、让融合网络无需重训就主动适配多任务。再用 reward-penalty 策略按任务性能变化奖/罚 RSC。在 M3FD/FMB/VT5000 上既保高融合质量又强多任务适配。
逐句拆解（verbatim 引原文）：
1) 痛点 — “existing fusion methods struggle with simultaneously adapting to multiple downstream tasks.”
2) 方案定位 — “a Closed-Loop Dynamic Network (CLDyN) that can adaptively respond to the semantic requirements of diverse downstream tasks for task-customized image fusion.” 「task-customized」是题眼。
3) 闭环机理 — “a closed-loop optimization mechanism that establishes a semantic transmission chain to achieve explicit feedback from downstream tasks to the fusion network through a Requirement-driven Semantic Compensation (RSC) module.” 关键词「explicit feedback」（显式反馈，对照现有方法的「隐式/单向」）。
4) RSC 内核 — “leverages a Basis Vector Bank (BVB) and an Architecture-Adaptive Semantic Injection (A2SI) block to customize the network architecture according to task requirements … without retraining.”
5) 优化策略 — “a reward-penalty strategy is introduced to reward or penalize the RSC module based on task performance variations.”
一句话抓 Abstract：不为每个任务各训一个融合网络，而是冻结一个融合网络（VFN）、用一个小 RSC 模块接收各下游任务反馈的语义、动态生成任务专属卷积核 + 定制卷积架构去补偿融合特征，并用「补偿后变好就奖、变差就罚」的闭环把这种补偿能力训出来——一次训练、推理期零梯度更新就能服务多任务。
📚 背景知识（外部，非本文原文 — 读懂 CLDyN 必备）
① 红外-可见光融合（IVIF）& task-aware fusion：把红外的显著热目标线索与可见光的纹理细节融成一张图，利于检测/分割/显著目标检测等高层任务。「task-aware fusion」让融合结果对齐下游任务目标，分两类：(a) loss-driven（SeAFusion/TDAL/MetaFusion/TDFu，用任务相关损失约束融合网络）；(b) task semantic-guided（DetFusion/UAAFusion/MRFS/SAGE，直接把任务特征注入融合过程）。两类的通病：只对「训练过的下游任务网络 DTN」好，换个 untrained 任务就退化（Fig1a）。
② 动态网络（dynamic network）& 动态卷积：不固定网络参数/结构，按输入自适应生成（如 Dynamic Convolution 用注意力组合多个卷积核）。CLDyN 把它推进到「按任务语义动态生成卷积核 + 选卷积配置」。
③ CAGrad（Conflict-Averse Gradient Descent）：多任务学习里不同任务梯度常冲突，CAGrad 找一个对所有任务都不太坏的更新方向，缓解冲突。本文用它缓解多任务闭环优化的梯度冲突。
④ 融合质量五指标：MI（互信息，↑）、QAB/F（基于梯度的融合性能，↑）、QCB（Chen-Blum，↑）、QCV（Chen-Varshney，↓越低越好）、QCC（相关系数，↑）。下游任务指标：OD 用 mAP50→95、Seg 用 mIoU、SOD 用 mFβ/Em。DTN：YOLOv5s（检测）、SegFormer mit-b2（分割）、CTDNet-18（显著目标检测）。
Q&A · 它要解决的主要问题是什么？
核心：让一个融合网络同时服务多个下游任务，且对「训练时没见过的下游任务网络」也不退化、无需为新任务重训融合网络。原文 Fig1a 指出现有 task-aware 法 “their performance degrades on other tasks with untrained DTNs”。
为什么难：不同任务对融合图的「语义偏好」不同——检测想要突出热目标区域、分割想要清晰边缘结构、SOD 想要显著性。一张固定的融合图无法同时最优满足所有任务（任务冲突）。CLDyN 的答案：不改融合图本身的训练，而是在推理时按当前任务反馈的语义需求，对融合网络的中间特征做「任务专属语义补偿」，等于为每个任务临时定制出一张更合该任务胃口的融合图 \(I^n_{f\leftarrow s}\)。
② §1 Introduction — problem → 现有不足 → solution → why 闭环
problem：task-aware fusion 想让融合结果对齐下游任务，但现有两类法（loss-driven / semantic-guided）都把「任务」绑死在训练阶段，“their performance degrades on other tasks with untrained DTNs, as shown in Figure 1(a).”
现有不足：loss-driven 多忽略 feature-level 语义约束（或只在固定任务上调损失）；semantic-guided 直接注入任务特征，但任务特征与融合特征分布差距大，直接注入次优；靠 SAM/instruction 的（SAGE/IDF-TDDT）要么只在特定任务好、要么靠任务指令难以捕获任务专属语义。共性 = 缺一条「下游任务→融合网络」的显式、可泛化反馈通道。
solution（闭环）：Fig1b——在融合网络 FN、RSC 模块、多个 DTN 之间建「semantic transmission chain」。RSC 接收各 DTN 反馈的语义特征 \(F^n_d\)，据此对 FN 做 task-specific 语义补偿。RSC = BVB（存可学习语义基，生成任务专属卷积参数）+ A2SI（按任务动态定制网络架构）。
why（机理 + 闭环关键）：引入 reward-penalty——比较「补偿前后」的任务性能，变好则奖、变差则罚，让 RSC 渐进获得对多任务语义需求的自适应响应能力。原文点出代价极低：“the fusion network could adaptively adjust itself according to the semantic requirements of different DTNs without retraining, while the RSC module is trained only once to support multiple downstream tasks within a fixed task set.”
Q&A · 为什么现有 task-aware 法在「untrained DTN」上退化？
根因：它们把任务信息以静态方式固化进融合网络——loss-driven 把任务损失烤进权重、semantic-guided 把某个 DTN 的特征注入。一旦换个任务（新的 DTN），融合网络既没有这个任务的损失信号、也没有它的特征注入，自然不对齐。
CLDyN 的不同：把任务信息从「静态固化」变成「运行时动态反馈」——任务网络 \(\Gamma_n\) 把它对融合图的语义偏好 \(F^n_d\) 实时反馈给 RSC，RSC 据此即时定制补偿。所以加新任务只要有它的 DTN 反馈即可（RSC 在固定任务集上训一次，参数跨任务共享 0.46M）。cross-detector 实验（Table4）佐证泛化：把 YOLOv5 换成 DETR 不重训 RSC，mAP 仍从 VFN 的 0.5610 提到 0.5810。
②′ §2 Related Work — task-aware fusion 两支演进谱系（每步「问题→改进」）
(一) Loss Function-Driven（用任务损失约束融合网络）：SeAFusion / TDAL / IRFS 用 task-related loss 提语义 → 缺陷 “the above methods often ignore feature-level semantic constraints” → MetaFusion “aligns fusion and task features to enhance the task-relevant semantics”；针对 noisy input，PAIF “introduces adversarial perturbations and leverages task-related losses to learn more robust semantic representations”；针对「任务性能 vs 视觉质量」平衡，BDLFusion “alleviates task conflicts by randomly weighting the task-related and visual-related losses”、TIMF “combines architecture search with a parameter initialization strategy”、TDFu 学权重聚合多源特征。共性短板（原文）：“most fail to exploit task features for semantic enhancement, thus limiting the semantic expressiveness of fused images.”
(二) Task Semantic-Guided（直接注入任务特征）：DetFusion / UAAFusion 用 task attention map 引导、SMiF 用 task↔多源特征 cross-attention 注入 → 缺陷 “the large distribution gap between task and fusion features makes direct semantic injection suboptimal” → PSFusion / MRFS / DetFusion++ / SDCFusion 用 feature sharing + joint optimization 强制语义一致 → 但 “the injected semantics in these methods lack robustness across scenes” → SAGE / SpTFuse 注入 SAM 语义增强泛化 → 但 “often perform well only on specific tasks and thus lack generality in multi-task scenarios” → IDF-TDDT 用 task instruction 微调融合网络做多任务 → 但 “relying entirely on task instructions makes it difficult to capture task-specific semantics, leading to suboptimal performance.”
CLDyN 的位置：原文收束于 “the CLDyN can explicitly leverage the semantic features fed back from multiple downstream tasks and adaptively perform task-specific semantic compensation”——用 feature-level 反馈（非 loss、非 instruction、非固定注入）+ 动态架构补偿，正面回应上面两支的所有遗留短板。
③ §3.1-3.2 两阶段框架 + VFN + 融合损失
两阶段：Stage-1 训 Vision-guided Fusion Network（VFN）产出「视觉好看」的融合图（用 \(L\) 个 FEB 提特征 + 一个 FRB 重建）；Stage-2 冻结 VFN，引入闭环优化，只训 RSC 做多任务适配。VFN 融合损失（式1）：
\[ \ell_f=\|I_f-\max(I_{ir},I_{vi})\|_1+\lambda\|\nabla I_f-\max(\nabla I_{ir},\nabla I_{vi})\|_1 \]
第一项=像素级取红外/可见光逐像素最大值（保显著强度），第二项=梯度级取最大（Sobel \(\nabla\)，保纹理边缘），\(\lambda\) 平衡。即「亮的地方跟最亮的源、边缘跟最清晰的源」，保证视觉保真。补充材料里 FRB 还用 GAP/GMP/MeanP/MaxP 池化 + Sigmoid 出注意力矩阵 \(A\)（式13）加权多模态特征。
③′ §3.2 + 附录A · VFN 内部：梯度驱动的多池化注意力融合（式13）
VFN 结构（Fig9）：由 2L 个 FEB（Feature Extraction Block）+ 1 个 FRB（Fusion Feature Reconstruction Block）组成。FEB：“when L = 1, the FEB contains a single convolutional block … When L > 1, each FEB is composed of three convolutional layers”，逐层提红外 / 可见光特征 \(\{F^l_{ir/vi}\}_{l=1}^{L-1}\)。FRB 的融合靠注意力（式13）：对最后一层特征用 Sobel 算子求梯度并拼接 \(G=[\nabla F^L_{ir},\nabla F^L_{vi}]\)，再用 四种池化（GAP / GMP / MeanP / MaxP）各自处理、逐元素相乘、Sigmoid 得注意力矩阵：
\[ A=\mathrm{Sigmoid}\big(G_{\text{GAP}}\odot G_{\text{GMP}}\odot G_{\text{MeanP}}\odot G_{\text{MaxP}}\big) \]
\(A\) 再与 \([F^L_{ir},F^L_{vi}]\) 逐元素相乘、过 \(L\) 个 FEB + 3 个卷积块生成融合图 \(I_f\)。读法：VFN 的「视觉融合」本质是用梯度显著性（边缘 / 纹理强度）驱动的注意力去加权两模态特征——与式1 损失（像素 max + 梯度 max）目标一致：哪里边缘强就更多保留哪个模态。这套 VFN 在 Stage-2 被整体冻结，多任务适配全交给 RSC。
④ §3.3 闭环机制之一：Semantic Transmission Chain（语义传输链）
四步链路（式2-5）：
① 冻结 VFN 出初始融合图 + 各层特征：\( (I_f,\{F^l_{ir/vi}\}_{l=1}^{L-1})=\mathrm{VFN}(I_{ir},I_{vi};\theta^*_\Phi) \)；
② 融合图喂第 \(n\) 个任务网络 \(\Gamma_n\)，拿任务输出 + 语义特征反馈：\( (\hat y^n_f,F^n_d)=\Gamma_n(I_f;\theta^{n,*}_\Gamma) \)，\(F^n_d\) 反映该任务对结构/纹理/显著区域的偏好；
③ RSC 据 \(F^n_d\) 对各层特征做任务专属补偿：\( \{F^{l,n}_{ir\leftarrow s/vi\leftarrow s}\}=\mathrm{RSC}(\{F^l_{ir/vi}\},F^n_d;\theta_\Psi) \)；
④ 补偿后特征替换原特征再过 VFN，生成任务定制融合图 \(I^n_{f\leftarrow s}\)（式5）。
原文点睛：RSC “emphasizes or suppresses features based on task requirements, for example, by highlighting thermal regions for detection tasks and enhancing edge structures for segmentation tasks.” 推理期 “no gradient update is applied to any network … the RSC module introduces only 174.06G FLOPs … only 0.46M parameters”（跨任务共享参数）。
⑤ §3.3 闭环机制之二：Reward-Penalty Strategy（奖惩策略）
动机：光有传输链，RSC 可能发生「语义补偿漂移」（compensation drift），需约束。奖惩定义（式6）：
\[ \ell^n_r=c_n(\hat y^n_{f\leftarrow s},y^n_{GT}),\quad \ell^n_p=\max\!\big(0,\ c_n(\hat y^n_{f\leftarrow s},y^n_{GT})-c_n(\hat y^n_f,y^n_{GT})\big) \]
\(c_n\)=第 \(n\) 任务的损失函数，\(\hat y^n_f/\hat y^n_{f\leftarrow s}\)=补偿前/后的任务预测。reward \(\ell^n_r\)=在 GT 监督下让补偿后预测更准；penalty \(\ell^n_p\)=当「补偿后比补偿前还差」（差值>0）才罚，否则为 0——专门压制「越补越糟」的有害漂移。闭环目标（式7）：\( \ell^n_{cl}=\ell^n_r+\delta\ell^n_p \)，\(\delta\) 控罚力度（默认 5）。用 CAGrad 缓解跨任务梯度冲突。
Q&A · reward-penalty 到底在奖/罚什么？为什么需要 penalty？
奖：补偿后任务更准（\(c_n\) 更小）→ 鼓励这种补偿方向（perceptual alignment）。罚：只在「补偿反而让任务变差」时触发（\(\max(0,\cdot)\) 铰链），抑制过度/有害补偿。
为什么必须有 penalty：多任务共享一个 RSC，若只用 reward（任务损失），RSC 容易偏科——把补偿能力都投给某个最好涨分的任务而牺牲其他。penalty 给「使某任务退化」的补偿一个显式惩罚，强制 RSC 学到「不伤害任一任务」的通用补偿。消融证据：Model II 去掉 penalty 约束仅用任务损失训 RSC → 明显偏向 SOD 任务（不均衡）；full model 各任务更均衡（Table5）。[注：原文 §4.5 小标题把该项写作 “Penalty Loss \(\ell^n_r\)”，与式6 的 reward 符号 \(\ell_r\) 略有出入，但描述的是「去掉奖惩约束后偏科」这一现象。]
⑥ §3.4 RSC 之 A2SI：按任务自适应「选卷积配置」（式8）
动机（原文）：“a single receptive field is insufficient to capture diverse task semantics”——单一感受野不够，故每个 A2SI 设 \(M\) 个语义提取分支，各分支按 \(F^l_{ir/vi}\) 与 \(F^n_d\) 自适应调卷积配置，覆盖多感受野。正交卷积原型：\( p\in\mathbb{R}^{4\times e_1}=[p_{1,1},p_{3,1},p_{3,2},p_{3,3}] \)，\(p_{k,d}\)=核大小 \(k\times k\)、膨胀率 \(d\) 的原型（共 4 种典型配置：1×1，3×3 dilation 1/2/3），\(e_1=16\)，互相正交且冻结（保配置表示独立）。配置选择矩阵（式8）：
\[ S=\mathrm{Softmax}\big(p\times\mathrm{Resh}(\mathrm{Proj}_3([\mathrm{Proj}_1(F^l_{ir/vi}),\mathrm{Proj}_2(F^n_d)]))\big) \]
\(S(j,i)\)=第 \(i\) 分支选第 \(j\) 种配置的概率，取最大者。即按「当前多模态特征 + 任务语义」决定每个分支用多大核/多大膨胀。
⑦ §3.4 RSC 之 BVB：按任务「生成卷积核参数」（式9-12）
Basis Vector Bank：\( R_{ir/vi}=[R^{1,1},R^{3,1},R^{3,2},R^{3,3}]\in\mathbb{R}^{4\times 32\times e_2} \)，4 个 sub-bank 对应 4 种卷积配置，每个含 32 个可学习基向量（维度 \(e_2=256\)，初始两两正交）。选基（式9-10）：把 \(F^l_{ir/vi},F^n_d\) 过 Proj4/5/6 聚合后，与每个基向量算余弦相似度 \( s_i=\cos(\mathrm{Proj}_6([\mathrm{Proj}_4(F^l),\mathrm{Proj}_5(F^n_d)]),r^{k,d}_{i}) \)，取最相关基 \( \tilde r_m=r^{k,d}_{i^*},\ i^*=\arg\max_i s_i \)。生成核 + 注入（式11-12）：\( W^{k,d}_m=\mathrm{Pred}_{k,d}(\tilde r_m) \)（两层线性），并行卷积后残差注入：
\[ F^{l,n}_{ir\leftarrow s/vi\leftarrow s}=F^l_{ir/vi}+\frac{1}{M}\sum_{m=1}^{M}\big(W^{k,d}_m * F^l_{ir/vi}\big) \]
即「基→核→卷积→补偿」，把任务语义注入每层特征，逐层传播。
Q&A · BVB + A2SI 为什么能「按需定制网络架构」？
两段式动态：① A2SI 决定「用什么形状的卷积」（核大小/膨胀，由式8 的配置选择矩阵选），相当于动态结构；② BVB 决定「这个卷积的参数是什么」（从 32 个正交基里按任务语义选最相关基、再 Pred 出核权重），相当于动态参数。两者都由「当前特征 + 任务反馈 \(F^n_d\)」驱动 → 同一个 RSC 对不同任务长出不同的卷积结构和权重 = task-customized architecture。
为什么用「正交基 + 选择」而非直接回归核：正交基提供多样化、互不冗余的语义先验，「选基 + 微调」比「凭空回归整个核」更稳更省参（全 RSC 仅 0.46M）。消融证据：去掉 BVB（直接预测核）各任务明显退化；固定 A2SI 多分支（不再自适应）偏向 OD、多任务适配下降（Table7/12）。

Q&A · CLDyN vs IDF-TDDT（最接近的多任务前作）差在哪？
IDF-TDDT [51]（同组 Information Fusion 2025 前作）：用任务指令（task instructions）微调融合网络来做多任务适配，指令用 LLaMA 编码。本文的三点超越（原文 §4.3 Further Analysis + Fig6）：① 反馈粒度——IDF-TDDT “relying entirely on task instructions makes it difficult to capture task-specific semantics, leading to suboptimal performance”；CLDyN 用 DTN 反馈的语义特征 \(F^n_d\)（细粒度、直接反映任务对结构 / 纹理 / 显著区的偏好）而非粗粒度文字指令。② 开销——IDF-TDDT “encodes task instructions using LLaMA, which introduces substantial parameter and computational overhead, limiting its deployment on resource-constrained platforms”；CLDyN 的 RSC 仅 0.46M 参数、跨任务共享。③ 是否动主干——IDF-TDDT 微调融合网络；CLDyN 冻结 VFN、只用小模块做即时补偿。结果（Fig6）：原文 “our method significantly outperforms IDF-TDDT in both quantitative and qualitative evaluations across multiple downstream tasks.” 本质差异：instruction-tuning 的「告诉网络要做哪个任务」 vs feature-feedback 的「让网络看到任务网络实际想要什么特征」——后者信息更密、更省、更可泛化（cross-detector 已验证）。

⚠ 诚实边界 & 疑问（含原文 limitation，推断标 [推测]）
① 固定任务集：原文明说 RSC「trained only once to support multiple downstream tasks within a fixed task set」——是「固定任务集内免重训」，并非任意全新任务类型都零成本（新任务类型仍需其 DTN 反馈、且可能需纳入训练任务集）[推测：跨任务类型的真正 zero-shot 未充分验证]。
② 复杂场景退化（原文 Table13/§H）：曝光衰减 \(\alpha\in[0.4,0.8]\) 等复杂场景下性能下降（OD 0.6304→0.6284、Seg 60.34→59.73）；原文坦言假设「正常天气」，重雨/低光/强噪声/传感器老化下会退化，列为 future work。
③ 多任务非全胜：个别单任务指标 full 不是最高（如 vs 联合训练法在其专精任务上仍有 marginal gap），卖点是「均衡 + 省参」而非「单任务碾压」。
④ 反馈依赖 GT：奖惩用 GT 监督（式6 需 \(y^n_{GT}\)），训练阶段仍需各任务标注；推理期才无梯度更新。
⑤ 标注/标号小瑕：原文 §4.5 reward/penalty 符号、补充 Model IV/V/VI 标号有少量不一致，阅读时需对照式6 与 Table12 复核。

📌 全文一页总结（≥3 takeaway）
problem：红外-可见光 task-aware 融合把任务信息静态固化进网络，换 untrained 任务就退化；要让一个融合网络免重训地服务多任务。
method：CLDyN 两阶段——先训视觉融合网络 VFN（式1）并冻结；再用闭环优化：语义传输链（式2-5）让各 DTN 把语义偏好 \(F^n_d\) 反馈给 RSC，RSC 用 A2SI 选卷积配置（式8，正交原型）+ BVB 选基生成卷积核（式9-12，正交基）做任务专属补偿，再用 reward-penalty（式6-7）+ CAGrad 训出「不伤害任一任务」的通用补偿。
takeaway 1：把任务适配从「为每任务重训/联合训」改成「冻结主网 + 一个 0.46M 共享小模块按任务反馈动态补偿」，参数/FLOPs 远低于联合训练法却多任务均衡 SOTA（OD 0.6304/Seg 60.34/SOD 0.8129）。
takeaway 2：「动态架构」= A2SI 选结构（核大小/膨胀）+ BVB 选参数（正交基→核），二者都由任务反馈驱动，等于为每任务长出不同卷积；正交先验比直接回归核更稳省参（消融证 BVB/A2SI 都关键）。
takeaway 3：reward-penalty 的 penalty（铰链，只罚「越补越差」）是防多任务偏科的关键；闭环「比较补偿前后性能」给了一条显式、可泛化的「任务→融合」反馈通道（cross-detector 换 DETR/YOLOv11 不重训仍提升）。
适用边界：固定任务集内免重训、训练需 GT；正常天气假设，复杂退化场景会掉点（原文 Table13）。
