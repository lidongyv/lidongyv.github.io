TLD 红绿灯模型方案设计

基于 Deformable DETR 的 e2e 方案，2V（Fn + Fw）输入，剔除 bbox 分支、以 reference point 定位灯位，直接输出四方向灯的 2D 点位与颜色；拆为找灯 + 识别两个子任务，2V 各识别四向、模型融合 + 后处理多重校验。当前最 Top 问题：ISP 导致灯色不识别。

01

模型概述与设计

decoder 起对 Fn / Fw feature 区分隔离；head 分 reg_branch（找灯）与 cls_branch（灯色）；颜色分类用两个单视图 cross attention 出单项后，再用独立 dir_query cross attention 融合出 2V e2e 结果。

🔍 子任务 1 · 找灯（reg_branch）

使用 DCN 方式直接监督和学习 dcn reference point 的点位；目前收敛得不错，几乎没有找不到灯的情况，仅剩特殊 corner case。

🎨 子任务 2 · 识别（cls_branch）

DCN 之后的结果直接进分类头做灯色识别。当前最 Top 问题：找到灯但 ISP 导致视觉特征太差、不识别灯色。

02

模型输入 / 输出

灯色 label 统一：0 green · 1 red · 2 unknown · 3 no-tld；四向维度对应 直行 · 右转 · 左转 · 掉头。
