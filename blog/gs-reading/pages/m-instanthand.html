InstantHand：Soft Alpha Band + 可靠度门控外观迁移

③ 监督正则类 arXiv 2611.08330 · NeurIPS 2026 ｜ 单图前馈手部 avatar 的两个监督盲区

中文核心说明

单图前馈重建手部 avatar 有两个「图像平均损失」盖不住的盲区：① alpha 泄漏——手指轮廓很细，轮廓附近的 alpha 误差在整图平均下极其微弱，模型学不到「把轮廓收回来」，结果手指变粗；② 颜色向先验漂移——从图像特征回归的颜色在可见区域也会滑向学到的先验，丢掉输入图的外观。

InstantHand 对应两个模块：

  • Soft Alpha Band（SAB）：只监督 GT 掩码外 2px 膨胀带与内 2px 腐蚀带，带外用 smooth-L1 的 hinge 形式：带外要求 alpha 压到 τ_out=0.03 以下，带内要求 alpha 抬到 τ_in=0.60 以上；权重 η(n) 前 5000 步为 0、5000–12000 步线性升到 1——先让整体形状收敛，再精修轮廓。
  • Reliability-gated Appearance Transfer：在源视角渲染一次，按每个高斯的 7×7 footprint 聚合出「源图颜色 / 渲染颜色 / 特征 / 掩码支持」，双门控：γ_i 衡量该高斯的渲染贡献可靠度（√C·m 相对 P95 归一化，且只对观测到的前端高斯开放），g_i 决定是否启用颜色迁移（bias 初始化 −1.5 → 初期不迁移）；合成时再加全局身份平移 Δ_s^aid。整个模块只改颜色，不动几何。
English summary. Single-image feed-forward hand avatars suffer from two blind spots of image-averaged losses: (1) alpha leakage thickens thin finger contours because silhouette errors are diluted in the average; (2) colors regressed from image features drift toward a learned prior even in observed regions. InstantHand adds two modules. The Soft Alpha Band supervises only a 2px dilated band outside the ground-truth mask and a 2px eroded band inside it, with hinge smooth-L1 terms pushing alpha below τ_out=0.03 outside and above τ_in=0.60 inside; a schedule η(n) keeps the term off for the first 5k steps and ramps it to 1 by 12k. The Reliability-gated Appearance Transfer renders the source view, aggregates per-Gaussian 7×7-footprint statistics, and gates color transfer with γ (rendering-contribution reliability, normalized by the P95 over supported Gaussians) and g (learned enable gate, bias −1.5 so transfer starts off), plus a global identity shift Δ_s^aid. It changes colors only, never geometry.

核心代码实现（示意，按论文 Eq.8、13、16 整理）

import torch
import torch.nn.functional as F

def soft_alpha_band(alpha, mask_gt, step,
                    t_out=0.03, t_in=0.60, lam_out=0.25, lam_in=0.05,
                    band=2, sched=(5000, 12000)):
    """
    Eq.16：只在轮廓带内监督 alpha。
    alpha: [B,1,H,W] 渲染 alpha；mask_gt: [B,1,H,W] GT 掩码 (0/1)
    """
    k = band * 2 + 1
    dil = F.max_pool2d(mask_gt, k, stride=1, padding=band)      # 膨胀
    ero = -F.max_pool2d(-mask_gt, k, stride=1, padding=band)    # 腐蚀
    b_out = (dil - mask_gt).clamp(0, 1).bool()                  # 外 2px 带
    b_in  = ero.bool()                                          # 内 2px 带

    # 不在带的像素不计入：用掩码乘 smooth-L1 的 hinge 项
    def hinge(a, tau, mask, sign):
        h = F.smooth_l1_loss(a, torch.full_like(a, tau), reduction='none')
        return (h * mask.float()).sum() / mask.float().sum().clamp_min(1)

    l_out = hinge(alpha, t_out, b_out, +1)   # 带外 alpha 应 <= t_out
    l_in  = hinge(alpha, t_in,  b_in,  -1)   # 带内 alpha 应 >= t_in

    eta = 0.0 if step < sched[0] else min(1.0, (step - sched[0]) / (sched[1] - sched[0]))
    return eta * (lam_out * l_out + lam_in * l_in)

def reliability_gamma(C, m, kappa=0.5, tau_m=0.5, p=95):
    """
    Eq.8：渲染贡献可靠度门控。
    C: [N] 每高斯渲染贡献（footprint 内 alpha 和）；m: [N] 掩码支持度 [0,1]
    """
    val = C.clamp_min(0).sqrt() * m                       # √C · m
    support = (C > kappa * C[C > 0].median()) & (m > tau_m)   # 前端+被观测
    p95 = torch.quantile(val[support], p / 100.0) if support.any() else val.max()
    gamma = (val / p95.clamp_min(1e-8)).clamp(max=1.0) * support.float()
    return gamma                                          # [N]

def appearance_transfer(c0, c_obs, gamma, g, delta_s_aid):
    """
    Eq.13：颜色合成——过渡只在被门控的可靠高斯上发生。
    c0: 规范颜色 [N,3]；c_obs: 观测聚合色；g: 启用门 [N,1] ∈ [0,1]
    """
    c = g * (gamma * c_obs + (1.0 - gamma) * c0) + (1.0 - g) * c0 + delta_s_aid
    return c.clamp(0.0, 1.0)
