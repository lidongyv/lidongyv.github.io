Mamba 入门指南

从状态空间模型 (SSM) → 选择性机制 → Selective Scan → S6 → Vision Mamba / World Model
一句话：Mamba 把序列建模看成用有限维记忆 \(h\) 压缩无限历史。 ZOH 负责连续→离散；选择性让 \(B,C,\Delta\) 随输入变化从而「记什么/忘什么」； Selective Scan 是高效算这套动力学的 GPU 算法；S6 就是带选择性的 SSM 层。 推理复杂度 \(O(1)\)/步，训练 \(O(L)\)。

符号速查（防混）

符号连续/离散含义
\(h(t)\)连续记忆状态向量
\(h'(t)\)连续状态对时间的导数（变化率），不是转置
\(h_t\)离散第 \(t\) 步结束后的状态
\(A\)连续参数记忆自然衰减/演化率（可学习，HiPPO 初始化）
\(\Delta\)离散化步长这一步跨越多长时间；Mamba 里由输入动态生成
\(\Delta A\)中间量步长 × 动力学矩阵，不是「变化的 A」
\(\bar{A}, \bar{B}\)离散参数ZOH 离散化后的转移/写入矩阵，由 \(\Delta,A,B\) 算出
\(C, D\)—读出矩阵 / skip connection

1. SSM：有记忆的滤波器

连续动力学

\[ h'(t) = A\,h(t) + B\,x(t), \qquad y(t) = C\,h(t) \]

类比水库：\(h\) 是水位，\(x\) 是降雨，\(A\) 是蒸发，\(B\) 是入流系数，\(C\) 是出水口。

离散递推（实际计算）

\[ h_t = \bar{A}_t\,h_{t-1} + \bar{B}_t\,x_t, \qquad y_t = C_t h_t + D x_t \]

LTI vs 选择性

LTI SSM (S4)Selective SSM (Mamba)
参数\(A,B,C,\Delta\) 固定\(B_t,C_t,\Delta_t\) 由 \(x_t\) 生成
训练可转 global convolution只能 recurrence scan
能力线性滤波器内容感知的读/写/遗忘

2. ZOH：Zero-Order Hold 离散化

假设：在 \([t, t+\Delta)\) 内输入保持不变，把连续 ODE 积分为一步递推。

\[ \bar{A} = \exp(\Delta A), \qquad \bar{B} = (\Delta A)^{-1}(\exp(\Delta A) - I)\cdot \Delta B \]

  • \(\bar{A}\)：旧记忆保留多少（\(\Delta\) 大 → 更忘旧状态）
  • \(\bar{B}\)：新输入写入多少
  • \(\Delta\) 大 ≈ RNN forget gate 大开；\(\Delta\) 小 ≈ 保持记忆、忽略当前输入

3. Mamba Block 工作流程

flowchart TB
  X["输入 x (B,L,D)"] --> Proj["Linear → x_branch, z_branch"]
  Proj --> Conv["Causal Conv1d（局部上下文）"]
  Conv --> Gen["从 x 投影 Δ, B, C"]
  Gen --> ZOH["ZOH 离散化 → Ā, B̄"]
  ZOH --> Scan["Selective Scan"]
  Scan --> Gate["y ⊙ silu(z)"]
  Gate --> Out["Linear 输出"]

核心动机

序列建模 = 用有限状态压缩无限上下文。Attention 不压缩（存 KV）；LTI SSM 压缩但「盲」；Mamba 压缩 + 内容感知。

4. Selective Scan 在做什么？

不是新模型，是高效计算「输入依赖 SSM 递推」的并行算法。

逐步递推：\(h_t = \bar{A}_t h_{t-1} + \bar{B}_t x_t\)。参数随时变 → 无法用固定卷积 → 必须 scan。

Parallel Scan 关键

仿射递推 \(h_t = a_t h_{t-1} + b_t\) 可结合：

\[ (a_2, b_2) \circ (a_1, b_1) = (a_2 a_1,\; a_2 b_1 + b_2) \]

→ 整条序列 \(O(L)\) 并行。工程上还做 kernel fusion（SRAM 内离散化+scan）和 recomputation（反向重算省显存）。

5. S6 是什么？

S6 = SSM + Selection（Mamba 论文 Algorithm 2）。相对 S4（LTI 结构化 SSM），S6 让 \(B,C,\Delta\) 输入依赖。

名称特点
S4LTI，可卷积，训练快但选择性差
S5多输入并行化变体
S6Selective SSM，Mamba 核心层

VMamba 的 SS2D 说「4 路 S6」= 4 个扫描方向各跑一遍 selective SSM。

8. 从 Mamba 设计能学到什么

  • 先定义约束：有限状态压缩无限历史 → 自然推出选择性 + scan
  • 内容感知 ≠ Attention：动态 \(B,C,\Delta\) 即可选择性读写
  • 算法×硬件协同：parallel scan + kernel fusion 决定能否落地
  • 知道边界：擅长长序列因果；弱于精确 copy/检索 → 常 hybrid attention
  • \(\Delta\) 是统一旋钮：同时控制时间尺度、记忆衰减、类似 RNN gate

9. 交互：\(\Delta\) 如何影响记忆保留

固定 \(A=-1\)，调节步长 \(\Delta\)，观察 \(\bar{A}=\exp(\Delta A)\) 下旧记忆衰减曲线（10 步递推，每步输入相同）。

纵轴：归一化记忆强度 · 横轴：时间步。\(\Delta\) 越大，旧记忆衰减越快（更「健忘」、更聚焦当前）。
