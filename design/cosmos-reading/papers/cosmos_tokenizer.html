一句话：Tokenizer = 把视频压成紧凑 token/latent 再由解码器重建的自编码器；连续版（AE）出 16 维连续向量喂扩散，离散版（FSQ）出整数 token 喂自回归。骨架 = Haar 无损小波前处理 + factorized 因果编码器 + 量化/AE + 镜像解码器。

2 · §4.1 架构（原文 + 源码）

原文："we employ causal temporal convolution layers and causal temporal attention layers to preserve the natural temporal order ... using a single unified network architecture. The encoder employs a wavelet transform ... a total spatiotemporal compression ratio ranging from 256 to 2048 ... For the continuous tokenizer, we use a vanilla autoencoder (AE) ... For the discrete tokenizer, we use the Finite-Scalar-Quantization (FSQ)."

指路：编码器 = 因子化（空间/时间分离）因果卷积 + 注意力；前端 Haar 小波；图像视频统一网络；总压缩 256–2048×。连续=AE、离散=FSQ。

# EncoderFactorized 关键结构 (layers3d.py:731)
conv_in = Sequential(
  CausalConv3d(in, 128, kernel=(1,3,3)),  # 只做空间
  CausalConv3d(128,128, kernel=(3,1,1)),  # 只做时间(因果) → "factorized"
)
# 下采样次数：空间/时间独立
num_spatial_downs  = log2(spatial_compression)  - log2(patch_size)  # DV:4-2=2
num_temporal_downs = log2(temporal_compression) - log2(patch_size)  # DV:3-2=1

因果 padding（原文+源码）："causal padding in temporal convolutions such that each token is a function of the current and past inputs but not the future ones" —— 时间维只 pad 过去，不看未来，对齐自驾/机器人的因果性。

4 · 量化：连续 AE vs 离散 FSQ（源码）

连续（AE）：z 直接是 16 维连续向量，不量化、全程可导，喂扩散。
离散（FSQ） quantizers.py:143 四步（output 每步标注）：

# FSQ.quantize / codes_to_indices（真实源码，levels=[8,8,8,5,5,5]）
def bound(z):                          # ① tanh 限幅到格点范围
    half=(levels-1)*(1+eps)/2
    return (z+shift).tanh()*half - offset   # output: 连续、有界
def quantize(z):
    q = round_ste(bound(z))            # ② STE 四舍五入到整数格点
    return q / (levels//2)             # ③ 归一化到[-1,1]; output: zhat
def codes_to_indices(zhat):            # ④ 混合进制 → 唯一整数
    return (scale_shift(zhat) * _basis).sum(-1)  # _basis=cumprod([1]+levels[:-1])
    # output: index ∈ {0 .. 8*8*8*5*5*5-1 = 63999}

码本大小 = 8·8·8·5·5·5 = 64000；embedding_dim = 6 = len(levels)。为何 FSQ 不用 VQ：FSQ 无可学码本、无 commitment/EMA、天然满码 → 不坍塌。

VQ（对比，源码 quantizers.py:307）——印证"是 argmin 最近邻不是分类器"：

# VectorQuantizer.forward
d = ||z||² + ||e||² - 2·z·eᵀ           # 到每个码字的距离
idx = torch.argmin(d, dim=1)           # ← argmin 最近邻(无 softmax/分类头)
z_q = matmul(one_hot(idx), embedding.weight)   # 查表; output: z_q
z_q = z + (z_q - z).detach()           # STE

5 · STE 真实实现 utils.py:106

def round_ste(z):
    zhat = z.round()
    return z + (zhat - z).detach()     # 前向=round, 反向=恒等(梯度直穿)
# output: 前向数值=z.round(); 反向 ∂output/∂z = 1

6 · Haar 小波怎么实现（源码 + 手算）

本质：相邻两个数 → 求和(低频) + 求差(高频)，stride=2 每次跳 2 格 → 长度减半。

一维手算 [4,6,2,8]：低通(和) [10,10]（4+6, 2+8）；高通(差) [-2,-6]（4−6, 2−8）→ output 低[10,10] + 高[-2,-6]，4 数→4 数，不丢信息只是分粗/细。

二维：先横(W)后竖(H) 各做一次 → 2×2 块出 4 子带 LL/LH/HL/HH（1 缩略图 + 3 方向细节）；三维视频：T/H/W 各一次 → 8 子带。

# patching.py 真实滤波器与卷积
haar = [0.707, 0.707]                  # 1/√2
hl = haar                              # 低通=求和
hh = haar * (-1)**[0,1] = [0.707,-0.707]  # 高通=求差
xl = conv2d(x, hl, stride=(1,2))       # 沿 W 求和, W÷2
xh = conv2d(x, hh, stride=(1,2))       # 沿 W 求差, W÷2
xll,xlh = conv2d(xl, hl/hh, stride=(2,1))  # 再沿 H, H÷2
xhl,xhh = conv2d(xh, hl/hh, stride=(2,1))
out = cat([xll,xlh,xhl,xhh], dim=1)    # output: 4 子带塞通道; RGB[3,H,W]→[12,H/2,W/2]

可逆无损：知道 和=a+b、差=a−b 就能解出 a=(和+差)/2, b=(和−差)/2；源码 UnPatcher3D._idwt 用 conv_transpose3d 精确逆回去。与 bilinear 区别：bilinear 丢高频、不可逆；Haar 把高频塞进通道全保留、可逆。该层 requires_grad=False（无参）。

7 · Gram 为何表征纹理 + "感知损失 vs 蒸馏"

Gram \(G_{ij}=\sum_p F_{ip}F_{jp}\)：对空间位置求和，丢掉"在哪"、只留"什么特征共现" → 纹理/风格统计。两图 Gram 接近=纹理接近（与物体位置无关）。

感知损失 vs 蒸馏（诚实澄清）：特征蒸馏确实存在（不止蒸 logits）。二者形式相通（都在冻结网络特征空间算 L1）；区别在意图：蒸馏=两个不同网络对同一输入对齐特征（迁移能力）；感知损失（本文）=同一冻结 VGG 对"原图 vs 重建图"两个不同输入算距离、优化的是重建图。机制上感知损失就是一种以 VGG 为参照的特征级监督。
