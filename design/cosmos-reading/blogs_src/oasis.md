# Oasis: A Universe in a Transformer (Decart & Etched)

Source: https://oasis-model.github.io/  (also Decart blog / Etched blog)
Date: October 31, 2024
Authors: Decart and Julian Quevedo, Quinn McIntyre, Spruce Campbell, Xinlei Chen, Robert Wachen

Oasis is the first experiential, realtime, open-world AI model — an interactive video experience entirely generated by AI. It takes in user KEYBOARD INPUT and generates a real-time experience, including physics, rules, and graphics (move around, jump, pick up items, break blocks). There is NO physics engine; just a foundation model. Released: code, weights of a 500M-parameter model runnable locally, and a live demo of a larger checkpoint.

## Architecture
The model is composed of two parts:
1. A SPATIAL AUTOENCODER — Transformer-based, based on ViT (An Image is Worth 16x16 Words).
2. A LATENT DIFFUSION BACKBONE — Transformer-based, based on DiT (Scalable Diffusion Models with Transformers).

Contrasting with recent action-conditioned world models such as GameNGen and DIAMOND (which use U-Net-style diffusion), Oasis chose Transformers to ensure stable, predictable scaling and fast inference on Etched's Transformer ASIC (Sohu).

In contrast to bidirectional models such as Sora, Oasis generates frames AUTOREGRESSIVELY, conditioning EACH FRAME on user input — enabling real-time interaction. Trained using DIFFUSION FORCING, which denoises with independent per-token noise levels, allowing novel decoding schemes.

## Temporal stability
A focus was temporal stability over long horizons. In autoregressive models, errors compound; small imperfections snowball into glitched frames. Solved with DYNAMIC NOISING: adjust inference-time noise on a schedule — inject noise in the first diffusion forward passes to reduce error accumulation, then gradually remove noise in later passes so the model can find and persist high-frequency details from previous frames for improved consistency. Because the model saw noise during training, it learned to deal with noisy samples at inference.

## Performance
Oasis generates real-time output at 20 fps. Current SOTA text-to-video models with a similar DiT architecture (Sora, Mochi-1, Runway) can take 10-20 seconds to create just one second of video even on multiple GPUs; to be interactive Oasis must generate a new frame every 0.04 seconds (>100x faster). With Decart's inference stack the model runs at live framerates. Oasis is optimized for Sohu (Etched's Transformer ASIC), which can scale to 100B+ next-gen models at 4K; the end-to-end Transformer architecture makes it efficient on Sohu (serve >10x more users even on 100B+ models).

## Results & limitations
Understands building, lighting physics, inventory management, object understanding. Limitations: fuzzy video in the distance, temporal consistency of uncertain objects, domain generalization, precise inventory/object control, difficulty over long contexts. Hypothesis: many issues addressable through scaling of model + datasets (plus inference innovations for sustainable latency/cost).
