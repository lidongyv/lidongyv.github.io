ChordEdit: One-Step Low-Energy Transport for Image Editing

Liangsi Lu ⋅ Xuhang Chen ⋅ Minzhe Guo ⋅ Shichu Li ⋅ Jingchao Wang ⋅ Yang Shi
arXiv PDF ⬇arXiv 摘要Scholar
一句话：把一步图像编辑建模为动态最优传输，用时间加权的 Chord Control Field 平滑高能轨迹，training-free/inversion-free 实时高保真编辑。

摘要 Abstract

The advent of one-step text-to-image (T2I) models offers unprecedented synthesis speed. However, their application to text-guided image editing remains severely hampered, as forcing existing training-free editors into a single inference step fails. This failure manifests as severe object distortion and a critical loss of consistency in non-edited regions, resulting from the high-energy, erratic trajectories produced by naive vector arithmetic on the models' structured fields. To address this problem, we introduce ChordEdit, a model agnostic, training-free, and inversion-free method that facilitates high-fidelity one-step editing. We recast editing as a transport problem between the source and target distributions defined by the source and target text prompts. Leveraging dynamic optimal transport theory, we derive a principled, low-energy control strategy. This strategy yields a smoothed, variance-reduced editing field that is inherently stable, facilitating the field to be traversed in a single, large integration step. A theoretically grounded and experimentally validated approach allows ChordEdit to deliver fast, lightweight and precise edits, finally achieving true real-time editing on these challenging models.

📝 精读笔记

灵魂一句
把"用一步 T2I 模型做文本图像编辑"重述成一个动态最优传输（OT）问题，推导出 Chord Control Field（弦控制场）——对朴素编辑残差场 R 在相邻两时刻做时间加权平均（Eq 4.5：û_t = [ t·R(x_τ, t−δ) + δ·R(x_τ, t) ] / (t+δ)）。这个时间平滑把高能、抖动的编辑场压成低能、稳定的场，于是一步大积分就能把源图传输到目标——training-free / inversion-free / model-agnostic 的真·实时编辑（SD-Turbo 上 0.38s）。
问题 & 动机
一步 T2I 模型（SD-Turbo / SwiftBrush-v2 / InstaFlow）合成极快，但把现有 training-free 差分编辑器（InfEdit / FlowEdit）强压到单步会崩：① 编辑对象严重扭曲；② 非编辑区（背景）一致性崩坏。根因（§1）：蒸馏出的一步模型把"文本条件→向量场"做成了高度非线性、敏感的映射；朴素编辑场 Δv = v(c_tar)−v(c_src) 是两条大幅值、发散轨迹的算术差 → 高能（high-energy）、erratic；用它走一步大积分会累积巨大误差。多步法靠"逐步平均"抹平这种高能场，单步则没有平均的机会。
核心方法（关键机制 + 公式）
① OT 视角（§4.1）：理想编辑场 u_t 是解 Benamou–Brenier 动态 OT（Eq 4.1：min ∫∫ ½‖u_t‖²ρ_t dx dt，受连续性方程约束）的最小动能全量传输场（原文强调它不是叠在参考场上的残差）。
② 可观测代理（§3.2）：u_t 拿不到，只能经 R(x_τ,t)=E_z[B_t·ΔQ(z,t)] 观测，ΔQ=Q(c_tar)−Q(c_src)；测量模型 R = u_t + ε（无偏噪声）。
③ Chord 估计（§4.2）：在短窗 [t−δ, t] 上最小化凸二次目标 Φ_t(u)=t‖u−û(t−δ)‖² + ∫‖u−R(ξ)‖²dξ（能量先验 + 测量一致），∇=0 取闭式解，再用一阶因果近似 → Chord Control Field（Eq 4.5）：û_t = [ t·R(x_τ, t−δ) + δ·R(x_τ, t) ] / (t+δ)，本质是对 R 的因果单边核平滑 û = K_δ * R。
④ 一步传输 + 可选 prox（§4.3-4.4）：x^pred = x_src + λ·û（一步大积分）；可选 proximal refinement 用 c_tar 单次前向 prox(x^pred, t_c, c_tar) 放大目标语义（不算进 transport，能量指标都在它之前算）。⑤ model-agnostic：B_t 是只依赖时间的线性映射，把任意参数化（ε / v / x_0 / score / consistency）的模型输出投到统一速度域 U（附录 C 给闭式系数，如 SD-Turbo 的 A_t^(ε) = −α̇/(α·σ)）。
关键结果（PIE-bench · 单张 Titan 24GB）
默认 ChordEdit(SD-Turbo, NFE=2)：0.38s / 6988 MiB，PSNR 22.20、CLIP-Edited 22.96。仅传输版 ChordEdit(w/o prox, NFE=1)：0.20s，PSNR 23.89（全表第二）。同骨干对比需训练的 SwiftEdit：ChordEdit PSNR 22.04>21.71、VRAM 6988 vs 15060（不到一半）、且 training-free。提速：比 FlowEdit 19×、比 Direct Inversion 208×、比最快 few-step 至少 3.4×。消融：去平滑(δ=0) PSNR 23.89→21.89；n=1 即够（20 seed CoV：CLIP 0.20% / PSNR 0.07%）。用户偏好：语义 42.5% / 背景 48.3%。
亮点（为何获 Best Student 提名 · 推断）
原文未写获奖理由，下为推断：① 理论优雅——把一个工程失败（单步编辑崩）重述成动态 OT 估计问题，推出闭式估计子，并给出可证的能量收缩保证（Jensen → L²/L∞ 收缩 → 收紧一致性代理 C(u) → 收紧单步全局误差界）；② 极简——核心是"两时刻时间加权平均"一行公式 / 1-NFE；③ 实用——training-free + inversion-free + model-agnostic，真·实时 0.38s，还在同骨干上打败需要训练的 SwiftEdit；④ 轻量稳健——单噪声 n=1、对随机种子近乎不敏感。"简单 + 可证 + 实用 + 快"四合一。
疑问 / 待深挖
① "Chord（弦）"命名原文未显式定义，推断取几何意象：不沿高能弯曲轨迹（弧）走，而取一条低能"弦"一步切到目标。② Intro 措辞"time-weighted average of the source and target drifts"，但 Eq 4.5 精确是对残差场 R（已是 target−source 之差）在 t 与 t−δ 两时刻的加权平均——措辞略松，以公式为准。③ t / δ / λ / t_c 的完整超参扫描在附录（正文未给数值表）。④ CLIP-Whole/Edited 全场最佳仍属多步 FlowEdit（26.64/23.69）——ChordEdit 走的是"质量×效率"帕累托最优而非单指标霸榜。

📖 逐段精读 · 笔记

批量精读初稿：① Abstract ② §1 Intro 闭环 ③ Method 逐条（含关键公式）④ 实验/消融全表 + 全文一页总结。最后更新 2026-06-19。
① Abstract（摘要）— 逐句精讲
原文（verbatim）：“their application to text-guided image editing remains severely hampered, as forcing existing training-free editors into a single inference step fails. This failure manifests as severe object distortion and a critical loss of consistency in non-edited regions, resulting from the high-energy, erratic trajectories produced by naive vector arithmetic on the models’ structured fields.”
在说什么：one-step T2I 模型（SD-Turbo 等）合成极快，但把现有"无训练编辑器"硬塞进单步会崩——表现为①被编辑物体严重扭曲、②非编辑区（背景）破碎。根因：现有方法用"两个 drift 相减"（naive vector arithmetic）得到编辑场，在单步大步长积分下是高能、不稳的轨迹。
原文（方法句）：“We recast editing as a transport problem between the source and target distributions … Leveraging dynamic optimal transport theory, we derive a principled, low-energy control strategy. This strategy yields a smoothed, variance-reduced editing field that is inherently stable, facilitating the field to be traversed in a single, large integration step.”
逐词指路：① “transport problem”——把编辑看成"把源分布搬到目标分布"的最优传输问题（不是向量算术）。② “low-energy control”——找一条"低能量"的传输路径（弦 chord）。③ “single, large integration step”——正因场稳，才能一步走完。④ 三个定语 “model agnostic, training-free, inversion-free”——不挑模型、不训练、不需 inversion，这是它相对 SwiftEdit 的核心卖点。
一句话抓 Abstract：把"drift 相减"换成"基于动态最优传输的低能量 Chord Control Field"（源/目标 drift 的时间加权平均），使编辑场平滑稳定，从而能一步大步长积分完成高保真实时编辑。
② 📚 背景知识（外部 — 读懂 ChordEdit 必备）
① one-step T2I 蒸馏模型：SD-Turbo / SwiftBrush-v2 / InstaFlow 把大扩散模型蒸馏成"单步从噪声直达图像"的紧凑模型，速度极快。代价：原文 “this distillation process yields a highly non-linear and sensitive mapping from the text condition to the vector field”——文本→向量场的映射变得高度非线性敏感，这是 naive 编辑场不稳的祸根。
② Probability Flow（概率流 ODE）：预训练 T2I 诱导一个条件概率流，状态随时间 \(t\in[0,1]\) 按 drift \(v(x_t,t,c)\) 演化：\( \frac{dx_t}{dt}=v(x_t,t,c) \)。\(p_1\) 是数据分布、\(p_0\) 是先验。编辑 = 把源图 \(x_{src}\sim p_1(\cdot\mid c_{src})\) 传输到目标 \(x_{tar}\sim p_0(\cdot\mid c_{tar})\)。
③ 动态最优传输（Benamou–Brenier）：把"把一个分布搬成另一个分布"建成"最小化动能"的流体力学问题——在满足连续性方程（质量守恒）约束下，找让总动能最小的速度场。"低能量"≈"路径最直、最省力"，这是 ChordEdit 全部理论的出发点。
④ NFE（Number of Function Evaluations）：调用一次网络前向算一次 NFE，是公平比"快慢"的硬指标。ChordEdit transport 是 1-NFE（所有中间量一个 batch 并行算），加可选 prox 共 NFE=2。
③ §1 Introduction — problem → 现有不足 → solution → why（闭环）
problem：one-step 模型许诺实时编辑，但 “this promise … remains unmet”。training-free + inversion-free 的主流做法是 “computes an editing field by differencing the drifts conditioned on source and target prompts”——多步生成器里好用，单步里崩（object distortion + background disintegrate，Fig 3）。
现有不足（两条路都不行）：① SwiftEdit 走"训专用 inversion 网络"路线 → 快，但 “sacrificing model-agnostic flexibility and relying on precise inversion”（挑模型 + 要 inversion）。② FlowEdit / InfEdit 走 training-free 差分路线 → “stable when averaged over multiple steps but collapse in the single-step limit due to high energy and variance”（多步平均才稳、单步因高能高方差崩）。ChordEdit 正卡在"training-free + inversion-free + single-step"这个最难的三角。
solution：原文 “recast the editing problem from the principled perspective of dynamic optimal transport (OT), seeking a low-energy chord to transport the source image distribution to the target. Our key contribution is the Chord Control Field, a theoretically-grounded, time-weighted average of the source and target drifts that replaces the instantaneous, erratic drift difference.”
why it works：原文 “This formulation acts as a potent temporal smoothing operator, yielding an inherently stable, low-energy field that can be traversed in a single, large integration step.”——时间平滑 → 压掉高能尖峰 → 场稳 → 单步大步长不积累误差。框架以"黑盒"查询模型 velocity/等价场来算控制场，保证 model-agnostic。
Q&A · 为什么 naive drift difference 在"单步"会崩，多步却没事？
根因（§1 + Fig 4）：naive 编辑场 \(\Delta v=v(\cdot,c_{tar})-v(\cdot,c_{src})\) 是"两条大幅值、发散轨迹之差"——本身高能、erratic。多步时每步只走一小段、且迭代等效于对场做了隐式时间平均，误差被摊薄（Fig 4a 稳）；单步时要用这个 volatile 场做一次大步长积分，原文 “tends to accumulate significant error, causing the observed distortions”（Fig 4b：实线大步长偏离、虚线真实路径乱窜）。所以问题不在"差分"本身，而在"单步大步长 + 高能场"的组合——ChordEdit 的解法是把场先平滑成低能（Fig 4c）。
④ §3 Preliminaries — 可观测代理场 R（式3.1–3.5）
编辑残差（式3.2）：理想连续时间控制 \( \Delta v(x_t,t)=v(x_t,t,c_{tar})-v(x_t,t,c_{src}) \)，对齐两个条件动力学。
可观测性问题（§3.2）：实践中拿不到任意 \(t\) 的 \(x_t\)，于是把编辑锚点固定在干净源态 \(x_\tau:=x_1\)，对一个模拟该时刻噪声水平的前向核 \(K_t(\cdot\mid x_\tau)\) 采 \(z\) 来查模型。定义可观测代理场（式3.3）：
\[ R(x_\tau,t)=\mathbb{E}_{z\sim K_t(\cdot\mid x_\tau)}\big[B_t\,\Delta Q(z,t)\big] \]
其中 \(\Delta Q=Q(z,t,c_{tar})-Q(z,t,c_{src})\)，\(B_t\) 是"只依赖时间"的线性映射，把模型输出投到统一的 drift/velocity 比较空间 \(U\)。参数化（式3.4–3.5）：噪声预测模型（SD-Turbo）\(Q=\hat\epsilon_\theta,\ B_t=A^{(\epsilon)}_t\)（由 schedule \(\alpha_t,\sigma_t\) 决定）；速度模型（InstaFlow）\(Q=v_\theta,\ B_t\equiv I\)。意义：这套抽象让 ChordEdit 对 score/x0-head/consistency 等各种参数化都适用（只需一个 time-only 线性 \(B_t\)）= model-agnostic 的技术根。
⑤ §4.1 OT View — 把编辑变成"估计真实低能场"（式4.1–4.2）
理想场 = Benamou–Brenier 动态 OT 解（式4.1）：
\[ \min_{\rho,u}\int_0^1\!\!\int \tfrac{1}{2}\|u_t(x)\|^2\,\rho_t(x)\,dx\,dt \quad \text{s.t.}\ \ \partial_t\rho_t(x)+\nabla_x\!\cdot\!\big(\rho_t(x)u_t(x)\big)=0 \]
传输密度 \(\rho_t\) 从源边界 \(\rho_1=p_1(\cdot\mid c_{src})\) 演化到目标 \(\rho_0=p_0(\cdot\mid c_{tar})\)，约束是连续性方程（质量守恒），目标是最小化动能 → 理想 \(u_t\) 就是那条"最省力"的低能场。
测量模型（式4.2）：理想 \(u_t\) 不可知，只能通过 \(R\) 观测，且 \(R\) 是真实场被零均值噪声污染：\( R(x_\tau,t)=u_t(x_\tau)+\varepsilon_t,\ \mathbb{E}[\varepsilon_t]=0 \)。关键转化：naive 做法直接拿 \(u_{nai}=R\) 当控制场，但这个"含噪测量"高能 → 单步不稳。于是问题被重述成：如何从含噪的 \(R\) 里估计出低能的真实场 \(\hat u_t\)——这正是一个估计/去噪问题。
⑥ §4.2 Chord Control Field（核心，式4.3–4.5 推导）
构造：在短窗 \([t-\delta,t]\) 内求一个局部常值估计 \(u\)，最小化严格凸二次代理（式4.3）：
\[ \Phi_t(u;x_\tau)=t\,\|u-\hat u_{t-\delta}(x_\tau)\|^2+\int_{t-\delta}^{t}\|u-R(x_\tau,\xi)\|^2\,d\xi \]
第一项是递归能量先验（贴近上一步估计 \(\hat u_{t-\delta}\)，权重 \(t\)），第二项是与新测量一致（贴近窗内 \(R\)）。令 \(\nabla_u\Phi_t=0\) 得唯一最小值（式4.4）：\( u^\star_t=\frac{t}{t+\delta}\hat u_{t-\delta}+\frac{1}{t+\delta}\int_{t-\delta}^{t}R(x_\tau,\xi)\,d\xi \)。
一阶因果近似（\(\hat u_{t-\delta}\approx R(x_\tau,t-\delta)\)，\(\int_{t-\delta}^t R\,d\xi\approx\delta R(x_\tau,t)\)）后得到可落地的 Chord Control Field（式4.5）：
\[ \hat u_t(x_\tau)=\frac{t\,R(x_\tau,t-\delta)+\delta\,R(x_\tau,t)}{t+\delta} \]
即"两个时刻 drift 的时间加权平均"。\(\delta=0\) 退化成 naive \(R\)。默认 \(t=0.90,\ \delta=0.15,\ \lambda=1.00,\ t_c=0.30\)。
Q&A · 这个加权为什么是 \(t:\delta\)？它凭什么压住高能？
权重来历：不是拍脑袋——它是式4.3 凸代理的解析最小值。能量先验项权重为 \(t\)（时间越往后、历史越可信，越该贴近递归估计 \(\hat u_{t-\delta}\)），测量积分项贡献 \(\delta\) 量级，归一化后就是 \(\frac{t}{t+\delta}:\frac{\delta}{t+\delta}\)。为什么压能量：式4.5 等价于对 naive 场 \(R\) 做因果单边核平滑 \(\hat u=K_\delta*R\)（\(K_\delta\ge0,\ \int K_\delta=1,\ \mathrm{supp}\,K_\delta\subset[0,\delta]\)）。由 Jensen 不等式，卷积是 \(L_2\) 收缩：\( \int\|\hat u\|^2\le\int\|R\|^2 \)——直接削掉高能尖峰。本质：用"加权平均"做时间维度的低通滤波。
⑦ §4.2 稳定性证明（为什么单步能成）
三个范数同时被收缩：因为微分与时间卷积可交换，场本身、其时间导、其空间梯度的 \(L_\infty\) 范数都被压：\( \|\hat u\|_\infty\le\|R\|_\infty,\ \|\partial_t\hat u\|_\infty\le\|\partial_t R\|_\infty,\ \|\nabla_x\hat u\|_\infty\le\|\nabla_x R\|_\infty \)。
收紧显式 Euler 一致性代理（式4.6）：\( C(u):=\|\partial_t u\|_\infty+\|\nabla_x u\|_\infty\,\|u\|_\infty \)。代入得 \( C_{cho}\le C_{nai} \)——Chord 场的一致性常数不大于 naive。原文：“This reduces the local truncation error \(M_f\) … and thus tightens the global \(O(h)\) error bound for our \(h=1\) step”（Appendix Thm C.6）；且步长稳定裕度（由 \(\|\nabla_x u\|_\infty\) 控制）被保持或改善（Prop D.7）。这就是"单步大步长还不崩"的数学保证：把场的能量/变化率压低 → 一步积分的截断误差上界随之被压低。Fig 9 实证：naive 场能量随 \(S\to1\) 暴涨、PSNR 崩；ChordEdit 能量恒低、PSNR 稳。
Q&A · 反复说的 "energy（能量）" 到底指什么？为什么 low-energy = 好？
定义：沿用 Benamou–Brenier 动能——编辑场 \(\hat u\) 在所有像素/通道上的平方和。论文 Fig 8 的 energy 图按 \( E=\frac{1}{SC}\sum_{s=1}^{S}\sum_{\text{channel}}(\hat u_{ts})^2 \) 计算；Fig 9 / §6.1 用未加权离散动能 \( \bar E=\frac{1}{SCHW}\sum_{s=1}^{S}\sum_{\text{dims}}(\hat u_{ts})^2 \)（dims 遍历通道 C、高 H、宽 W，S 是总步数）。为什么 low-energy = 好：能量高 = 场幅值大、空间/时间变化剧烈（erratic），而一阶显式 Euler 单步的截断误差正比于场的变化率（见式4.6 的 \(C(u)\)），高能场一步大步长积分会把误差放大成可见的物体扭曲与背景破碎；低能场幅值受控、平缓，一步走完仍贴近真实传输路径。Fig 8 把 naive 的高能场（亮）与 ChordEdit 的低能场（暗）并排可视化，高能区正好对应失真发生的位置。所以"低能量"不是审美口号，而是与数值稳定性（截断误差上界）严格挂钩的物理量。
Q&A · 为什么叫 "Chord（弦）"？命名的几何直觉
几何直觉：chord（弦）是连接曲线上两点的直线段。在传输几何里，理想 OT 路径是一条可能弯曲的低能轨迹；naive 差分场相当于只看"某一瞬时的切线方向"就猛冲一大步，极易冲出轨道（Fig 4b 虚线乱窜、实线大步偏离）。ChordEdit 的时间加权平均 \(\hat u_t=\frac{tR(x_\tau,t-\delta)+\delta R(x_\tau,t)}{t+\delta}\) 相当于用一条连接窗口两端 \(R(t-\delta)\) 与 \(R(t)\) 的"弦"来近似这段路径——弦比乱窜的切线更短、更直、更低能，于是"沿弦一步走"既快又稳（Fig 4c 红色直箭头）。这正呼应标题 "Low-Energy Transport"：用弦代替高能折线，把传输路径"拉直"。诚实标注 [推测]：正文未明文定义 "chord" 的几何来源，此为基于式4.5（两端点加权平均）与 Fig 4/5 的合理解读。
⑧ §4.3–4.4 Proximal Refinement（式4.7）+ Algorithm 1
可选精修（式4.7）：传输得 \(x_{pred}=x_{in}+\lambda\hat u\) 后，做一次只用 \(c_{tar}\) 的前向以放大目标语义：\( \mathrm{prox}(x_{pred},t_c,c_{tar})=B_{t_c}Q(x_{pred},t_c,c_{tar}) \)，实现为一次原生 “predict-x0” 调用（固定 noise）。原文强调它 “requires no re-inversion, and is not part of the transport. All energy metrics are computed before it.”——把"结构保持的传输"与"语义增强"解耦。
Algorithm 1（单噪声 n=1，VAE latent 空间）：输入源图 \(x_{src}\)、prompts、\(t,\delta,\lambda,t_c\) → ① \(\hat u\leftarrow\frac{t R(x_{in},t-\delta)+\delta R(x_{in},t)}{t+\delta}\)；② \(x_{pred}\leftarrow x_{in}+\lambda\hat u\)；③（可选）\(x_{tar}\leftarrow\mathrm{prox}(x_{pred},t_c,c_{tar})\)。所有 \(\hat u\) 中间量一个 batch 并行 → transport 严格 1-NFE。

Q&A · ChordEdit 到底"快"在哪？NFE=1 与 NFE=2 怎么取舍？
快的来源：① 1-NFE transport——\(\hat u\) 只需查两个时刻的 \(R\)（\(t,t-\delta\)），中间量一个 batch 并行算，等效一次前向；② 无 inversion——省掉多步/迭代 inversion（FlowEdit 33 步、Direct Inversion 100 NFE）；③ n=1 单噪声——靠场本身低方差省掉 MC 平均。NFE=1 vs 2：w/o prox（NFE=1, 0.20s）背景最好（PSNR 23.89）但语义偏保守；加 1 次 prox（NFE=2, 0.38s）把 CLIP-Edited 从 21.87 拉到 22.96，牺牲一点 PSNR（23.89→22.20）换语义——按需选。
⑩ §6 消融（CCF / 噪声 / 解耦 / model-agnostic）
① Chord 场 vs naive（§6.1，Fig 9）：\(\delta=0\) 退化 naive。随步数 \(S\to1\)，naive 能量暴涨、PSNR 崩；CCF（\(\delta=0.15\)）能量恒低、PSNR 稳，并在感知-语义权衡上严格 Pareto 支配 naive。
② 噪声样本数 n（§6.2，Fig 10/11）：经典需 \(n>1\) 降方差，但 CCF 内禀低方差——\(n=1\dots4\) 的 Pareto front 几乎重合；ChordEdit 的 n=1 甚至支配 naive 的 n=4；20 seed 下 CLIP CoV 0.20%、PSNR CoV 0.07%（对随机种子近乎不敏感）。结论：单噪声即可达到传统 MC 平均的精度。
③ transport vs refinement 解耦（Table 2）：w/o prox 23.89 PSNR / 21.87 CLIP；w/ prox 22.20 / 22.96——Chord 场负责一致性（PSNR），prox 负责语义（CLIP），职责分离清晰。
④ model-agnostic（Table 3）：InstaFlow（22.05→23.05 PSNR、20.19→21.39 CLIP）、SwiftBrush-v2（20.52→22.04、21.06→22.58）、SD-Turbo（21.38→22.20、21.96→22.96）——三种参数化的模型上 Ours 全面 > Naive，验证"只需 time-only 线性 \(B_t\)"的通用性。
📌 全文一页总结（问题 → 方法 → 实验 → takeaway）
问题（§1）：one-step T2I 想做实时文本编辑，但 training-free + inversion-free 的 naive drift 差分在单步大步长下高能不稳 → 物体扭曲 + 背景破碎；而要稳的方法要么靠多步平均、要么靠训练 inversion 网络（挑模型）。
方法（§3–4）：把编辑重述为动态最优传输（Benamou–Brenier）下"估计低能真实场"的问题：可观测代理场 \(R=u_t+\varepsilon_t\) 含噪高能 → 用凸二次代理（式4.3）解出 Chord Control Field \(\hat u_t=\frac{tR(t-\delta)+\delta R(t)}{t+\delta}\)（源/目标 drift 时间加权平均 = 因果核平滑）。理论上 \(L_2/L_\infty\) 收缩 → 一致性代理 \(C_{cho}\le C_{nai}\) → 收紧单步 Euler 误差界（h=1 仍稳）。可选 prox 解耦语义增强；transport 1-NFE、n=1。
实验（§5–6）：PIE-bench 上 w/o prox（NFE=1）PSNR 23.89 验证场稳定性；默认版 0.38s/6988MiB（VRAM 不到 SwiftEdit 一半），19× 快于 FlowEdit、208× 快于 Direct Inversion；消融证 δ 平滑、n=1 足够、transport/prox 职责分离、跨 3 模型 model-agnostic。
Takeaway（≥3 条 + 适用边界）：
① 换视角即解题：把"向量算术差分"重述成"最优传输下的低能场估计"，让一个工程难题（单步编辑崩）获得有理论保证的解——视角(OT)比技巧更根本。
② 时间平滑 = 稳定性来源：Chord 场本质是对编辑场做因果低通滤波，\(L_2/L_\infty\) 收缩直接收紧单步积分误差界，这是"敢用一步大步长"的底气。
③ 低方差 → 省算力：平滑构造内禀低方差，使 n=1 单噪声就达到传统 MC 多采样精度（seed CoV <0.2%），实现真·实时（0.38s）。
适用边界 / 诚实：(a) 绝对指标上 InfEdit 的 PSNR(24.14) 仍略高于默认 ChordEdit(22.20)——ChordEdit 的卖点是"同等质量下极致效率 + model-agnostic"，不是单项指标全部第一；(b) 多数稳定性定理（Thm C.6 / Prop D.7）、\(A^{(\epsilon)}_t\) 闭式系数、超参 \(t/\delta/\lambda/t_c\) 完整分析都在 Appendix [需查附录]；(c) 一阶因果近似（\(\hat u_{t-\delta}\approx R(t-\delta)\) 等）在剧烈非线性场下的近似误差未在正文量化 [推测：靠 δ 小来保证]；(d) 默认版加 prox 后 PSNR 反降，说明"语义增强"与"背景保持"存在固有权衡。
