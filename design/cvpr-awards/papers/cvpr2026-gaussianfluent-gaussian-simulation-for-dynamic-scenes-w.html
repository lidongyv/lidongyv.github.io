CVPR 2026   Finalist

GaussianFluent: Gaussian Simulation for Dynamic Scenes with Mixed Materials

Bei Huang ⋅ Yixin Chen ⋅ Ruijie Lu ⋅ Gang Zeng ⋅ Hongbin Zha ⋅ Yuru Pei ⋅ Siyuan Huang
arXiv PDF ⬇arXiv 摘要Scholar

摘要 Abstract

3D Gaussian Splatting (3DGS) has emerged as a prominent 3D representation for high-fidelity and real-time rendering. Prior work has coupled physics simulation with Gaussians, but predominantly targets soft, deformable materials, leaving brittle fracture largely unresolved. This stems from two key obstacles: the lack of volumetric interiors with coherent textures in GS representation, and the absence of fracture-aware simulation methods for Gaussians. To address these challenges, we introduce GaussianFluent, a unified framework for realistic simulation and rendering of dynamic object states. First, it synthesizes photorealistic interiors by densifying internal Gaussians guided by generative models. Second, it integrates an optimized Continuum Damage Material Point Method (CD-MPM) to enable brittle fracture simulation at remarkably high speed. Our approach handles complex scenarios including mixed-material objects and multi-stage fracture propagation, achieving results infeasible with previous methods. Experiments clearly demonstrate GaussianFluent's capability for photo-realistic, real-time rendering with structurally consistent interiors, highlighting its potential for downstream application, such as VR and Robotics.

📝 精读笔记

灵魂一句
给 3D Gaussian Splatting 补内部 + 会碎裂：先用预训练生成模型（MVInpainter + SD-XL）无训练地给 GS 填充带真实纹理的内部体积，再把点云断裂法 CD-MPM 搬进 GS 并修好它的数值不连续（连续 return mapping）+ GPU 并行（4 min/帧→1 s/帧），从而第一次在 GS 框架里做出脆性断裂 + 混合材质 + 流体的物理可信仿真渲染。
问题 & 动机
3DGS 是 surface-based 表示，两大硬伤挡住动态仿真：① 没有内部——原文 “Gaussian Splatting inherently lacks representation of internal structures”，应力/惯性/接触力算不出，断裂时新暴露的内表面是空心无纹理的（西瓜掉地摔开看不到红瓤黑籽）；② 没有断裂仿真——PhysGaussian/OmniPhysGS/Pixie 只做弹性形变，原始 CD-MPM 点云法 CPU-bound、缺连续 return-mapping → 物理不可信且慢。
核心方法（两件套 + 关键公式）
① 内部纹理合成（training-free）：scale 正则（式1 L=L_MSE+L_SSIM+λ·Σ‖s_i‖²）逼高斯变小→密度场 d(x)（式2）定边界→内部填新高斯→opacity-only 优化把多余高斯 opacity 压到 0 再剪枝；纹理两阶段：单视 X 切片 inpaint 起步（MVInpainter+SD-XL，式3 初始化 SH0）→ X/Y/Z 三轴低强度迭代 inpaint 求三轴一致。
② GS 版 CD-MPM + 混合材质：每个高斯当 MPM 粒子，用形变梯度 F_p（式5）演化协方差+SH；NACC 屈服面 y(p,q)=q²(1+2β)+M²(p+βp0)(p−p0)，p0=K·sinh(ξ·max(−α,0))，α 是损伤变量；关键创新=连续 return mapping，用动态中心 p′_c=p_c+φ_k·(p_tr−p_c)，φ_k=((p_tr−p_c)/(p0−p_c))^k（取 k=2）消除原法在 p=p0 处的跳变；混合材质=给不同部位赋不同 β；p0→0 退化成流体。GPU(NVIDIA Warp) 4 min/帧→1 s/帧。
关键结果
内部填充（Table 1）CLIP 22.3(PhysGaussian)/30.1(2D Inpaint)/35.4(Ours)，用户偏好 3.57%/25.00%/71.43%。动态仿真（Table 2）CLIP 12.2/13.1/22.7(Ours)，用户偏好 3.84%/7.69%/88.46%。耗时（Table A1）西瓜 3.56 s/帧(27M 粒子)、jelly 0.39 s/帧(1M)，显存 ~10GB（峰值 <16GB）。
亮点
① 第一个在 GS 里做脆性断裂；② 内部纹理合成完全 training-free（不像 FruitNinja 要 fine-tune 自采数据集，原文评其 “extremely costly and lacks generalizability”）；③ 一个 CD-MPM 框架靠调 β/p0 统一覆盖脆性固体↔粘弹凝胶↔流体↔颗粒；④ 把不连续 return mapping 修成连续、解决数值不稳定（带极限推导）。
疑问 / 边界
① 物理参数（β/E/ν 等）目前手动设（Limitations 自陈），未自动反演；② 材质划分需先靠分割/part-aware 生成/启发式，pipeline 偏重；③ 评测主要用 CLIP + user study（无 ground-truth 物理量化），偏感知层。

📚 背景知识（外部，非本文原创，理解 GaussianFluent 必备）
① 3DGS（Kerbl 2023）：用一堆各向异性 3D 高斯椭球（位置 \(x_p\)、协方差 \(A_p\)、不透明度 \(\alpha_p\)、球谐 SH 颜色 \(C_p\)）显式表示场景，splatting 光栅化实时渲染。关键缺陷：高斯只贴在物体表面、内部是空的——这正是本文要补的。② MPM（Material Point Method，物质点法）：混合 Lagrangian 粒子 + Eulerian 背景网格的仿真法，单步三阶段——P2G（粒子质量/动量插值到网格）→ Grid Update（网格算力更新速度 \(v_i^{n+1}=v_i^{n}+\Delta t\,f_i/m_i\)，eq A4）→ G2P（网格速度插回粒子、更新形变梯度 \(F_p^{n+1}=(I+\Delta t\,\nabla v_p)F_p^n\)，eq A7 + 位置）。GS 与 MPM 天然兼容，因为两者都是粒子（原文 "particle-like primitives"），PhysGaussian 首次结合二者。③ Cam-Clay / NACC 屈服面：源自土力学的弹塑性本构，屈服面 \(y(p,q)=0\) 是应力空间的分界：\(y\le 0\) 内是弹性，越界要把试探应力"拉回"面上（return mapping）；\(p\)=体积应力、\(q\)=剪切应力。NACC = Non-Associated Cam-Clay。损伤变量 \(\alpha\) 随形变累积 → 屈服面收缩 → 可承受弹性应力变小 → 塌缩即断裂。④ CD-MPM（Wolper 2019）：Continuum Damage MPM，把连续损伤力学引入 MPM 做动态断裂，原是点云 / CPU 方法；本文把它搬进 GS、修连续性、GPU 化。⑤ SH（球谐）：3DGS 用球谐系数表达视角相关颜色；零阶 \(sh^0\) 对应各向同性基色。⑥ SDS：Score Distillation Sampling，用 2D 扩散模型梯度优化 3D 资产，本文借其"逐步纠正"思想做低强度迭代 inpaint。
② §1 Introduction — problem → 现有不足 → solution → why 闭环
problem（两个 fundamental issues）：(1) 原文 "as a surface-based method, Gaussian Splatting inherently lacks representation of internal structures" → 因此固体仿真需要的应力/惯性/接触力 "remain undefined"，断裂时 "GS cannot realistically render the newly exposed surfaces"（西瓜例：绿皮下红瓤黑籽，现有 GS 重建 "hollow and textureless"）。(2) 前作只做弹性：PhysGaussian / OmniPhysGS / Pixie 即便自动估材质参数（Young's modulus、Poisson's ratio）仍 "remain confined to elastic deformation"。
现有不足（为什么旧法不行）：已有点云断裂法（CD-MPM 原版）与 GS 不兼容——原文 "they lack a continuous return-mapping scheme, resulting in physically implausible fracture dynamics, and their reliance on CPU-bound execution, with limited parallelism, imposes severe performance bottlenecks"（不连续 → 物理不可信；CPU → 慢）。内部纹理方面，FruitNinja 用自采数据 fine-tune 扩散模型 "extremely costly and lacks generalizability"。
solution（Intro 自包含）：原文 "we introduce: 1) internal texture synthesis ... leveraging publicly available generative models, requiring no additional training data, and 2) optimized CD-MPM for GS ... resolving instability issues in the previous algorithm and implementing GPU parallelism." —— ① 免额外训练的内部纹理合成；② 修不稳定 + GPU 并行的 CD-MPM。两条直接对消两个 fundamental issues。
Q&A · 为什么"在 GS 上做脆性断裂"特别难？
三层难点（被现有方案的具体失败逼出来）：① 没内部——GS 是表面表示，断裂会暴露新表面，但内部既无几何也无纹理，无法渲染；且固体力学量（应力/惯性/接触）在"空壳"上无定义。② 没断裂模型——主流 GS 仿真（PhysGaussian 系）只建弹性形变，无法表达"开裂 + 拓扑变化"。③ 能用的断裂法不兼容——CD-MPM 原版是点云 + CPU，return mapping 在 tip 处不连续会数值爆，且 CPU 串行慢到 4 min/帧无法交互。[点评] 本文的聪明在于"不发明新物理"，而是把成熟的 CD-MPM 移植 + 修 bug（连续性）+ 工程化（GPU）到 GS，并配一个 training-free 的内部纹理管线——是"系统集成 + 关键修复"型创新，落点清晰。
③ §3.1.1 内部体积初始化（公式 1/2）
① scale 正则化（式 1）：multiview 训初始 3DGS 时，给渲染损失加一项 scale 正则，逼高斯变小、别跨边界：\[ L_{total}=L_{MSE}+L_{SSIM}+\lambda\sum_{i=1}^{N}\|s_i\|_2^2 \]其中 \(s_i\) 是高斯 \(i\) 的 scale，\(\lambda\) 控强度。原文："This encourages smaller, more localized Gaussians, crucial for interior definition and plausible performance under relighting."（小而局部的高斯才能清晰分内外、relighting 也稳——这条 scale 正则后面还被复用来算法线做 Blinn-Phong 光照）。
② 密度场定边界（式 2）：把场景空间离散成 \(n^3\) 网格，每格中心算密度：\[ d(x)=\sum_{p\in P}\alpha_p\exp\!\Big(-\tfrac{1}{2}(x-x_p)^\top A_p^{-1}(x-x_p)\Big) \]（\(\alpha_p,x_p,A_p\) 为高斯 \(p\) 的不透明度/中心/协方差）。\(d(x)\ge\tau_d\) 标为高密度 = 物体边界，内部按 PhysGaussian 填新高斯。③ opacity-only 优化 + 剪枝：密度阈值填充会把高斯误填到真实边界外，故固定其它属性、只优化新高斯的 opacity，用渲染损失把"多余高斯"的 opacity 压到 ~0 再剪枝 → 干净实心体（Fig 2）。
④ §3.1.2 内部纹理生成（training-free 两阶段，公式 3）
为何 training-free：物体内部纹理训练数据稀缺（原文 "scarce training data for object interiors"），所以借现成生成模型、不另训。阶段 1（Coarse）：沿 X 轴均匀切片，每片渲初始外观 \(C_{initial}\) + 内部 mask \(M_{init}\)；mask 区用 MVInpainter（文本 prompt \(P\) + SD-XL 参考图引导）inpaint 成 \(C_{inpaint}\)；落在 inpaint 区的内部高斯 \(i\) 双线性采色 \(c_i\)，初始化零阶 SH（式 3）：\[ sh_i^0=\frac{c_i-0.5}{C_0},\quad C_0=\frac{1}{2\sqrt{\pi}} \]高阶 SH 置 0（初始各向同性）。
阶段 2（Iterative Refine）：受 SDS"逐步纠正"启发，做 successive low-strength inpainting，循环两步——(a) Generative Inpainting：沿 X/Y/Z 三轴切片，用低 inpaint strength 喂 SD-XL（约束去噪，小幅注入新细节、保全局结构）；(b) Gaussian Optimization：把 inpaint 后的 2D 图当 target，小步优化内部高斯的 SH 系数以最小化渲染差异。循环到收敛。原文对比：本策略产出 sharp/realistic 纹理，"in stark contrast to vanilla SDS, which leads to blurry and oversaturated results"。
Q&A · 为什么"三轴 + 低强度"迭代能得到 3D 一致的内部纹理？
机理：单视图初始化只在一个轴上一致，跨 3D 结构/视角会矛盾。关键在于不同轴的切片在交线处天然耦合（co-dependent through intersections）：MVInpainter 先让所有 X 切片符合参考图结构（如三层蛋糕的三层），随后 SD-XL 的低强度 inpaint 把这一约束传播到 Y/Z 切片——因为任何偏离都会与已确立的 X 切片结构矛盾。低强度是关键：每步只小幅修改，避免一次性大改破坏已有一致性（类似 SDS 的"温和纠正"），从而逐步收敛到三轴一致。[点评] 用"正交切片的交线约束 + 小步迭代"实现 3D 一致，是个聪明且 training-free 的工程技巧。
⑤ §3.2 CD-MPM：GS 属性如何随仿真演化（公式 4/5 + eq A10）
赋物理量：每个高斯被赋 mass / velocity / volume / stress，经背景 Eulerian 网格交互（同 PhysGaussian）；新增内部高斯初始化为球形协方差，半径 = 每粒子体积，保证 GS 与 MPM 离散的空间一致。连续介质演化：形变图 \(x=\varphi(X,t)\)（式 4，\(\varphi\) 是 MPM 仿真函数，\(X\)/\(x\) 是仿真前/后状态），形变梯度 \[ F_p(t)=\frac{\partial x}{\partial X}=\frac{\partial \varphi(X,t)}{\partial X} \]（式 5，编码局部旋转 + 拉伸剪切）。每步把 \(F_p\) 作用到协方差与 SH：动态协方差 \(a_p(t)=F_p(t)\,A_p\,F_p(t)^\top\)（eq A10），旋转 经极分解 \(F_p=R_pS_p\) 提出用于渲染各向异性外观；opacity 与 SH 幅值视为时不变。
Q&A · MPM 单步三阶段（P2G → Grid Update → G2P）到底在算什么？（Supp.A，公式 A2-A8）
① P2G（粒子 → 网格，rasterization）：用插值函数（shape function）\(N_{ip}\) 把每个粒子的质量、动量摊到周围网格节点：\[ m_i=\sum_p m_p N_{ip},\qquad p_i=\sum_p m_p v_p N_{ip} \]节点速度 \(v_i=p_i/m_i\)（当 \(m_i\gt 0\)）。② Grid Update（核心物理在网格上算）：节点总力 \(f_i=f_i^{internal}+f_i^{external}\)（内力来自粒子应力，外力如重力），显式时间积分更新节点速度：\[ v_i^{n+1}=v_i^{n}+\Delta t\,\frac{f_i}{m_i} \]（eq A4），并在网格上施加边界/碰撞。③ G2P（网格 → 粒子，gather）：把更新后的网格速度插回粒子 \(v_p^{n+1}=\sum_i v_i^{n+1}N_{ip}\)（eq A5），算速度梯度 \(\nabla v_p=\sum_i v_i^{n+1}\nabla N_{ip}^\top\)（eq A6），推进形变梯度 \(F_p^{n+1}=(I+\Delta t\,\nabla v_p)F_p^{n}\)（eq A7），更新位置 \(x_p^{n+1}=x_p^{n}+\Delta t\,v_p^{n+1}\)（eq A8）。为什么这样：粒子（=高斯）擅长携带物质属性与大变形/拓扑变化，网格擅长算空间微分（力、梯度）；MPM 每步在两者间来回搬数据，兼得二者之长——这正是 GS（粒子）能天然接入物理仿真的根本原因。每步算出的 \(F_p\) 再喂给下面的断裂判据。
⑥ §3.2 断裂机制：NACC 屈服面 + softening（不是硬阈值）
软化律而非硬阈值：原文 "Fracture is not triggered by a sharp threshold but emerges when this capacity becomes negligible and fails to sustain internal forces." 把 \(F_p\) 分解成 rigid + non-rigid，只有 non-rigid 部分（体积拉伸 \(p\)、剪切 \(q\)）致断。弹性（产应力）区由屈服面 \(y(p,q)\le 0\) 定义，随形变累积在 \((p,q)\) 平面收缩，可承受弹性应力消失即断。NACC 屈服面（原文式）：\[ y(p,q;p_0,\beta,M)=q^2(1+2\beta)+M^2(p+\beta p_0)(p-p_0),\quad p_0=K\sinh(\xi\max(-\alpha,0)) \]\(\beta,M,K,\xi\) 为超参，\(\alpha\) 是关键损伤变量。每步用 return mapping 强制 \(y\le 0\) 并更新 \(\alpha\)（Fig 4 可视化 jelly 内的 \(\alpha\) 热力图：\(\alpha\) 升高的区域开裂）。
⑦ §3.2 连续 Return Mapping（本文的核心修复 + 同伦证明，公式 6）
原算法的病（不连续 → 数值不稳）：试探态 \((p_{tr},q_{tr})\) 越界（\(y\gt 0\)）需投影回 \(y=0\)。内部压力区 \(-\beta p_0\lt p_{tr}\lt p_0\) 原法连到固定中心 \(p_c=\tfrac{1-\beta}{2}p_0\) 求交点，但在 \(p=p_0\)、\(p=-\beta p_0\) 处不连续：令 \(q_{tr}\to\infty\)，\(\lim R(p_0-\varepsilon,q_{tr})\) 跳到椭圆上顶点，而 \(\lim R(p_0+\varepsilon,q_{tr})=(p_0,0)\)右尖。原文："This jump triggers numerical instability: a machine-precision fluctuation δ about p0 can map an identical geometric state to completely different return points."
修法（动态中心，式 6 / eq A19）：把固定 \(p_c\) 换成自适应 \(p'_c\)：\[ p'_c=p_c+\phi_k(p_{tr})(p_{tr}-p_c),\qquad \phi_k(p_{tr})=\Big(\frac{p_{tr}-p_c}{p_0-p_c}\Big)^{k} \]连续性证明：任意有限 \(k\)，当 \(p_{tr}\to p_0^-\) 有 \(\phi_k\to 1\Rightarrow p'_c\to p_{tr}\)，故两侧极限都 \(\to(p_0,0)\)，连续；又 \(k\to\infty\) 时对任意内部 \(p_{tr}\) 有 \(\phi_k\to 0\Rightarrow p'_c\to p_c\)，退化回原不连续法——即 \(k\) 是"连续正则法（有限 \(k\)）↔ 原法（\(k\to\infty\)）"的同伦（homotopy）。实现取 \(k=2\)（robust + smooth）。投影后合成 \(p,q\) 得 \(F_p\)，更新硬化参数 \(\alpha\leftarrow\alpha+\ln(J_{tr}/J_{new})\)（\(J=\det F_p\)）。注：Supp.B.2 另给等价的"最近点投影"（normal closest-point return）版本，二者都达成连续映射 + well-defined consistent tangent。
⑧ §3.2 混合材质 + 流体退化（统一框架的关键 insight）
混合材质：不像 PhysGaussian 假设均匀材质，本文给同一物体不同部位赋不同 \(\beta\)。西瓜例（Fig 5 + Table A1 实测参数）：按 GS 颜色分——黑籽 \(\beta=5\)（高）、红瓤 \(\beta=0.6\)（低）、绿皮 \(\beta=2\)（中），比统一 \(\beta\) 产生更自然的裂纹（统一 \(\beta\) 会出 artifact）。材质划分靠分割 / part-aware 生成 / 启发式。
流体退化（一个 solver 通吃固体↔流体）：原文 "our NACC model naturally degenerates to fluid behavior when p0→0"——当 \(p_0\to 0\) 弹性区消失、材料失去抗分离能力 → 像液体自由流。实操把 \(\alpha_0\) 和 \(\beta\) 设近 0 达成 \(p_0\to 0\)。且与弹性本构无关：只要 \(p_0\) 够小，linear / Neo-Hookean 都呈同样流体行为；留个小屈服面则得 clay 黏塑性流。→ 不换 solver、同一 CD-MPM 覆盖脆性固体、黏弹凝胶、软组织、流体、颗粒（Supp Fig A2 牛奶/沙堡）。
⑨ §3.2 GPU 并行（让它能用的工程关键）
从分钟级到秒级：原 CD-MPM 是 CPU-bound，本文做完整重实现，用 NVIDIA Warp 库并行化核心仿真循环。原文（Supp.B.3）："Our implementation reduces simulation times from 4 minutes per frame to a single second."——4 min/帧 → 1 s/帧，约 240× 加速，才使复杂场景可交互。硬件：约 103 Tensor TFLOPS（FP16），显存约 10GB、峰值 \(\lt\) 16GB。

📌 全文一页总结（problem → method → experiment → takeaway）
① problem：3DGS 是表面表示、内部空且无纹理，又缺断裂仿真模型 → 做不了"脆性断裂 + 暴露真实内部"的动态场景；可用的 CD-MPM 又是点云/CPU、return mapping 不连续。
② method：(a) training-free 内部纹理合成——scale 正则（式1）+ 密度场填充（式2）+ opacity 剪枝；MVInpainter/SD-XL 三轴低强度迭代 inpaint（式3 初始化 SH）保三轴一致；(b) GS 版优化 CD-MPM——形变梯度驱动协方差/SH（eq A10）、NACC 屈服面 + softening 断裂、连续 return mapping（\(k=2\) 同伦，式6）修数值不稳、混合 \(\beta\) 做多材质、\(p_0\to 0\) 流体退化统一固体/流体、NVIDIA Warp GPU 把 4min/帧 → 1s。
③ experiment：内部填充 CLIP 35.4（vs 2D-inpaint 30.1 / PhysGaussian 22.3）、用户偏好 71.43%；动态仿真 CLIP 22.7（vs OmniPhysGS 13.1 / PhysGaussian 12.2）、用户偏好 88.46%；计时 1M 粒子 jelly 0.39 s/帧、27M watermelon 3.56 s。
④ takeaway（≥3 条 + 适用边界）：
• Takeaway 1：这是第一个在 3DGS 框架内做出脆性断裂 + 混合材质 + 流体的统一物理仿真渲染——靠"补内部纹理 + 移植并修好 CD-MPM"，而非发明新物理。
• Takeaway 2：断裂仿真的工程命门是 return mapping 的连续性——用 \(k\) 参数化的动态中心（式6）把"连续正则法"与"原不连续法"做成同伦，一举消除 tip 处的数值不稳。
• Takeaway 3：NACC 在 \(p_0\to 0\) 时自然退化为流体，使同一个 CD-MPM solver 无缝覆盖脆性固体→黏弹→软组织→流体→颗粒，是"统一仿真"的关键洞察。
• 适用边界 / 诚实点：① 物理参数全手动设（\(\beta,M,K,\xi,\alpha_0\)、各部位材质），原文将"用 inverse rendering / 学习法自动估参"列为 future work；② 材质划分依赖外部分割 / part-aware 生成，非端到端；③ 评测靠 CLIP + 用户研究，无物理 ground-truth（缺真实断裂的定量对照），消融偏定性；④ 仅在 food / fruit / 液体等可控对象上验证，复杂真实场景的可扩展性未充分检验。
