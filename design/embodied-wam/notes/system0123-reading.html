0. 结论速览（我的总结）

  1. S1/S2 没有具身领域的新定义：概念源头是 Kahneman 的双过程理论（S1 快/直觉/自动，S2 慢/审慎/分析）。具身论文里对 S1/S2 都是「沿用常规定义」。
  2. S0 与 S3 是 Taniguchi et al. (2025) 新加的：arXiv:2503.06138 提出四过程框架——S0 = 前认知的具身过程（形态计算/被动动力学，超快时间尺度、无显式计算）；S3 = 集体智能与符号涌现（超慢）。这是 S0 的唯一学术一手定义。
  3. 工程界的「双系统」只取 S1/S2：GR00T N1（S2=视觉语言模块、S1=扩散 Transformer 动作头，端到端联合训练）与 Figure Helix（S2=7–9 Hz 板载 VLM、S1=200 Hz visuomotor 策略）都不提 S0/S3。
  4. 容易混淆的三件事：①四过程框架 ≠ 工程双系统；②S0 ≠ 世界模型（S0 是身体物理计算，不是预测未来的模型）；③「双系统」在工程里还分频率/语义/梯度三种解耦，π0 的动作专家、WALL-OSS 的 Flow Head 严格说不算双系统。
  5. Physical AI 视角的文章存在但未取到正文：Taniguchi 的 IEEE SII 2026 全会报告标题明确用了四概念；中文「三层脑」类文章有，但触发验证未读到内容——本页只作提示。

2. 原文区①：Taniguchi 2503.06138（四过程框架）

来源：arXiv abs ｜ ar5iv 全文（以下为逐字摘录，非全文；论文共 60+ 页，本页收录已核实的定义性段落。每段英文下附中文译文。）

Abstract（逐字）

"This paper introduces the System 0/1/2/3 framework as an extension of dual-process theory, employing a quad-process model of cognition. Expanding upon System 1 (fast, intuitive thinking) and System 2 (slow, deliberative thinking), we incorporate System 0, which represents pre-cognitive embodied processes, and System 3, which encompasses collective intelligence and symbol emergence. We contextualize this model within Bergson's philosophy by adopting multi-scale time theory to unify the diverse temporal dynamics of cognition. System 0 emphasizes morphological computation and passive dynamics, illustrating how physical embodiment enables adaptive behavior without explicit neural processing. … The System 0/1/2/3 model provides a novel theoretical foundation for understanding the interplay between adaptive and cognitive processes…"
译文：本文提出 System 0/1/2/3 框架，作为双过程理论的扩展，采用认知的四过程模型。在 System 1（快速、直觉式思维）与 System 2（缓慢、审慎式思维）的基础上，我们纳入 System 0——它代表前认知的具身过程——以及 System 3——它涵盖集体智能与符号涌现。我们借助柏格森（Bergson）哲学中的多时间尺度理论来定位该模型，以统一认知中多样的时间动态。System 0 强调形态计算（morphological computation）与被动动力学（passive dynamics），说明物理具身如何在没有显式神经处理的情况下实现自适应行为。……System 0/1/2/3 模型为理解自适应过程与认知过程之间的相互作用提供了新的理论基础……

§1 Introduction（为何需要 S0）

"Embodied AI systems, such as robots, have difficulty with adaptive real-world behavior because their cognitive models often fail to integrate fast, reactive motor control with slow, deliberative planning."
译文：具身 AI 系统（如机器人）在真实世界的自适应行为上存在困难，因为它们的认知模型往往无法把快速、反应式的运动控制与缓慢、审慎的规划整合起来。
"However, physical interactions that do not require neural processing exhibit super-fast dynamics. Recent AI studies have often overlooked this layer, which we refer to as System 0 in this paper."
译文：然而，不需要神经处理的物理交互表现出超快动力学。近期的 AI 研究常常忽视这一层——本文将其称为 System 0。
"The newly introduced terms of Systems 3 and 0 contrast with Systems 1 and 2 from dual-process theory [69]. By considering self-organizational dynamics both inside and outside the brain, we move beyond the computational view of intelligence to a self-organizational perspective."
译文：新引入的 System 3 与 System 0 与双过程理论中的 System 1/2 形成对照[69]。通过同时考虑大脑内部与外部的自组织动力学，我们从计算主义视角走向自组织视角。

§3.1 S0 的正式定义（逐字）

"The dynamics of the body itself, which lie below System 1, perform morphological computation. System 0 corresponds to what is described in Section 2.2. A well-designed body can realize adaptive behaviors such as walking, even without a brain, as proven by the passive dynamic walker. System 0 represents the foundational layer of cognition in our proposed framework, encompassing the pre-cognitive, embodied processes that occur at the fastest (i.e., super-fast) timescale. … This system is characterized by direct physical interactions between an agent's body and its environment and operates without explicit computation. System 0 includes phenomena such as morphological computation and passive dynamics, exemplified by the self-stabilizing properties of bipedal walking or the inherent grasping capabilities of a soft robotic hand…"
译文：身体自身的动力学位于 System 1 之下，执行形态计算。System 0 对应第 2.2 节所述内容。设计良好的身体即使没有大脑也能实现行走等自适应行为——被动动态步行者（passive dynamic walker）即是证明。System 0 是我们框架中认知的基础层，涵盖发生在最快（即超快）时间尺度上的前认知、具身过程。……该系统的特征是智能体身体与环境之间的直接物理交互，且无需显式计算即可运作。System 0 包括形态计算与被动动力学等现象，例证如双足行走的自稳定特性或软体机械手的固有抓取能力……

§3.1 S1/S2 的来源声明

"For Systems 1 and 2, we follow the conventional definitions [69]."
译文：对于 System 1 与 System 2，我们沿用常规定义[69]。

§3.1 S3 的定义（逐字）

"System 3 represents the highest level of (super-)cognitive processing in our proposed framework, encompassing collective intelligence and symbol emergence. … This system operates on the longest timescale, facilitating the development and evolution of shared symbolic systems, such as language, cultural norms, and societal institutions."
译文：System 3 是我们框架中最高层级的（超）认知处理，涵盖集体智能与符号涌现。……该系统在最长的时间尺度上运作，促进共享符号系统（如语言、文化规范与社会制度）的发展与演化。
"The dynamics of semiotic, e.g., language-based, interactions in society lies above System 2. … adaptation and creation process is not happening within our individual brains but operates in a distributed manner within the social group. This corresponds to symbol emergence and cultural evolution…"
译文：社会中符号性（如基于语言的）交互动力学位于 System 2 之上。……适应与创造过程并非发生在我们个体大脑之内，而是以分布式方式在社会群体中运作。这对应符号涌现与文化演化……

§2.1.1 S1/S2 在 AI 中的对应（逐字）

"Symbolic AI is considered to correspond to System 2 and machine learning to System 1 [117]. Systems 1 and 2 are sometimes considered data-driven and knowledge-driven, respectively."
译文：符号主义 AI 被认为对应 System 2，机器学习对应 System 1[117]。有时也把 System 1 与 System 2 分别看作数据驱动与知识驱动。

§2.1.2 神经动力学中的时间层级（逐字）

"These models introduce a temporal hierarchy [71], [72], where the lower level exhibits a high temporal resolution, which may correspond to System 1, and the higher level exhibits a lower temporal resolution, which may correspond to System 2."
译文：这些模型引入了时间层级[71],[72]：低层具有高时间分辨率，可能对应 System 1；高层具有较低时间分辨率，可能对应 System 2。

§2.2 形态计算（S0 的例证段，逐字节选）

"…We refer to the layer mentioned in this subsection, which performs morphological computation, as 'System 0', as defined in Section 3, within the framework of System 0/1/2/3."
译文：……我们把本节所述、执行形态计算的那一层称为「System 0」——即第 3 节所定义的 System 0/1/2/3 框架中的 System 0。

§3.2 S3 的理论核心：集体预测编码 CPC（逐字节选）

"At the core of System 3 is the concept of collective predictive coding (CPC). In this system, groups of individuals collaboratively construct and refine shared mental models of the world through predictive processing and continuously update these models through social interactions and cultural transmission."
译文：System 3 的核心是集体预测编码（collective predictive coding, CPC）概念。在该系统中，个体群体通过预测处理协作构建并精炼共享的世界心智模型，并通过社会互动与文化传承持续更新这些模型。
"CPC expands the predictive coding concept [57] from individual cognition to collective societal systems. This framework allows the formalization of the emergence of symbol systems, including language, as a process of decentralized Bayesian inference…"
译文：CPC 将预测编码概念[57]从个体认知推广到集体社会系统。该框架使符号系统（包括语言）的涌现得以被形式化为一个去中心化的贝叶斯推断过程……

该文的精读要点（我的总结）

  1. 划分主轴是时间尺度：S0 超快（物理交互，无需神经计算）→ S1 快（直觉/自动）→ S2 慢（审慎推理）→ S3 超慢（社会/符号演化）。
  2. S0 不是「世界模型」：它是身体本身的物理计算（形态计算、被动动力学），例证是「无脑也能下坡的被动动态步行者」「软体手的固有抓取能力」。
  3. S1/S2 无新定义：明确沿用常规定义，并给出 AI 对应（符号 AI≈S2、机器学习≈S1）与神经动力学时间层级（低层高时间分辨率≈S1、高层低时间分辨率≈S2）。
  4. S3 有独立理论工具：集体预测编码（CPC），把自由能原理/预测编码从个体推广到社会尺度，形式化为去中心化贝叶斯推断。
  5. 理论背景：Bergson 多时间尺度哲学（各事件有固有持续时间，不可随意伸缩）+ Friston 自由能原理。

3. 原文区②：GR00T N1（工程双系统，S1/S2）

来源：arXiv:2503.14734（NVIDIA，2025-03-18）。仅摘要级已核实；正文未取。

"GR00T N1 is a Vision-Language-Action (VLA) model with a dual-system architecture. The vision-language module (System 2) interprets the environment through vision and language instructions. The subsequent diffusion transformer module (System 1) generates fluid motor actions in real time. Both modules are tightly coupled and jointly trained end-to-end. … we deploy our model on the Fourier GR-1 humanoid robot for language-conditioned bimanual manipulation tasks…"
译文：GR00T N1 是一个采用双系统架构的视觉-语言-动作（VLA）模型。视觉语言模块（System 2）通过视觉与语言指令理解环境；随后的扩散 Transformer 模块（System 1）实时生成流畅的运动动作。两个模块紧密耦合、端到端联合训练。……我们将模型部署在 Fourier GR-1 人形机器人上，执行语言条件下的双臂操作任务……

我的总结：GR00T N1 是「工程双系统」最常被引的一手——S2 负责语义/指令，S1 负责实时动作，二者 紧耦合、端到端联合训练；这既不同于 Helix 的训练取舍（见下），也完全未涉及 S0/S3。

4. 原文区③：Figure Helix 博客（S1/S2，全文相关段落）

来源：figure.ai/news/helix（2025-02-20，厂商博客，L1）。以下为逐字段落，各附中文译文。

标题与定位

"Helix is a first-of-its-kind 'System 1, System 2' VLA model for high-rate, dexterous control of the entire humanoid upper body. … Prior approaches face a fundamental tradeoff: VLM backbones are general, but not fast, and robot visuomotor policies are fast but not general. Helix resolves this tradeoff through two complementary systems, trained end-to-end to communicate:"
译文：Helix 是首个「System 1 + System 2」VLA 模型，用于对整个人形上半身进行高频率、灵巧的控制。……以往方法面临一个根本性权衡：VLM 主干通用但不快，机器人视觉运动策略快但不通用。Helix 通过两个互补的系统（端到端训练、彼此通信）化解了这一权衡：

S2 / S1 定义（逐字）

"System 2 (S2): An onboard internet-pretrained VLM operating at 7-9 Hz for scene understanding and language comprehension, enabling broad generalization across objects and contexts."
译文：System 2（S2）：板载的、经互联网预训练的 VLM，以 7–9 Hz 运行，负责场景理解与语言理解，从而实现对物体与情境的广泛泛化。
"System 1 (S1): A fast reactive visuomotor policy that translates the latent semantic representations produced by S2 into precise continuous robot actions at 200 Hz."
译文：System 1（S1）：快速的、反应式视觉运动策略，把 S2 产生的潜在语义表征转换为 200 Hz 的精确连续机器人动作。
"This decoupled architecture allows each system to operate at its optimal timescale. S2 can 'think slow' about high-level goals, while S1 can 'think fast' to execute and adjust actions in real-time."
译文：这种解耦架构让每个系统在各自最优的时间尺度上运行：S2 可以「慢想」高层目标，S1 可以「快想」实时执行与调整动作。

接口与训练（逐字）

"S2 is built on a 7B-parameter open-source, open-weight VLM… S2 distills all semantic task-relevant information into a single continuous latent vector, passed to S1 to condition its low-level actions."
译文：S2 基于一个 70 亿参数的开源开放权重 VLM……S2 把所有与任务相关的语义信息蒸馏成一个连续的潜在向量，传给 S1 以条件化其低层动作。
"S1, an 80M parameter cross-attention encoder-decoder transformer, handles low-level control. … S1 outputs full upper body humanoid control at 200hz, including desired wrist poses, finger flexion and abduction control, and torso and head orientation targets."
译文：S1 是一个 8000 万参数的交叉注意力编码器-解码器 Transformer，负责低层控制。……S1 以 200Hz 输出完整的上半身人形控制，包括期望的手腕位姿、手指屈伸与外展、以及躯干与头部朝向目标。
"Helix is trained fully end-to-end… Gradients are backpropagated from S1 into S2 via the latent communication vector… allowing joint optimization of both components."
译文：Helix 完全端到端训练……梯度经由潜在通信向量从 S1 回传到 S2……从而实现两个组件的联合优化。

训练-部署一致性（逐字，工程价值高）

"During training, we add a temporal offset between S1 and S2 inputs. This offset is calibrated to match the gap between S1 and S2's deployed inference latency, ensuring that the real-time control requirements during deployment are accurately reflected in training."
译文：训练时，我们在 S1 与 S2 的输入之间加入一个时间偏移。该偏移经过校准，以匹配部署时 S1 与 S2 的推理延迟差，从而确保部署期的实时控制要求被准确反映在训练中。
"S2 operates as an asynchronous background process, consuming the latest observation … and natural language commands. It continuously updates a shared memory latent vector that encodes the high-level behavioral intent. S1 executes as a separate real-time process, maintaining the critical 200Hz control loop."
译文：S2 作为异步后台进程运行，消费最新的观测……与自然语言指令，并持续更新一个编码高层行为意图的共享记忆潜在向量。S1 作为独立的实时进程执行，维持关键的 200Hz 控制回路。

我的总结：Helix 的文章只讲 S1/S2，没有 S0/S3——这是用户问题的直接答案。它的可学之处在接口（单连续 latent 向量）与「训练镜像部署」（时间偏移 + 异步执行）两个工程决策。

6. 精读分析（我的总结）

6.1 四个概念的正确用法

  • 引用 S0/S3：只能引 Taniguchi 2503.06138，并说明是「四过程理论」的一部分；不要把工程双系统叫成 S0/S1/S2/S3 体系。
  • 引用工程双系统：引 GR00T N1（端到端紧耦合）或 Helix 博客（异步、时间偏移训练）；两者对「双系统」的实现取舍不同，引用时注明。
  • S1/S2 的概念史：Kahneman 2011；具身领域沿用，不改定义。

6.2 为什么「双系统」在机器人里流行

频率冲突是物理性的：大局理解依赖数十亿参数的 VLM（单次前向约十 Hz 级），而灵巧操作需要百 Hz 闭环。拆成慢 S2（低频出意图）+ 快 S1（高频消费意图出动作）是这一族架构的共同动因（GR00T N1 与 Helix 均如此；Helix 原文写明 "each system to operate at its optimal timescale"——让每个系统在各自最优的时间尺度上运行）。

6.3 三种「解耦」不是一回事（重要辨析）

解耦类型拆的是什么判据典型
双系统（频率）运行频率两套网络以不同 Hz 运行、异步衔接GR00T N1、Helix、Gemini Robotics（二手汇总）
分层（语义）语义抽象是否有显式高层子目标中介π0.5（自然语言子任务）
知识隔离（梯度）训练梯度流向动作专家梯度是否 stop-gradientπ0.6（KI）

注：π0.6 与 Gemini Robotics 的具体细节来自二手汇总（具身星图专题），本页未做一手核实；π0 的「动作专家」、WALL-OSS 的「Flow Head」是同一主干内的权重/输出头，严格说不构成「两套不同频率的网络」。

7. 三个常见混淆（引用前必读）

  1. 「双系统」≠ 四过程框架：工程文章只取 S1/S2 并重定义为「两套网络」；S0/S3 只存在于 2503.06138。两者不是同一理论。
  2. S0 ≠ 世界模型：S0 是形态计算/被动动力学（无显式计算）；行业话语里的「世界模型层」属于 S2 或独立世界模型。
  3. 「双系统」标签被滥用：判断标准是「频率 + 两套网络 + 异步接口」三件套；只有 MoE 或两个输出头不算。
