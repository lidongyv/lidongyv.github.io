VLA / VA 方案主要参考论文：方法与实现方式

调研日期：2026-10-26 · 用途：《VLA 在 L4 的可执行落地方案》参考资料
核实方式：所有 arXiv 条目均经 arXiv 官方 API/检索页核对标题与年份；个别无 arXiv 论文的工作（MiniVLA、π0-FAST）以官方博客链接给出并在文末注明。已剔除 10 余个记忆错误的论文 ID。

TL;DR

  • VLA（Vision-Language-Action）= 观测 + 语言指令 → 直接输出动作；VA（Vision-Action）= 弱化/去掉语言，视觉直接到动作。你的 L4 方案语境下，两者都对应「感知不再作为上游依赖任务、直接输出驾驶行为」这一代方案，与 two-stage（模块化管线）相对。
  • 三条技术主脉：
    1. 离散动作 token 的 VLM 路线（RT-2 → OpenVLA → GR00T N1）：互联网知识迁移强、语言接地好，但推理重（7B+）；
    2. 连续动作生成路线（ACT 回归 / Diffusion Policy 扩散 / π0 流匹配）：工程成熟、可实时、LeRobot 全家桶可直接落地，是「遥操数据 → 策略」最直接的底座；
    3. 自动驾驶端到端/VLM 路线（UniAD/VAD → DriveVLM/LMDrive/EMMA/Senna）：动作空间是轨迹 waypoint 或控制量，与你的 two-stage 共存、遥操替换场景最贴合。
  • 与你方案最对症的 6 篇（先读）：LMDrive、Senna、DriveVLM(-Dual)、ACT、Diffusion Policy、LAPA；外加两篇 2025 底 survey 作为目录。
  • 开源实现栈已收敛：LeRobot（训练/推理全栈）、OpenVLA-ft（LoRA 微调 7B）、openpi（π0 系 50Hz）、VAD/Senna/LMDrive/OpenDriveLab（驾驶侧）。

一、概念与分类

1.1 VLA vs VA vs two-stage

术语含义代表工作
VLA视觉-语言-动作：多模态观测 + 自然语言指令 → 直接输出动作（token/连续量/轨迹）RT-2、OpenVLA、π0、GR00T N1、EMMA
VA视觉-动作：语言弱化或仅作目标条件，视觉直接映射动作Diffusion Policy、ACT、DP3、GNM
two-stage模块化：感知→预测→规划→控制 逐级传递，感知是上游依赖你司现有方案；DriveVLM-Dual/Senna 是「VLM 高层 + 传统/E2E 低层」的混合体

1.2 动作输出范式（选型关键）

  • 离散 token：动作量化成文本 token 自回归生成（RT-2、GR00T N1、BeT/VQ-BeT）——语言对齐最好、推理较慢；
  • 连续回归/分块：直接回归 k 步动作 chunk（ACT、UniAD/VAD 的轨迹点）——最小可行、实时；
  • 扩散/流匹配：去噪/直线 ODE 生成动作（Diffusion Policy、π0）——多模态分布建模好，流匹配推理快于扩散；
  • 潜空间动作：先学视频潜动作再映射（LAPA、UniPi）——可用无标签行车视频预训练。

1.3 自动驾驶侧的动作空间

轨迹 waypoint（EMMA、UniAD、VAD、Senna 低层）vs 直接控制量（DriveGPT4、LMDrive 低层控制）。低速 robovan 场景两者都可用；waypoint + 已有跟踪控制器是最稳妥的组合。

OpenVLACoRL 20247B：Llama 2 + DINOv2/SigLIP 视觉融合，970k 真实演示预训练，动作离散 token；比 RT-2-X(55B) 高 16.5% 成功率、比 Diffusion Policy 高 20.4%开源权重+代码；LoRA 消费级 GPU 可微调、量化无损推理；OpenVLA-ft 是微调生态
TinyVLAarXiv 2024面向快速、数据高效的小型 VLA（小 VLM 骨干 + 动作头）开源；车载小模型路线的参考实现
MiniVLA2025（斯坦福博客）「更小 footprint 的更好 VLA」：研究不同小 VLM 骨干 + 动作头的 Pareto 前沿无 arXiv 论文（❗仅有官方博客+代码）；选骨干时直接抄它的结论
FASTarXiv 2025高效动作 tokenization（FAST tokenizer）：连续动作压缩成 ~1k 离散 bin，比扩散版 π0 收敛显著更快开源；π0-FAST 的动作头基础；车载 token 化效率的关键参考
π₀RSS 2025VLM（PaliGemma）+ 动作专家：流匹配生成 50Hz 动作 chunk；语言指令或高层 VLM 调度；多平台预训练openpi 开源含权重；「指令-动作」分流架构最值得借鉴；3B 级，车载需蒸馏/量化
π0.5arXiv 2025π0 增强版：开放世界泛化，few-shot 学习能力强化openpi 生态
π0-FAST2025（PI 博客）自回归 + FAST tokenizer 替代扩散推理，推理加速 ~5×无独立论文（❗博客+openpi 代码）；「扩散→自回归蒸馏」是车载部署的现成路子
GR00T N1arXiv 2025NVIDIA：2B 双系统（System 1 快动作 + System 2 慢推理 VLM），开放权重权重/训练数据开源（HF/NGC），Isaac GR00T 平台配套；团队自训 VLA 的流程参照
Gemini Robotics / -ERarXiv 2025基于 Gemini 2.0 的 VLA（直接控制）+ ER（具身推理：3D 框、轨迹/抓取预测）；100 演示即可学新短时任务、可适配新本体未开源；方法论：先训 ER 再训 VLA 的两级路线
Gemini Robotics 1.5arXiv 2025Motion Transfer 机制学多本体异构数据；动作与自然语言推理交错（think before acting）未开源；多本体数据混合 + 推理交织是 2025 主流方向
Qwen-VLAarXiv 2026Qwen 官方：统一操作/导航/轨迹预测于一体，DiT 动作解码器，embodiment-aware prompt；R2R/RxR 导航与轨迹预测成绩强2026 最新；唯一同时覆盖「导航 + 轨迹预测」的开源系 VLA，与车辆场景距离最近，重点跟踪

Survey：A Survey on Vision-Language-Action Models for Embodied AI（arXiv 2024，方向全景目录）。

三、VA 及动作生成方法（弱语言 / 无语言）

面向「遥操数据 → 动作策略」的训练方法学，是 L4 遥操替代路线的直接技术底座。

3.1 动作分块 + Transformer

论文会议/年方法核心实现
ACTRSS 2023CVAE+Transformer 回归 k=100 步连续动作 chunk（L1+KL），多相机 RGB+关节角官方 tonyzhaozh/aloha；约 80M 参数，50Hz 实时，temporal ensemble 平滑；LeRobot 已有 ACT 车辆控制实现 → 低速车入门首选
BeTNeurIPS 2022动作 k-means 离散为多模态 bin 分类 + 连续残差回归notmahi/bet；作者在 CARLA 上评测过；多模态（直行/转弯/停车）契合驾驶
VQ-BeTICML 2024Residual-VQ 动作 token 化 + GPT 式分类；推理比扩散快约 5×jayLEE0301/vq_bet_official；适合车载实时

3.2 扩散策略

论文会议/年方法核心实现

DP3RSS 2024稀疏点云 MLP 点编码器 + 扩散头；10 次演示/72 仿真任务、真机 85%3d-diffusion-policy.github.io；点云输入与 LiDAR 天然契合（iDP3/RDT 均复用其基座）
iDP3IROS 2025DP3 改进：3D LiDAR 点云 + 本体感知，纯机载算力实机部署，>2000 rollouthumanoid-manipulation.github.io；最贴近「车载传感器 + 机载计算」
CrossFormerCoRL 2024跨本体 Transformer：900K 轨迹/20 种本体（含轮式、无人机），动作空间自动对齐，扩散头crossformer-model.github.io；轮式平台并入多源数据的范式参考
RDT-1BICLR 20251.2B 扩散 Transformer，物理可解释统一动作空间，1~5 演示微调rdt-robotics.github.io 开源；对低速车过重，统一动作空间设计可借鉴
UniPiNeurIPS 2023先扩散生成未来视频，再逆动力学模型提取动作（视频内规划）universal-policy.github.io；两步推理延迟高，仅方法储备
SeedPolicy2026 arXivSEGA 门控注意力扩展观测/动作时间视野，参数比 RDT-1B 少 1–2 个数量级github.com/Youqiang-Gui/SeedPolicy；低成本长视野控制，值得跟踪

3.3 流匹配 / 整流流

论文会议/年方法核心实现
Rectified FlowICLR 2023学习直线 ODE 传输分布，reflow 使路径变直、少数步采样github.com/gnobitab/RectifiedFlow；少步采样=低延迟，策略流匹配的理论底座

3.4 潜空间动作

论文会议/年方法核心实现
LAPAICLR 2025VQ-VAE 从无标签视频学离散潜动作（帧间变化），预训练 VLA 预测潜动作，少量遥操数据微调到真机latentactionpretraining.github.io（UniPi 团队）；用行车视频（无标签）预训练 → 少量遥操数据微调，最契合本项目数据形态

动作 token 化选型对比：BeT = k-means 单层离散（高维难扩展）；VQ-BeT = 残差 VQ 层次 token + GPT 分类（快、欠平滑）；LAPA/π0 = 潜动作/流匹配（连续、保真度高、训练要求更高）；UniPi = 视频潜空间（最重）。选择取决于部署算力与延迟预算。

3.6 开源工具栈

工具要点
LeRobot（ICLR 2026）Hugging Face 端到端库：数据采集/存储/训练/异步推理全栈；内置 ACT、Diffusion Policy（CNN/Transformer）、VQ-BeT、TDMPC。推理：receding-horizon（chunk 默认 16 步每 n 步重推）+ temporal ensemble 重叠平均；ACT 加温度采样；50Hz 场景需小模型或 chunk 复用。可直接作为低速 robovan 遥操数据训练与车端推理的统一栈

  • 驾驶：nuScenes（UniAD/VAD/DriveVLM/Senna）、nuPlan、CARLA（LMDrive/CarLLaVA）、DriveX（Senna 预训练）、LangAuto 64K 指令片段（LMDrive）、SUP-AD（DriveVLM）、BDD-X（DriveGPT4）。
  • 无标签视频预训练：Ego4D（GR-1）、自车行车记录仪视频（LAPA 思路）——与你们「用存量行车数据 + 少量遥操数据」的预算结构一致。
