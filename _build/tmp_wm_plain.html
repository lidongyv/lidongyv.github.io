定位框架：一个好的世界模型，取决于它「为谁服务」

读五阶段之前，先立一条第一性原理的判据——它同时化解"李飞飞 vs LeCun"之争。
金句 · David Marr《Vision》(1982) · §63
"The usefulness of a representation depends upon how well suited it is to the purpose for which it is used."
—— 一种表征的有用性，取决于它对其所服务的目的适配得有多好。
引申：没有目的的表征就没有意义——无目的 ＝ 无损失函数 / 无评价指标，表征便无从优化、无从判定好坏。"有用"永远是相对于目的而言的。

把这句话套到世界模型上：WM 本质是一种"对世界的表征 / 模型"，因此同样服从这条铁律—— 不存在"绝对最好"的世界模型，只有"对其服务对象适配得好不好"的世界模型。 评价任何一个 WM 之前，先问一句：它到底为谁服务？

① 按「服务对象」，世界模型分两大类

类别一 · 面向人 human-facing

产物给「人」看 / 用

  • 目的：让人理解、体验、决策——高真实感生成、可交互的 3D / 视频世界、给人当"决策沙盘"。
  • 评判标准：感知真实感、可控生成、空间 / 时序一致——因为消费者是人的眼睛与判断。
  • 代表取向：李飞飞的空间智能 / World Labs（可体验的 3D 世界）、Cosmos 等生成式 WFM（给人看的高真实渲染）。
类别二 · 面向 model model-facing

产物给「模型 / agent」内部用

  • 目的：当 agent 的内部预测器 / 脑内沙盘，供策略规划、训练——不追求像素级好看，只求对决策有用。
  • 评判标准：预测 / 表征对下游策略是否有用、动作是否可控——因为消费者是另一个模型。
  • 代表取向：LeCun 的 JEPA（非生成、学"对 agent 有用的表征"）、Dreamer 类 model-based 世界模型。

② 面向 model 的世界模型，再分「开环 / 闭环」

开环 open-loop

不接动作反馈的预测

  • 给定条件生成未来（纯视频 / 未来帧预测），策略不在环。
  • 用途：离线数据引擎 / 表征学习——造静态数据喂下游训练（对应本页阶段 ①的"开环生成数据"）。
  • 门槛较低：不需动作可控、不需长时序闭合。
闭环 closed-loop

动作条件预测，策略在环

  • 预测 → 决策 → 执行 → 再预测闭合：WM 当可交互仿真器，策略在环 rollout + 迭代。
  • 用途：model-based 规划 / 自驾闭环仿真 / 具身（对应本页阶段 ③及以后）。
  • 门槛较高：需动作可控性 + 长时序一致，故晚于开环。
✔ 所以：李飞飞与 LeCun 并不冲突
用 Marr 的判据一以贯之——两人只是服务对象不同：李飞飞更偏面向人的空间智能（给人 / agent 一个可体验、可交互的世界），LeCun 更偏面向 model的表征（给 agent 一个"对决策有用"的内部世界）。 没有谁对谁错，而是同一棵树的两大分支——各自都是"对自己目的适配得好的表征"。 那怎么在一个架构里统一这两条路线？ → 统一视角：一个 Sampler，多层 latent 出口 ↗ （机制级答案：像素只是 latent 谱最表层，真问题是"消费哪层 latent + render 接多深"）。这也是本站 原创方案 · 按消费方分叉（人看生成、机器吃表征）↗ 与 路线之争↗ 的底层逻辑。

🎬 三个 Demo · 面向不同受众的落地展示

技术上是五阶段；对外展示可浓缩成三个递进的 demo，各讲给不同受众。Demo 编号是"展示顺序"，与技术阶段号不完全一一对应（见每块末尾的映射）。
Demo ① · 现在

Perception 打榜：让检不出来的能检出来

  • 做什么：朴素地刷榜——把原本检不出来的目标 / 场景 / 长尾 case 检出来。纯感知即可起步，门槛清晰、可量化。
  • 怎么讲：感知做扎实，就是"从 perception 到 cognition"这条大叙事的起点。
  • 引申的大市场：通用云端大模型 → 端侧（mobile）小模型——用大模型赋能在真实世界交互的广义机器人（把云端认知蒸馏 / 下放到能在物理世界实时跑的小模型）。
↔ 对应技术阶段 ①（视觉刷 SOTA）。受众：关注数据引擎 / AI 基础设施 / 通用模型方向的投资人。
Demo ② · 下一步（重点·最有讲头）

快慢机遥操：人脑 × 机脑

  • 做什么：搭建一个当前具身智能无法自主交互的复杂场景；由人脑（高级智能）把复杂交互拆解成一连串简单机操，具身脑（执行器）逐步执行 → 实现快慢机遥操（慢的人脑做决策，快的机脑做执行）。
  • 核心杠杆 = 人机比 > 1:100：一个人脑同时驱动 / 辅助上百个机器人的决策；机器人是放大人决策的执行器，帮人把决策落地。
  • 共赢飞轮：随能力提升，人机比越来越高 → 单人产出与收入 ↑、机器人产出与市场 ↑ → 人机共赢。
↔ 对应技术阶段 ④（具身）。人在环、不需 WM 全闭环，故可作为重点 demo 提前展示。受众：面向实际具身智能的投资人。
Demo ③ · 更后期 · WM 闭环
让 WM 真正做到闭环（策略在环、可交互仿真、自主决策）——这已是更后期的事，对应技术阶段 ③（自驾闭环）及以后。节奏：Demo ① 打底 → Demo ② 用人脑杠杆过渡（人在环）→ Demo ③ 收敛到 WM 自主闭环。

① GPT 时刻 · 视觉全刷到 SOTA，验证开环生成数据（纯仿真数据）

先证明"scaling + 自监督"在视觉世界模型上成立，能力涌现——就像 GPT-3 之于 LLM。
WM 侧 · 要做什么

把视觉世界模型刷到 SOTA，跑通开环数据引擎（纯仿真数据）

  • 开环生成数据：用 WM 生成的视频/场景当训练数据，喂给下游感知/预测/规划，能涨点（数据引擎）。
  • 只做开环（纯仿真数据）：离线生成静态数据集喂下游训练，不涉及策略在环——可交互的闭环仿真更难（需动作可控 + 长时序一致），故下沉到阶段③。
  • 纯相机视觉路线在各视觉 benchmark / 生成质量上全面对齐或超过既有方法。
LLM 侧 · 对应事实

2020 · GPT-3「涌现」

  • 175B 参数 + 海量文本 + 自监督下一 token 预测 → few-shot 涌现。
  • 证明"把规模拉满，能力会涌现"这条路成立，奠定后续一切。
  • 此刻还谈不上"好用"，但可行性被证明——正是 WM 现在要做的事。
▲ 到达这一阶段的信号
① WM 在视觉任务/生成质量上刷到 SOTA；② 生成的纯仿真数据训下游稳定涨点（开环验证）。两者齐备 = WM 的"GPT-3 时刻"坐实。（闭环仿真属阶段③，需动作可控，不在本阶段）
现在到哪了：正在发生。生成式视频/自驾世界模型持续刷榜，开环数据引擎已有雏形；"生成的纯仿真数据能涨点"正被逐案验证。本 demo 的 v0 调研与 SOTA 全景就是这一阶段的证据留存。

①·达成路径：两个任务合并 = vision 的 GPT time

来自自驾的经验——90% 的问题靠数据驱动，剩下的靠"数据友好型模型"。两条腿（平台任务 + 科研任务）合流，即达成阶段 ①。
▲ 出发点：自动驾驶的经验
Vision 里应用最广、烧钱最多、数据最多的领域是自动驾驶。它的实战经验是：90%+ 的问题都能靠数据驱动解决， 剩下的约 10% 就是怎么构建一个「数据友好型模型」。→ 阶段 ① 因此拆成两条腿：数据驱动（平台/infra） + 数据友好型模型（科研）。
依赖 A · 平台任务（纯 infra）

数据驱动

两个方面：

  • ① Corner case 数据挖掘 + 新增
  • ② 数据配平（balancing）

这是纯 infra 工作，等价于 GPT 当年 RLHF 清洗出来的高质量人类数据——数据质量决定模型上限。

WM 在数据驱动上的作用：
  1. 通过生成，增广 corner case 数据；
  2. 通过 WM 自动发掘 corner case + 自动配平。
（正对应阶段 ① 的"开环生成数据 / 纯仿真数据"；闭环见阶段③）
依赖 B · 科研任务

数据友好型模型 = Unified Vision Model

等价于 AD 的 e2e 模型迭代。核心洞察：把所有 vision 任务看作 AD model 的 hydra head，一个 unified vision model 就出现了。它必须满足四个"数据友好"要求：

  • 数据吞吐友好：能高吞吐地消费海量数据；
  • memory 足够强：记得住上亿数据，又不 overfit 小数据；
  • 动态增量训练：支持持续新增数据继续训练；
  • 任务友好（像 AR）：各类 vision 任务用一个 task formulation 统一实现。
✔ 两者合并 = vision 的 GPT time
第一件（数据驱动 · 平台任务）负责源源不断产出高质量、配平好的数据（含 WM 生成/发掘/配平）； 第二件（unified vision model · 科研任务）负责用一个数据友好的统一模型把它们全吞下去。 两者合流 = 复刻 LLM 的 GPT 时刻：高质量数据飞轮 × 一个能吞下它们的统一模型 → 能力涌现。
一句话：平台侧把"数据"做成 RLHF 级别的高质量燃料，科研侧把"模型"做成能无限吃数据又不过拟合的统一体——燃料 × 引擎 到位，vision 的 GPT-3 时刻就到了。

② LLM 时刻 · 数据飞轮（车队真实数据 + 生成数据）

靠数据规模化把"能力"变"可用"——就像指令数据 + RLHF 让 GPT 变 ChatGPT；自驾靠车队真实数据 + 生成数据转起飞轮。
WM 侧 · 要做什么

把自驾数据飞轮转起来：车队真实数据 + 生成数据

  • 车队真实数据：规模化路采，天然自带动作标注（转向/油门/刹车/轨迹），是自驾的数据主力。
  • 生成数据补长尾：用①的开环生成能力批量造 corner case / 危险场景，补真实数据采不到的尾部。
  • 两者合流 → 数据飞轮转起来（越跑越多、越多越好），WM 从"能生成"跃迁到"可用"。
LLM 侧 · 对应事实

2022 · ChatGPT / InstructGPT「对齐」

  • 在 GPT 能力之上，用指令数据 + 人类反馈(RLHF)对齐 → 从"会补全"变"会听话、能用"。
  • 产品化后数据飞轮启动：用户越多 → 数据越多 → 模型越好。
  • WM 的车队真实 + 生成数据 ≈ LLM 的指令/反馈数据：都是把能力变可用的关键燃料。
▲ 到达这一阶段的信号
自驾车队真实数据规模化 + 生成数据补长尾，WM 被喂到"可用"质变，数据飞轮开始自转（越跑越多、越多越好）。
为什么排在 GPT 之后：和 LLM 一样——先有涌现的底座（①），再用规模化数据把它对齐成"可用"（②）。注：机器人操作的 teleoperation 数据不在此列——它没有现成大规模数据、需人工遥操，属阶段④具身的数据前提，可与③自驾并行积累（自驾靠车队数据，不等 teleop）。

③ vibe coding 时刻 · WM 解决自动驾驶问题

第一个能大规模闭环落地、真正改变一个行业的垂直场景——就像 coding 之于 LLM。
WM 侧 · 要做什么

让 WM 端到端解决自驾

  • 数据生成：批量造长尾/危险场景，突破真实数据采集瓶颈。
  • 闭环仿真（阶段③核心，从①开环数据进阶）：WM 当可交互仿真器，策略在环 rollout+评测+迭代，渲染真实 log 没走过的新轨迹；需动作可控性（自驾的动作=驾驶控制，车队真实数据自带，不靠 teleop）+ 长时序一致，故晚于①的纯开环数据。
  • 端到端：WM 作为"内部沙盘"直接服务规划/决策 → 可量产、可运营。
LLM 侧 · 对应事实

2023-24 · Copilot / Cursor「vibe coding」

  • LLM 第一个大规模改变生产方式的垂直落地——写代码。
  • 特征：任务闭环清晰、价值可量化、数据可自举、容错可控。
  • 自驾之于 WM ≈ coding 之于 LLM：第一个真正跑通商业闭环的杀手场景。
▲ 到达这一阶段的信号
WM 驱动的自驾在数据生成 + 闭环仿真 + 端到端决策三方面达到可量产/可运营门槛，成为行业标配基础设施。
为什么是自驾先：自驾天然满足"vibe coding 场景"的四条件——闭环清晰、价值可量化、长尾可用生成数据补、纯视觉可行；且安全攸关，最需要"在模型里试错"。

④ agent 时刻 · WM 解决具身问题

从"预测/仿真"走向"驱动实体在真实世界自主行动"——就像 LLM 从对话走向 agent。
WM 侧 · 要做什么

通用具身智能

  • 数据前提 = teleoperation：机器人操作没有现成大规模动作数据，靠人遥操采集"动作↔后果"（贵、慢，但可与③自驾并行积累）——具身 WM 动作可控性的燃料。
  • 快慢机遥操（人在环的中间形态）：人脑=高级智能做决策、把复杂场景交互拆成一连串简单机操，具身脑=执行器执行；人机比 >1:100 作杠杆，机器人放大人的决策，比例越高 → 人的产出/收入与机器人市场同涨（共赢）。既是采 teleop 数据的方式，也是面向具身投资人的重点 demo（见 🎬 Demo ②）。
  • WM 不只预测画面，而是驱动机器人在开放环境里自主完成长程、多步任务。
  • 用"脑内仿真"做前瞻规划：先在世界模型里试走，再在真实世界执行择优动作。
  • 跨本体、跨任务泛化，不再为每个任务单独训练。
LLM 侧 · 对应事实

2024-25 · Agent「自主执行」

  • LLM 从"对话"走向自主执行任务、调用工具、多步决策。
  • 核心跃迁：从"回答"到"行动"，从单步到长程闭环。
  • 具身之于 WM ≈ agent 之于 LLM：都是从"生成/预测"跨到"在世界里自主行动"。
▲ 到达这一阶段的信号
teleop 攒够具身动作数据 → 通用具身 WM 让机器人在开放、非结构化环境中，靠"世界模型前瞻 + 自主决策"完成长程任务，且能跨本体/任务迁移。

⑤ 新工业革命 · WM 真正泛化 → Physical AI

当"和物理世界打交道"被抽象成写软件（可编程、可复现、成本可控），就是新工业革命——WM 的终局是 Physical AI（不是 AGI；AGI 是 LLM 侧的终局）。
WM 侧 · 终局 = Physical AI

物理交互 = 软件问题 → Physical AI

  • WM 真正泛化到任意物理场景，不再受限于单一领域/本体。
  • 与真实世界交互被抽象成可编程接口：造数据、试方案、部署实体 = 写/调软件。
  • 成本可控 → 规模化工业部署，物理世界的自动化像今天部署软件一样廉价可复制。
LLM 侧 · 对应愿景

AGI / 通用化（LLM 的终局）

  • 智能变成可编程、可复制、边际成本趋零的"软件"。
  • 能力泛化到几乎所有认知任务，成为通用基础设施。
  • 但 WM 的终局不是 AGI，而是 Physical AI——把这套"软件化"从比特世界扩展到原子世界，让 AI 真正进入物理世界。
✔ 为什么叫"新工业革命" · 终局 = Physical AI
第一次工业革命把体力自动化，信息革命把脑力/比特自动化；世界模型把"与物理世界交互"变成可编程的软件问题，就把自动化推进到原子世界——这就是 Physical AI 的终局（LLM 的终局是 AGI，WM 的终局是 Physical AI），量级不同的生产力跃迁。
