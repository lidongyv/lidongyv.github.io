新石器慧通（北京）科技有限公司

AD 算法负责人 · AD 二部

负责感知、端到端与世界模型的整体算法架构：用一个 group query-based 模型统一单任务与多任务，把感知任务重构成适配 E2E 的形态，并用两阶段预训练 + 世界模型把 VLA 推到可量产。

  • 用 group query-based 模型统一单任务 / 多任务训练，从 multi-head 设计改为数据友好的 single-head；在 token 级别（BEV token / image token）而非 task-loss 级别做任务权重重配平。
  • 一个 query-based 模型覆盖 object detection、lane detection、occupancy network、E2E 红绿灯检测与导航模型；lane 与红绿灯升级为 navi-based static E2E，为上游决策提供强先验。
  • 两阶段预训练：从 Cosmos / VGGT 做 LLM 蒸馏（CoT、3D 几何估计、3D OD、lane、failsafe、场景识别），并做 perception model inception；支持 frozen head / frozen backbone 的可控迭代与随时加数据。

NVIDIA

Principal Engineer · 自动驾驶部门 Free IC

从感知模型演进到两阶段端到端，再升级到单阶段 Alpamayo；负责 backbone 预训练 / 微调 / post-training 框架，以及 Cosmos 世界模型的预训练与 render 研究。

2023.06 — 2024.07

北京地平线机器人技术研发有限公司

静态感知算法负责人 · 「土星五号」项目

负责轻地图 PNC 方案与众包建图下的道路结构认知：把车道线检测从 segment-based 换到 query-based，同时重建整条数据闭环。

  • 路沿采用「所见即所得」策略，模型只输出车道线与路沿、不输出中心线；针对路口遮挡等场景重新设计数据清洗与标注规则。
  • 以 query-based 方案替换 segment-based：去掉后处理、人力前移，计算效率持平而 F1 提升 15%；路口两侧横向及远处弱可见区域 recall 显著提升，且相比 entry-point 策略可以直接构建车道。
  • 离散要素（arrow / crosswalk / junction）用 query-based 替换两阶段检测器：分数持平，计算效率提升 30% 以上；query 分组把单任务与多任务的指标差距拉平，支持同源数据的单模型多任务训练。
