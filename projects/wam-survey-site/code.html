投机推理（训练-free 加速）　WAMotorarXiv 2609.25413

物理：同一动作块的多步去噪里，速度在相邻步变化平滑，可用一个 anchor 速度外推多步。
为何：省去逐步模型调用；首步强制 Euler 避开首步速度剧变。
优势：3.24–6.62× 去噪加速、2.86–4.28× 端到端；代价：窗口/阈值敏感，需按步长缩放验收。

# 官方代码 speculative/action.py
thr = eps * (median(|Δ|)/|Δ|)**2        # 时间步感知阈值（步长大→更严）
u = predict(a, t[0]); a = euler(a, u, Δ[0])   # 首步强制 Euler（推迟投机）
draft = a + u * cumsum(Δ[m:end])              # 一个 anchor 速度外推 w 步
v = predict_batched(draft)                     # 一次前向验证全部候选
acc = longest_prefix(mse(v, u) < thr)          # 接受最长前缀
a = euler(a, v[acc-1], Δ[m+acc])               # 边界回退一步

循环深度 + 弹性蒸馏　LoopedWAMarXiv 2611.25595

物理：把「深网络」换成「浅网络循环」——同一组权重反复用，参数少但有效深度大。
为何：显存/参数受限下保留深度；弹性蒸馏让一个 checkpoint 覆盖多档算力。
优势：0.58B 达 96.1%、比 Fast-WAM 少 7.4× 显存；代价：激进降深度需专门蒸馏训练。
