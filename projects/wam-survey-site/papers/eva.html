物理意义IDM 把生成视频解成关节动作，用平滑/限幅奖励对齐可执行性。
为什么这么做视频合理≠可执行；动作空间奖励直接惩罚抖动与越限。
方法出处论文 §4.2/§4.3（L2）。
优势与代价优势：Kinematic 70.5→91.4；代价：依赖 IDM，奖励可被 hacking。

代码类型：论文伪代码（按 §4 结构化）。Kinematic 通过率 70.5→91.4；LVP→SFT→RL 三级管线。

# 动作空间奖励 + Flow-GRPO（§4.2/§4.3）
q = IDM(video)                                  # 冻结 IDM
v, a, j = diff(q), diff(v), diff(a)
R = -(λj*huber(j) + λα*huber(a) + λv*relu(|v|-vmax).pow(2) + λa*relu(|a|-amax).pow(2))
Adv = (R - R.mean()) / (R.std() + eps)          # 组归一化
loss = min(ratio*Adv, clip(ratio,1-ε,1+ε)*Adv) - β*KL(π||π_ref)
update(generator LoRA)
