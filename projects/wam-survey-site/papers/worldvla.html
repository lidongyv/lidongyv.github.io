核心贡献

中文：基于 Chameleon 的单一 LLM 兼任动作模型与世界模型；共享 65,536 词表（8,192 图像 + 256 动作 token）；「屏蔽先前动作」掩码抑制自回归误差累积。

English: One Chameleon-based LLM does action model + world model; shared 65,536 vocab (8,192 image + 256 action tokens); action-mask blocks prior actions to curb AR error accumulation.

原文断言（摘要）+ 中译

原文（Abstract，verbatim）All texts, actions, and images are discretized into tokens and are trained under the autoregressive manner.
中译（译者译，非论文原文语言）文本、动作、图像全部离散为 token，并以自回归方式训练。

核心机制（原文 + 中译）

原文（论文方法节，verbatim）The text inputs are "What action should the robot take to + task instruction + ?". The overall token sequence is: [BOS]{text}[BOI]{image}...[EOI]×M [EOS][BOA]{action}...[EOA]×K
中译（译者译）输入为固定模板文本 + M 帧图像 token，输出 K 个动作 token；动作块用并行掩码生成。

物理意义把图像/动作/文本都离散成 token，同一 LLM 自回归出动作与下一帧。
为什么这么做统一词表可复用 LLM；世界模型分支提供未来监督。
方法出处论文 §3.2/§3.3（L2）；Chameleon 初始化。
优势与代价优势：单一模型两用；代价：自回归误差累积（action mask 缓解）。

代码类型：论文伪代码（按 §3.2/§3.3 结构化）。动作=7 tokens（3 相对位置+3 相对角度+1 夹爪），每维 256 bins；LIBERO 81.8(512)。

# 序列与掩码（§3.3）
seq = [BOS] + text_tokens + repeat([BOI]+img_tokens+[EOI], M) + [BOA] + action_tokens + [EOA]
# action 分支掩码：当前动作只能看文本+图像，不能看先前动作
mask = causal_mask | block_prior_actions()
loss = CE(action_tokens) + alpha * CE(image_tokens)     # alpha=0.04
