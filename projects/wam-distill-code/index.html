分类总览：按「蒸什么」分五族

蒸馏 WAM 的差异不在模型大小，而在知识以什么形式从教师流向学生。五族：A 直接把教师隐状态变成学生的上下文条件；B 把多步去噪能力压成少步；C 把教师表征蒸进策略（部署无教师）；D 用大模型生成数据/伪动作；E 在学生的轨迹上做 on-policy 蒸馏。

What differs across WAM distillation methods is not model size but the form in which knowledge flows from teacher to student: A) teacher hidden states become student context; B) multi-step denoising is compressed into few steps; C) teacher representations are distilled into a policy that deploys without the teacher; D) a large model generates data / pseudo-actions; E) on-policy distillation on the student's own trajectories.

族蒸什么方法部署时是否需要教师
A 教师→学生中间层隐状态 → 上下文 tokenCKT-WAM需要（一次前向）
B 自蒸馏/步数压缩多步去噪 → 一步/少步S-VAM、DIDO、APM、AnyStep、LoopedWAM不需要
C 表征→策略冻结教师特征 → 学生表征THAW-VLA、DreamFree、W2A、ForeTime-VLA不需要
D 数据/标签视频/潜动作/伪动作GR00T N1 管线（LAPA/DreamGen/IDM）不需要
E On-policy教师在学生轨迹上的条件分布WAM-OPD、HINT-WAM、WAM-Policy不需要（训练期）

A. 教师→学生：隐状态变成上下文（Teacher → Student Knowledge Transfer）

CKT-WAM L3

核心：14B 教师 WAM 只做一次观测编码（取第 20/40 层隐状态），经可学习 query 压成 32（通用）+32（专家）个 token，拼到 2B 学生 WAM 的文本条件序列；教师、学生全冻结，只训 CKT 模块（187.4M，1.17%）。专家只有 top-2/8 激活。

Core: the 14B teacher runs once as an observation encoder (layer 20 of 40); learnable-query cross-attention compresses its states into 32 general + 32 specialized tokens, appended to the 2B student's text-conditioning sequence. Both backbones stay frozen; only the CKT module (187.4M, 1.17%) is trained, with top-2-of-8 experts active.

# inputs : obs [B,N_img,d_tea], text [B,N_txt,d_tea], future_video, future_action
# output : v_hat, a_hat (student's clean latents); loss
for (obs, text, fv, fa) in loader:
    H  = teacher.encode(obs, text, t=0).layer[20].detach()   # one pass, stop-grad
    Z  = LN(up(down(H)))                                      # [B,N,d_stu], d_b=512
    Cg0 = LN(MHCA(Qg, Z, Z) + Qg)                             # 32 general tokens
    Cs0 = LN(MHCA(Qs, Z, Z) + Qs)                             # 32 specialized tokens
    Cg  = Cg0 + up_g(act(down_g(Cg0)))                        # always-on adapter
    p   = softmax(router(mean_pool(H)))                       # [B,8]
    idx = topk(p, 2)
    Cs  = sum(renorm(p,m) * (Cs0 + up_m(act(down_m(Cs0)))) for m in idx)
    CA  = concat([Cg, Cs], dim=1)                             # [B,64,d_stu]
    Et  = concat([student.text_emb(text), SEP, CA], dim=1)    # inject
    v_hat, a_hat = student.denoise(noisy_v, noisy_a, cond=Et) # frozen student
    loss = L_act + 1.0*L_vid + 0.01*L_bal; opt.step(ckt)      # only CKT

推理：教师一次 + CKT 一次，CA 在所有去噪步复用（不再查教师）。坑：教师必须 t*=0；top-k 路由必须重归一化。

Inference: one teacher pass + one CKT pass; the context is reused across all denoising steps. Pitfalls: teacher must be queried at t*=0; renormalize top-k routing.

结果：LIBERO-Plus 86.1%（零样本）、真机 4 任务均值 83.3% ｜ 来源：arXiv:2605.06247

B. 自蒸馏 / 步数压缩（Self-Distillation & Step Compression）

S-VAM L3

核心：教师不是外部模型，而是SVD 自己多步生成的视频：用冻结 DPAv3 提几何、DINOv2 提语义特征当目标；两个轻量时空 decoupler 把「一步去噪的噪声特征」映射成这两类前瞻表征。推理单次前向，不做视频 rollout。

Core: the teacher is the diffusion model's own multi-step generated video; frozen DPAv3 (geometry) and DINOv2 (semantics) extract teacher features. Two lightweight spatio-temporal decouplers map noisy one-step features onto these foresight representations; inference is a single forward pass with no video rollout.

# stage 2: self-distillation (SVD frozen; 50k steps, 1x H100)
for (obs, instr) in data:
    V_hat  = SVD.sample(obs, steps=S)                  # teacher: own multi-step video
    Y_geo  = DPAv3(interp(V_hat)); Y_sem = DINOv2(interp(V_hat))
    F      = concat([interp(f) for f in SVD.step1.upsample_feats])
    for i in [geo, sem]:
        Y_ref = Phi_i(interp(obs))                     # anchor from CURRENT obs
        F_i0  = concat([F, repeat(Y_ref, T)], dim=ch)
        F_iK  = decoupler_i(F_i0)                      # student
        loss_i = mse(F_iK, Y_i)
    update(decouplers, loss_geo + loss_sem)            # SVD/VFM frozen

Pitfalls: scoring with own generated video (not ground-truth future) avoids trajectory misalignment; the reference feature must come from the current observation.

结果：CALVIN 平均序列长度 4.16（VPP 3.58）｜ 来源：arXiv:2603.16195

DIDO L1

核心：把多步视频模型的收敛交互动态蒸成一步：分布匹配（DMD）+ 交互中心引导（夹爪/物体 bbox 视觉推理 token，目标物体多层特征对齐冻结 DINOv3）。

Core: distill the converged interaction dynamics of a multi-step video model into one step: distribution matching (DMD) plus interaction-centric guidance (bbox tokens for gripper/object and multi-layer alignment to frozen DINOv3).

# per sample: teacher multi-step -> converged dynamics; student one step
z_t = teacher.multi_step(obs)                       # frozen
z_s = student.one_step(obs)
L = DMD(z_s, z_t)                                   # distribution matching
  + BCE(token_head(feat), boxes)                    # gripper / object bbox tokens
  + mse(proj(student.layers), dinov3(target_obj))   # semantic anchor
update(student, token_head, proj)

结果：LIBERO 99.0 / LIBERO-Plus 76.6 / RoboTwin 92.0 ｜ 来源：arXiv:2609.15570（摘要级）

APM（Anchored Path Matching） L1

核心：从学生自己到达的状态继续教师到零噪声，取教师终点与首个中间态作锚；两个模态路由 adapter 同时拟合；梯度冲突时「锚优先」（保端点梯度、去掉局部冲突分量）。一个 checkpoint 支持 1/2/4 步。

Core: from the state the student itself reaches, continue the teacher to zero noise and use its endpoint plus first intermediate state as anchors; two modality-routed adapters match both; on gradient conflict, anchor-priority keeps the endpoint gradient. One checkpoint serves 1/2/4 steps.

for (obs, a0) in data:
    s = student.sample_state(obs, steps=k)          # student's own state
    a_end, a_mid = teacher.continue_to_zero(s)      # anchors
    L_end, L_mid = mse(adapter_end(s), a_end), mse(adapter_mid(s), a_mid)
    if cos(grad(L_end), grad(L_mid)) < 0:
        g = grad(L_end) - project(grad(L_mid), grad(L_end))  # anchor priority
    else:
        g = grad(L_end) + grad(L_mid)
    update(adapters, g)

结果：RoboTwin +2.0 Clean / +1.4 Rand；PSNR 30.169→32.317；真机延迟 21.3× 低于 8 步教师 ｜ 来源：arXiv:2611.22592（摘要级）

AnyStep-WAM L1

核心：用冻结教师的真实转移训练「区间条件 flow map」+ 共享 LoRA，一次训练覆盖 1…K 步；推理时一个轻量调度器用一步预览预测难度，选满足风险的最小预算。

Core: train interval-conditioned flow maps with shared LoRA on frozen-teacher transitions, covering 1..K steps in one model; at inference a light scheduler predicts difficulty from a one-step preview and picks the smallest budget that meets the risk target.

# training: teacher rollouts provide interval targets
traj = teacher.rollout(obs)                         # frozen
for k in budgets:
    for (x_t, x_next) in subsample(traj, k):
        loss = mse(flow_map(x_t, k), x_next); update(flow_map, LoRA)
# inference
preview = student.one_step(obs); k = scheduler(preview)
a = student.sample(obs, steps=k)

结果：Motus/FastWAM/LingBotVA 去噪步 -60.2% / -49.8% / -85.28% ｜ 来源：arXiv:2609.33748（摘要级）

LoopedWAM L1

核心：共享 6-block core 循环 5 次——只存 12 个 block 却执行 30 层；视频专家每 query 算一次、动作专家每采样步重复；用弹性自蒸馏训练单一 checkpoint，跨 action-depth 与采样步预算。

Core: a shared 6-block core is applied 5 times, storing 12 blocks but executing 30 layers; the video expert runs once per query while the action expert repeats per sampling step; elastic self-distillation trains one checkpoint across action-depth and sampling-step budgets.

# shared core + looped depth; elastic budgets
for (depth, steps) in budgets:
    y = loop(shared_core, depth)                    # 6 blocks x 5
    loss = distill(teacher_30step, y, steps=steps)
update(shared_core)
# one checkpoint: 1/2/4 steps x different action depths

结果：0.58B；LIBERO 96.1 / RoboTwin 91.9 / RoboCasaGR1 52.2；比 Fast-WAM 少 7.4× 显存；27.6ms ｜ 来源：arXiv:2611.25595（摘要级）

C. 表征 → 策略：部署不带教师（Representation Distillation to Policy）

THAW-VLA L2

核心：冻结世界模型（Cosmos3-Nano 理解塔，layer-24、每视图 mean-pool、4096-D）只离线跑一次，特征写进 memory-mapped 缓存；0.8B 学生训练时只加视图级 cosine 对齐（λ=0.5）；部署删掉投影器，与未蒸馏基线逐位一致。

Core: a frozen world model (Cosmos3-Nano understanding tower, layer 24, per-view mean-pool, 4096-D) runs once offline; features go into a memory-mapped cache. The 0.8B student adds only view-level cosine alignment (λ=0.5) during training; the projector is dropped at deployment, matching the undistilled baseline exactly.

# 0) offline: teacher runs once
for (traj, idx, frame) in train_frames:
    cache[traj, idx] = teacher.layer24(mean_pool_views(frame))
# 1) student training (teacher not in memory)
h = student.prefill(obs, instr)
s = projector(view_mean_pool(h))
loss = flow_loss(a, h) + 0.5 * (1 - cos(s, cache[traj, idx]))
update(student)
# 2) deployment: drop projector + cache; 4 flow steps

结果：LIBERO 97.9（+2.6）；RoboCasa-GR1 50.5；真机 28/30；32ms / 1.86GB ｜ 来源：arXiv:2609.24682（L2 正文）

DreamFree L1

核心：把视频扩散模型当「预测性视觉编码器」：学生编码器只用当前观测预测冻结教师对未来的表征；动作模块从中抽动作相关信息。推理不生成未来视频（14B 骨干 11Hz）。

Core: repurpose the video diffusion model as a predictive visual encoder: the student encoder predicts the frozen teacher's future representation from the current observation only; an action module reads it. No future video at inference (11Hz with a 14B backbone).

for (obs, future, a) in data:
    z_t = stopgrad(video_model.encode(future))      # teacher representation
    z_p = visual_encoder(obs)                       # student, current obs only
    loss = mse(z_p, z_t) + L_action(a, action_head(z_p))
update(visual_encoder, action_head)

结果：14B 骨干下 11Hz 闭环 ｜ 来源：arXiv:2611.04527（摘要级）

W2A L1

核心：两阶段：训练期把视频模型中间去噪表征蒸进动作模型（低维子空间足够），测试期完全丢弃视频模型。LIBERO 95.9%，约 21× 加速。

Core: two stages: distill intermediate denoising representations from the video model into the action model during training (a low-dimensional subspace suffices); drop the video model entirely at test time. 95.9% on LIBERO, ~21x faster.

h_t = video_model.denoise(obs, instr, step=t)      # intermediate rep
h   = compress(h_t)                                 # low-dim subspace
loss = L_action(a, action_model(obs, h))
update(action_model, compress)                      # video model frozen

结果：LIBERO 95.9%；约 21× 加速 ｜ 来源：arXiv:2611.02600（摘要级；推理时 h 的来源待回原文核对）

ForeTime-VLA L1

核心：因果未来 token 蒸馏：当前+未来视频潜压成「白化 64-D 目标」；8 帧历史编码器在线预测它，并同时预测操作阶段与归一化 transition 时间；4 个 future token + 1 个 phase token 进 VLM 前缀，预测的未来与 horizon 条件化动作专家。

Core: causal future-token distillation: current+future video latents are compressed into a whitened 64-D target; an 8-frame history encoder predicts it online together with manipulation phase and normalized time-to-transition. Four future tokens plus one phase token condition the VLM prefix; the predicted future and horizon condition the action expert.

target = whitening(compress64D(video_latent(cur) + video_latent(fut)))
pred   = history_encoder_8frames(obs_hist)
loss = L_flow + cos(pred, target) + L_relational_geom
     + L_phase + L_T2T + L_action_equiv
prefix = concat(detach(future_token * 4), phase_token)

结果：传送带抓取 81.1%（静止）/ 58.9%（慢速）；44/90 vs pi0.5 23/90 ｜ 来源：arXiv:2608.20735（摘要级）

D. 数据 / 标签蒸馏：用大模型造监督（Data & Label Distillation）

GR00T N1 管线（含 LAPA / DreamGen / IDM） L3

核心：三条数据蒸馏同时做：①潜动作——VQ-VAE 在帧对上学习，编码器当 IDM；②神经轨迹——视频生成模型在 88h 遥操作上微调，生成 827h（10×）；③IDM 伪动作——把生成视频标成动作。后训练真机:神经轨迹 = 1:1。

Core: three data-distillation tracks: (1) latent actions — a VQ-VAE trained on frame pairs, with its encoder reused as an IDM; (2) neural trajectories — a video generator fine-tuned on 88h of teleop, producing 827h (10x); (3) IDM pseudo-actions — labeling generated video with actions. Post-training mixes real and neural trajectories 1:1.

# 1) latent action (LAPA-style)
train(VQVAE, pairs=(x_t, x_tH)); z = VQVAE.encode(x_t, x_tH)
# 2) neural trajectories
finetune(image2video, 88h teleop); gen = image2video(prompts)   # 827h
# 3) IDM pseudo actions
train(IDM, real_pairs); a_hat = IDM(x_t, x_tH)
# 4) mixed flow-matching training
loss = flow_matching(a_or_z, cond=obs, instr)

结果：88h→827h 视频；78 万仿真轨迹（6500h，11h 计算）；预训练 5 万 H100 小时 ｜ 来源：arXiv:2503.14734（L3）

E. On-policy 蒸馏：在学生的轨迹上教（On-Policy Distillation）

WAM-OPD L1

核心：闭式模仿的分布漂移问题用 on-policy 蒸馏解决：用固定轨迹池（初学生 rollout + 任务教师 rollout）重放历史，在每个决策点让当前学生重新采样去噪路径，教师在这些路径上给监督；用前缀累积分数做代理重要性权重，补偿历史分布偏移。

Core: fix the distribution shift of off-policy imitation with on-policy distillation: replay stored histories from a fixed pool (initial-student rollouts plus task-teacher rollouts), let the current student re-sample fresh denoising paths at each decision, and have the teacher supervise on those paths; prefix-accumulated scores give proxy importance weights.

pool = initial_student_rollouts + teacher_rollouts
for traj in pool:
    for t in decisions(traj):
        hist = traj.history[:t]
        path = student.denoise(hist)                # fresh path
        L_t  = KL(teacher(hist, privileged) || student(hist))
        update(student, w_t * L_t)                  # prefix weight

结果：任务适配不增加环境交互 ｜ 来源：arXiv:2609.34250（摘要级）

HINT-WAM L1

核心：学生用自己的去噪轨迹生成动作；同一模型再以「示教未来视频」为特权信息当教师；用 energy score 做分布级匹配，而不是回归速度场。

Core: the student generates its action through its own denoising trajectory; the same model conditioned on the demonstration's future video acts as the teacher; an energy score matches distributions instead of regressing the velocity field.

a_s = student.sample(obs)                           # own trajectory
p_t = student.sample(obs, cond=hindsight_video)     # teacher distribution
L   = energy_score(p_t, a_s)
update(student)

结果：无需环境奖励 / 仿真交互 ｜ 来源：arXiv:2611.24789（摘要级）

WAM-Policy L1

核心：两阶段：①跨形态适配把手臂 WAM 转到四足，并用 OPSD 蒸成「一视频+两动作步」的学生（14× 快）；②任务 RL 教师 + 多教师 M-OPD 合并多个慢专家成少步学生。

Core: two stages: (1) adapt an arm-centric WAM to a quadruped and distill the transferred policy into a student with one video and two action steps via OPSD (14x faster); (2) tune teachers with task RL, then merge slow specialists into one few-step student with multi-teacher OPD.

# stage 1: OPSD (one video, two action steps)
student = OPSD(teacher, budgets=(video=1, action=2))
# stage 2: task RL teachers -> multi-teacher OPD merge
student = M_OPD(teachers=[rl_teacher_1, ...], student)

结果：77.0→OPSD 76.7（14× 快）→85.0；Unitree Go2 真机 ｜ 来源：arXiv:2611.24011（摘要级）

级别、来源与缺口

级别：L3 = 论文方法节逐字核对（CKT-WAM、S-VAM、GR00T N1）；L2 = 部分正文（THAW-VLA）；L1 = 摘要级（其余 9 个），其代码为「按摘要重构」，模块形状/超参需回原文核对。
诚实缺口：W2A 的「推理时条件从哪来」、DIDO 的 bbox 标注要求、APM 的梯度冲突阈值、AnyStep 的调度器输入、LoopedWAM 的弹性采样策略——摘要均未给全。

实现顺序建议：先做 CKT-WAM（最接近「标准」蒸馏，接口最小改动）→ 再做 THAW-VLA（部署零开销）→ 需要少步时上 APM/AnyStep → 有视频无动作时走 GR00T 数据管线。

Suggested order: start with CKT-WAM (minimal interface change) -> THAW-VLA (zero deployment overhead) -> APM/AnyStep for few-step budgets -> GR00T data pipeline when videos lack actions.
