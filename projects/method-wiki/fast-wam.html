1. 定位

WAM（World-Action Model）联合建模未来观测与动作：p(o′, a | o, l)。训练时预测未来（视频/潜），推理时可以只出动作——既保留「想象」带来的表征，又不为生成视频付延迟。

项值
骨干Wan2.2-5B 视频 DiT（世界模型）+ 1B ActionDiT（动作专家），MoT 共享注意力
动作块H=32；未来视频帧 9（4× 降采样）
推理删未来分支，单次前向 → 32 步动作；190ms（RTX 5090D）
结果LIBERO 97.6 / RoboTwin 91.8；去掉视频共训掉到 83.8（RoboTwin）/ 10%（真机毛巾折叠）

3. 关键公式

L = L_act(a_τ, τ) + λ · L_vid(v_τ, τ)，两项都是 flow matching
L_act = ‖ v_θ(a_τ, τ, c) − (ε − a) ‖²，c = 首帧 latent + 语言 + proprio
注意力掩码：M[action, future]=−∞；M[first, others]=−∞（首帧只做条件）

物理意义：未来视频 token 只在训练时提供「世界会怎么变」的梯度；推理时不需要生成视频，所以动作模型仍能享受世界模型表征，却不背生成延迟。

4. 核心代码（带注释）

# —— 训练：联合 flow matching ——
z0 = vae(first_frame)                     # clean 条件
z_f = vae(future_frames)                  # 未来（9 帧，4× 降采样）
z_f_t = (1-τ)*z_f + τ*ε                   # 加噪：学未来速度场
a_t = (1-τ)*a + τ*ε                       # 动作同样加噪
v_vid = video_dit(z_f_t, z0, lang, proprio, mask)   # 未来 token 可见条件
v_act = action_dit(a_t, z0, lang, proprio, mask)    # 动作 token 掩掉未来
loss = mse(v_act, ε-a) + λ*mse(v_vid, ε-z_f)

# —— 推理：删掉未来分支 ——
z = video_dit.encode(z0)                  # 单次前向，不生成视频
a = sample(action_dit, cond=z, steps=K)   # 32 步动作块
execute(a)                                 # 190ms（RTX 5090D）

5. 结果与坑

  • LIBERO 97.6 / RoboTwin 91.8；去掉视频共训：RoboTwin 83.8、真机毛巾折叠 10%——证明「未来监督」不是装饰。
  • 坑：未来帧数/降采样率影响显存；动作掩码写错会「抄未来」导致推理崩；proprio 只 1 token，信息瓶颈要留意。
