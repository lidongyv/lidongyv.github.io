3. 关键公式与训练

训练：L = Σ_t ‖ a_t − π_S1(vision_t, proj(z), state_t) ‖²，梯度经 z 回传到 S2
时间偏移：训练时用 x_{t+Δ} 作为 S1 输入，Δ = 部署时 S2 推理延迟（帧）
接口：z = S2(img, state, lang) ∈ R^d（d 未公开；建议先试 256–1024）
  • 单阶段端到端：像素+文本 → 连续动作，无任务头、无 per-task 微调。
  • 数据：500h 遥操作；用 VLM 对视频做 hindsight 指令标注（"如果想让机器人做出视频里的动作，你会给什么指令？"）。
  • 35-DoF：腕位姿、手指屈伸/外展、躯干/头朝向；外加「任务完成百分比」动作（自预测终止）。

# —— 训练（单阶段端到端）——
z = s2(img_t, state_t, lang)            # 语义意图：慢、低频，但决定「做什么」

loss = mse(a, a_gt)                     # 标准回归；梯度经 z 回传，S2 也被动作监督

# —— 部署（双 GPU 异步）——
# GPU0：S2 后台，7–9Hz
shared_latent.write(s2(latest_img, state, lang))
# GPU1：S1 实时，200Hz
a = s1(vision_s1(img), proj(shared_latent.read()), state)  # 读最新意图，不追旧
robot.set_targets(a); sleep(5ms)        # 5ms = 200Hz 周期
