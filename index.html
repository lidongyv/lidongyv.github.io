    • 用 group query-based 模型统一单任务 / 多任务训练，从 multi-head 设计改为数据友好的 single-head；在 token 级别（BEV token / image token）而非 task-loss 级别做任务权重重配平。
    • 一个 query-based 模型覆盖 object detection、lane detection、occupancy network、E2E 红绿灯检测与导航模型；lane 与红绿灯升级为 navi-based static E2E，为上游决策提供强先验。
    • 两阶段预训练：从 Cosmos / VGGT 做 LLM 蒸馏（CoT、3D 几何估计、3D OD、lane、failsafe、场景识别），并做 perception model inception；支持 frozen head / frozen backbone 的可控迭代与随时加数据。
    • 基于自回归的轨迹预测：多任务 FT + CoT debugger + 多模态扩散 + RL post-training；通用世界模型用 D4RT 统一并行 AR 与 3D insight，条件注入支持语言 / layout / 轨迹。
    • AI-native 与 RaaS 转型：VLM 自动 triage、agent skills 驱动评测与仿真、仿真器 auto checker、agent 驱动的前后端开发与客服。
